# 第1786-1790章 设定分析

## 基础设定

### 世界观
- **银河世界**：故事主要舞台，包含神州大地、天宫、魔鬼海域、域外之地、魔窟、魔域等区域。
- **世界裂隙**：破坏世界完整性的存在，需修复。天宫原有六道世界裂隙。
- **世界道痕**：剑痕状裂痕，持续破坏世界。世界虽有自我修复能力，但会持续消耗银河世界力量。道痕中蕴含道的力量，可观摩悟道，被部分种族视为镇族至宝。天宫有十九道道痕，全银河世界共三百六十九道道痕。
- **神域**：神灵飞升后前往之地。距离诸神黄昏与现实施融合还有六个多月时，神灵都要飞升前往神域。
- **十年保卫战（银河保卫战）**：期间只允许凡人参战，且成神之路会断开。神灵不可出手。
- **凡殿**：林天浩创立的组织，有长老、弟子之分。凡殿拥有"绝对忠诚"规则加持。弟子令牌可使人加入凡殿受此规则约束。
- **诸神黄昏**：游戏/世界系统名，玩家称为冒险者。

### 势力与人物
- **凡殿成员**：林天浩（殿主/雪帝）、白凛风（老殿主，永恒之境，已离开银河世界）、姜子牙、申公豹、金无罪（无罪和尚，曾只差一丝成圣）。
- **邪帝君无道**：为林天浩带路寻找世界裂隙和道痕所在地。
- **青天源主**：曾预言神灵飞升时间。
- **阿来特星系**：敌对外星势力，欲进攻银河世界。
- **魔域/魔窟**：魔物聚居地。原由申公豹填压，申公豹离开后魔窟之门大开，魔物涌出。
- **魔主"残烛不年少"**：外貌为八九十岁年迈老人，实为蓝星人、冒险者身份，比林天浩早生百来年。
- **盘古一族**：曾为胖子种下魂种的永恒之境势力。

## 属性系统

### 基础属性
- **十大基础属性**：修复世界裂隙可上涨5%，修复世界道痕可上涨1%。
- **幸运值**：修复世界裂隙+50；修复世界道痕+10。
- **自由属性点**：修复世界裂隙+500万；修复世界道痕+100万；吞噬未知剑痕+1000；吞噬未知道痕+2000。
- **属性加点方向**：攻速、移速、攻击、防御、生命值等。

### 累计成果（半个月）
- 共修复世界裂隙79道（仅剩2道未修复）。
- 共修复世界道痕308道（后续增至355道，最终剩14道，总计369道）。
- 全服经验值奖励累计达37%（世界裂隙每道+5%，世界道痕每道+1%）。

### 全服通告机制
- 修复世界裂隙/道痕后可全服通告，可选择隐藏姓名（雪帝选择公开）。
- 通告效果：所有冒险者刷怪、任务等一切经验值奖励增加（裂隙+5%，道痕+1%）。

## 装备系统

### 武器
- **混沌开天锤**：林天浩的武器，配合"力之异象"使用，以力量著称，可被根须缠绕崩裂。

### 凡殿令牌
- **弟子令牌**：可使他人加入凡殿，受凡殿绝对忠诚规则加持，规则之力引动后短期内完成归属。

## 技能系统

### 圣人异象（林天浩）
- **力之异象**：以力量著称，配合混沌开天锤使用。
- **毒之异象·满堂红**：以自身为中心将天地浸染成红色，是一种特殊的【域】（有别于常规领域），无法被狂风吹散，可使根须快速枯败。
- **风之异象·泯灭风眼**：泯灭之风不狂暴，但所过之处狂风尽数湮灭，可使根须腐朽化作灰烬。
- **雷之异象·九天不灭雷尊**：召唤被雷霆缠绕的巨大虚影，引动万千神雷从天而降。
- **灵魂异象·九魂九魄镇九州**。
- **冰之异象·冰魄玄雨**。

### 其他技能
- **天罚锁头**：羽箭锁定技能，可同时锁定多个目标。
- **天道神雷**：天穹汇聚的神雷，比雷之异象强大无数倍，可威胁神灵生命。
- **吞天噬地**：可吞噬未知剑痕/道痕，获得对应道的悟性、护甲、魔抗、自由属性点等。是抹除道痕的简便方法。
- **土之道境**：可移开土坡等土系操作。
- **天道点化**：可点化NPC和冒险者，被点化者获得属性提升，林天浩获得悟性加持。点化冒险者收益递减，转而点化顶级NPC更划算。
- **加好友**：仅冒险者之间可用，可屏蔽加好友。
- **视频语音**：冒险者之间的通讯功能。

### 法则/道境系统
- **境界层次**：凡人 → 圣人 → 天道圣人 → 永恒之境。
- **法则层次**：道境 → 大道境 → 天道境。
- **道境冲击天道境**：难度倍数增加，需尽可能提升悟性。
- **相关法则**：灵魂本源法则、灵魂法则、黑暗法则等。
- **时空修炼宝塔**：可辅助修炼，林天浩当前不具备。

## 怪物系统

### 参天巨树（神灵）
- 栖息于世界裂隙之中，可化十二位绿叶长裙女子分身。
- 手段：释放根须缠绕、汇聚绿叶成巨大扇子扇动狂风（加持神力，可使林天浩站立不稳）、无穷根须破土阻挡攻击。
- 根系已蔓延至神州大地，可知晓神州之事。
- 恢复能力极强，天道神雷亦难击杀。
- 可强行飞升神域脱离战斗。
- 拒绝加入凡殿，因知凡殿绝对忠诚规则。

### 魔物（魔域）
- **整体特征**：等级高、品阶高，战斗力天然强于同等级同品阶的职业者。在神灵不出手时战力难以估量。
- **魔鬼海域魔物**：等级基本2000级以上，品阶白银起步。占据魔鬼海域周边岛屿，规模不小。
- **鳞片魔物**：浑身被漆黑如墨鳞片包裹，无脸、无鼻、无眼、无头、无指甲，每寸肌肤皆由鳞片包裹。可飞行，担任魔主使者。
- **魔主**：外貌与人类相同，看似八九十岁年迈老人，举手投足散发强大压迫感。实为蓝星人冒险者，ID"残烛不年少"。

### 魂种（盘古一族）
- **本质**：老怪物夺舍的筹码，层次最次为圣人境，种下者达永恒之境，甚至可能是天道圣人层次。
- **特性**：进入体内后消失无踪，难以探查（需经验丰富且境界高超者方能发现）。
- **爆发时间**：根据宿主灵魂力强度而定。灵魂力强则延长，弱则缩短。胖子的情况约为半年到一年爆发。
- **解决方法**：
  1. 反吞噬（需灵魂本源法则达道境，或灵魂法则达大道境；或黑暗法则达同层次）。
  2. 击杀（需找到魂种，难以实现）。
  3. 转移（需找到魂种，难以实现）。
  4. 硬拖至银河保卫战结束，请永恒之境强者出手。

## 副本系统

### 地点
- **天宫**：含六道世界裂隙、十九道道痕。
- **落日镇·醉仙楼**：林天浩情怀之地，镇外出现秘境，聚集冒险者。
- **魔鬼海域**：剩余十四道道痕所在地，魔物聚集。
- **魔窟**：魔域核心，魔主所在。内部有阴暗宫殿。

### 秘境
- 落日镇外出现秘境，吸引冒险者聚集（本章未深入秘境内容）。

## 战斗系统

### 战斗机制
- **境界压制**：高境界攻击对低境界效果显著，林天浩攻击层次高，寻常手段难以阻挡。
- **神力加持**：参天巨树狂风加持神力，可使林天浩站立不稳。
- **【域】系统**：特殊领域，有别于常规领域，如满堂红属于此类，无法被常规狂风吹散。
- **恢复类手段**：大部分恢复手段在承受攻击时会被打断或大幅削减回血。仅治愈、吸血类手段可在战斗中快速回血。
- **超级神通·黑洞（胖子）**：
  - 来源：连环任务最终奖励。
  - 效果：吞吐天地之气快速恢复，每秒最大回血量 = 等级 × 1000万。
  - 胖子等级13500+级，一秒回血约1300多亿。
  - 不受攻击打断。
  - 类似移动泉水。
- **战斗属性搭配**：胖子定位全能型战士（攻高、防高、生命值高、回血高），属性点集中加在攻速和移速。

### 圣人限制规则
- 圣人不可出手参与凡间战斗（十年保卫战期间）。
- 申公豹填魔窟后离去，导致魔窟之门大开。

## 特殊机制

### 飞升机制
- 神灵可强行飞升神域脱离战斗，飞升后无法被阻止。
- 距诸神黄昏与现实施融合还有六个多月时，所有神灵都将飞升前往神域。

### 凡殿绝对忠诚规则
- 加入凡殿者受绝对忠诚规则加持，无法背叛。
- 规则之力引动后呼吸之间完成归属。
- 参天巨树因知晓此规则而拒绝加入。

### 现实与游戏交互
- 冒险者均为蓝星人。
- 加好友、视频语音为冒险者之间独有功能。
- 魔主"残烛不年少"通过冒险者身份与林天浩建立联系，曾在现实中通过"指引"安排野心道长出现在林天浩妹妹手术室门口。

### 全服增益机制
- 林天浩修复世界裂隙/道痕后，全服冒险者获得经验值奖励加成。
- 累计加成达37%，意味升级时间减少约三分之一。
- 加成可促使冒险者用省下的时间做其他事情，间接带来更大提升。

### 点化机制
- 天道点化可作用于NPC和冒险者。
- 被点化者属性提升，林天浩获得悟性加持。
- 顶级冒险者点化收益递减，转点化顶级NPC更划算。

### 时空修炼宝塔
- 辅助修炼的特殊设施，林天浩当前不具备，影响悟道效率。
