# 第四百五十一章至第四百五十五章 设定分析

## 一、基础设定

### 1.1 圣地争霸赛设定
- **举办时间**：诸神黄昏开服两年第一次举办
- **参与者**：圣地最顶尖的强者
- **历届冠军**：第一、二届浩渺无极宫，第三届冰火洛斯岛
- **传言**：冰火洛斯岛在大灾变后接触到某位特殊存在，实力突飞猛进

### 1.2 浩渺无极宫二宫主设定
- **姓名**：修德里·浩途
- **等级**：宗师级半神
- **特点**：上位者威压，实力强大，固执，不相信林天浩能杀他

### 1.3 月轮克簇设定
- **姓名**：月轮克簇
- **等级**：宗师级九转
- **特点**：隐瞒了林天浩身边有第二尊神灵的事实

### 1.4 修德里·茉莉设定
- **姓名**：修德里·茉莉
- **等级**：铂金级，500级
- **生命值**：6152万
- **攻击**：101万
- **技能**：言出法随，清净术，复活术
- **身份**：浩渺无极宫二宫主之女，魔窟三当家

### 1.5 赤花半神设定
- **姓名**：赤花半神
- **等级**：半神
- **特点**：使用花瓣攻击，有恢复能力，曾被林天浩敲诈神级天赋觉醒石

### 1.6 洛斯井空设定
- **姓名**：洛斯井空
- **身份**：冰火洛斯岛代表
- **特点**：与月轮魔宫一同施压

### 1.7 浩渺大陆局势设定
- **现状**：各大圣地联合向凡殿施压，要求归还月轮帝国五城十镇
- **浩渺无极宫态度**：名义上是和事佬，实则偏袒月轮帝国，担心山海帝国完全复苏
- **月轮帝国态度**：要求归还领土并割地赔偿，态度强硬

### 1.8 死亡轮回设定
- **效果**：概率性击杀目标
- **限制**：面对高等级、高品阶存在时概率被压制很低，但仍有几率触发
- **案例**：修德里·浩途被死亡轮回击杀

### 1.9 复活术设定
- **效果**：复活死亡目标
- **概率**：成功概率很低
- **双重复活术**：两个复活术同时释放，概率会提高

### 1.10 神力设定
- **获取**：半神积攒神力极为不易
- **用途**：保命用，可注入复活术提高成功率

### 1.11 生命叠加设定
- **机制**：天罚之手叠加生命值，每箭叠加生命值，生死簿叠加生命值
- **速度**：一秒九箭叠加二十七点生命值，加上生死簿四点，一秒增加三十一点生命值
