# 《诸神黄昏》设定提取 - 第196-200章

## 一、基础设定

### 1.1 守护者之塔
- **效果**: 将目标笼罩其中，困住敌人
- **限制**: 蕾欧娜用冰蓝色旗帜从守护者之塔中传送走

### 1.2 冰火莲花（蕾欧娜技能）
- **效果**: 从脚底绽放，造成巨大伤害
- **伤害**: -531089，暴击-1062178

### 1.3 冰蓝色旗帜（传送道具）
- **效果**: 从守护者之塔中传送走
- **用途**: 蕾欧娜逃脱林天浩的围困

### 1.4 血战菩提前往浩渺大陆
- **奖励**: 自由属性点+200，金币+50000，无限制黄金级套装+1，本职业技能书+3
- **意义**: 龙国区第一个前往浩渺大陆的玩家

### 1.5 十大主城占领
- **过程**: 林天浩带领魔窟大军势如破竹，攻占十大主城
- **影响**: 震惊龙国区，玩家开始站队魔窟

### 1.6 天星城决战准备
- **星辰王国**: 集结五十万大军，王村长、洛林牧野等顶尖战斗力
- **魔窟**: 集结五十万夜行者大军，五位三转黄金大将军
- **玩家**: 狂战公会十万，浮屠神狼两万，普陀天龙、苏璃等

### 1.7 瀚海乾坤符（特殊道具）
- **效果**: 催动后能使所在空间，方圆千米无法进行位移，传送等，持续时间五分钟
- **类型**: 一次性道具，使用后摧毁
- **来源**: 黑袍首领，疑似海神相关

### 1.8 黑袍首领背后势力
- **身份**: 并非简单的魔窟首领，背后有神秘势力
- **对话**: 提及父亲的预言，预感浩劫降临
- **态度**: 不把林天浩当棋子，认为他可能是时代搅局者

### 1.9 国战开启
- **触发条件**: 夜行者大举进攻天星城
- **奖励**: 每击杀一位夜行者，可获得丰厚奖励
- **参与**: 狂战刀锋带领十万玩家，浮屠神狼两万玩家

### 1.10 打神鞭打破不可摧毁装备
- **过程**: 林天浩用打神鞭加持的羽箭，打碎新手木剑
- **时间**: 0.5秒百箭，1秒不到破碎
- **意义**: 不可摧毁装备并非绝对不可摧毁

- **守护者之塔**: 困住蕾欧娜，防止逃跑
