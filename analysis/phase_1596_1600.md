# 第1596-1600章 设定分析

## 基础设定

### 境界划分
- **凡人境界**：一转至九转以内（下位）
- **上位境界**：九转之上
- **神灵**：人族中的佼佼者才能达到
- **圣人**：人族中凤毛麟角的存在
- **更高境界**：天道圣人 → 永恒之境 → 道之源神（圣人之上还有数个境界）

### 种族九族体系
九族在星空中的排名（从低到高）：
1. **人族**（垫底）：成神者即为佼佼者，成圣者凤毛麟角
2. **妖族**：成年后自然而然拥有神灵级实力
3. **魔族**：实力强于妖族
4. **鬼族**：修炼奇才，只要鬼气、阴气充足，短时间内可修炼到神灵之境；神出鬼没，手段诡谲难测，魔族遇到也要避让三分
5. **修罗族**：主杀伐之道，修炼进度不如鬼族，但排名在鬼族之前
6. **灵族**
7. **古族**（上三族）
8. **天族**（上三族）
9. **地族**（上三族）

> 上三族个体强大，数量极其稀少。创造银河世界的大人没有能力引入这三族强者。

### 巨灵一族
- **巨灵一族**：成年即神灵（即"巨灵神"）
- **巨灵王族**：天生将士，成年即为伪圣，天赋好些的可直入圣人境；身高超过十二米

### 上下位划分
- **下位**：九转以内
- **上位**：九转之上

### 神灵分级（由低到高）
1. **制式神灵**：最低级，类似于鬼差
2. **香火神灵 / 神格神灵**：比一品神灵弱小
3. **一品神灵**
4. **二品神灵**
5. **三品神灵**（更高品阶依此类推）

### 品阶系统（神域与无尽星空划分）
共八个品阶：**凡、黄、玄、地、天、神、圣、源**

对应诸神黄昏品阶：
| 神域品阶 | 对应诸神黄昏品阶 |
|---------|----------------|
| 凡 | 普通、精英、黑铁 |
| 黄 | 青铜、白银、黄金 |
| 地 | 铂金、钻石、星耀 |
| 天 | 宗师、王品、皇品 |
| 神 | 帝品、神品 |
| 圣 | （神品之上，未知） |
| 源 | （未知） |

> 该品阶划分比诸神黄昏更浓缩，升品难度更高。

### 阶级系统
- 以"阶"为单位的等级体系，对应诸神黄昏的"转"
- 出现等级：七阶（七转）、九阶（九转）、十阶、十一阶、十二阶、十三阶
- 十转有特殊条件限制，比前九转更难突破
- 九阶以后可使用破境丹辅助破境

## 属性系统

### 核心属性
- **天罚攻速**：特殊攻速属性，普通天罚装备+1，天罚长弓+10
- **攻速阶段性削减**：常规攻速受阶段性削减影响
- **百分比减伤**：可对神灵级攻击生效
- **最大生命值**：基础属性
- **最大护甲**：基础属性
- **最大魔抗**：基础属性
- **移速**：基础属性
- **基础生命值**：装备百分比增幅/减损的基准值

### 基础生命值与百分比增幅机制
- **增幅逻辑**：百分比增幅只作用于基础生命值，不叠加作用
  - 例：基础生命值10000，得+50%生命装备 → 15000；再得+100%生命装备 → 15000+10000=25000（不是30000）
- **减损逻辑**：百分比减最大生命值同样作用于基础生命值
- **递减结算**：每次降低3%是在降低后的生命值上计算
  - 例：生命值100，第一次降3点（剩97），第二次降97的3%=2.91（剩94.09），而非100的3%

## 装备系统

### 天罚长弓（未知级别）
天罚弓箭手主武器。

| 字段 | 内容 |
|------|------|
| 佩戴要求 | 天罚弓箭手 |
| 效果1 | 天罚攻速+10，不受攻速阶段性削减影响 |
| 效果2 | 百分比减伤5%，对神灵级攻击依旧有效 |
| 效果3 | 能够阻挡一次致命攻击，冷却时间1小时 |
| 效果4 | 每次普攻，移速临时+1，无上限；停止攻击10分钟后，临时叠加的移速消失 |
| 效果5 | 每次普攻，天罚攻速临时+0.05，无上限；停止攻击10分钟后，临时叠加的攻速消失 |
| 效果6 | 最大生命值增加+100% |
| 效果7 | 最大护甲增加50% |
| 效果8 | 最大魔抗增加50% |
| 效果9 | 天罚落雷：普攻有1%概率降下一道落雷，必定命中，命中后永久降低对方3%最大生命值，对神灵依旧有效 |
| 耐磨度 | 不可摧毁，佩戴后不可盗取、不可掉落 |

> 对比：其他天罚装备的天罚攻速只+1，天罚长弓+10。

### 人皇幡（超神级装备）
- **外观**：似丧葬用灵伞，暗金色，上有无数细小红色符文流转
- **三大好处**：
  1. 幡里魂种绝对不会背叛
  2. 魂种可以无副作用吞噬其他同类生魂变强
  3. 魂种可以悟道（无战斗时基本都在悟道）
- **缺点**：
  - 整个人皇幡中只有九族之魂
  - 每一族只能有一个魂种
  - 无法容纳其他生灵灵魂
  - 无法存在更多魂种（更多魂种只会被同类魂种吞噬）
- **九族**：人、妖、魔、鬼、修罗、灵、古、天、地
- **藏海神僧的人皇幡现状**：仅含五族魂种（人、妖、魔、鬼、修罗），原为神灵，自碎神格后境界降至凡人，现为十转帝级

### 万魂幡（对比）
- 吸收生魂太多可能失控
- 冤魂悟道几乎不可能
- 需掌控者足够强大才能驾驭

### 货币与资源
- **下品神石**：基础神灵货币
- **上品神石**：神力更纯粹，吸收炼化更容易
  - 1枚上品神石 = 10000枚下品神石（等价兑换）
  - 1枚上品神石 ≈ 15000枚下品神石（实际价值）
- **悟道石**：增快悟道速度，对低品神灵也比较珍贵
- **香火之力**：跟随个人的力量，几乎不可转移
- **功德之力**：跟随个人的力量，几乎不可转移
- **积分**：厄难之都专用，通过成就获取，可兑换升品至宝、九阶后破境丹等

## 技能系统

### 天罚落雷（天罚长弓被动）
- 触发概率：1%（普攻触发）
- 命中方式：必定命中
- 效果：永久降低目标3%最大生命值
- 适用范围：对神灵依旧有效
- 特性：百分比生命值削减，触发频率足够快可清空血牛血条

### 天赋·天供地养（林天浩天赋）
- 一星：每秒提供1个悟道点
- 二星：每秒提供2个悟道点

### 其他技能/天赋
- **空间穿梭**（林天浩）：位移技能，对移速需求不高
- **赏善罚恶**（林天浩）：特定条件下可转移功德之力

## 怪物系统

### 巨灵王族
- 天生将士，身高超过十二米
- 成年即为伪圣，天赋好可直入圣人境
- 拥有领域（可被雷鞭破碎）
- 持有巨斧等武器

### 鬼差
- 制式神灵级别
- 九幽之地常见怪物

### 高阶阴神
- 九幽之地怪物
- 也无法抵挡厄难之都雾气诅咒

### 雷鞭（厄难之都规则之力）
- 触发条件：进入厄难之都者身高超过三米
- 第一鞭：抽在血肉上
- 第二鞭：灵魂和血肉一起抽
- 特性：无视物理防御，可破碎领域
- 强度：可抽飞巨灵王族高手

## 副本系统

### 九幽之地
- 尽头有朦胧雾气
- 雾气无法被视线和神识穿透
- 雾气有诅咒，进入会招惹灾厄
- 伤害跳变：-100、-200、-400（递增式削减最大生命值）
- 类似十殿阎罗的腐烂血肉伤害
- 高阶阴神亦无法抵挡

### 厄难之都
- **位置**：九幽之地尽头之后，五座高耸入云的山峰之间（似五指山）
- **空间属性**：多世界空间折叠门
  - 被折叠的空间，存在于阴曹地府，也可能存在于其他空间
  - 不同空间的人穿过城门后会来到同一区域
  - 离开后回到自己原本的世界
  - 类似诸神黄昏的登陆技术
- **城门规则**：进入者身高不可超过三米，否则遭雷鞭抽击
- **城内**：街道宽敞整洁，商铺打开，有人来往
- **特殊现象**：城外荒凉无人，城内却人流稀疏存在（完成空间跳转）
- **总部**：神域有厄难之都总部，可用香火之力和功德之力下注

### 弑神擂台
- **外观**：圆形建筑，外部看约二十几米高
- **内部**：空间折叠，高度超过300米
- **门户**：共23道门户
- **规则**：生死对决
- **报名**：检测境界和品阶，安排对决
- **功能**：
  - 弑神挑战（挑战制式神灵、香火/神格神灵、一品至多品神灵）
  - 观赛
  - 下注（仅收悟道石或神石）
- **赔率示例**：宇文穷（挑战者）1赔2，三品神灵1赔1.6

### 五岳秘境
- 包含心魔古城等地

## 战斗系统

### 攻速机制
- 攻速阶段性削减：常规攻速达到一定阶段会被削减
- 天罚攻速：不受阶段性削减影响

### 防御机制
- **物理防御**：可被部分攻击无视（如雷鞭）
- **百分比减伤**：可对神灵级攻击生效
- **致命攻击阻挡**：天罚长弓可阻挡一次致命攻击（CD 1小时）
- **领域**：高级强者可展开领域（巨灵王族拥有领域）

### 灵魂攻击
- 雷鞭第二鞭同时抽灵魂和血肉
- 灵魂与血肉双重伤害机制

### 百分比伤害
- 天罚落雷：永久降低3%最大生命值
- 雾气诅咒：递增式削减最大生命值

### 弑神挑战
- **凡人弑神**：在凡人之境弑神可赚取积分
- 挑战对象分级：
  - 制式神灵（最低）
  - 香火神灵 / 神格神灵
  - 一品神灵（12转挑战者已无法获得积分）
  - 二品、三品神灵等
- **生死对决**：不放水的最佳选择

### 下注系统
- 下注货币：悟道石、神石
- 总部下注货币：香火之力、功德之力
- 赔率机制：根据挑战双方实力对比设定

## 特殊机制

### 转职系统
- 十转有特殊条件限制，比前九转更难
- 不同职业十转条件不同
- 天罚弓箭手为特殊职业（需天罚长弓作为主武器）

### 升品系统
- 神域/无尽星空的品阶提升体系
- 通过积分兑换升品至宝
- 升品难度高于诸神黄昏升品

### 积分系统
- 获取方式：
  1. 上下位之战
  2. 弑神之战（凡人弑神）
  3. 各类副职业挑战
  4. 特殊至宝直接兑换
- 用途：兑换升品至宝、九阶后破境丹等

### 多世界空间折叠
- 厄难之都存在于多个空间
- 通过城门完成空间跳转
- 不同世界的人可汇聚于同一城池
- 类似诸神黄昏的跨区登陆技术

### 规则之力
- 可欺骗感官（方向感、移速感知）
- 让人在小范围内转圈却感觉在前进
- 高境界者也难以破解

### 诅咒机制
- 雾气诅咒：削减最大生命值
- 灾厄上身：纵使高阶阴神亦无法抵挡

### 神格系统
- 神灵拥有神格
- 可自碎神格降低境界（从神灵降至凡人之境）

### 悟道系统
- **悟道点**：林天浩通过天供地养天赋获取（每秒1-2个）
- **悟道石**：增快悟道速度的资源
- **魂种悟道**：人皇幡中的魂种可在无战斗时悟道

### 装备绑定机制
- 不可摧毁
- 佩戴后不可盗取
- 佩戴后不可掉落

### 封神榜
- 林天浩可收纳部下的特殊容器
- 可收纳九大幽主、藏海神僧等

### 全服通告
- 林天浩在厄难之都仍能听到全服通告
- 暗示可能存在特殊原因（非银河世界本地）

### 装备百分比叠加规则
- 百分比增幅仅作用于基础生命值
- 多件百分比装备不互相叠加作用
- 百分比减损同样遵循基础生命值规则
