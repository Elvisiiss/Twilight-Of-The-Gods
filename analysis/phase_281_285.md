## 一、基础设定

### 1.1 大灾变信息
- **来源**：首老亲口告知林天浩
- **时间**：几年后游戏与现实融合
- **性质**：史无前例的灾难，蓝星将遭遇大危机
- **各国准备**：龙国正在准备应对，其他国家也有所行动

### 1.2 灭龙斩首计划
- **发起方**：米国联合另外八个国家
- **目标**：针对龙国在游戏里的高玩，削弱龙国战斗力
- **首要目标**：雪帝（林天浩）
- **时间**：游戏两个月时启动（前世是半年后）

### 1.3 排行榜系统
- **战力榜**：诸神黄昏根据等级、天赋、装备、战绩、战斗技巧等综合排榜
- **竞技榜**：类似排位赛，随机匹配对手，排名越高奖励越多
- **开启时间**：游戏三个月后

### 1.4 神域
- **定义**：超神级转职祭坛所在地
- **进入条件**：成神以后
- **特殊物品**：超神级天赋觉醒石、超神级转职祭坛

## 二、属性系统

### 2.1 战斗力排行榜因素
| 因素 | 说明 |
|------|------|
| 等级 | 玩家当前等级 |

| 装备 | 装备品质和属性 |

| 战斗技巧 | 操作水平 |

### 2.2 水如烟属性
- **攻速**：2.1
- **职业**：超神级隐藏职业天罚弓箭手
- **特点**：受天所选，直接获得隐藏职业

### 2.3 箭术真意效果
- **品质**：真意秘本
- **效果**：领悟后提升羽箭飞行速度，圆满提升30%

## 三、装备系统

### 3.1 天罚弓箭手转职令

| 属性 | 描述 |
|------|------|
| 品质 | 超神级 |
| 使用要求 | 未转职隐藏职业的弓箭手 |
| 效果 | 手持令牌进入超神级转职祭坛，转职为天罚弓箭手 |
| 耐磨度 | 不可摧毁 |

### 3.2 诸神赐福前置任务卷轴（首老赠送）

#### 卷轴一
- **任务内容**：一个月内战力榜和竞技榜进入前十
- **惩罚**：未知
- **奖励**：诸神的赐福+1，圣品天赋觉醒石+1

#### 卷轴二
- **任务内容**：摧毁瀚海王国和幽冥之地西方余孽的阴谋
- **惩罚**：无
- **奖励**：诸神的赐福，山海帝国六品官职称号

### 3.3 独霸公会会长面具
- **特点**：面具上有神力波动
- **效果**：隐藏昵称，无法被查询ID

## 四、任务系统

### 4.1 诸神赐福前置任务（战力榜/竞技榜）
- **要求**：战力榜和竞技榜进入前十
- **时限**：一个月（从排行榜公布之日开始）
- **奖励**：诸神的赐福+1，圣品天赋觉醒石+1

### 4.2 诸神赐福前置任务（西方余孽）
- **要求**：摧毁瀚海王国和幽冥之地的阴谋
- **失败条件**：山海帝国任何一座城镇被攻下
- **奖励**：诸神的赐福，山海帝国六品官职称号

### 4.3 独霸公会清算任务
- **内容**：独霸公会每个成员最少杀十次
- **执行者**：林天浩（承诺科斯墨渊）
- **剩余目标**：独霸公会会长（神秘人）

### 4.4 进攻月轮帝国约定
- **约定者**：水如烟
- **期限**：一年内
- **奖励**：箭术真意秘本（已交付）

## 五、战斗系统

### 5.1 城镇战斗规则
- **非战斗模式**：简单肢体碰撞不会被判定攻击
- **战斗模式**：进入战斗模式后攻击会被判定
- **守卫警告**：守卫警告后仍不收手会被关禁闭（24-72小时）

### 5.2 独霸公会会长实力
- **战斗技巧**：非常强
- **面具神力**：面具上有神力波动，可隐藏身份
- **分析能力**：能够分析出林天浩的行动目的

### 5.3 落日镇守卫
- **职责**：维护城镇治安，禁止械斗
- **惩罚**：违规者关禁闭

## 七、特殊机制

### 7.1 生死簿机制
- **批量击杀**：可同时记录多个目标名字
- **持续掉血**：目标复活后仍会继续掉血
- **应用**：清算独霸公会所有成员

### 7.2 神力面具机制
- **隐藏身份**：面具上有神力波动，可隐藏昵称和ID
- **来源**：神秘，可能与神灵有关

### 7.3 超神级转职机制
- **天选者**：受天所选，直接获得超神级隐藏职业
- **普通转职**：需要进入超神级转职祭坛
- **祭坛位置**：神域或高级秘境

### 7.4 钱庄系统
- **功能**：存钱业务
- **覆盖范围**：山海帝国全国
- **投入使用**：七天内初步投入，一个月内覆盖全国
