# 第2086-2090章 设定分析

## 基础设定
### 世界背景
- 林天浩小世界：开始创造星球、生命，模拟蓝星格局
- 沙漠试炼之地：动乱墟主留下的第二关试炼场景，一望无际的沙漠，无食物水
- 神界：星界之上的更高层次世界，资源丰富但时空至宝失效
- 神界之外：试炼之地属于神界之外，规则之力凌驾于神界天道之上

### 主要势力与组织
- 骨剑仙宗：神界大宗门，派遣源宗和三尊源尊到中等世界
- 山海图势力：林天浩新创建的势力基地，容纳三十多万妥协的源神
- 动乱墟主势力：留下试炼之地的神秘存在

### 关键NPC/人物
- 塔洛菲斯小精灵：动乱墟主坐下小精灵，负责守护试炼之地，脑子不太正常
- 动乱墟主：试炼之地的创造者，神秘强大存在
- 面黄肌瘦青年：被困沙漠试炼几百年的试炼者
- 三人组：沙漠中吃人喝血的团队，存活20天
- 炼芊芊：神域源王，灵魂与世界不适配，受林天浩保护

## 属性系统
### 基础属性
- 源神境界：林天浩从半步源神突破到源神，体内磅礴力量
- 三炼之法：突破一万层，一万零一层持续提升
- 源宗：高于源尊的境界
- 源尊：高于源神的境界
- 兽神之躯：在试炼之地仍可使用，持续增强体魄
- 天供地养：在试炼之地仍可使用
- 凡人状态：试炼之地中除转生技能外其他手段几乎全无

### 称号系统
- 雪帝：林天浩在另一世界的旧称，炼芊芊对他的称呼
- 主人：妥协的源神对林天浩的尊称
- 大人：林天浩下属的尊称
- 动乱墟主：试炼之地创造者

### 品阶系统
- 境界序列：仙帝 → 半步源神 → 源神 → 源尊 → 源宗 → 源主 → 源王 → 源尊 → 源帝
- 战力品阶：林天浩源神境界，可快速击败仙界天道
- 规则之力品阶：凌驾于神界天道之上

## 装备系统
- 时空修炼宝塔：林天浩闭关核心场所
- 山海图：林天浩新炼制，可容纳上亿人，时间差30倍（参考之前设定），融入妥协的源神
- 银河世界：林天浩可打开，作为通道
- 魔法杖：塔洛菲斯小精灵的施法工具
- 蜥蜴：沙漠中唯一可食用的动物，体内有毒

## 技能系统
### 林天浩技能
- 创造星球：使用金木水火土等元素充实星球
- 创造生命：飞禽走兽肉身塑造+灵魂本源大道塑造灵魂
- 创造城市：拔地而起高楼大厦、街道、线路、线网、路灯、地铁、隧道
- 山河大地塑造：花草树木、高山、雪山、戈壁、草原、盆地、江河
- 兽神之躯：在试炼之地持续增强体魄
- 天供地养：在试炼之地仍可使用
- 天罚之手：天赋技能（待测试）
- 天罚之心：天赋技能（待测试）
- 转生技能：在试炼之地仍可使用
- 万法之躯：肉身强横
- 三炼之法：突破一万层
- 给个面子：规则之力，让神界任何一人给面子（说话、投票、收徒、承诺庇护），不能实质出手，1年冷却

### 塔洛菲斯小精灵技能
- 飞行：从虚空飞出
- 魔法杖挥动：传送能力，使人天旋地转
- 守护试炼之地

### 试炼之地机制
- 第一关考验：赚取100万+保护肉身不被摧毁
- 第二关考验：沙漠生存一年
- 灵魂拖拽：强行将灵魂拖出体外，融入虚假身体
- 复活机制：死后消失，随机复活
- 昼夜温差：夜晚寒冷难熬
- 食物限制：无食物水，蜥蜴有毒

## 怪物系统
- 蜥蜴：沙漠中唯一动物，体内有毒，食用后导致翻江倒海、肌肉酸痛、寒冷、口吐白沫
- 飞禽走兽：林天浩创造的生命

## 副本系统
- 试炼之地（动乱墟主所留）：
  - 第一关：现代化城市，赚取100万元下线，怪物攻击肉身
  - 第二关：沙漠求生，活够一年时间出去
  - 规则之力奖励：三选一，凌驾于神界天道之上
  - 试炼者：通过第一关的人，困在第二关几百年
  - 不成文规定：任何接近过关者都会被群起攻之
- 林天浩小世界：林天浩创造的"蓝星"，有大陆、城市、生命
- 山海图：林天浩下属源神修炼场所

## 战斗系统
- 源神境界战力：林天浩源神境界可快速击败仙界天道
- 越级限制：源神境界仍难对抗源尊
- 体魄对抗：兽神之躯增强体魄，一拳打退凡人数步
- 凡人状态战斗：试炼之地中体魄相近，但林天浩有兽神之躯加持
- 三人组战术：挑选小菜鸟下手吃肉喝血

## 特殊机制
- 创造星球机制：掌握足够多的道，可徒手捏出星球
- 创造生命机制：肉身塑造+灵魂本源大道塑造灵魂
- 山海图融入机制：签订主仆契约后融入，修炼时间大幅降低
- 妥协率机制：几百万人中不到百分之十妥协，约三十多万人
- 时空至宝失效：到达神界后中等世界时空至宝失效
- 突破源神条件：吞噬世界之心+三炼之法提升
- 试炼之地规则之力三选一：
  1. 无道：方圆千米无道空间，击杀源神以上扩大范围，无冷却无消耗，对自己也有效
  2. 给个面子：让神界任何一人给面子，仅限说话投票收徒承诺庇护，不能实质出手，1年冷却
  3. 妇女之友（妇幼之友）：生过孩子的女人必有好感，不下杀手，无冷却无消耗，仅神界有效
- 灵魂拖拽机制：神鬼莫测，源王都无法抗衡，灵魂被强行融入虚假身体
- 复活机制：试炼之地死后消失，随机复活
- 不成文规定：接近过关者被群起攻之
- 蜥蜴毒素机制：食用后翻江倒海、肌肉酸痛、寒冷、口吐白沫，体魄增强后可抗住
- 第二次吃蜥蜴：明显要好很多
- 神界创造论：神界可能被某位不可知大能创造
- 源帝限制：源帝之上可能存在更不可知存在
- 规则之力限制：仅在神界有用，对塔洛菲斯小精灵无效
- 试炼之地归属：属于神界之外
- 银河世界炼金石：目的让林天浩变强，成为双本源世界永恒强者
- 阿来特星系变数：原本顺理成章，因变数导致林天浩来到这里
