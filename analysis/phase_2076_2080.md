# 第2076-2080章 设定分析

## 基础设定
### 世界背景
- 不枉星/不枉城：星界大本营所在地，星盟总部所在，城主府是核心
- 魔域：与星界并列的区域
- 神界之外：广袤星空，大多没有思考能力，但并非全部
- 林天浩小世界：仅一块大陆，连星球都没有形成

### 主要势力与组织
- 星盟：星界第一势力，长老团决策，半步源神级长老，做事守规矩
- 魔族：强取豪夺之辈，非善男信女，不会正常交易
- 星盟长老团：星盟决策机构

### 关键NPC/人物
- 老大爷：被困城市的原源主，被困三百多年
- 黑影怪物：约二十岁青年，仙皇境界，被不详侵蚀或神界之外存在，无法沟通
- 吴管家：星盟城主府管家，仙皇初期，妖族，妖气
- 吴长老：星盟长老，半步源神（半步仙祖），吴管家之父，妖力雄浑

## 属性系统
### 基础属性
- 万法之躯：林天浩身躯特性，对万法都有抗性，对万法悟性越高，抗性越高
- 先天道胎：极其珍贵的体魄，林天浩可随手捏造，修炼天赋极高
- 源王：高于源主的境界（源主之上）
- 半步源神 = 半步仙祖（中等世界称谓）
- 仙皇境界：怪物无法说话，疑似被不详侵蚀或神界之外

### 称号系统
- 韩飞羽：林天浩在星盟所用化名
- 前辈：被困者对林天浩的尊称

### 品阶系统
- 境界序列：仙皇初期 → 仙皇 → 仙帝 → 半步源神 → 源神 → 源主 → 源王 → 源尊 → 源帝
- 战力品阶：林天浩肉身可挡仙祖级攻击
- 宝物品阶：时空修炼至宝（极其珍贵，星盟都掂量）

## 装备系统
- 时空修炼宝塔：林天浩所有，内三年=外三天（约365倍时间差），可分身观察外部
- 时空修炼手镯：林天浩炼制，容纳千人，10倍时间差
- 山河图：林天浩炼制
  - 容纳一亿人
  - 30倍时间差
  - 原计划容纳十亿人，为保证时间差降至一亿
  - 内部空间越大，时间差越难提升
- 钞票：被困城市中的货币，100万钞票可获下线选项
- 玉符：通讯工具
- 悟道茶：星盟招待贵客的茶
- 世界之心：战略物资，可稳定培育仙帝

## 技能系统
### 林天浩技能
- 万法之躯：对万法有抗性，可抵挡黑气侵蚀、电锯切割、利爪攻击
- 转生技能：可动用转生能力离开险境
- 重塑肉身：使用本源世界之力+生命大道之力+灵魂大道之力+各种大道之力塑造肉身
- 一口气塑造千具肉身：可同时重塑大量肉身
- 掐诀分化分身：可操控分身探路
- 时空本源之力：时间和空间两种本源之力在周身流淌
- 主仆契约：奴役他人的核心契约
- 注入规则本原之力：在肉身中留后手
- 叶墟魔功：结合控制他人

### 怪物技能
- 黑气侵蚀：可摧毁肉身和小世界
- 利爪攻击：金铁交鸣
- 电锯攻击：可发出刺耳轰鸣

### 秘术/术法
- 受罚万载：林天浩的惩罚手段
- 炼制成傀儡：林天浩的威胁手段
- 替身术：可留下替身逃脱

## 怪物系统
- 黑影怪物：仙皇境界，约二十岁青年模样，面色铁青，眼神凶厉，口中发出低沉嘶吼
- 不详侵蚀怪物：可能仍可简单沟通
- 神界之外生物：大多没有思考能力

## 副本系统
- 现代化城市副本（源主秘境内部）：
  - 困人机制：意识脱离肉身，肉身在外
  - 离开条件：100万钞票获得下线选项（肉身被毁后选项灰色）
  - 死亡机制：死后以婴儿身份重生
  - 自杀惩罚：下一个家庭越来越差
  - 力量压制：无法调动体内力量
  - 提示面板：叮，是否消耗一百万钞票下线
  - 进入50米后意识被剥夺
  - 困住几百万曾经的源神和源主
  - 城市自成一方微型世界

## 战斗系统
- 万法之躯抗性：可抵挡各种侵蚀和物理攻击
- 空间禁锢：林天浩可定住仙皇级怪物
- 神念检查记忆：可探查他人记忆，但若有记忆枷锁则可能崩碎
- 越级压制：半步仙祖可瞬间定住仙皇级怪物

## 特殊机制
- 万法之躯机制：对万法悟性越高，对万法抗性越高
- 先天道胎：林天浩随手可造，修炼天赋极高
- 重塑肉身机制：林天浩可使用多种大道之力塑造肉身，一次可造千具
- 主仆契约+规则本源之力：双重控制手段
- 时空宝物炼制：林天浩可炼制时空修炼宝物
  - 内部空间越大，时间差越难提升
  - 容纳千人，10倍时间差（手镯）
  - 容纳一亿人，30倍时间差（山河图）
  - 容纳十亿人原计划失败
- 时空修炼宝塔：内三年=外三天（约365倍）
- 世界之心：战略物资，可稳定培育仙帝
- 魔族特性：强取豪夺，不会正常交易
- 星盟特性：守规矩，正常交易
- 一人双世界/一体三世界理论：林天浩的猜测
- 时间长河多元论：不同时间长河时间节点不同
- 提示面板：被困者可见，叮声提示
- 钞票系统：城市内货币，100万可获下线选项
- 婴儿重生机制：被困者死后以婴儿身份重生
- 自杀惩罚：自杀后下一个家庭越来越差
- 意识脱离肉身：肉身被毁后无法离开
- 万法之躯+三炼之法：双重防御，无视仙皇级攻击
- 转生技能：林天浩可动用转生能力离开险境
- 几百万源神/源主：被困者总量
- 源王背景：部分被困者背后有源王坐镇势力
