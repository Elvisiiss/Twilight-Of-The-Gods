# 第2111-2115章 设定分析

## 基础设定

### 世界背景

- **第三关·大禹王朝·陌雪领**：林天浩离开北罔城，接管边关诸侯领地陌雪领，开始建立正规军。
- **陌雪领结构**：三座城池（核心陌雪城），领地面积大，挨着北莽山脉；山脉是屏障也是险地；领地居民少，可种植粮食区域少。
- **大禹王朝分封制**：800+诸侯，常年阳奉阴违不纳税；朝廷想收拾诸侯又怕得罪；边关领地战乱不断。
- **野蛮子（北莽王朝）威胁**：骑蛮牛冲锋，甲胄可防御羽箭；不断进攻边关领地；有万夫长指挥。
- **蜕凡机制（延续）**：林天浩以凡人角度从乞丐到领主，心境持续提升。

### 主要势力与组织

- **陌雪领**：林天浩接管的领地；原领主独孤陌雪；三座城池；八千军人（接管时）；一百八十万百姓；挨着北莽山脉。
- **野蛮子（北莽王朝军队）**：骑蛮牛冲锋；有万夫长耶利泽鸿指挥；甲胄防御羽箭；不断骚扰边关。
- **神武司**：大禹王朝武道机构；有武道大宗师坐镇；可指点修炼；武功秘籍无数；招募武道天才。
- **五峰领**：陌雪领邻居；五座大山天然屏障；守几个峡谷可阻止野蛮子；领主福君笑；最近被野蛮子猛攻，强弩之末。
- **大禹王朝朝廷**：800+诸侯；想收拾诸侯但不敢真得罪；与野蛮子有高手博弈。
- **北莽王朝**：大禹敌对王朝；有武道宗师坐镇重要地方；野蛮子即其军队。

### 关键NPC/人物

- **林天浩**：接管陌雪领成为新领主；一流武夫展示箭术击杀两千野蛮子；与独孤陌雪结拜为兄弟；三月突破武道宗师。
- **独孤陌雪**：原陌雪领领主，年近五十中年人；二流巅峰武夫；管理陌雪领五年；与林天浩结拜为异姓兄弟（林天浩为大哥）；被林天浩留任管理三座城池。
- **王五**：陌雪领流民，被林天浩善意打动；劝说其他流民回陌雪城参军；代表百姓视角。
- **熊福**：胡子拉碴中年人，王五流民伙伴；愿意回陌雪城参军保卫家乡。
- **耶利泽鸿**：野蛮子万夫长；指挥进攻陌雪城；被林天浩箭术重创后撤退；欲吞并陌雪领立大功。
- **王三烈**：神武司使者，火拳；火红色长发中年壮汉；一流巅峰武夫/半步宗师；来陌雪领招募林天浩加入神武司；明示威胁野蛮子会派高手杀林天浩。
- **福君笑**：五峰领领主；带武功秘籍"笑傲山林"求林天浩庇护三年；被林天浩拒绝。

## 属性系统

### 基础属性

- **林天浩武道境界进阶**：一流武夫（接管陌雪领时） → 三月后武道宗师。
- **独孤陌雪境界**：二流巅峰武夫。
- **王三烈境界**：一流巅峰武夫/半步宗师。
- **耶利泽鸿**：万夫长，未展示武道境界，但能指挥军队。
- **陌雪领军民比例**：180万百姓，8000军人（接管时） → 三月后15000军人+185万百姓。
- **林天浩箭术**：连珠箭法+五箭齐射；远距离精准击杀；一人成军；一人击溃野蛮子全军。
- **林天浩击杀数**：首战击杀2000野蛮子（一人）。

### 称号系统

- **"领主大人"**：林天浩接管陌雪领后的称呼。
- **"大哥"**：独孤陌雪对林天浩的称呼（结拜后）。
- **"二弟"**：林天浩对独孤陌雪的称呼（结拜后）。
- **"火拳"**：王三烈的称号。
- **"万夫长大人"**：耶利泽鸿的军职称呼。
- **"万岁"**：陌雪领军民对林天浩的狂热崇拜呼喊。

### 品阶系统

- **武道境界体系（完整）**：三流 → 二流 → 一流 → 武道宗师 → 武道大宗师 → 武道神话/陆地神仙（传说中的至高境界）。
- **武夫等级对应**：
  - 三流：普通武夫
  - 二流：中等武夫
  - 一流：高等武夫（独孤陌雪二流巅峰，林天浩一流，王三烈一流巅峰/半步宗师）
  - 武道宗师：宗师级（林天浩三月突破，独孤问剑诀可修至此）
  - 武道大宗师：大宗师级（神武司有坐镇）
  - 武道神话/陆地神仙：传说境界（独孤问剑诀可问鼎）
- **万夫长**：野蛮子军队军职（耶利泽鸿）。
- **千夫长/百夫长**：野蛮子军职体系。
- **诸侯领地规模品阶**：
  - 三座城池：中等水平（陌雪领）
  - 五座大山：五峰领
  - 30万大军：北山王府（顶级）
- **武夫天赋品阶**：年轻一流武夫骇人听闻（独孤陌雪评价林天浩）。

## 装备系统

- **霸王弓**：林天浩的武器（前文打造），用于守城射杀野蛮子。
- **羽箭**：林天浩的弹药，可连珠射、五箭齐射。
- **独孤问剑诀**：独孤家祖传剑法秘籍，可修炼至武道宗师，甚至问鼎武道神话/陆地神仙；对剑道理解要求极高；只有独孤家的人可修炼（结拜可绕过）。
- **笑傲山林**：五峰领福家祖传身法秘籍；修炼到圆满，身法速度超出自身一个大境界；福家老祖曾凭此以武道宗师境界从两位武道大宗师手中逃脱。
- **蛮牛**：野蛮子骑乘的大型坐骑，体型庞大，可被缴获（235头）。
- **武器装备（缴获）**：1555套（首战缴获）。
- **天星诀（普及）**：林天浩将天星诀普及给士兵，大部分修炼出一点内力，体魄得到滋养提升。

## 技能系统

### 林天浩箭术（深化）

- **连珠箭法**：连续射出羽箭，手速极快，看呆武将。
- **五箭齐射**：一次出手五个野蛮子被击杀；准度恐怖。
- **远距离精准击杀**：射程远超其他弓箭手，野蛮子无法反击。
- **移动炮台**：一流武夫中的弓箭手，战场上移动炮台。
- **战绩**：一人击杀2000野蛮子，一人成军击溃敌军。

### 独孤问剑诀（独孤家秘籍）

- **品阶**：可修炼至武道宗师，甚至问鼎武道神话/陆地神仙。
- **修炼要求**：对剑道有很深的理解；只有独孤家的人才能够修炼。
- **外传后果**：严重（但独孤家已没落，最多良心谴责）。
- **绕过限制**：与独孤家之人结拜为异姓兄弟，算是独孤家一份子。
- **林天浩修炼速度**：如鱼得水，三月从一流武夫到武道宗师；得益于林天浩之前剑道层次极高。
- **修炼成果**：周身剑气肆虐。

### 笑傲山林（福家身法）

- **品阶**：身法秘籍，修炼到圆满速度超出自身一个大境界。
- **战绩**：福家老祖以武道宗师境界从两位武道大宗师手中逃脱。
- **限制**：修炼难度非常大；神武司已收录此功法；福家只有修炼要诀。

### 天星诀（普及版）

- **普及效果**：大部分士兵修炼出一点内力，体魄得到滋养提升；虽连三流都算不上，但有内力滋养肉身。
- **限制**：只能够修炼到一流武夫境界。

### 林天浩战略技能（深化）

- **结拜稳固人心**：与独孤陌雪结拜为异姓兄弟，让陌雪领军民对林天浩认同度大幅提升。
- **边防军建设**：将山贼打散编入正规军，发挥其山林经验；建立北莽山脉防线。
- **流民开垦体系**：安排流民进山开垦种菜；吸引流民定居形成小镇；边防军保护免受豺狼虎豹攻击。
- **商业大本营转移**：将北罔城商业大本营搬迁至陌雪领；增加税银收入。
- **以战立威**：首战击溃野蛮子，立威稳固统治，百姓回流。

## 怪物系统

（本阶段为凡人世界，无超自然怪物，但有野兽提及）

- **北莽山脉野兽**：豺狼虎豹等，开垦过度会引来；边防军可保护流民开垦。
- **蛮牛**：野蛮子骑乘的大型坐骑，体型庞大；被缴获后可分食（上百口大锅炖肉）。

## 副本系统

- **第三关·乞丐到皇帝副本（继续）**：
  - 第二根据地：陌雪领（三座城池+北莽山脉防线）
  - 武装建设：8000军人 → 15000军人（三月后）；山贼编入正规军；天星诀普及
  - 商业布局：大本营搬迁至陌雪领；商贩来往税银增加
  - 阶段性目标：稳固陌雪领，击退野蛮子，建立北莽山脉防线
  - 林天浩境界提升：一流武夫 → 武道宗师（三月）
  - 新挑战：朝廷神武司来人（王三烈）；野蛮子可能派高手暗杀；五峰领求援

## 战斗系统

### 林天浩 vs 野蛮子攻城（首战）

- **过程**：
  - 野蛮子骑蛮牛冲锋，趴在牛背防羽箭
  - 林天浩手持霸王弓，连珠箭法精准击杀
  - 切换五箭齐射，一次五个野蛮子被击杀
  - 短时间击杀上百野蛮子，武将瞠目结舌
  - 野蛮子撤退，林天浩追击阻止带走尸体
  - 林天浩追击再射杀几百野蛮子
- **结果**：首战大捷，不费一兵一卒；缴获1555套武器装备、235头蛮牛；击杀2000野蛮子。
- **军民反应**：城卫军狂热崇拜，呼喊"领主大人万岁"；百姓热泪盈眶；流民王五、熊福决定参军。

### 野蛮子vs陌雪领（背景）

- **历史**：野蛮子跟陌雪城交手数年，陌雪城强弩之末。
- **野蛮子战术**：夜袭陌雪城；带走尸体避免被林天浩点名。
- **耶利泽鸿反应**：脸色铁青撤退，欲通过密探了解情况；副将猜测是独孤陌雪求来的援军。

## 特殊机制

### 诸侯领地机制

- **领主责任**：带兵防守敌国进攻；战死沙场是牺牲；逃跑是逃兵诛九族。
- **领地接替**：领主扛不住可找替罪羊接替；有底蕴的大家族大势力不愿接手。
- **朝廷态度**：分封出去后朝廷基本不管；800+诸侯阳奉阴违不纳税；朝廷想收拾诸侯又怕得罪。
- **陌雪领特殊情况**：三座城池，领地大居民少，挨着北莽山脉；自身情况不太妙；多次求助卸任无人接。

### 武道境界机制（完整）

- **境界体系**：三流 → 二流 → 一流 → 武道宗师 → 武道大宗师 → 武道神话/陆地神仙。
- **武道神话**：传说中的至高境界，可问鼎（独孤问剑诀上限）。
- **武道大宗师**：神武司有坐镇，可指点修炼。
- **武道宗师**：宗师级，独孤问剑诀可修至；三月从一流武夫到武道宗师（林天浩，骇人听闻）。
- **境界与剑道关联**：林天浩因之前剑道层次极高，修炼独孤问剑诀如鱼得水。
- **境界与功法关联**：天星诀只能到一流武夫；独孤问剑诀可到武道神话/陆地神仙。

### 神武司机制

- **机构性质**：大禹王朝武道机构。
- **资源**：武功秘籍无数；有武道大宗师坐镇可指点修炼。
- **招募对象**：武道天才（如林天浩）。
- **招募话术**：加入神武司可成就武道宗师甚至武道大宗师。
- **博弈机制**：神武司与大禹那边的高手有博弈，博弈期间林天浩安全；博弈结束林天浩不安全。
- **威胁机制**：王三烈明示威胁，野蛮子会派高手杀林天浩。

### 野蛮子暗杀机制

- **触发条件**：林天浩一人击杀2000野蛮子，对战局影响太大。
- **暗杀者境界**：大概率半步宗师（类似王三烈）。
- **武道宗师限制**：野蛮子武道宗师不轻易出手，需坐镇更重要地方；大禹武道宗师可出手搞破坏杀伤力恐怖。
- **安全期**：神武司与野蛮子高手博弈期间林天浩安全；博弈结束不安全。
- **结果**：林天浩等了三个月野蛮子未派高手；实际威胁其他领地。

### 独孤问剑诀传承机制

- **传承限制**：只有独孤家的人才能够修炼；外传后果严重。
- **绕过方法**：与独孤家之人结拜为异姓兄弟，算是独孤家一份子。
- **独孤家没落**：外传后果最多是良心上的谴责。
- **修炼天赋要求**：对剑道有很深的理解；天赋要求高得吓人。
- **林天浩优势**：之前剑道层次极高，修炼如鱼得水。

### 北莽山脉防线机制

- **防线结构**：山贼建立的山寨形成防线；林天浩将山贼编入边防军打散管理。
- **山贼优势**：了解北莽山脉，山林生活建设经验丰富。
- **流民开垦**：边防军保护下流民进山开垦种菜；形成小镇；开辟山路。
- **屏障作用**：天然屏障防御野蛮子。

### 陌雪领发展机制

- **军民比例**：180万百姓+8000军人（接管时） → 185万百姓+15000军人（三月后）。
- **人口增长**：三月增长5万人，边关城市恐怖速度。
- **税银增长**：商业环境变好，商贩来往密集，税银收入上去。
- **自给率**：陌雪领自身产业+林天浩补贴，林天浩补贴银两需求大幅降低。
- **军队扩招**：首战胜后招兵踊跃，扩招2000人；三月后达15000人。
- **天星诀普及**：大部分士兵修炼出一点内力，体魄得到滋养提升。

### 五峰领求援机制

- **地理位置**：陌雪领邻居，五座大山天然屏障，守几个峡谷可阻止野蛮子。
- **困境**：林天浩击溃陌雪领野蛮子后，野蛮子更卖力攻打五峰领，强弩之末。
- **求援代价**：福君笑献上笑傲山林身法秘籍，求林天浩庇护三年。
- **林天浩拒绝原因**：
  - 神武司已收录笑傲山林
  - 福家不是铁桶一块
  - 修炼难度非常大
  - 一部功法换三年庇护太轻
- **战略威胁**：五峰领被破后野蛮子可夹击陌雪领。

### 林天浩蜕凡机制（继续）

- **心境提升**：在第三关中以凡人角度谋求发展，心境持续提升。
- **境界突破**：三月从一流武夫到武道宗师，速度骇人听闻。
- **兽神之躯加成**：兽神之躯增强体魄+不灭兽魂增强灵魂，身体强度恐怖。
- **剑道关联**：之前剑道层次极高，修炼独孤问剑诀如鱼得水。
