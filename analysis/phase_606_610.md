# 第六百零六章至第六百一十章 设定分析

## 一、基础设定

### 1.1 修德里·白芸融合妖魔祖奎力量设定
- **状态**：完全融合妖魔祖奎的力量，举手投足间睥睨天下
- **实力**：不是神灵，却有接近神灵的战斗力和高阶神灵的防御手段
- **特点**：正常战斗，神灵不爆发打不过她，爆发会被雷罚攻击，完克神灵
- **生命值**：不如囚海死女，但也极其庞大（林天浩秒伤百分之四左右无法击杀）
- **吸血能力**：一秒吸血量毫不逊色，甚至溢出

### 1.2 浩渺无极宫神灵设定
- **数量**：九尊可以出战的神灵
- **状态**：之前的接连战斗让浩渺无极宫底蕴受到不小冲击，还能凑出九尊已属难能可贵
- **态度**：跟随修德里·白芸主动出击凡殿

### 1.3 决战凡殿设定
- **参战方**：凡殿（林天浩+十二尊被雷罚后复活的神灵）vs 浩渺无极宫（修德里·白芸+九尊神灵）
- **地点**：凡殿中央广场
- **氛围**：肃然，超过二十尊神灵对峙，寻常七转八转职业者抬不起头

### 1.4 林天浩战斗策略设定
- **三尊神灵牵制**：派遣三尊神灵拖住修德里·白芸数秒
- **天罚输出**：开启三头六臂和天罚，一秒三十箭，每箭附带本源灼烧伤害
- **死亡轮回**：利用幸运属性和幸运硬币，赌死亡轮回触发概率
- **封神榜轮换**：神灵被雷罚重创后收入封神榜，派遣新神灵继续战斗

### 1.5 死亡轮回触发设定
- **时间**：战斗打响五分钟左右
- **代价**：三尊神灵爆发被雷罚重创
- **效果**：修德里·白芸血条瞬间清空，被击杀
- **全服通告**：恭喜玩家雪帝成功击杀修德里·白芸

### 1.6 浩渺无极宫尘封设定
- **条件**：放浩渺无极宫九尊神灵安全离开，同意浩渺帝国和浩渺无极宫尘封
- **奖励**：天罚戒指
- **过程**：浩渺无极宫和浩渺帝国所有建筑开始下沉，全服通告告知玩家
- **原因**：神域强者定下的规矩，以尘封为代价的点到为止

### 1.7 神域设定
- **位置**：神州大地之上
- **主宰**：真正主宰一切的是神域的强者，浩渺大陆的圣地和神灵只是遗留在这方世界的棋子
- **规矩**：以尘封为代价的点到为止是神域强者定下的规矩，破坏会引来神域强者

### 1.8 山海帝国复苏奖励设定
- **技能**：回归（不可升星，仅限雪帝，可在诸神黄昏范围内立即回归凡殿，不可阻挡）
- **气运**：山海帝国气运+10
- **幸运**：个人幸运+20
- **自由属性点**：+100000

### 1.9 天罚戒指属性设定
- **佩戴要求**：天罚弓箭手
- **效果1**：天罚攻速+1，不受攻速阶段性削减影响
- **效果2**：百分比减伤5%，对神灵级攻击依旧有效
- **效果3**：能够阻挡一次致命攻击，冷却时间一小时
- **效果4**：幸运+10
- **效果5**：心境通明，悟道速度+10倍
- **效果6**：最大生命值增加50%
- **效果7**：最大护甲增加50%
- **效果8**：最大魔抗增加50%
- **效果9**：绝对迟缓（主动释放，可让目标单位接下来三秒移速下降90%，攻速下降90%，绝对成立，神灵同样会被迟缓，冷却时间一个小时）

### 1.10 希图帝国全民副本设定
- **原因**：希图帝国自甘堕落，沦为妖魔乐园
- **公告**：全服通告，希图帝国化为全民副本，所有冒险者都可以进入猎杀妖魔，击杀获得双倍奖励
- **状态**：整个希图帝国被血光笼罩，大地出现裂纹，血光从裂纹中弥漫出来
- **限制**：未知，可能有限制神灵级强者出手的规则

## 二、属性系统

### 2.1 林天浩属性
- **类型**：玩家，凡殿之主，天罚弓箭手三转
- **生命值**：突破三十六亿大关（佩戴天罚戒指和天罚护心镜后，基础生命值+100%）
- **攻速**：九十（基础），天罚攻速12.15（佩戴天罚戒指和天罚护心镜后，消耗十万自由属性点提升）
- **天罚伤害**：突破六亿/箭（双倍增伤+银河战神20%增伤，暴击突破100%）
- **天罚之手**：四星进化后（每次普攻造成自身4%生命值真实伤害，每次普攻永久提升4点生命值，每次普攻恢复自身4%生命值）
- **技能**：三头六臂、天罚、生死簿、玄冰之翼、火眼金睛、十七种弑神者印记能力、凝水分身、七十二变、伤害转移、霸体、回归、箭由心发
- **等级**：一百级（三转后可继续升级）
- **剑道法则**：第五层
- **新属性**：幸运+60（六福神灵能力），悟道速度+100倍（问心悟道），剑道理解提升100倍（无上剑心）
- **自由属性点**：十万（山海帝国复苏奖励，全部转化为天罚攻速）

### 2.2 修德里·白芸属性（融合妖魔祖奎后）
- **类型**：NPC，浩渺无极宫成员
- **品阶**：皇级
- **力量**：超越诸神黄昏允许的极限力量，丝毫不输神灵甚至更强
- **防御**：血色光盾可挡住体修神灵攻击
- **吸血能力**：一秒吸血量毫不逊色，甚至溢出
- **结局**：被林天浩死亡轮回击杀

### 2.3 浩渺无极宫九尊神灵属性
- **类型**：NPC，浩渺无极宫神灵
- **实力**：可出战的神灵，实力强大
- **态度**：跟随修德里·白芸主动出击凡殿，后选择尘封

### 2.4 铂烟神灵属性
- **类型**：NPC，浩渺无极宫高挑女性神灵
- **态度**：提出浩渺无极宫尘封，以天罚戒指换取安全离开
- **目的**：避免被林天浩击杀送上封神榜

### 2.5 弑神者印记新增能力属性
- **第16，枯冤神灵（与佛有缘）**：加入佛门可获得诸神赐福，最少一个
- **第17，百屠神灵（百屠增强）**：每连续击杀一百个同等级生灵，伤害提升10%，最高可提升100%
- **第18，峥木神灵（木系转移）**：将木系植物的生命力转移到其他生命体上，可治愈无法自主恢复的伤势
- **第19，六福神灵（来福）**：幸运属性+60
- **第20，悲天神灵（悲天）**：用力量感化众生，调动众生悲伤的情绪
- **第21，问心神灵（问心悟道）**：大幅度提升悟道速度，心境越佳提升越大，最大100倍
- **第22，北冰神灵（无限冰爆）**：在有冰的情况下，操控冰块爆炸造成伤害
- **第23，火狼神灵（嗜血狼化）**：变身狼人形态，进入近战模式，吸血提升30%
- **第24，墨刀神灵（战意滔天）**：强行提升战斗意志，驱散负面效果，增强10%战力
- **第25，蓝熊神灵（天空之子）**：自由在天空中行走奔跑
- **第26，青衫剑神（无上剑心）**：对剑道的理解提升100倍，剑道手段威力提升10倍
- **第27，滥食神灵（无限滥食）**：通过吃东西提升自由属性点，食物能量越多获得越多
