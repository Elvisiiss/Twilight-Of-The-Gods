# 第1366-1370章 设定分析

## 基础设定

### 世界观与势力分布
- **诸神黄昏**：当前游戏主世界，在神灵之上的存在眼中被视为"稍大的副本"
- **神州大地**：原本属于神域，神域曾爆发过一场旷世之战，被打得分崩离析；一些小的世界碎片被绝世大能收集起来，炼制成自己的小世界，其上有些东西连神灵之上的存在都会眼红
- **蛮荒神朝**：过去的势力，至本章时已"连根基都没有"
- **域外之地**：与神域、蛮荒古地等并存的不同区域，存在不同于一个时代的生灵

### 主要势力
- **三清门下**：太上老君、元始天尊一脉（神灵气息）
- **凡殿**：林天浩为当代殿主，"顺为凡，逆为仙"，被高大虚影评价为"不行"；设有贡献值兑换体系
- **南蛮圣宗**：宗主曾与坤天城主结盟
- **百里书院**：院长知晓九幽、天宫相关情报
- **寒楼**：楼主为林天浩的人
- **阴阳合欢宗**：宗主为林天浩的人
- **修罗公会**：修罗奕泽为首，对抗阿来特星系
- **坤天城**：表面为城池，实为"城镇类怪物"

### 时代规则
- **圣人不能出手**：当前时代的限制规则
- **神灵不出手**：除大帝之境走得较远者（如罗天之主）、十转/十一转隐世大能外，能与林天浩抗衡者不多

### 境界体系（凡人→神灵→圣人→神灵之上）
- **凡人境**：宗师（含大圆满）→大宗师→王级→皇级→帝级
- **神灵境**：一品神灵→神王→神皇→神帝
- **圣人**：寿元以"纪元"计算
- **神灵之上**：如坤天城下高大虚影、心魔古城苍穹之上那位

### 转数系统
- 转数层级：九转、十转、十一转、十二转、十三转（传说级）
- 两千级为七转门槛

## 属性系统

### 寿元系统（核心新增设定）
| 境界 | 寿元 |
|------|------|
| 王级凡人 | 突破万年 |
| 皇级凡人 | 更久（高于王级） |
| 帝级凡人 | 可达十万年 |
| 一品神灵（刚成神） | 超过两万年 |
| 圣人（正常） | 60-80纪元 |
| 圣人（部分） | 突破100纪元，甚至120纪元 |

- **纪元换算**：1纪元 = 12万9千6百年
- **永生**：仅存在于传说，任何人都无法做到真正意义上的永生（圣人亦不行）
- **寿元影响因素**：功法、道、自身境界
- 成神 ≠ 长生不老（与神话传说不同）

### 其他属性/数值
- **自由属性点**：任务奖励可得（本章奖励+50000）
- **生命值**：道卷宝策可+1亿
- **贡献值**：凡殿兑换货币
- **神灵赐福**：可叠加多种（林天浩身上有神灵赐福及神灵之上的赐福）
- **神魂本源**：可交出供强者驱使（为奴契约形式）

## 装备系统

### 道卷宝策（特殊装备）
- **佩戴要求**：无
- **效果1**：悟道速度+200%
- **效果2**：生命值+1亿
- **耐磨度**：100
- **出处**：第1368章（坤天城主任务奖励，共获+10）

### 寿元神币（未知品阶）
- **使用要求**：无
- **效果1**：每佩戴一年，可增加一个月寿元
- **效果2**：直接食用，可获得一千年寿元
- **耐磨度**：不可摧毁
- **出处**：第1368章（任务奖励+1，推测比鸿蒙炼丹师转职卷轴残卷更珍贵）

### 鸿蒙丹方残卷（未知品阶）
- **使用要求**：鸿蒙炼丹师
- **效果**：其上记录了不少珍贵丹药的丹方
- **耐磨度**：不可摧毁
- **出处**：第1368章（任务奖励+1）

### 鸿蒙炼丹师转职卷轴残卷
- 转职道具残卷，林天浩此前已得一份，本章再得一份
- **出处**：第1368章（任务奖励+1）

### 装备进化卷轴
- 任务奖励+20
- **出处**：第1368章

### 天罚装备
- 林天浩职业转职所需的关键装备
- 线索指向：大概率在**九幽**和**天宫**
- 域外之地有两件天罚装备（对林天浩是难得机会）

### 装备品阶与等级体系
- **品阶**：钻石级、星耀级（更高）
- **怪物品阶对应**：黄金怪、铂金怪（七转冒险者通常只能刷同级黄金怪，铂金怪仅敢想想）
- **等级与转数对应**：
  - 2000级 = 七转门槛
  - 3000级 = 七转之上（星耀级套装）
- **套装兑换价格（凡殿贡献值）**：
  - 3000级法师星耀级套装：约580万贡献值
  - 3000级阵法师星耀级套装：约650万贡献值（因附加阵法师属性，多花70万）

### 七转钻石级套装
- 用于交易天赋进化之花
- 七转冒险者能凑齐一整套同级黄金套装者凤毛麟角

## 技能系统

### 真海符茹功（双修功法）
- **上卷**：可修行至宗师大圆满之境，但无法突破至大宗师
- **副作用**：导致气血不稳、身体持续受损
- **破解之法**：
  - 气血不稳时逆向运转上卷，可稳定气血
  - 到达宗师大圆满后，持续逆向运转上卷可冲击大宗师之境
  - 配合双修可事半功倍
- **风险**：逆行运转功法一不小心会筋脉破碎或走火入魔
- **出处**：第1366章

### 鸿蒙炼丹师
- 独立转职体系，需转职卷轴（残卷可拼接）
- 转职后可使用鸿蒙丹方残卷学习珍贵丹方

### 阵法师
- 法师职业的细分分支
- 对应装备有阵法师专属星耀级套装

### 天赋系统
- **天赋进化之花**：可进化自身天赋；天赋凌驾于其他大部分技能神通之上
  - 极稀缺，没人愿意出售
  - 林天浩当前累计7朵，进化天罚之心还需3朵
- **神级天赋觉醒石**：任务奖励+3

### 闭关机制
- 神灵一闭关千年起步，否则得不到多大提升

## 怪物系统

### 城镇类怪物（新增怪物类型）
- **代表**：坤天城本身
- **特性**：
  - 以城池形态存在，平时不可见真面目
  - 通过阵法悄无声息吸走城中百姓寿元
  - 可引动"黑色雷云"
- **辨识方法**：当无法找到人为雷云来源时，可推断该城镇本身为城镇类怪物
- **出处**：第1366章

### 黑色雷云
- **传说级别**：可以泯灭一切
- **出现条件**：传说只在神灵升位时出现
- **当前异常**：圣人不能出手时仍被引动（因坤天城为城镇类怪物）
- **表现**：乌云密布、雷蛇翻滚、巨大压迫感

### 怪物等级分类
- **黄金怪**：七转冒险者通常能刷的同级别怪物
- **铂金怪**：七转冒险者"也就敢想想"的高级怪物

### 九转巨龙
- 可由特定兵巢批量招募
- 修罗奕泽惊呼"要是有一万九转巨龙，那都不是领主争霸赛了，那都可以去开疆拓土了"

### 植物系星空异种
- 推测身份为面纱女子（古神秘境那尊）
- 战力可抵挡神灵之上存在（高大虚影）的指压
- 武器：漆黑如墨的藤蔓（可缠绕、包裹、撕碎赤金色手指）
- 武器道具：银白色权杖（可念诵咒语复活死者）

## 副本系统

### 古神秘境
- 面纱女子（植物系星空异种）所在秘境
- 寒楼楼主、阴阳合欢宗宗主曾进入

### 心魔古城
- 苍穹之上存在一位神灵之上的存在

### 九幽 / 天宫
- 推测为天罚装备所在地
- 寒楼楼主、阴阳合欢宗宗主大概率知晓情报

### 领地空间（领地争霸赛战场）
- 详见"战斗系统-领地争霸赛"

### 诸神黄昏（宏观副本）
- 在神灵之上的存在眼中仅为"稍大的副本"
- 但因含神域碎片，存在让神灵之上存在眼红的资源

## 战斗系统

### 转数与神灵潜力对应关系（核心规则）
| 凡人转数 | 神灵潜力 | 备注 |
|---------|---------|------|
| 九转星耀级成神 | 最大九品神灵 | 几乎不可能成为神王 |
| 九转王级成神 | 可努力抵达神王 | 需打破自身枷锁、突破自我极限 |
| 十转王级成神 | 顺利抵达神王 | 标准路径 |
| 十一转皇级 | 潜力神皇 | — |
| 十二转帝级 | 潜力神帝 | 推荐路径（尼德栗芙建议林天浩追求） |
| 十三转 | 传说 | 把潜力拉满 |

- **核心原则**：品阶大于等级
  - 九转帝级依旧有机会成为神帝
  - 等级破极限比品阶破极限要容易很多
- **凡人境层次决定神灵境潜力**

### 成长速度参考
- 林天浩当前速度：12转成神约需百年；成圣约需一万年
- 神灵闭关：千年起步

### 领地争霸赛（新增PVP系统）
- **开启条件**：全服领地数量突破1000
- **开启时间**：本章时为"一个月后"开启（较前世提前约半年）
- **规则**：
  1. 所有领地被拉入领地空间
  2. 领地空间内只剩两个领地
  3. 只能派遣兵种出战
  4. 以攻占对方领地为目的
  5. 为期三天对战
  6. 领主只能指挥，冒险者不能参战
  7. 仅限兵种交战
- **奖励机制**：
  - 获胜方领地获得不少奖励
  - 攻占对方领地，己方领地奖励非常大
  - **失败方领地被掠夺一条加成词条**
- **词条系统**：
  - 正常词条可加攻击力、生命值
  - **百分比加成词条最珍贵**
  - 前世有领地击败20几个领地，掠夺20多个词条（其中9个百分比词条），一跃成为超级领地
- **兵种优势**：对兵种强大的领地有天然优势

## 特殊机制

### 寿元神币机制
- 双重获取寿元方式：佩戴（1年=1月寿元）或食用（一次性1000年寿元）
- 不可摧毁
- 对已成长到神灵者意义不大（成神后基本无尽寿元，待考证）

### 天赋进化之花
- 进化自身天赋的核心道具
- 凌驾于其他大部分技能神通之上
- 极度稀缺，公会成员收集到多自用
- 可用高品阶套装交换（七转钻石级套装 / 三千级星耀级套装）

### 道卷宝策
- 同时提供悟道速度+200% 与生命值+1亿的双重加成
- 优先分配给自己人（眼镜、猴子、胖子、林青青、苟到万古、苏璃、狂战刀锋等）

### 兵巢系统
- 招募兵种的领地建筑
- 存在可招募"九转巨龙"的兵巢
- 领地争霸赛核心战力来源
- 兵巢强度影响领地争霸赛胜负

### 领地词条系统
- 领地加成属性条目
- 分为固定值词条与百分比词条
- 百分比词条最珍贵
- 可通过领地争霸赛掠夺

### 神灵赐福系统
- 可叠加多种神灵赐福
- 存在"神灵之上的赐福"
- 高大虚影可感应到林天浩身上的太上老君、元始天尊、神魔时辰等气息

### 复活机制
- 面纱女子持银白色权杖，念诵繁杂咒语
- 可使死者血肉重组、复活
- 坤天城主被拍死后以此法复活

### 回归技能
- 林天浩的脱困技能，可脱离危险场景

### 神魂本源契约
- 交出神魂本源即可为强者所用（为奴形式）
- 高大虚影要求坤天城主交出神魂本源被拒，遂将其击杀

### 阵法系统
- 邪派阵法可悄无声息吸走百姓寿元
- 破阵方法：摧毁阵法关键结构（如金属铁柱）
- 阵法破除时符文闪烁微光、溃散
- 金属铁柱数量众多时破阵耗时较长（林天浩耗时3天多）

### 凡殿贡献值兑换
- 凡殿内部装备兑换体系
- 可兑换各职业、各等级套装
- 附加职业细分属性（如阵法师）需额外贡献值

### 昆仑镜
- 林天浩持有的传送道具
- 可往返凡殿

### 神秘存在庇护机制
- 神灵之上的存在可"结善缘"庇护凡人
- 面纱女子庇护林天浩，挡下高大虚影攻击
- 高大虚影评价"按理说，你不应该保他"

### 世界碎片炼制机制
- 绝世大能可收集神域分崩离析的碎片
- 炼制成自己的小世界
- 碎片上存在令神灵之上存在眼红的资源
