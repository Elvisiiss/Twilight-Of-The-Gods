# 《诸神黄昏》设定提取 - 第46-70章（合并版）

## 一、基础设定汇总

### 1.1 公会系统
- **升级条件**: 公会成就值达到满值自动升级
- **成就值获取**: 觉醒天赋、获得隐藏职业、首通副本、首杀boss
- **公会加成**: 
  - 2星: 攻击力+20
  - 3星: 移速+3
  - 4星: 攻速+1
  - 5星: 生命值+10000、伤害+1%、暴击+10%
- **升级需求**: 五星升六星需要一千万公会成就点

### 1.2 新手村隐秘
- **王村长**: 王铁匠的哥哥，原本是新手村村长，被驱逐后一念入魔成为野外boss
- **权力斗争**: 上任老村长不想放权，驱逐了王村长
- **诸神赐福**: 新手村存在多份诸神的赐福，王村长获得"可以跟冒险者一样升级成长"的赐福
- **复活机制**: 野外boss被击杀后会重新刷新

### 1.3 星辰王国政治
- **王位争夺**: 三位公主竞争王位（蒂雪涧、清芙芸、蕾欧娜）
- **大公主蒂雪涧**: 实力强大，寒冰剑气一击必杀，在王国如日中天
- **二公主清芙芸**: 一直在王国中经营势力，王后菲欧丁雨支持
- **三公主蕾欧娜**: 从新手村回来，需要扶持才能成为国王
- **国王亚伯拉**: 通过考验测试人心，观察公主们的反应
- **王后菲欧丁雨**: 非蕾欧娜生母，与幽冥一族有来往，策划陷害蕾欧娜

### 1.4 夜行者组织
- **组织目的**: 救出魔王之子格雷洛林森
- **组织成员**: 潜伏在王宫的士兵和刺客，使用美杜莎之毒等技能

### 1.5 世界boss系统
- **全服通告**: 世界boss出世时发布全服警报
- **血量推测**: 旱魃血量不低于1亿，现阶段玩家无法单独对抗

### 1.6 红名惩罚系统
- **猎杀任务**: 红名值大于1万触发全服猎杀任务，黑风城奖励青铜装备+10自由属性，星辰王国奖励双倍
- **等级清零**: 红名值过高，死亡一次等级和经验值全部清空
- **主城规则**: 红名值超过10点无法进入主城，在主城杀人会被城卫军逮捕

### 1.7 幽冥一族
- **种族设定**: 神秘种族，与王后菲欧丁雨有来往
- **秘密威胁**: 暴露来往会影响王位之争

### 1.8 王位之争策略
- **保护策略**: 陷害蕾欧娜是为了保护她，避免被推上风口浪尖
- **政治平衡**: 在不威胁另外两位公主的情况下展现能力
- **三步走计划**: 协助清芙芸击溃蒂雪涧→搞垮王后→蕾欧娜成为新王

## 七、战斗系统汇总

### 7.1 战斗机制
- **远程击杀**: 通过生死簿可远程击杀任何知道名字的目标
- **封印状态**: 封印状态下目标无法使用技能，被动回血也无法触发
- **真实伤害**: 生死簿造成真实伤害，无视防御和抗性
- **取整反伤**: 取承受伤害的最大数值的整数进行反伤，反伤至少50%以上

### 7.2 群体战斗
- **宫廷侍卫队**: 21人团队，20个青铜护卫+1个白银统领，协同作战能力强
- **夜行者围攻**: 数百夜行者同时暴露，协同作战，使用美杜莎之毒等技能
- **逐梦公会精英团**: 100多人，普遍十四五级，装备齐全，团灭于林天浩手下

### 7.3 吸血机制
- **嗜血项链**: 每次普攻恢复1%最大生命值（64万生命值时每箭6400）
- **九合长弓**: 5%吸血效果
- **生命女神的眼泪**: 每秒恢复10000生命值
- **复苏技能**: 每秒恢复500生命值（四星）
- **总恢复**: 每秒恢复47600生命值

### 7.4 连击系统
- **浮空连击**: 古武者特殊战斗技巧，打出无限连击
- **连击伤害**: 连击次数越多伤害越高
- **无限连击**: 四人配合打出无限连击，无净化难以打断

### 7.5 副本战斗
- **地狱级难度**: 属性大幅增强，血眼龙龟1685万血条
- **控制链规避**: 星月净化解除控制，玄冰之翼飞行规避技能
- **回血压制**: 四大恢复效果加持，每秒恢复47600生命值
