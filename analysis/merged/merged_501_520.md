# 第五百零一章至第五百二十章 设定分析汇总

## 一、基础设定汇总

### 1.1 圣地天骄新人赛半决赛设定
- **对阵**：凡殿 vs 浩渺无极宫，希图神殿 vs 西极神殿
- **结果**：凡殿击败浩渺无极宫，希图神殿击败西极神殿，晋级总决赛
- **总决赛对阵**：凡殿 vs 希图神殿

### 1.2 林青青设定
- **身份**：凡殿成员，林天浩妹妹
- **等级**：500级
- **生命值**：突破一亿九千万（服用蟠桃后）
- **职业**：狂战士
- **技能**：不动玄灵（解除灵魂控制）、火焰刀气、寒冰刀气、位移技能、连击技能
- **特点**：单点爆发秒人能力强，战斗意识强，心机深沉，钓鱼执法

### 1.3 幽冥诡匠设定
- **身份**：浩渺无极宫参赛选手
- **等级**：729级
- **职业**：灵魂系职业
- **武器**：镇魂钉（暗红色钉子）、骨杖
- **技能**：镇魂钉控魂（锁住影子控制灵魂）、暗影分裂（无限分裂黑影分身）、灵魂力剥夺（悄无声息弱化周围人灵魂力增强自身）
- **特点**：隐匿手段强大，控魂无解，霸体无法解除，谨慎但最终上当

### 1.4 北陌王爷设定
- **身份**：赤花沙宫参赛选手，官方人员（自称），实际为浩渺无极宫棋子
- **等级**：500级
- **属性**：生命值2997万，攻击101万（可提升）
- **天赋**：一圣一神双天赋
- **特点**：故意放水，为浩渺无极宫探底，十句话九句假

### 1.5 西伯利亚之狐设定
- **身份**：浩渺无极宫参赛选手
- **等级**：50级
- **属性**：生命值1.1亿（与召唤兽共享），攻击力0
- **职业**：召唤师
- **召唤兽**：火焰翼龙（生命值1.1亿），两尊百万生命值战兽
- **特点**：生命共享，召唤强大战兽

### 1.6 是依然呀设定
- **身份**：赤花沙宫参赛选手，古武者
- **职业**：牧师/格斗家（双职业）
- **特点**：距离把控细致入微，暴力牧师，会镜花水月，治疗和护盾时弹射闪电攻击敌人

### 1.7 封赤大元帅设定
- **身份**：浩渺帝国兵马大元帅
- **等级**：九转星耀级
- **目的**：成为浩渺帝国新皇，推倒浩渺无极宫
- **背后势力**：弗雷尔教（自称），战神弗雷尔创建的圣地

### 1.8 弗雷尔教设定
- **类型**：隐世圣地
- **创建者**：战神弗雷尔
- **目的**：重新回到属于自己的地盘，目标不是浩渺大陆
- **现状**：支持封赤大元帅谋反

### 1.9 元希扶摇设定
- **身份**：希图神殿大长老
- **特点**：修炼媚功，对男人吸引力大，身材婀娜
- **目的**：与凡殿合作，一起进攻月轮帝国

### 1.10 希图神殿目的设定
- **目的**：帮助另一个圣地复苏，替代月轮魔宫
- **手段**：寻找强者尸体，可能有复活或控制尸体的方法

### 1.11 小样外八身份设定
- **身份**：官方内部人员
- **目的**：主导让官方与林天浩撇清关系，引导舆论宣扬诸神黄昏是成神之地
- **关联**：乐神会，背后有浩渺无极宫支持

### 1.12 乐神会设定
- **类型**：组织
- **幕后**：阿来特星系的人，浩渺无极宫支持
- **目的**：引导舆论，宣扬诸神黄昏是成神之地，渗透各行各业
- **现状**：被定义成邪教，官方大力打击，但背后有神灵主导

### 1.13 尸山血海设定
- **位置**：月轮帝国
- **内容**：封印着一尊强大的神灵
- **目的**：林天浩想要去尸山血海收服这尊神灵

### 1.14 蜉蝣商人设定
- **类型**：可遇不可求的商人，神出鬼没，没有固定出现地点
- **特点**：物品更加牛掰且逆天，比吟游诗人更厉害
- **传说**：有人从蜉蝣商人手中购买到了第二天赋

## 六、副本系统汇总

### 6.1 圣地天骄新人赛
- **类型**：赛事
- **规则**：每个圣地参赛人员最少六个，最多八个
- **赛制**：淘汰赛制，每轮五局三胜
- **奖励**：神器、伪神器、半神器、自由属性点、诸神的赐福、天赋高级进化
- **半决赛结果**：凡殿击败浩渺无极宫，希图神殿击败西极神殿，晋级总决赛
- **总决赛对阵**：凡殿 vs 希图神殿

### 6.2 竞技场
- **类型**：切磋场地
- **规则**：被击杀不会掉级，可以放开手脚战斗

### 6.3 弑神学院
- **位置**：星海之中，不在诸神黄昏内
- **年级**：文素瑶能接触到四个年级
- **班级**：普通班和特优班（魔鬼班）

### 6.4 古朝秘境
- **位置**：浩渺大陆
- **内容**：古朝相关任务和野怪
- **产出**：晶核，任务奖励

### 6.5 五岳秘境
- **要求**：五大圣属性都到达法则之境
- **圣属性**：空间、黑暗、死亡、光明、生命

### 6.6 尸山血海
- **位置**：月轮帝国
- **内容**：封印着一尊强大的神灵

### 6.7 凡殿
- **位置**：浩渺大陆
- **内容**：林天浩的圣地，九尾仙狐成为守护兽

### 6.8 石垭城
- **位置**：希图帝国边疆，与石坦城比邻
- **现状**：重兵把守，封赤大元帅在此

## 七、任务系统汇总

### 7.1 圣地天骄新人赛任务
- **任务要求**：参加圣地天骄新人赛，争取第一名
- **任务进度**：进行中，凡殿击败浩渺无极宫，希图神殿击败西极神殿，晋级总决赛
- **任务奖励**：第一名圣地获得神器+1，圣地之主品阶+1；参赛队员每人获得自由属性点+10000，诸神的赐福+1；最佳队员额外获得天赋高级进化一次

### 7.2 赌约任务
- **任务要求**：圣地天骄新人赛获胜，赢得一件神器
- **任务进度**：进行中，浩渺无极宫已落败，总决赛对阵希图神殿
- **任务奖励**：神器

### 7.3 挑拨离间任务
- **任务要求**：挑起希图帝国和月轮帝国的战争
- **任务进度**：进行中，希图帝国想要与凡殿合作进攻月轮帝国
- **任务奖励**：混乱局面

### 7.4 生死簿锁头任务
- **任务要求**：用生死簿锁头天口千刃，等级清零
- **任务进度**：已完成，天口千刃被逐出镇龙古刹，等级清零

- **效果**：锁住影子控制灵魂，霸体无法解除
- **特点**：控魂而非控身，无法被霸体解除

- **效果**：影子一分为二，分出黑影分身，可无限分裂（2→4→8→16……）
