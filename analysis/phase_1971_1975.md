# 第1971-1975章 设定分析

## 基础设定
### 世界背景
- 故事发展到洞玄盟总部、谷仁星战场、北王星等多地
- 土灵族与洞玄盟战争持续，五大灵族（土、火、水、金、木）最终同时进攻
- 天域规定：行星级强者不可在生命星系战斗，违背会引来天劫
- 洞玄盟掌管十九个星域，战争损失惨重：
  - 武神强者：5659位 → 4566位（首战损失）
  - 后续：十九大星域只剩七个，武神缩水至1000人，行星级陨落14人
- 北山星域失守，洞玄盟商议放弃现有领地退走

### 主要势力与组织
- **洞玄盟**：
  - 掌管十九个星域
  - 武神强者数量：5659位 → 4566位 → 1000人（持续衰减）
  - 五大家族：欧家等
  - 理事会：由恒星级理事组成
- **五大灵族**：土灵族、火灵族、水灵族、金灵族、木灵族
  - 同时进攻洞玄盟
  - 土灵族总部：土玄星，地底宫殿，首领"土玄王"
  - 土灵族隐藏在星球内部，寻找困难，高阶土灵族更难寻找
- **欧家**：洞玄盟五大家族之一
  - 欧玄冥：行星级二十一层（欧星野太爷爷）
  - 欧旸子：武神（欧星野爷爷）
  - 欧秋枫：恒星级理事（欧玄冥三叔）

### 关键NPC/人物
- **林天浩（韩飞羽）**：洞玄盟核心长老，编号10025，主动戍边
- **欧旸子**：武神强者，带领林天浩加入洞玄盟，后被土灵族年轻强者越级斩杀陨落
- **欧玄冥**：行星二十一层，负责测试林天浩，欧家太爷爷级人物
- **欧秋枫**：恒星级理事，欧玄冥三叔
- **龙荀**：龙人，武神59级，戍边主位
- **洛不悔**：林天浩朋友，后随欧星野撤离，疑似陨落
- **欧星野**：北路城城主，后灵魂玉牌碎裂，确认陨落
- **土玄王**：土灵族首领
- **陆玲北璐**：陆玲家族恒星级理事，主持理事会
- **葛问宙**：葛家理事

## 属性系统
### 基础属性
- **吞噬土灵元晶奖励**：
  - 土属性悟性+10
  - 土属性抗性+10
  - 生命值+100
  - 魔抗+10
  - 护甲+10
- 武神级后吸收神力（非灵力），到达行星级后力量蜕变为圣力
- 行星级 ≈ 高配圣人（比银河世界圣人强50-60%）

### 称号系统
- **核心长老**：洞玄盟核心成员，编号制（如10025）
- **极致武神**：九十九级半步行星级强者
- **双极致武神**：两种法则同时到达极致的强者
- **无敌武神**：林天浩杀退土灵族后获得的称号

### 品阶系统
- 武道境界：武将 → 武王 → 武皇 → 武帝 → 武神 → 半步行星级 → 行星级 → 恒星级
- 武神级别以"级"代表法则悟道层次：
  - 武神九级 = 法则9层
  - 武神十九级 = 法则19层
  - 武神三十三级 = 法则33层
  - 武神五十九级 = 法则59层
  - 极致武神 = 九十九级（半步行星级）
- 问道境：武神到达行星级需要到达问道境
- 行星级二十一层：欧玄冥的境界
- 半步星系级、星系级、恒星级等更高境界

## 装备系统
- **核心长老令牌**：身份证明，可自由出入洞玄山河图
- **战舰**：
  - 洞玄盟武神强者专属战舰
  - 超级战舰用于交通
- **土灵元晶**：土灵族体内元晶，击杀证明
  - 天品土灵元晶：兑换普通贡献值
  - 武帝级、武神级土灵元晶：兑换长老贡献值
- **神石**：武神级以上修炼资源，替代灵石

## 技能系统
- **空间本源之力**：
  - 隔绝气息，与大地融合，土灵族无法发现
  - 切碎敌人身体
  - 瞬移穿梭
  - 林天浩闭关后到达999层（远超常规极限）
- **时间本源法则**：林天浩新领悟，到达667层
- **土之本源法则**：可自由遁地，与大地融合
- **不灭兽魂**：灵魂力强大，探寻土灵族更容易
- **万法之躯**：持续提升本源悟性和本源抗性，悟道越来越快
- **空间莲花（异象）**：空间本源异象（后续章节出现）

## 怪物系统
- **土灵族**：
  - 地底战斗力、敏捷、防御、感知增强
  - 武神十九级、武神三十三级等高手
  - 极致武神级高手
  - 半步行星级、法则88级高手
- **星空异种**：后续出现，吞星蛤蟆等
- **星兽**：各品阶，武将级、武王级、武皇级、武帝级、武神级

## 副本系统
- **洞玄山河图**：洞玄盟总部，5倍时间差
  - 核心区域25倍时间差
- **洞玄府**：洞玄山河图内特殊宝地
  - 时间差与外界25倍
  - 修炼需10万贡献值/年
  - 外界2年 = 洞玄府50年
- **谷仁星战场**：土灵族与洞玄盟主战场
- **北王星战场**：后续战火蔓延地

## 战斗系统
- **戍边贡献值奖励**：
  - 击杀武帝级土灵族：1000贡献值
  - 击杀武神级土灵族：最低1万贡献值
  - 对方悟道超10层，每多1层+1000贡献值
- 林天浩戍边战果（首次）：
  - 武帝级85人（8.5万贡献值）
  - 武神级13人（其中5人超10级，共9.9万贡献值；8人九级，8万贡献值）
  - 总计：长老贡献值26.4万，普通贡献值98.6万
- 林天浩第二次戍边战果：
  - 杀穿土灵族占据的十几颗星球
  - 斩杀两尊土灵族极致武神
  - 长老贡献值520万（可兑换52年修炼时间，25倍时间差即1300年）
- 林天浩战力：
  - 空间本源法则41层：可击杀半步行星级、法则88级高手
  - 空间本源法则999层：行星级之下无敌
- 五大灵族阵法：五行锁天大阵（15位恒星级布置）

## 特殊机制
- **天域规定**：行星级强者不可在生命星系战斗，违背会引来天劫
- **贡献值体系**：
  - 长老贡献值：单独计算，可兑换武神级资源
  - 普通贡献值：只能兑换武神之下资源
- **洞玄府时间差**：外界1年 = 洞玄府25年
- **万法之躯**：持续提升悟性，悟道越来越快
- **不灭兽魂**：灵魂力远超同级武者
- **斩断大道**：林天浩可封锁天地空间本源法则，寻常空间法则即便问道境、道境也无法使用
- **空间本源法则封锁**：
  - 空间本源法则需666层以上才能在封锁下感应空间之道
- **时间差架构**：
  - 时间本源法则突破99层可架构时间差
  - 需要载体承受空间本源之力和时间本源之力
  - 两种力量不同，融合易出问题，需极高掌控力
- **戍边轮换**：一年一批，五年一轮
