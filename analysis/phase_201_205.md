# 《诸神黄昏》设定提取 - 第201-205章

## 一、基础设定

### 1.1 击杀蕾欧娜
- **过程**: 林天浩使用瀚海乾坤符打断蕾欧娜的传送，在守护者之塔中击杀蕾欧娜
- **奖励**: 装备+3，技能书+3，自由属性点+300，金币+100000，吸血鬼侯爵的信物+1
- **后果**: 星辰王国覆灭，国战结束

### 1.2 瀚海王国成立
- **建立**: 魔窟建立新的王国，更名瀚海王国
- **奖励**: 所有瀚海王国冒险者自由属性点+5，经验值+1000
- **意义**: 整个龙国区所有玩家都得到加成

### 1.3 九重盾战（神级隐藏职业）
- **来源**: 黑袍首领奖励，神级隐藏职业转职卷轴
- **转职者**: 周小胖
- **被动技能**: 九重甲、九重盾、九重斩、九重韧、九重减、九重伤（六个被动）
- **最高效果**: 反伤90%，九重护盾，九重技能，韧性90%，减伤90%，重伤90%
- **成长属性**: 每天自动增加一万生命值，一百点护甲，一百点魔抗
- **初始状态**: 六个被动技能都是二重水准，成长属性100生命值，1点魔抗，1点护甲

### 1.4 海神波塞冬赐福（两次）
- **第一次**: 获得技能瀚海乾坤
- **第二次**: 获得海之子称号

### 1.5 瀚海乾坤（技能）
- **类型**: 特殊
- **学习要求**: 仅限雪帝
- **效果**: 以你为中心，方圆千米之地不可用传送，位移，飞翔等手段，持续时间五分钟
- **消耗**: 无
- **冷却**: 1小时
- **熟练度**: 不可升星
- **备注**: 你和你的队友不受此效果影响

### 1.6 海之子称号
- **类型**: 特殊称号
- **佩戴要求**: 仅限雪帝
- **效果1**: 在海洋中可以自由行动，移速提升三倍
- **效果2**: 在海洋中攻击不受海水阻碍和削弱（不包括火属性攻击）
- **效果3**: 在海洋中血量和蓝量恢复速度提升三倍（不包括吸血能力）
- **备注**: 佩戴此称号能够得到海洋中大部分种族的尊敬

### 1.7 天罚之心（超神级天赋）
- **类型**: 超神级天赋
- **1星效果1**: 技能每对生命体造成一次伤害，永久提升一点生命值
- **1星效果2**: 装备附加效果（技能、召唤、灼烧、溅射等）每对生命体造成一次伤害，永久提升1点生命值
- **2星效果**: 每次伤害叠加两点生命值
- **提升方式**: 熟练度0/1000，通过造成伤害提升

### 1.8 吸血鬼侯爵敏德凯度
- **身份**: 吸血鬼中的贵族，蕾欧娜的相好
- **实力**: 强大，能够帮助蕾欧娜迈入四转
- **复仇**: 因为蕾欧娜之死和信物被夺，对林天浩展开复仇
- **手段**: 反伤机制，用反伤消耗林天浩生命值

### 1.9 混乱之地
- **特点**: 鱼龙混杂，三教九流的人都有，隐藏了不少强者
- **位置**: 需要穿过黑风山脉，再翻过几座大山
- **环境**: 怪石嶙峋，经常发生战斗

### 1.10 疾风马（坐骑）
- **类型**: 普通坐骑
- **等级**: 50
- **使用要求**: 无
- **效果**: 保持移速50+奔跑两个小时
- **限制**: 超过两个小时移速会持续下降，超过八个小时会有累死的风险

### 1.11 黑风山脉隐藏复活祭坛
- **位置**: 黑风山脉一处洞窟之中
- **归属**: 瀚海王国的隐藏地图
- **用途**: 敏德凯度和洛林牧野等人在此恢复

### 1.12 冰雪女神血液
- **用途**: 敏德凯度需要冰雪女神的一滴血液来快速恢复
- **获取**: 需要打开装着冰雪女神左腿的棺材，使用特殊葫芦摄取

## 五、战斗系统

### 5.1 战斗机制
- **瀚海乾坤符**: 打断传送，克制蕾欧娜的逃跑
- **生死簿反伤**: 敏德凯度反伤机制，反伤比例为十分之一
- **天罚之心**: 技能和装备附加效果叠加生命值

### 5.2 战斗场景
- **守护者之塔之战**: 林天浩击杀蕾欧娜
- **黑风山脉之战**: 敏德凯度与洛林牧野等人策划复仇
- **混乱之地之战**: 林天浩遭遇乱石谷劫匪

### 5.3 攻防对比
- **林天浩**: 965万+生命值，天罚之心叠加，嗜血龙甲承伤吸血30%，每秒回血近一万六
- **蕾欧娜**: 四转冰火大法师，被瀚海乾坤符打断传送后击杀
- **敏德凯度**: 吸血鬼侯爵，反伤机制，需要冰雪女神血液恢复
- **乱石谷劫匪**: 最高50级黑铁，属性垃圾，不足为惧

### 5.4 战术运用
- **瀚海乾坤符**: 打断蕾欧娜的传送，确保击杀
- **天罚之心**: 利用技能和装备附加效果快速叠加生命值
- **生死簿**: 锁头敌人，同时利用天罚之心叠加生命值
