# 第2211-2215章 设定分析

## 基础设定
### 世界背景
- **高等世界与中等世界**：林天浩和胖子在所有高等世界和中等世界建立测试阵法，十年完成
- **昆山界**：中等世界，林天浩和胖子收徒之地
- **昆山圣地**：昆山界的霸主势力，昆山龙言为少主
- **上官家**：昆山界小势力，上官青青的家族
- **上官青青的小世界**：体内有阿来特星系时间长河缠绕的小世界
- **神域大世界、神界大世界**：林天浩和胖子寻找银河世界的大世界
- **主世界之外**：没有时间和空间概念的地方，是壁垒
- **不可知之地深处**：林天浩和胖子探索之地

### 主要势力与组织
- **昆山圣地**：昆山界霸主，昆山龙言为少主，有老怪物坐镇
- **上官家**：上官青青家族，二叔上官蓝鹰掌权
- **百花楼**：林天浩和胖子休息宣泄情绪之地

### 关键NPC/人物
- **林天浩**：无上墟主，收上官青青为徒
- **胖子（周小胖）**：动乱墟主，与林天浩分头寻找银河世界
- **上官青青**：林天浩的徒弟，昆山界天才，体内小世界有阿来特星系时间长河
- **上官蓝鹰**：上官青青二叔，鹰钩鼻中年人，囚禁上官青青母亲逼婚
- **上官青青母亲（中年妇人）**：被林天浩一念提升到仙祖巅峰
- **昆山龙言**：昆山圣地少主，欲纳上官青青为鼎炉
- **昆山圣地老祖宗**：识时务，称昆山龙言罪有应得
- **长生源王**：被林天浩叫出来提供信息，求林天浩保留阿来特星系

## 属性系统
### 基础属性
- **小世界检测**：通过测试阵法可检测体内小世界是否包含银河世界或阿来特星系的时间长河
- **道之运用**：上官青青对道的运用达到登峰造极的地步（林天浩加持后）

### 称号系统
- **墟主大人**：林天浩和胖子在收徒时的身份
- **师父**：上官青青称呼林天浩
- **鼎炉**：被炼制提升修为的工具人（上官青青差点成为）

### 品阶系统
- **境界体系（完整）**：
  - 仙王 → 仙皇 → 仙帝 → 仙祖 → 源神 → 源王 → 源皇 → 源帝 → 墟主 → 无上墟主
- **境界说明**：
  - 仙帝：传说中的强者
  - 仙祖：能够横压一个世界的存在
  - 墟主：一个念头就能抹杀仙祖，在高等世界无敌的存在
- **境界跨度**：
  - 仙王以下 → 仙祖巅峰（林天浩一念提升上官青青母亲）
  - 仙祖巅峰（上官青青母亲被一念提升后的境界）
  - 林天浩可培养上官青青到源王、源皇，但难以成为新墟主

## 装备系统
- **测试阵法**：检测小世界是否包含银河世界/阿来特星系时间长河的阵法
- **长剑**：上官青青的武器
- **小世界**：上官青青体内拥有

## 技能系统
### 林天浩的墟主级能力
- **一念提升修为**：林天浩点在上官青青母亲眉心，瞬间从仙王以下提升到仙祖巅峰
- **一念抹杀仙祖**：墟主一个念头就能抹杀仙祖
- **神识进入小世界**：林天浩和胖子可神不知鬼不觉进入他人小世界
- **生命力操控**：林天浩一步迈出，让昆山龙言容颜以肉眼可见速度衰老
- **传音**：可传音给徒弟
- **人物瞬移**：挥手将上官青青母亲带到身旁
- **不详之力掌控（推演）**：林天浩推演借助不详之力托举时间长河
- **万法之躯**：林天浩的体质，掌控万道万法，与无道背道而驰

### 战斗技能
- **道之运用**：上官青青在林天浩加持下，一招一式让上官蓝鹰难以招架
- **剑术**：上官青青使用长剑攻击

### 境界能力
- **仙祖巅峰**：林天浩一念赋予的境界
- **仙祖能力**：横压一个世界
- **墟主能力**：
  - 一个念头抹杀仙祖
  - 高等世界无敌
  - 可恢复小世界本源
  - 可让小世界恢复如初
  - 可重塑星辰、海洋、陆地、植物、动物、智慧生物

## 怪物系统
- **不详怪物**：
  - 栖息在不祥之地
  - 不详之力可约束时间长河成河
  - 可被墟主隔绝

## 副本系统
- **收徒测试副本**：
  - 在所有高等世界和中等世界建立测试阵法
  - 检测拥有小世界的强者
  - 检测是否包含银河世界/阿来特星系的时间长河
  - 十年完成所有阵法建立
- **寻找阿来特星系副本**：
  - 在昆山界（中等世界）找到阿来特星系时间长河
  - 位于上官青青的小世界中

## 战斗系统
- **境界碾压**：林天浩对昆山龙言的生命力操控
- **昆山圣地老祖宗臣服**：昆山圣地老怪物向林天浩下跪
- **上官青青 vs 上官蓝鹰**：林天浩加持下上官青青压制上官蓝鹰
- **上官蓝鹰被吓**：感受到林天浩的巨大压力，身体颤抖

## 特殊机制
- **测试阵法机制**：
  - 可检测小世界是否包含特定时间长河
  - 林天浩能感应每个测试阵法的测试情况
  - 测试到银河世界可在第一时间发现
- **世界之心融合机制**：
  - 一个人在已拥有小世界的情况下，再次炼化世界之心
  - 会出现上官青青那样的情况：两条时间长河共用一个小世界
  - 炼化阿来特星系和银河世界的世界之心，可牵引两个世界的时间长河到炼化者体内
- **幕后之人推测**：
  - 身受重伤，命不久矣
  - 想要利用时间长河逆天改命
  - 给林天浩成长起来的天赋和血脉
  - 用某种方法对林天浩思维进行影响，让其着魔一样想复苏蓝星
  - 借林天浩复苏蓝星的力量复苏自己
- **长生者推测**：
  - 蓝星曾走出过一位绝世强者（墟主级别）
  - 长生者可跨越时代与林天浩生活在同一时代
  - 武当张三丰为传说中的长生者
- **道之源神**：创造蓝星的存在，但无此实力
- **执念机制**：林天浩对蓝星的执念近乎疯魔，本身不科学
- **不详之力容器**：可借助不详之力托举时间长河（林天浩推演）
- **无道**：不详之力的根本，与林天浩万法之躯背道而驰
- **林天浩收徒目的**：
  - 真有收徒打算，培养人手
  - 主要因上官青青小世界中有阿来特星系时间长河
  - 可一点点牵引时间长河
- **阿来特星系还原**：林天浩和胖子有力量还原阿来特星系的世界本源
- **胖子推演能力**：抬手掐诀，世界开始成形（星辰、海洋、陆地、植物、动物、智慧生物）
