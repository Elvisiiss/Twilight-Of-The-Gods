# 第2066-2070章 设定分析

## 基础设定
### 世界背景
- 星界（神界之下层）：三界结构中的过渡层，星盟总部所在地，繁华程度远超凡界
- 不枉城：星盟总部所在城市，星盟商会所在地，是星界重要的交易中心
- 神界（源界）：星界之上的更高层次世界，源神、源主居住之地
- 血渊古地（旧称血海炽渊）：叶祖陨落后被封印形成的古地，需要万血种作为秘钥才能进入，内有叶祖留下的传承和至宝

### 主要势力与组织
- 星盟：星界第一势力类型组织，底蕴深厚，总商会主持只是仙帝境，高层有仙祖中期高手坐镇，盟主实力深不可测
- 星盟商会：星盟下属商会，定期举办拍卖会，分高级会员（二楼包间）和普通席位
- 圣教：神界势力，与林天浩关系微妙，潜在敌对势力
- 叶祖一脉：叶墟（叶祖）的传承派系，掌握大虚无手印等秘技

### 关键NPC/人物
- 林天浩（化名韩飞羽）：半步仙祖境界，战力可斩仙祖级，肉身成帝，拥有叶墟记忆
- 郝文雪：星盟高层，半步仙祖，常驻星盟商会，性格鲁莽
- 郝文雪师父：星盟成员，仙祖中期高手，老成持重
- 狐媚娘：星盟商会拍卖主持，仙帝境界，狐媚之术
- 暗沅源神：神界来客，半步源主级高手，叶祖传人兼道门传人，擅长大虚无手印和三针燃魂术

## 属性系统
### 基础属性
- 修为境界：半步仙祖 < 仙祖 < 半步源主 < 源主（神界对应：半步源神 < 源神）
- 道之层次：道的层次高于境界可越级战斗，但相差一整个大境界仍难以弥补
- 肉身力量：肉身成帝可使肉身力量达到恐怖级别，不依赖法则和小世界也可拥有强横力量
- 灵魂力：强大灵魂力可固守灵台，抵抗魔气侵蚀灵魂

### 称号系统
- 高级会员：星盟商会会员等级，可享二楼包间
- 叶祖传人：叶墟传承者的身份标识
- 道门传人：道门术法的传承者

### 品阶系统
- 境界品阶：仙帝 → 半步仙祖 → 仙祖 → 半步源主 → 源主（神界称源神）
- 战力品阶：林天浩半步仙祖，战力可斩仙祖级，与半步源主对抗
- 宝物品阶：魔道至宝（万血种）、源主级宝物、源神级武器（稀缺，多数源神无源神级武器）

## 装备系统
- 万血种：魔道至宝，用一万种神兽血脉炼制而成，可培育神兽或炼制超级至宝，是进入血渊古地的秘钥，拍卖价1亿悟道点（后被免单零元购）
- 黑暗龙源宝液：拍卖所得宝物，林天浩竞拍获得，给了小黑龙
- 暗红色灯笼：暗沅源神的源神秘技载体，用于施展囚天
- 三枚黑色钢针：三针燃魂术的施法媒介，扎入后颈激发秘术
- 旗帜：暗沅源神所用无道手段兵器，可破开时空之力
- 帝兵：可交易的帝王级兵器

## 技能系统
### 林天浩技能
- 空间本源之道：可封锁空间
- 死亡之道：可让枯寂死星继续凋零
- 时间本源之力：运转双眸可拉慢对手速度，提前预判
- 力之本源法则：运转体内拔高自身力量
- 生命本源之力：可修复受伤身躯
- 隔空取物：可悄无声息取走拍卖台物品（仙祖级阵法布置的拍卖台）
- 大虚无手印（第四层以上）：叶墟自创秘技，虚无之手自动攻击，第四层不需动手，第七层可锁定远距离目标追打
- 三炼之法：层次极高，速度是强项，可承受重击

### 暗沅源神技能
- 空间本源之道：可切割敌人身躯
- 魔气侵蚀：直接侵蚀身躯而不侵蚀灵魂，使身躯被动魔化
- 源神秘技：囚天：用暗红色灯笼施展，以锁链封锁敌人小世界，使其无法动用小世界力量
- 大虚无手印（未达第四层）：叶祖秘技，虚无之手攻击
- 三针燃魂术（燃三魂之法）：道门顶尖术法，三枚黑色钢针扎入后颈激发，大幅提升速度和攻击力

### 秘术/术法
- 魔道追踪秘术：可种下隐秘印记追踪位置，叶墟记忆中记载
- 无道手段：不依赖道之力的攻击手段，层次高时可破开时空之力

## 怪物系统
- 神兽：万血种炼制材料，一万种神兽血脉
- 魔化身躯：被魔气侵蚀后会魔化，需要强大意志抵抗

## 副本系统
- 血渊古地（血海炽渊）：叶祖陨落之地，封印形成，面积庞大，封印不彻底，需万血种进入，内有叶祖传承和至宝
- 死寂星空：林天浩引诱敌人的战场，本身已枯寂

## 战斗系统
- 道的力量：引动天地之力，对自身消耗低
- 境界力量：纯粹自身境界力量，对自身消耗大
- 越级战斗：道之层次高于境界可越级，但相差一整个大境界仍难以弥补
- 时空扭曲：空间之道+死亡之道可让时空疯狂扭曲
- 速度对比：三炼之法层次高时速度极强，但三针燃魂术后暗沅源神速度让林天浩都难以招架
- 战斗机制：道vs境界、法则vs肉身、小世界力量（可被囚天封锁）

## 特殊机制
- 悟道点：星界通用货币，可培养仙帝（六千万悟道点可培养一尊仙帝）
- 拍卖会机制：价高者得，恶意抬价会被处罚，星盟商会内部有让利机制
- 星盟会员等级：高级会员享有特权
- 生死台：星盟公开决斗场所
- 肉身成帝：肉身修炼到极致，不依赖法则和小世界也可拥有强横力量
- 道与境界关系：道之层次高于境界可越级，但相差一整个大境界仍是硬伤
- 万血种功能：培育神兽、炼制超级至宝、作为血渊古地秘钥
- 叶祖传承：叶墟在多处留下传承和宝物，只有叶祖一脉传人可掌握大虚无手印
- 魔气侵蚀机制：不侵蚀灵魂，直接侵蚀身躯，使身躯被动魔化
