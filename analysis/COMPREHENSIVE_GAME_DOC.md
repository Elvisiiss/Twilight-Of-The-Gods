## 第一章：世界观与背景

### 1.1 游戏世界概述

| 设定项 | 描述 |
|--------|------|
| 游戏名称 | 《诸神黄昏》 |
| 开服时间 | 2032年5月20日 |
| 游戏性质 | 跨时代虚拟网游，由银河主神用地球远古诸神力量打造的造神游戏 |
| 游戏目的 | 应对五年后的大灾变（阿来特星系进攻银河星系） |
| 账号绑定 | 虹膜和DNA绑定，换登录器不改变账号 |

### 1.2 世界层级体系

```
不可知之地
    ↓
高等世界（神域）→ 源神→源主→源皇→源帝→墟主→无上墟主
    ↓
中等世界（仙界/天域/星界等）→ 仙祖/源神级别
    ↓
小世界（银河世界等）→ 神灵/圣人级别
    ↓
凡界（玩家初始世界）→ 凡人/武者级别
```

### 1.3 核心世界观设定

#### 三次造神时代
- **东方造神时代**：三千神魔时代，盘古开天辟地，诸神征战
- **西方造神时代**：希腊神话时代，奥林匹斯众神统治
- **克苏鲁造神时代**：近现代神话，不可知的外神降临

#### 第四次造神时代
- 玩家（冒险者）属于第四次造神时代的人
- 道之源神打造了《诸神黄昏》游戏
- 目的：培养强者对抗阿来特星系入侵

#### 阿来特星系威胁
- 来自银河世界之外的强大势力
- 幕后黑手"老父亲"实力达到墟主级别
- 通过控魂虫、渗透势力等方式入侵银河世界

### 1.4 世界背景故事

**主线剧情**：
1. 银河主神预见阿来特星系即将入侵
2. 创造《诸神黄昏》游戏培养人类强者
3. 玩家进入游戏开始冒险，逐步揭开世界真相
4. 发现游戏与现实世界的联系（植物人康复、大灾变融合）
5. 最终成为无上墟主，守护银河世界升级为高等世界

- **保留**：天赋、血脉、记忆
- **次数**：9次
- **转生后**：无属性面板，需重新修炼

### 12.6 血祭大阵

- **数量**：两个（摧毁祭坛阵旗+献祭虫母）
- **阵脚位置**：镇北城、天古城、红枫城
- **触发条件**：死亡人数足够多

### 12.7 控魂虫体系

- **控制方式**：寄生在目标体内，控制灵魂
- **识别方法**：绿魂烛照出
- **解除方式**：海神波塞冬取下并捏碎
- **源头**：阿来特星系

### 12.8 心魔古城规则

- **四大规则**：目不可视、耳不能听、腿不能行、手不能攻
- **无尽地狱规则**：将目标拖入熔岩地狱
- **心魔模拟**：可模拟王级、皇级强者分身

### 12.9 不祥侵蚀机制

- **侵蚀范围**：人、规则、所有一切
- **同化效果**：增强体魄和灵魂，但道的力量溃散
- **秘境起源**：所有秘境都是被不祥侵蚀的平行世界

### 12.10 世界之心系统

- **构成**：本源之力 + 先天之气
- **作用**：加快修炼速度，改造身体和灵魂
- **战略价值**：可稳定培育仙帝，培育源神必需

### 14.2 伤害计算公式

```
基础伤害 = 攻击力 × (1 + 暴击率 × (暴击伤害 - 1))
实际伤害 = 基础伤害 × (1 + 物穿/法穿) × (1 - 护甲减免/魔抗减免)
真实伤害 = 目标最大生命值 × 百分比
```
