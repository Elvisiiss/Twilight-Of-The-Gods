# 《诸神黄昏》设定提取 - 第61-65章

## 一、基础设定

### 1.1 神使系统
- **神使身份**: 冒险者中出现了神使，沉眠的神灵可能想要再次掌控星辰王国
- **神使活动**: 发现了神使活动的痕迹，但无法确定身份
- **神使能力**: 拥有诸神之力，可能拥有特殊能力

### 1.2 公会成就系统
- **升级需求**: 五星升六星需要一千万公会成就点
- **成就获取**: 击杀boss、完成首杀可获得公会成就点
- **当前进度**: 击杀宫廷侍卫队获得4万5公会成就点

### 1.3 上古法宝
- **空间之门铜镜**: 上古残缺法宝，能够打开空间之门，直接穿越空间进入其他地方
- **法宝用途**: 可用于潜入封印之地，制造不在场证明

### 1.4 主城规则补充
- **红名处罚**: 在主城杀人会被逮捕，不在主城杀人最多被驱逐
- **法外开恩**: 特殊情况下可获得在主城行走的资格

### 1.5 NPC智商系统
- **人形怪物**: 智商高，会评估实力，不敌时会逃跑
- **宫廷侍卫**: 协同作战能力强，会更换战术应对敌人

## 七、战斗系统

### 7.1 战斗机制
- **控制链衔接**: 多个青铜护卫连续释放挑飞，形成长时间控制链
- **无敌金身**: 0.5秒无敌时间，可规避大招伤害
- **死亡轮回**: 概率性秒杀技能，升星后概率提升（0.5%→1%）
- **生死簿**: 远程真实伤害，每秒10000+1%最大生命值

### 7.2 群体战斗
- **逐梦公会精英团**: 100多人，普遍十四五级，装备齐全
- **战斗策略**: 远程控制+黑铁boss扛伤+战士冲锋
- **团灭原因**: 技能无法命中林天浩，黑铁boss扛不住攻击

### 7.3 吸血机制
- **嗜血项链**: 每次普攻恢复1%最大生命值
- **九合长弓**: 5%吸血效果
- **药剂加持**: 可服下多瓶药剂提升吸血效果

### 7.4 战斗技巧
- **错位攻击**: 利用雷电跳跃和错位攻击实现攻击有效化
- **走a拉扯**: 利用高移速持续走a，逐个击破敌人
- **技能规避**: 通过走位避开控制技能和攻击
