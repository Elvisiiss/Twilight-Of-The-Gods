# 第2071-2075章 设定分析

## 基础设定
### 世界背景
- 魔域：星界之外的另一片区域，从星界到魔域需半个月追击
- 碎环星域：星界中的一片破败星域，有无名死星
- 神界之外：还有无比广袤的星空，存在神界规则无法理解的事物
- 时间长河：多元时间线概念，不同时间长河的时间节点不同，可从不祥之地进入其他时间长河
- 不祥之地：特殊区域，可窥见其他时间长河
- 源主秘境：源主级强者留下的秘境，藏有传承和宝物，通常需杀穿秘境才能看到名字铭刻

### 主要势力与组织
- 赤血魔宗：魔域势力，拥有仙帝级强者坐镇
- 叶祖一脉：叶墟传承派系，掌握大虚无手印、血魂大天咒术等秘技
- 魔族：叶墟曾为魔族源帝
- 星盟虚拟对战游戏：林天浩曾玩过的全息虚拟网游

### 关键NPC/人物
- 青炽源神（真名）：原化名暗沅（仇人名字），半步源主级高手，散修身份，加入过14个势力，后被林天浩奴役收服
- 猿魔王：仙王级魔猿，擅长替身术，知道源主秘境位置
- 赤炉仙王：赤血魔宗成员，仙王境界，被林天浩所杀
- 老大爷：被困现代化城市的源主级高手，被困三百多年
- 寒无心：冰封银河世界之人，进入不祥之地

## 属性系统
### 基础属性
- 境界对应：半步源神（神界）= 半步源主（星界），同为半步源主级
- 大道境：中等世界（仙界/星界）的道之境界上限
- 大道境第一层：道之层次的基础阶段
- 完全体世界：宇宙之晶创造的世界，可诞生人类
- 中等世界：比小世界层次更高的世界，强者难以移山填海

### 称号系统
- 魔族源帝：叶墟在魔族中的至高称号
- 叶祖传人：叶墟传承者的身份
- 散修：无固定势力归属的修士

### 品阶系统
- 境界序列：仙王 → 仙皇巅峰 → 仙帝 → 仙祖 → 半步源主 → 源主 → 源尊 → 源帝
- 战力品阶：林天浩半步仙祖（半步源神），战力达源主级
- 材料品阶：源主级炼器材料（数十种，每样珍贵）
- 秘境品阶：源主秘境（高危，仙王进入十死无生）

## 装备系统
- 时空修炼宝塔：林天浩所有，可进入第二层闭关，分身可在外观察
- 万血种：可配合万血化兽大法使用
- 暗红色灯笼：暗沅源神的囚天秘技载体
- 源主级炼器材料：青炽源神提供的数十种珍贵材料
- 秘境碑文：铭刻秘境主人名字的石碑
- 钞票：现代化城市中的货币

## 技能系统
### 林天浩技能
- 命运之力（左手）：可追踪敌人
- 因果之力（右手）：可追踪敌人
- 遮天巨手：远程攻击手段
- 大虚无手印（第四层以上）：自动攻击
- 三炼之法：层次极高
- 吞天噬地：吞噬类天赋，受中等世界层次限制
- 时空本源之道：在中等世界算顶尖
- 神识：可扩散窥探秘境情况
- 分身术：林天浩可分身，但境界不够且需修炼

### 青炽源神技能
- 替身术：可留下替身逃脱
- 无道手段：层次高，可破开时空之力
- 三道分身：可分化三道分身探路
- 自身威压：可压制仙皇巅峰级对手

### 秘术/术法
- 血魂大天咒术：叶墟的奴役秘法，魔族中少有人知，可奴役他人建立主仆契约
- 血魂咒术：流传在外的普通版本
- 万血化兽大法：叶墟功法，可幻化为各种兽类，几乎无破绽，高出三个大境界也难看穿
- 三针燃魂术：道门顶尖术法，副作用大
- 叶墟吞噬杀戮大法：掠夺类功法，可吞噬被猎杀者力量增强自身，连源帝级都可吞噬，本质是掠夺

## 怪物系统
- 魔猿：猿魔王种族
- 凡人修士：境界低于仙王的存在
- 婴儿重生：被困者死后以婴儿身份重生

## 副本系统
- 源主秘境（淳血源主秘境）：位于魔域破败星域的星球残骸内部
  - 因一场旷世大战而显露
  - 内部是一座现代化城市（高楼大厦、商场、公交、地铁、红绿灯）
  - 建筑脆弱，无阵法保护，给纯粹凡人居住
  - 被困者包括13+位源神级高手
  - 困人机制：意识脱离肉身，肉身在外，无法离开
  - 死亡机制：死后以婴儿身份重生，自杀会让下一个家庭越来越差
  - 力量压制：无法调动体内力量
  - 已困住原源主三百多年

## 战斗系统
- 因果沾染：随便杀人会沾染因果
- 越级战斗：道之层次高可越级，但相差一整个大境界仍是硬伤
- 境界威压：可瞬间压制低境界者动弹不得
- 道vs境界：道之力量消耗低，境界力量消耗大
- 半月追击战：林天浩从星界追击青炽源神至魔域，半个月
- 替身术逃脱：可留下替身本体逃脱

## 特殊机制
- 悟道点价值：1万悟道点为小额，1亿悟道点为天文数字，6千万悟道点可培养一尊仙帝
- 一人双世界：林天浩的蓝星与诸神黄昏可能是同一人创造的双小世界
- 一体三世界：蓝星、阿来特、诸神黄昏可能是同一创造者的三个小世界
- 时空宝物：神界时空宝物时间差大多在100倍以内，超过100倍的较少
- 世界层次递减：小世界强者到中等世界后实力大减
- 时空宝物跨世界：仙界至宝带入神界会因不适配而无法打开，甚至被摧毁
- 完全体世界：宇宙之晶创造，可诞生人类，一人双完全体世界极难
- 伪装世界特征：文明数量稀少、生命星球数量稀少、星球上的人难以离开所在星系
- 香火之力：伪神通过收集婴儿繁衍文明提供香火之力
- 诸神黄昏与蓝星融合：游戏角色技能、法则、神通可具现
- 阿来特世界：进攻蓝星的世界，林天浩施展超远距离传送逃离
- 时间长河多元论：银河世界可能不在当前时间长河
- 现代化城市幻境：源主秘境内部，意识被困，肉身在外
- 婴儿重生机制：被困者死后以婴儿身份重生
- 自杀惩罚：自杀后下一个家庭越来越差
- 万血化兽大法伪装：高出三个大境界也难看穿
- 大道境限制：中等世界悟道无法超过大道境
