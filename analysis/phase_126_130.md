# 《诸神黄昏》设定提取 - 第126-130章

## 一、基础设定

### 1.1 冒险者公会系统
- **等级**: 一星到七星
- **积分系统**: 完成公会任务获得积分，积分越高等级越高
- **徽章加成**: 等级越高的冒险者徽章，属性加成越高
- **钱庄业务**: 存钱取钱，年化30%利息
- **会长徽章**: 佩戴后成为星辰王国冒险者公会会长，可自行经营

### 1.2 钱庄系统
- **利息**: 年化30%（林天浩高额利息被动支持）
- **业务**: 存钱取钱
- **竞争对手**: 蒂雪涧一系管理的钱庄（年化1%-5%）
- **收益**: 林天浩一天含泪血赚1500万金币

### 1.3 净化玉佩进化
- **第一次进化**: 免控85%→88%
- **第二次进化**: 免控88%→90%
- **进化卷轴**: 已使用2张

### 1.4 火神祝融赐福·天火流星
- **类型**: 被动，1星
- **效果**: 攻击有1%概率触发天火流星，一千枚天火流星从天而降，方圆百米每枚相当于一次普攻伤害
- **消耗**: 无
- **冷却**: 无
- **熟练度**: 0/100（触发一次为一点熟练度）

### 1.5 死亡轮回升星
- **升星**: 2星→3星
- **触发概率**: 1%→1.5%

### 1.6 光暗之书
- **效果**: 可以自主关闭和开启被动技能
- **用途**: 叠加生命值时关闭被动技能，战斗时开启

### 1.7 旱魃的故居副本

- **格局**: 跟雪尸的足迹相似，但到处都是滚烫的岩浆
- **进入方式**: 副本移动之门

### 1.8 发丘天官
- **身份**: 眼镜获得发丘印，成为发丘天官
- **能力**: 盗墓，从古墓中带出珍贵物品
- **层次**: 发丘不出，摸金为王，层次在摸金校尉之上

### 1.9 等级榜
