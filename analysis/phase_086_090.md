# 《诸神黄昏》设定提取 - 第86-90章

## 一、基础设定

### 1.1 弑神者印记
- **等级**: 神级
- **效果1**: 不受神威影响
- **效果2**: 每击杀一位神灵，可剥夺其一种力量
- **当前效果**: 对冰雪系伤害及负面效果免疫（诛杀冰雪女神）
- **获取方式**: 完成李村长任务，获得弑神者印记绑定
- **绑定特性**: 一旦绑定不可抹去，会受到西方众神仇视

### 1.2 东方古国历史
- **历史背景**: 东方古国被西方众神封印于皑皑白雪之下
- **弑神事件**: 曾有冒险者以凡人之躯斩杀冰雪女神，惹怒众神
- **神灵内战**: 东方神灵在很久很久以前发生内战（疑似巫妖量劫）
- **世界变化**: 现在所在大陆不及当时洪荒世界的亿分之一

### 1.3 成神之道
- **香火成神**: 依靠他人信奉获得香火之力
- **功德成神**: 依靠自己善举获得功德
- **悟道成神**: 领悟一种道到极致，诞生对应道的神格
- **封天成神**: 新的成神之道，"天作棋盘星作子，封天成神"

### 1.4 凡殿
- **建筑风格**: 大夏古代庙宇风格，比普通庙宇恢弘大气
- **牌匾文字**: "凡殿"
- **石柱文字**: "神无道，仙无德，凡人苦。向天战，弑神生，铸不朽。"
- **作用**: 弑神将军的宫殿，压制神威

### 1.5 岩浆通道
- **环境**: 岩浆与白雪共存，中间有一条漆黑带血色纹路的道路
- **特点**: 岩浆区域没有怪物，冰雪女神从岩浆中漂浮而出
