# 第1651-1655章 设定分析

## 基础设定

### 场景与势力
- **七号矿坑**：本段剧情主要发生地，为绝矿老魔的地盘。矿坑中大部分矿石已被取走，但残留矿石仍为天文数字，七号矿坑外有大量晶矿魔人活动。
- **天宫**：更大范围的场景，据绝矿老魔所述，天宫之中超神级天赋觉醒石数量不下十枚。
- **晶矿魔人**：原本是活生生的人，被绝矿老魔转化同化而成，受其控制，可被指挥作战。
- **水中花妖族群**：七号矿坑内存在数量不在少数的水中花妖。

### 主要人物
- **林天浩**：主角，拥有多种超神级天赋，法则层次为冰之道境第十九层并已掌控异象，可展开十六种圣人异象。自评"圣人之下无敌"略有夸张。
- **绝矿老魔**（魁梧壮汉）：七号矿坑晶矿魔人之主，拥有规则之力与位移手段，可短暂赋予他人一刻钟法则之力。
- **水火魔女**（红裙女人/水中花妖本体/老妖婆）：水火双属性的超级邪族，外观为身着红色长袍、淡蓝色卷发女子。
- **林天浩奴仆**：黑天傲真（返祖黑龙，跟随最久）、黑暗天使、九幽之主、冥王白小风等。

### 天赋觉醒机制
- **超神级天赋觉醒石**：外观为半透明石头，无法直接查看属性；对于天赋过高者，仅能觉醒部分天赋（林天浩第二枚仍无法完全觉醒）。
- **天赋等级体系**：存在天道级及天道级之上的层级（林天浩推测）。
- **觉醒提示流程**：使用后会有"是否确实"确认提示，确认后天赋开始觉醒。

## 属性系统

### 基础属性类型
- 生命值
- 护甲
- 魔抗
- 火属性抗性
- 水属性抗性
- 欲火抗性
- 自由属性点
- 经验值

### 吞天噬地获得的具体属性数值
| 吞噬对象 | 属性提升 |
|---------|---------|
| 石块 | 生命值+1，护甲+1 |
| 炎铁矿 | 火属性抗性+15，生命值+500，护甲+50，魔抗+10 |
| 天品觉醒石 | 生命值+100万，护甲+1000，魔抗+500，自由属性点+10000 |
| 无名欲火 | 魔抗+500万，欲火抗性+50000，自由属性点+50万 |
| 火焰（每单位） | 火属性抗性+100，魔抗+500，自由属性点+500 |
| 水火魔女（击杀） | 经验值+99万亿，自由属性点+9900万 |
| 水火魔女（吞噬） | 生命值+1398亿，魔抗+2000万，水属性抗性+1000万，火属性抗性+1000万，自由属性点+2000万 |

### 数值规模
- 林天浩启用吞天噬地一分钟内，生命值增加十几亿。
- 吞噬品阶越高，获得的属性越多。

### 法则与道境层次
- **冰之道境第十九层**：林天浩的法则层次（实际高于此，未对绝矿老魔说实话）。
- **法则之力/规则之力**：神级以上层次才可动用，凡人境无法使用。
- **圣人异象**：林天浩可展开十六种；罗天之主在凡人境掌握圣人异象，其他生灵多在神王、神魂层次掌握。

## 装备系统

### 觉醒石类
- **超神级天赋觉醒石**：半透明石头，无法直接查看属性；绝矿老魔手中这枚为其孕养多年，使用者会沦为奴仆。天宫中超神级觉醒石不下十枚。
- **天品觉醒石**：可被吞噬，吞噬后获得生命值+100万，护甲+1000，魔抗+500，自由属性点+10000。

### 矿石类
- **炎铁矿**：吞噬后获得火属性抗性+15，生命值+500，护甲+50，魔抗+10。
- **晶矿**（绝矿老魔留下的）：使用后会受绝矿老魔掌控，是晶矿魔人的转化来源；超神级天赋觉醒石也属于此系列的孕养之物。

### 特殊道具
- **墨绿色水晶**（绝矿老魔持有）：催动后可让他人短暂使用一刻钟（15分钟）法则之力，让各种道的掌控全部回归。仅能使用一次。
- **羽箭**（林天浩的"箭由心发"技能产物）：可大量倾泻，普通晶矿魔人无法招架，可轻易被击杀。

## 技能系统

### 林天浩技能
- **吞天噬地**（天道级天赋，第1652章觉醒）
  - 效果：天地万物皆可吞噬，且能够在极短时间内炼化吸收，以增加实力；可笼罩方圆百里，包括生灵。
  - 消耗：无
  - 冷却：无
  - 熟练度：不可升星
  - 不可升星
  - 限制：需要肺部功能正常才能使用（肺部石化时无法使用）。
- **箭由心发**：以心脏为发动条件，需要心脏功能正常。石化状态下心脏恢复后方可使用。
- **十六种圣人异象**：展开后可碾压七号矿坑范围。
- **冰之道境**（第十九层及以上）：法则之力，需在能使用法则的环境下发挥。

### 绝矿老魔技能/规则
- **晶矿奴役规则**：使用其留下的晶矿者会受其控制；可下达指令操控中招者。表现为身体僵硬、脑子石化、全身长出赤红色晶石。
- **位移手段**：可瞬移消失，但位移规则可被识破。
- **规则之力**：可让敌人身体变沉、动作变慢；存在使用限制，被围攻时难以招架。
- **法则赋能**：通过墨绿色水晶让他人短暂获得一刻钟法则之力。

### 水火魔女技能
- **水属性规则之力**：将敌人拉入水中，使其窒息。
- **火属性规则之力**：将敌人拖入火海，伤害远超窒息（对无法使用法则者是死局）。
- **欲火攻击**：声音平淡即可让目标心中升腾火焰，难以压制。
- **火海领域**：可制造火海包围敌人。
- **火遁逃窜**：身体被火焰包裹化作流光逃窜。

### 奴仆战斗特性
- **黑天傲真**（返祖黑龙）：肉身力量极强，寻常神灵也不愿硬扛其拳头；跟随林天浩最久，感情最深。
- **黑暗天使、九幽之主**：体魄强横，不能使用规则之力时仍可用拳脚作战。
- **奴仆指令系统**：林天浩失去意识前下达的最后指令会被奴仆持续执行，直至新指令覆盖或林天浩恢复。

## 怪物系统

### 水火魔女（水中花妖本体）
- 类型：水火双属性的超级邪族（超级邪族级别BOSS）
- 外观：红裙女人，面容精致，淡蓝色卷发
- 强项：火属性规则之力（胜于水属性）
- 弱点：吞噬类技能可克制其火海；被绝矿老魔的墨绿色水晶赋能法则之力后会被秒杀
- 击杀奖励：经验值+99万亿，自由属性点+9900万
- 吞噬奖励：生命值+1398亿，魔抗+2000万，水属性抗性+1000万，火属性抗性+1000万，自由属性点+2000万

### 晶矿魔人
- 来源：原本为活人，被绝矿老魔转化
- 数量：七号矿坑内有大量，方圆百里内可被吞噬干净
- 战斗力：可使用规则之力（范围小于方圆百里）
- 规则效果：让敌人身体变沉、动作变慢
- 弱点：对羽箭无法招架，轻易被击杀；可被吞天噬地直接吞噬

### 水中花妖
- 普通族群，数量不在少数，被水火魔女同化

## 副本系统

### 七号矿坑
- 类型：天宫内的矿坑场景（绝矿老魔领地）
- 难度特征：内部无法使用法则之力（需借助墨绿色水晶方可短暂使用一刻钟）
- 主要敌人：水火魔女、晶矿魔人、水中花妖族群
- 资源产出：超神级天赋觉醒石（绝矿老魔孕养）、晶矿、炎铁矿、天品觉醒石、各类散乱矿石
- 通关关键：在能使用法则之力的15分钟内击杀水火魔女

## 战斗系统

### 战斗规则
- **法则之力限制**：七号矿坑内通常无法使用法则之力，需借助外部道具（墨绿色水晶）才能短暂使用一刻钟。
- **规则之力对抗**：规则之力可对敌人产生压迫、减速、僵硬等效果；不同规则的覆盖范围不同（吞天噬地方圆百里 vs 晶矿魔人规则不及方圆百里）。
- **抗性机制**：火属性抗性、水属性抗性、欲火抗性等可对应削减伤害；高抗性可让对应属性攻击完全失效（林天浩身处火海却伤不到分毫）。
- **吞噬克制**：吞天噬地可吞噬敌方攻击（如欲火、火焰、火海）、敌方本体及敌方手下。
- **体魄战斗**：不能使用规则之力时，体魄强度成为主要战斗力（黑天傲真、黑暗天使的体魄强横）。
- **位移识破**：位移规则可被多次战斗后摸透，从而预判拦截。

### 击杀与吞噬收益
- 击杀BOSS获得经验值与自由属性点奖励。
- 吞噬BOSS本体获得生命值、抗性、自由属性点等额外收益（数值远超仅击杀）。
- 吞噬量越大、品阶越高，收益越高。

## 特殊机制

### 晶矿奴役机制（绝矿老魔的规则）
- **触发条件**：使用绝矿老魔留下的晶矿，或使用其孕养的超神级天赋觉醒石。
- **中招过程**：
  1. 身体僵硬，动弹不得
  2. 脑子被神秘力量侵蚀，反应迟钝
  3. 皮肤下出现鼓包，逐渐变大
  4. 脑子完全变成赤红色晶石
  5. 全身（手臂、大腿、腹部、后背、脸、脑袋）长出赤红色晶石，眼眸也变为赤红色晶石
- **控制方式**：绝矿老魔可对中招者下达指令。
- **特性**：中招者即使意识消失，最后下达的指令仍会持续执行（奴仆系统）。
- **解除方法**：击杀施术者（绝矿老魔）。

### 神秘寒气（林天浩体内）
- **特性**：林天浩无法主动掌控，但总是在关键时刻自行发动。
- **作用**：可解除石化状态，恢复脑子、心脏、五脏六腑（肺部）等功能。
- **恢复顺序**：脑子（天灵盖）→心脏→肺部。
- **恢复效果**：意识恢复、可使用箭由心发、解除窒息感、可再次使用吞天噬地。
- **历史**：此前已多次救林天浩于危难。

### 奴仆指令系统
- 林天浩的奴仆在林天浩失去意识后仍执行其最后指令。
- 新指令需林天浩恢复后下达方可覆盖。
- 奴仆可自主判断局势，以伤换伤、不计代价执行指令。

### 短暂法则赋能机制
- 通过墨绿色水晶催动，可让目标在一刻钟（15分钟）内能够使用法则之力。
- 各种道的掌控全部回归。
- 仅能使用一次。
- 限制：若不成功，施术者在七号矿坑的日子不会好过。

### 吞噬品阶与收益关联
- 吞噬品阶越高，获得的属性越高。
- 吞噬对象包括：矿石、觉醒石、火焰、欲火、生灵本体等。
- 吞噬范围方圆百里，可覆盖生灵。
- 持续吞噬可使各项属性飞速提升（坐火箭般提升）。
