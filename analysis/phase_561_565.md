# 第五百六十一章至第五百六十五章 设定分析

## 一、基础设定

### 1.1 林天浩破局策略设定
- **策略**：劝说镇北十城撤离，承诺帮助出海建立政权和商贸，互通有无
- **目的**：避免大战，阻止杀戮之神复苏，同时为自己争取出海寻找祖神遗宝和破解无尽杀戮的机会
- **手段**：签订契约，发布全国悬赏清理海外岛屿

### 1.2 杀戮之神复苏条件设定
- **普通军队**：一亿起步才能让杀戮之神复苏到能动用无尽杀戮的地步
- **普通百姓**：十亿起步
- **领域强者**：几百万领域强者差不多
- **彻底复苏**：需要两百亿百姓交代，月轮帝国两百三十亿百姓至少要交代两百亿

### 1.3 无尽杀戮限制设定
- **目标限制**：只能对一人使用
- **最佳目标**：雪帝（林天浩）
- **月轮魔宫计划**：请雪帝入局，借雪帝之手屠尽十方，达到数十亿乃至百亿屠戮量

### 1.4 希图帝国来犯设定
- **规模**：三百万大军
- **目的**：并非真支援月轮帝国，而是来找事，想要独吞月轮帝国利益
- **借口**：指责林天浩当初说好合作进攻月轮帝国，如今想独吞

### 1.5 地缺商帮常水泱设定
- **身份**：地缺商帮帮主，宗师品阶，半神
- **态度**：公开支持林天浩，揭露希图帝国和浩渺帝国的阴谋
- **情报能力**：强大，知道杀戮之神的秘密，知道月轮克玄的谎言

### 1.6 常水泱揭露真相设定
- **杀戮之神复苏后首要目标**：不是对付林天浩，而是去做某件事
- **复苏状态**：刚刚复苏的虚弱状态无法做成那件事，需要满状态或接近满状态
- **满状态条件**：月轮帝国两百三十亿百姓至少交代两百亿
- **结论**：杀戮之神复苏后唯一选择是主动登上封神榜，成为林天浩的神王

### 1.7 修德里·浩鸿出现设定
- **身份**：浩渺无极宫宫主
- **目的**：带领浩渺帝国三百万大军来帮助月轮帝国，促成杀戮之神复苏
- **态度**：坚信杀戮之神会对林天浩动用无尽杀戮

### 1.8 月轮克玄反水设定
- **行动**：捏碎传音符，调遣大军进攻浩渺帝国
- **理由**：浩渺无极宫底蕴大不如前，趁机进攻
- **真正目的**：引浩渺帝国和希图帝国大军来此，让浩渺帝国边防空虚，趁机进攻

### 1.9 月轮克玄自称凡殿月字派设定
- **身份**：凡殿月字派成员
- **历史**：老殿主在尘封前留下天地日月四个分派，暗中积蓄力量寻求机会
- **师承**：老殿主师承杀戮之神，杀戮之神反对东西方之争，帮助凡殿
- **月轮魔宫西方神灵**：支持西方的神灵已被解决，主动送杀戮天使上封神榜

### 1.10 图图鲁圣山设定
- **身份**：凡殿地字派
- **实力**：堪比浩渺无极宫的强大圣地
- **行动**：洪穹大人开始进攻浩渺帝国
- **关联**：在背后支持月轮魔宫

### 1.11 林天浩怀疑设定
- **疑点1**：前世从未听过凡殿所谓的日月天地四个字号
- **疑点2**：若两大圣地联手复苏凡殿，前世凡殿一定会复苏
- **疑点3**：上官虹旬、欧阳纹龙等人不知道这四个字号
- **疑点4**：凡殿之主之前未提前告知

### 1.12 常水泱证实设定
- **月轮克玄谎言**：编造天地日月四个字号，欺负林天浩是冒险者对凡殿不了解
- **真实目的**：拉山海帝国对付浩渺帝国和希图帝国，打下后对林天浩动用无尽杀戮，联合图图鲁帝国覆灭山海帝国
- **图图鲁圣山野心**：一直不甘心在海外，试图登上浩渺大陆建立帝国
