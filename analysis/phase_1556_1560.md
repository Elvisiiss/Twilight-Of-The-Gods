# 第1556-1560章 设定分析

> 基于第1556章《发疯的神魂！》、第1557章《盘古秘术，强行灌顶！》、第1558章《盘古一族强者的善意！》、第1559章《三十六神纹！》、第1560章《湮灭之风！》提取整理。

## 基础设定

### 世界观背景
- **盘古一族设定**：盘古一族在三千年神魔之中是独一档的存在，被族人尊称为"祖神"。
- **盘古一族特性**：没有神魂，正因为没有神魂，眼睛看到的东西更真切、更纯粹。盘古一族的修炼之法并非秘密，连尼德栗芙这种与盘古一族打交道不多的人都知道大概（不详细但大致了解）。
- **巫族由来**：盘古死亡之后，其精血后裔化作祖巫，即巫族。巫族独特之处在于没有神魂。
- **盘古秘术本质**：盘古一族的炼体秘术。修炼需要神魂支撑，但有神魂的躯体经不住盘古秘术的炼制——存在先天矛盾。

### 主要地点
- **不周古地 / 不周圣地**：故事主要发生地，藏有超神级隐藏职业转职祭坛，盘古一族强者驻守于此。
- **域外之地**：九幽通道之外的区域，茫茫戈壁滩地貌。
- **九幽之地**：通过九幽通道进入，原被"万鬼"（疑为规则系怪物）阻挡，是探索目标之一。
- **天宫**：与九幽并列为追求极致力量之地，目前难以寻找。
- **云巅世界**：另一处可闯荡之地。
- **银河世界**：主角不愿放弃的世界，与闯荡星空构成二选一抉择。
- **平行世界**：主角曾因遇到城镇类组合怪物意外去到。

### 重要事件 / 节点
- **灾变降临**：未来事件。届时盘古一族强者会在不周古地等候主角三个时辰（一时辰=2小时），可带其横渡星空。
- **超神级隐藏职业转职祭坛修复**：需运送最后一根不周神铁，最少三个月（后文中提到还剩两个半月）。

## 属性系统

### 生命力（HP）
- 主角拥有极高的生命力，但盘古一族强者指出其生命力是"空的"，并未蜕变成体魄的强横——属于"虚"的生命力。
- 强横体魄应包含：身躯防御、速度、体能等诸多方面，单看生命力无法等同炼体士的强横身躯。
- 生命力难以再完成品阶提升（盘古一族强者语）。

### 灵魂力
- 主角被怪物强行灌顶后灵魂力暴涨，数值变化过程（呼吸之间）：
  - 60亿 → 80亿 → 突破百亿大关 → 120亿 → 140亿 → 160亿 → … → 最终提升到 **三百亿**。
- 主角实际能吸收的不足怪物灌顶灵魂力的十分之一，但已是"一场造化"。
- 灵魂力实实在在增强了神魂，与"虚"的生命力形成对比。
- 灵魂力提升带来的压力远超体魄提升——主角需动用力之大道强行镇压神魂于体内，否则神魂将离体而出。
- 成神后，神魂与体魄不平衡的问题自然能够解决。

### 自由属性点
- 击杀神秘怪物单次获得：**自由属性点 +100万**。
- 半个月猎杀 80+ 只怪物，共获得 **6000万自由属性点**（注：原文数值，与单次奖励×数量理论值不完全对应）。

### 属性外增益
- 修炼盘古秘术后，身躯增强**不在属性面板上体现**，但实际存在以下提升：
  - 反应速度大幅提升。
  - 被怪物攻击时承受的冲击力随修炼不断降低。
  - 身躯更加坚韧，体魄爆发的力量、速度更强大。
  - 五感增强，可感受规则之力的波动（常规神识和洞察之眼无法观测规则之力）。

## 装备系统

### 武器 / 道具
- **修罗神剑**：主角主武器，可被主人召唤回手中；可用来斩开怪物神纹防御。
- **刻刀**：刮神纹的最佳工具，类似"作弊器"，可轻易破开怪物防御；主角曾用其刮怪物神纹。
- **昆仑镜**：可用来在域外之地与九幽通道外穿梭。
- **不周神铁**：修复超神级隐藏职业转职祭坛的关键材料，盘古一族强者扛运。
- **神符楼**：青牙鬼煞的本命重宝，可变大、可吸入小型规则之力引动的沙尘暴。

### 神纹系统
- **力之神纹（神品）**：
  - 类型：神纹图纸。
  - 使用要求：神纹师。
  - 效果：观之力之神纹，可学习力之神纹。
  - 耐磨度：不可摧毁。
- **神纹师**：灵符师之上的职称，对应神灵之境。主角当前境界即使学习也几乎不可能成功。
- **神纹图纸收集**：半个月共获得 82 张神纹图纸（含重复），去重后共 **36 种神纹图纸**。
- **怪物身上神纹**：可亮起阻挡攻击、可治愈自身伤口；承受攻击或治疗自身时都会暗淡下去；被刮掉时连带血肉肌肤一起被刮下。

## 技能系统

### 主角技能
- **修罗神剑**：武器技，斩击敌人。
- **虚空的归途**：强行把已经离开的目标拉回来（无反应时间即可追击）。
- **力压山河**：使目标身形猛然一沉，压制效果。
- **空间禁锢**：以空间之道禁锢目标。对该怪物无效（疑因本源法则或神纹过强）。
- **箭由心发**：远程羽箭覆盖射击；羽箭受水火本源法则之力影响降低威力，但持续射击仍有效；可附带天罚锁头探查规则之力。
- **神魂至尊**：将神魂汇聚为流光撞击进入目标脑海；施展后神魂战斗力 **提升三倍**；可在敌方神魂中战斗。
- **绝对格挡**：可挡住规则之力攻击。
- **无敌虚化**：可挡住规则之力攻击。
- **三头六臂**：形态技，开启后增强战斗。
- **天锁头 / 天罚锁头**：规则之力，可锁定目光所及最远目标；可与寻常规则之力相互抗衡；附于羽箭可探查规则之力存在。
- **邪剑仙形态**：形态切换。
- **天雷地火**：攻击技，滚滚不绝。
- **行走虚空 / 空间之道**：空间移动手段，但禁空规则下无法脱困。

### 怪物传授的盘古秘术
- **修炼条件**：
  - 神魂与身躯必须匹配。盘古秘术太过强大，凌驾于亿万体修之法上，光修神魂难以维持平衡。
  - 需要新的力量维持平衡——即 **力之大道**。以力之大道平衡神魂与身躯，方得大道。
  - 怪物建议：散功重修力之大道，至少追求 **14层之上** 方可修炼盘古秘术。
- **修炼流程**：
  - 铭刻神纹之前都有回头路可走。
  - 铭刻神纹前，只要灵魂力足够强大，就不会发生意外，身躯会愈发强横。
  - 修炼用素材：心头血（窃贼/怪物心头血效果优于大部分凶兽；太古黑龙、不死神鸟精血亦是助力）。
- **失败后果**：神魂意志崩塌，身躯不受控制，变成人不人鬼不鬼的怪物；最后关头刮掉大量神纹可获得一丝清明（如本怪物）。
- **精血炼体**：吸收太古黑龙 3 滴精血、不死神鸟 3 滴精血；身躯变化不在属性上体现。

## 怪物系统

### 神秘怪物（修炼盘古秘术失败者）
- **外形**：浑身血肉模糊，神纹残缺不全（多为自行刮除或让他人刮除），面目狰狞，血淋淋，狰狞恐怖。
- **神魂**：灰白之色，面目狰狞，完全失去理智，癫狂状态。
- **能力**：
  - 空间穿梭（可遁走）。
  - 神纹防御（亮起阻挡攻击）。
  - 神纹自愈（伤口肉眼可见恢复，但神纹会暗淡）。
  - 体魄极为强横。
- **弱点**：神魂不算强大；神纹暗淡时理智逐渐恢复。
- **掉落**：力之神纹 +1、自由属性点 +100万、金币 +1亿（首次被主角击杀的怪物掉落，全服通告）。
- **自杀与击杀区别**：自杀被击杀无全服通告；被主角击杀有全服通告（玩家"雪帝"），可摸尸。
- **数量分布**：往西方向有不少同类怪物，半个月内被击杀 80+ 只后数量骤减。

### 规则系怪物 / 规则系生命体
- **特性**：
  - 无形无色，常规神识和洞察之眼无法观测。
  - 修炼盘古秘术后的五感可感受其波动。
  - 大部分规则之力是无差别的。
  - 可被天罚锁头探查，无法与天罚锁头对抗的会主动离开。
  - 可引发现象：空间回溯、禁空、沙尘暴等。
- **奴役规则系怪物**：
  - 生命存在体独特的难以奴役。
  - 直观可观察的生命体奴役概率较大。
  - 实力足够皆可奴役；需将灵魂本源法则领悟到一定境界方有用。
- **聚集地**：九幽通道外的戈壁滩聚集大量规则系生命体，可能与九幽之地的绝世至宝有关（至宝对规则系生命体有滋养作用，久居可能进阶）。

### 规则之力类型
- **空间回溯规则**：踏足某地点后，被传回之前待的地方（主角从九幽通道外被传回不周圣地）。
- **禁空规则**：禁止飞行，身体会下沉入泥沙；可凭强横体魄硬生生带飞出来。
- **沙尘暴规则**：由小型规则之力引动，可被神符楼吸入。
- **湮灭规则**：苍老难听声音操控；风过之处岩石尽皆化作灰飞；可使天罚锁头羽箭剧烈颤抖后溃散；"规则之力的强弱，从不是品阶能够决定"；在青牙鬼煞生活的时代都算非常强；表现为"尘归尘，土归土，一切不过是虚妄，一切本该消亡"。
- **天罚锁头规则**：主角的规则之力，霸道；理论上寻常规则之力难以与之抗衡。

### 神兽级存在
- **黑天傲真**：太古黑龙，神兽级存在，体魄极为强横。
- **不死神鸟**：神兽级存在，体魄极为强横。
- **青牙鬼煞**：规则系生命体，神品之境，是银河世界历史长河中极少几位神品之境的规则系生命体之一；本命重宝为神符楼。

## 副本系统

### 不周古地
- 驻守：盘古一族强者（在地底）。
- 资源：超神级隐藏职业转职祭坛（待修复，需不周神铁，3个月周期）。
- 怪物：大量修炼盘古秘术失败的怪物（窃贼），可取心头血修炼盘古秘术。
- 离开后向西方可继续遇到同类怪物。

### 九幽之地 / 九幽通道
- 入口：域外之地茫茫戈壁滩的尽头。
- 阻挡：万鬼（疑为规则系怪物）阻挡通道。
- 探索收益预期：绝世至宝（对规则系生命体有滋养作用）；强横身躯很有用。
- 难点：禁空规则、空间回溯规则、沙尘暴规则、湮灭规则等多重规则之力阻路。
- 历史背景：九幽之地当初十分强盛。

## 战斗系统

### 战斗节奏
- 武器切换：修罗神剑 ↔ 刻刀，根据目的切换（练技巧用剑，快速刮神纹用刻刀）。
- 多人协作：黑天傲真 + 不死神鸟前后夹击；主角以空间之道辅助禁锢；箭由心发持续输出。
- 神魂战：神魂至尊进入对方脑海，以 3 倍神魂战斗力压制对方神魂。

### 伤害表现
- 修罗神剑斩腹部：深可见骨剑痕，流淌猩红血液；神纹亮起阻挡，主角拼尽全力可破。
- 修罗神剑斩肩颈：砍入脖子三分之一位置才被神纹锁住。
- 怪物反击：一拳将主角打飞。

### 战斗机制要点
- 神纹承受攻击或治疗自身都会暗淡，是判断怪物状态的关键。
- 怪物空间穿梭可逃跑，但虚空的归途可强行拉回。
- 修炼盘古秘术后，体魄增强虽不体现在属性上，但实战中反应力、抗冲击力明显提升（多次在关键时刻避开并反击）。
- 选用刻刀破防效率极高，数个回合即可击杀怪物。

### 规则对抗
- 规则之力之间可相互抗衡（天罚锁头 vs 寻常规则之力）。
- 不可强行对抗的规则（湮灭规则）需谨慎应对。
- 主角可用绝对格挡或无敌虚化挡住规则之力攻击。

## 特殊机制

### 转职祭坛
- **超神级隐藏职业转职祭坛**：位于不周古地，需不周神铁修复，最短三个月。盘古一族强者在灾变降临后才能离开此地，即使修复完毕也不能离开，必须等灾变到来。

### 全服通告
- 击杀怪物触发：提示"恭喜你，成功击杀了神秘怪物，即将进行全服通告，是否隐藏姓名？"（可选"否"）。
- 通告内容示例："全服通告，恭喜玩家雪帝成功击杀神秘怪物，特此通告，望广大冒险者再接再厉！！"
- 自杀型怪物不触发全服通告，仅被玩家击杀者可摸尸。

### 神魂与体魄平衡机制
- 体魄过强 → 神魂跟不上 → 不平衡 → 神魂意志崩塌 → 身躯失控变怪物。
- 反之亦然：神魂过强 → 体魄跟不上 → 不平衡（怪物强行灌顶主角灵魂力暴涨验证此机制）。
- 平衡力量：力之大道（建议散功重修至 14 层以上）。
- 主角特殊性：拥有力之大道傍身，理论上可修炼盘古秘术。

### 传承 / 灌顶机制
- 怪物抬手一指点向眉心，可传递记忆（盘古秘术修炼法）。
- 强行灌顶：怪物将自身灵魂力灌入主角脑海，灵魂力暴涨至三百亿（实际吸收不足十分之一）。
- 灌顶目的：怪物试图让主角踏上修炼盘古秘术之路，验证其理论（将主角当小白鼠）。

### 精血炼体机制
- 神兽级存在（太古黑龙、不死神鸟）各祭出 3 滴精血。
- 运转盘古秘术吸收精血，身躯发生玄之又玄的变化。
- 变化不在属性面板体现，但身体感受实实在在。

### 心头血机制
- 取怪物心头血可用于修炼盘古秘术，效果优于大部分凶兽血。
- 窃贼心头血尤其有效。

### 体修职称体系
- 灵符师 → 神纹师（对应神灵之境）。
- 神纹师可学习神纹图纸上的神纹。

### 力之大道层级
- 建议散功重修至 **14层之上** 方可修炼盘古秘术。
- 主角当前力之大道"有成"，但"底蕴不足"。

### 灾变与横渡星空
- 灾变降临后，盘古一族强者在不周古地等候主角三个时辰，可带其横渡星空。
- 主角面临抉择：放弃银河世界去闯荡星空 vs 留在银河世界探索。

### 修炼资源获取路径建议（盘古一族强者）
- 不周古地往西：猎杀怪物取心头血修炼盘古秘术。
- 追求极致力量：去九幽和天宫，去云巅世界。
- 无法领悟此地本源法则之力（主角无法领悟不周古地本源法则），若能领悟对探索其他地方有意想不到的帮助。
