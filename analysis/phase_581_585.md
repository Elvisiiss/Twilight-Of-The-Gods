# 第五百八十一章至第五百八十五章 设定分析

## 一、基础设定

### 1.1 天罚护心镜设定
- **类型**：天罚弓箭手装备
- **佩戴要求**：天罚弓箭手
- **效果1**：天罚攻速+1，不受攻速阶段性削减影响（天罚攻速从4.86提升到5.86）
- **效果2**：百分比减伤5%，对神灵级攻击依旧有效
- **效果3**：能够阻挡一次致命攻击，冷却时间一小时
- **效果4**：幸运+10
- **效果5**：心境通明，悟道速度+10倍
- **效果6**：最大生命值增加50%（从十八亿突破二十七亿）
- **效果7**：最大护甲增加50%
- **效果8**：最大魔抗增加50%
- **效果9**：绝对格挡（主动释放，可格挡接下来一秒降临在身上的所有伤害，格挡效果绝对成立，神灵级攻击仍然会被格挡，冷却时间一个小时）
- **耐磨度**：不可摧毁，佩戴后不可盗取，不可掉落
- **来源**：小小囚的东西，从一个去过龙凤仙岛的老人身上掠夺来的

### 1.2 船长安德烈仲斯设定
- **身份**：魔腾鬼船船长
- **目的**：寻找龙凤仙岛，获得传承
- **手段**：抓住小小囚，从他口中得知龙凤仙岛消息，用他的血液炼药
- **行为**：带一百万人出海，准备将他们当成祭品

### 1.3 小小囚真相设定
- **身份**：苦海囚心，海神波塞冬的一道分身，神灵级
- **伪装**：七岁孩子，恶魔之子，拥有仙凤血脉
- **目的**：饲养诡异，缔造魔腾鬼船
- **手段**：说出上龙凤仙岛需要很多人，让安德烈仲斯准备祭品；暗中帮助安德烈仲斯抓住囚海死女，进行一系列操作让她诡异化

### 1.4 囚海死女真相设定
- **身份**：王级，2359级，苦海囚心饲养的诡异
- **诡异化原因**：被安德烈仲斯抓住，遭受非人的折磨，被苦海囚心进行一系列操作后诡异化
- **实力**：诡异化后成为皇级，百万亿生命值，拥有诡异规则护佑
- **主人**：原本是苦海囚心，海神波塞冬融合苦海囚心后成为海神波塞冬的主人

### 1.5 海神波塞冬分身设定
- **能力**：全盛时期可一分为七，化作七尊神灵，散于天地各处
- **实力**：神王中的佼佼者，全盛时期在海上可单手镇压十个杀戮之神
- **现状**：融合一具分身（苦海囚心）后，品阶从二品提升到三品，实力快速恢复

### 1.6 仙凤血脉设定
- **拥有者**：小小囚（苦海囚心）
- **作用**：囚海死女升品的必要条件，吸收后从王级进化为皇级
- **来源**：龙凤仙岛

### 1.7 龙凤仙岛设定
- **位置**：落星海域，距离大陆数十万海里
- **内容**：拥有两大神级传承，小小囚的故乡
- **传说**：米国一批人去过，好几个得到神级传承
- **天罚装备来源**：天罚护心镜是从一个去过龙凤仙岛的老人身上掠夺来的

### 1.8 天罚弓箭手二转设定
- **条件**：佩戴天罚护心镜
- **技能**：伤害转移（不可升星）
- **伤害转移效果**：可将承受的百分之九十的伤害转移给一个羁绊单位，冷却半个月，消耗无
- **羁绊范围**：可以绑定见到过的任何存在，包括浩渺无极宫的神灵、修德里·白芸、图图鲁·洪穹等，无需征得同意，可强行绑定

### 1.9 伤害转移应用设定
- **策略**：绑定海神波塞冬，利用他的回血能力转移伤害；绑定敌对势力成员，让海神波塞冬攻击自己，转移伤害击杀对方
- **伤害计算**：林天浩二十七亿生命值，在海洋中可秒回满血，转移百分之九十伤害出去，被转移对象每秒掉两百四十三亿生命值

### 1.10 超神级隐藏职业转职祭坛设定
- **位置**：古朝秘境
- **功能**：进行超神级隐藏职业转职
- **效果**：转职时光柱从天而降，身体被不断改造提升
