# 第1311-1315章 设定分析

## 基础设定

- **主角身份**：林天浩（雪帝），具有龙族血脉传承，肉身体魄强横。
- **世界背景**：诸神黄昏游戏世界，存在领地、兵巢、职业者等设定。
- **墨渊副本结构**：多层空间结构，本段涉及第七层、第八层、第九层。
  - 第七层：疯人院，由疯王守护，擎天大圣（妖族强者）所在。
  - 第八层：巨大圆形石室，孤王宫所在，魔化护卫驻守。
  - 第九层：可绕过孤王直接前往，但击杀孤王可获得"醍醐灌顶"大幅增幅。
- **下层层机制**：击杀疯王后三个小时，穿过房子可去到墨渊第八层；七层到八层需通过沼泽下沉。
- **身份验证机制**：
  - 普通方式：对暗号。
  - 高级方式：窥探灵魂之力（复制人没有灵魂，可通过灵魂判断身份）。
- **复活币机制**：对机械生命有效，对机械物品无效；某些伤害状态（如阴阳双棋之力）连复活也无法化解。
- **入魔机制**：在墨渊中需要定期以雷霆覆盖全身以避免入魔。

## 属性系统

- **基础属性**：气血、内劲、体魄、防御力、感知力。
- **境界表现**：高境界者憋气几十分钟都是小问题。
- **异常状态**：
  - 阴阳颠倒：体内气血逆行，内劲逆转，所有正向循环逆向循环，无法调动内劲，无法使用龙炎等需内劲支撑的攻击。
  - 该状态无法被快速杀死，会持续折磨，最终五脏六腑化作碎肉而死。
  - 死亡与复活均无法化解此状态。
- **玄黄之气**：泰山水牛加持双臂的淡淡黄色光晕，可使气息陡然拔高，拳头力量增强。
- **龙族血脉**：随着血脉不断觉醒，体魄持续增强。
- **感知力**：在沼泽中视线等于零时，依托被压缩到极点的感知力感知危险。

## 装备系统

- **阴阳双棋**：一黑一白两枚棋子，可穿透窗户后消失打入人体内；效果为颠倒阴阳、逆转气息、使气血逆行；死亡与复活均无法化解。
- **龙鳞**：林天浩可周身覆盖龙鳞，大幅提升肉身防御力；叠加铜皮铁骨三星后，连野心道长的雷霆都难以破防。
- **火焰**：林天浩覆盖周身的火焰保护；阴阳颠倒后火焰消失。
- **雷霆之力**：野心道长可操控雷霆覆盖全身或进行攻击；亦用于避免入魔。
- **孤王剑**：林天浩等人在墨渊第五层获得的剑。
- **魔化护卫装备**：魔化护卫自身实力不算太强，但装备对其增幅不小。
- **古代衣服**：林天浩从周小丰处获得的江湖侠客风格衣物。

## 技能系统

### 铜皮铁骨（核心技能详解）

- **品阶**：三品神通（章节中显示）。
- **效果**：提升筋骨皮的防御力，能够显著增强抗击打力。
- **消耗**：无。
- **冷却**：无。
- **升星机制**：
  - 熟练度根据承受攻击计算。
  - 每提升一星，神通品阶同步提升（神通品阶等同于星级）。
  - 升星后防御力大幅增加，相同攻击带来的熟练度大幅下降。
- **升星数据**：
  - 一星 → 二星：约100熟练度（不到1分钟，靠阴阳颠倒+雷霆双重伤害）。
  - 二星 → 三星：明显放缓（3分钟仅提升50熟练度，后续因起身痛苦略加快）。
  - 三星 → 四星：需要10,000熟练度。
  - 四星 → 五星：需要100,000熟练度。
- **防御力增幅**：两次升星后体魄防御力提升大几百倍。
- **特性**：仅增强筋骨皮防御，对自身力量增幅不大；不增强抗击退能力（仍可被踹飞）。

### 其他技能/手段

- **龙炎**：需调动内劲才能使用，阴阳颠倒状态下无法动用。
- **雷霆之力（野心道长）**：可控制力量比例（七成、九成等）；雷霆麻痹全身，在五脏六腑、奇经八脉中游走，造成伤害同时淬炼身体。
- **玄黄之气（泰山水牛）**：加持拳头的强化手段。
- **窥探灵魂之力（楚篮渡等）**：用于辨别复制人与真实身份。
- **金光环绕（野心道长）**：周身金光环绕可加快下潜速度。

## 怪物系统

- **疯王**：第七层疯人院BOSS。
- **裂头蛇女**：疯人院相关怪物，强度不容小觑。
- **魔化生物（经验宝宝）**：智商低，无脑攻击，遇攻击不逃窜。
- **沼泽怪物**：已知道保命逃窜，会因雷霆受惊逃离，与魔化生物行为不同。
- **魔化护卫**：第八层孤王宫驻守，本质为人形副本，有智慧，隶属孤王宫，具备协同作战与未知传讯能力；攻击附带穿透性极强的毒素；自身实力不强但装备增幅显著。
- **魔化护卫队长 / 魔化统领**：当形成规模性战斗且能挡住护卫时出现，更高阶的统领。
- **孤王**：第八层BOSS，比疯王更强，且有手下。
- **复制人**：没有灵魂的复制体。

## 副本系统

### 墨渊第七层（疯人院）
- 由疯王守护。
- 擎天大圣（妖族强者）所在，可考虑复活机械生命。
- 含下棋老头儿（使用阴阳双棋）。

### 墨渊第七层 → 第八层通道
- 通过沼泽下沉进入。
- 沼泽有毒，侵蚀时可为铜皮铁骨提供微弱熟练度。
- 视线等于零，依赖感知力。
- 下潜约5分钟后遇怪物，30分钟后脚下无沼泽坠落入第八层石室。

### 墨渊第八层
- 巨大圆形石室，上方沼泽被无形力量阻挡，身上淤泥不残留。
- 已有人物：楚篮渡（山里人）、泰山水牛、枯岁道姑（夺舍飞升失败者）。
- 核心据点：孤王宫（极为庞大的宫殿）。
- 怪物配置：每一重空间有1,000名孤王宫魔化护卫，另有少量队长、统领等。
- 怪物特性：人形副本，有智慧，协同作战，具备传讯能力，攻击一点会引来其他点支援，挡住后会有魔化统领出现。
- 反抗者势力：第八层另有反抗孤王统治的势力，数量少、力量一般、合作积极性不强。
- 多重空间：墨渊有多重空间，第八层多重空间应有共同连接处（孤王宫）；第五层亦曾有孤王宫。
- 增益奖励：解决孤王宫所有人可获得"醍醐灌顶"大幅增幅，对前往第九层有非常大帮助。
- 可绕过孤王直接前往第九层（但失去增幅机会）。

## 战斗系统

- **协同作战**：魔化护卫具备协同作战与传讯能力，攻击一点会引来多点支援，形成规模性战斗后会出现魔化统领。
- **战术策略**：
  - 斩首行动（理想但难以实现，因孤王比疯王更强且有手下）。
  - 拉锯战 / 声东击西 / 消耗战术：一组吸引兵力，第二组掩护，第三组从其他方向收割魔化士兵。
- **沟通问题**：墨渊中最大问题是无法有效沟通，第三组收割时可能被交代进去。
- **攻击效果细节**：
  - 雷霆：麻痹全身，游走五脏六腑、奇经八脉，造成伤害同时淬炼身体。
  - 拳击：力量冲击震荡五脏六腑，逆行气血翻滚。
  - 穿透性毒素：魔化护卫攻击附带，穿透性极强。
- **承受伤害训练**：林天浩通过承受队友攻击提升铜皮铁骨熟练度。
  - 野心道长九成雷霆5分钟仅增加200多熟练度（消耗内劲近七成）。
  - 尸祖天月一拳增加17点熟练度。
  - 泰山水牛普通一拳增加20+点熟练度；密集连击每拳超过20点；加持玄黄之气后每拳11-12点（四星后）。

## 特殊机制

- **阴阳双棋之力**：颠倒阴阳、逆转气息，无法被死亡或复活化解；可通过提升体魄防御（铜皮铁骨升星）减轻痛苦但无法根除。
- **夺舍**：飞升失败者可夺舍他人躯体重生；需与原身体亲人朋友做了断；道门对此有所抵触。
- **飞升雷劫**：飞升需扛住雷劫，力量不足会失败。
- **入魔避免**：墨渊中需定期以雷霆覆盖全身避免入魔。
- **醍醐灌顶**：解决孤王宫所有人后带来的大幅增幅机制。
- **兵巢招募**：诸神黄昏领地系统，消耗资源从兵巢招募士兵守护领地；孤王宫可类比为领地。
- **领地战**：有兵巢招募士兵的据点攻防战，攻击方人数通常较少。
- **多重空间**：墨渊含多重空间，可能存在共同连接处。
- **石室净化机制**：第八层石室上方无形力量阻挡沼泽，进入后身上淤泥不残留。
- **铜皮铁骨升星衰减**：升星后防御力大幅提升，相同攻击提供的熟练度大幅下降（如泰山水牛普通拳从20+点降至2-3点，玄黄拳从更高降至11-12点）。
