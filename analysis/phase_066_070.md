# 《诸神黄昏》设定提取 - 第66-70章

## 一、基础设定

### 1.1 幽冥一族
- **种族设定**: 幽冥一族是神秘的种族，与王后菲欧丁雨有来往
- **来往目的**: 王后通过幽冥一族获取某种利益或力量
- **秘密威胁**: 暴露王后与幽冥一族的来往会影响王位之争

### 1.2 王位之争策略
- **保护策略**: 陷害蕾欧娜是为了保护她，避免被推上风口浪尖
- **政治平衡**: 在不威胁另外两位公主的情况下展现能力
- **暗中发展**: 有能力才能在暗处拉拢王公贵族
- **三步走计划**: 
  1. 协助清芙芸击溃蒂雪涧
  2. 搞垮王后菲欧丁雨
  3. 蕾欧娜成为新王

### 1.3 公会副会长系统
- **权限**: 可招揽高手加入公会
- **管理**: 协助会长管理公会事务

## 七、战斗系统

### 7.1 战斗机制
- **卡位打法**: 利用boss庞大身躯卡位，躲在视野盲区
- **遮影步**: 精准走位卡视野，让boss无法锁定目标
- **回血压制**: 高恢复能力压制boss伤害，四大恢复效果加持

### 7.2 群体恢复
- **生命女神的眼泪**: 每秒恢复10000生命值
- **嗜血项链**: 每次普攻恢复1%最大生命值
- **九合长弓**: 5%吸血效果
- **复苏技能**: 每秒恢复500生命值

### 7.3 走位技巧
- **遮影步**: 利用boss体型卡位，躲在视野盲区
- **预判走位**: 根据技能名称预判攻击模式
- **精准躲避**: 360度旋转、后仰翻身等高难度躲避动作

### 7.4 BOSS战斗策略
- **远程拉扯**: 利用普攻增幅的攻击距离远程输出
- **范围规避**: 移速足够快时可规避大范围技能
- **狂暴应对**: 狂暴状态下爆发伤害高，需提升恢复能力
