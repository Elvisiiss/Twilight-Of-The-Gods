# 第1451-1455章 设定分析

## 基础设定

### 世界架构
- **诸神黄昏**：游戏世界主体，超过一万级的生灵不多。
- **银河星系 / 神州大地**：墨可渊卜为躲避大势力追击逃窜至此，建立墨可古国。
- **域外之地**：至少存在两件天罚装备，林天浩攻略优先级最高。
- **中州**：沙海毒帝老友提及此处应有天罚装备，但当前局势复杂。
- **墨可沙国 / 墨可古国 / 墨可古城**：全民机械师国度，墨可古城被二维化封印于冰封图内。
- **古朝秘境**：十转转职地点。
- **灵网世界**：墨可沙国大部分意识体所在，主要管理者为核心主脑小风。
- **无尽星空**：存在多种族，其他种族大能会出手扼杀异族天骄。

### 世界大能层级
- **道之源神**：当前腾不出手。
- **三清圣人**：守护方世界，不允许其他世界生灵乱来。
- **鸿钧老祖**：三清圣人的师父，可能存在。
- **力量层次**：凡人级 → 神灵级 → 圣人级（其上可能还有更高层级）。
- 跨世界规则：方世界大能不允许其他世界生灵在此乱来，可破开虚空出手干预。

## 属性系统

### 核心属性
- **生命值**：林天浩生命值达二十七万亿。
- **减伤属性**：修德里·黑皇减伤非常高，二十七万亿伤害转移仅实际承受两万亿。
- **体魄蜕变**：高体魄蜕变者才能从生死簿锁头下扛住。
- **自由属性点**：可永久叠加，神级天赋一大特征。
- **机械熟练度 / 悟道速度**：墨可渊卜天赋进化后可获取。
- **双抗**：物理 / 法术双抗属性。
- **人王令**：百分比属性，收服墨可沙国后从 75% 提升至 80%（+5%）。

### 等级系统
- **十转等级要求**：两万级。
- **一万级后升级机制**：升级非常困难，只能通过猎杀黑铁级以上 boss 获取经验值；击杀比自身等级低的普通野怪无法获得经验值。

### 隐藏职业品阶
- **品阶序列**：玄级 → 地级 → 天级 → 圣级 → 神级。
- **稀有度**：
  - 玄级 / 地级隐藏职业：万中无一。
  - 天级 / 圣级：更为稀有。
  - 神级：上千万人中未必诞生一个。

## 装备系统

### 机械材料与晶片
- **超神级机械晶片**：十转所需，奎微长天使用十枚进行十转转职。
- **超神级机械材料**：坚不可摧，转职时可化为无数光点。
- 虚影曾以摧毁身上所有超神级机械材料作为交换筹码。

### 装备类型
- **天罚装备**：林天浩攻略优先级最高，域外之地至少两件，中州可能存在。天罚锁头羽箭威力极强。
- **防御机械物品**：可被更高层级力量压制报废。
- **黑金色导弹**：奎微长天所使用的机械武器，可制造真假难辨的障眼法。
- **白色光团**：奎微长天底牌，拍入眉心后可释放电磁波，原地复活般恢复状态。

### 防御体系
- **冰封图防御系统**：类似未来商会防御系统，但转化率更高。
  - 转化率极限：40%。
  - 有效利用率：约 36%。
  - 理想抵挡伤害上限：76%。
  - 机制：吸收攻击力量用于防御后续攻击（闭环），但防御体系不成熟。
- **机械物品双抗与生命值加成**：墨可渊卜制作的机械物品可额外获得。

## 技能系统

### 林天浩技能
- **三头六臂**：输出强化技能，配合箭由心发全力输出。
- **箭由心发**：羽箭输出强化，配合三头六臂使用。
- **天罚锁头**：远距离锁头击杀，星耀级 / 宗师级职业者无法扛住；可被高体魄蜕变者抵抗。
- **无敌领域**：
  - 范围：方圆十米。
  - 效果：笼罩范围内可掌控对方身上所有机械物品，使对方无法动弹。
  - 限制：有冷却时间。
  - 战术：10 米内拉神灵入领域或可击杀普通神灵。
- **空间闪烁**：位移技能，可连续闪烁规避攻击。
- **绝对格挡**：硬挡致命攻击，挡住后仍会气血翻涌、五脏六腑剧痛。
- **碧海潮生**（治疗技能）：
  - 一星：恢复十万 + 林天浩 2% 最大生命值。
  - 五星：恢复十亿 + 林天浩 10% 最大生命值。
  - 冷却时间：一小时。
  - 升星途径：刷熟练度 + 升品带来技能升星。
  - 作用于：所在队伍所有人。

### 墨可渊卜天赋（神级天赋：机械传承者）
- **初始效果**：他人通过其研发图纸制作机械物品时，获得 1 个自由属性点（无法升星）。
- **进化后效果**：
  - 仍获得自由属性点。
  - 额外获得机械熟练度、悟道速度。
  - 制作的机械物品额外获得双抗和生命值。
- **战略价值**：前期对新人机械师几乎无助力（独立制作新图纸困难），后期可无限刷。

### 二维化（攻击手段）
- 将人或区域二维化，可封印对方，也可在二维化后摧毁对方。
- 几乎所有生灵被二维化后比三维状态脆弱无数倍。

### 血红色眼眸技能
- 来自其他世界大能的技能（非真身降临）。
- 仅一只眼眸即达圣人级以上力量层次。
- 一道玄妙攻击可追踪目标、越追越快，使目标汗毛倒立、血液流动变慢。
- 忌惮方世界大能，最终被虚空探出的一指逼退。

## 怪物系统

### Boss 分级
- **黑铁级以上 boss**：一万级后升级所需经验来源。
- **修德里·黑皇**：减伤极高，二十七万亿转移伤害中仅承受两万亿。

### 主要 NPC / 角色层级
- **黑天傲真、冥王白小风、焚心梦魇、沙海毒帝**：四人联手方能在短时间对林天浩造成高伤害。
- **焚心梦魇、沙海毒帝**：林天浩手中的神品强者。
- **墨可渊卜**：墨可沙国先祖，星际流浪者 / 星际雇佣兵，神级天赋 + 神级隐藏职业，天赋经过数次蜕变。

## 副本系统

### 古朝秘境
- 十转转职地点，超神级隐藏职业转职声势浩大，会引动天地异象。

### 冰封图（二维化封印空间）
- 封印墨可古城。
- 防御机制：吸收攻击力量转化为防御（闭环）。
- 转化率极限 40%，有效利用 36%，理想抵挡 76% 伤害。
- 林天浩以三头六臂 + 箭由心发全力输出，最终破开裂纹。
- 破坏冰封图不会让墨可古城从二维变三维（二维化本身即为攻击手段）。

## 战斗系统

### 锁头与击杀机制
- **生死簿锁头**：可远距离锁头击杀名单目标。
- **抗性门槛**：星耀级、宗师级职业者扛不住；除非拥有极高体魄蜕变才能扛住。

### 伤害转移机制
- 林天浩可极致转移伤害，配合双重真身近乎无解。
- 唯一短板：冷却时间过久。

### 组队与辅助
- **组队邀请**：可跨成员释放辅助技能。
- **碧海潮生**：队伍群奶技能，五星恢复十亿 + 10% 最大生命值。

### 渡劫 / 天劫系统
- **一般雷劫**：每道天雷之间有间隔，给渡劫之人喘息。
- **十转雷劫**：
  - 频率：每三秒一道天雷。
  - 强度：一道比一道强。
  - 后期：连续三道天雷后结束，天雷不再增强即预示天劫将尽。
- **异象**：超神级隐藏职业十转打破常规转职进度，可能引来其他世界大能窥探（如血红色眼眸）。
- **底牌使用**：渡劫受创时可使用特殊道具（如白色光团）恢复状态。

### 转职升华机制
- **超神级隐藏职业十转效果**：
  - 之前九转获得的所有本职业技能完成一次升华，品阶再上一个台阶（等同实力质飞跃）。
  - 十转新获得的技能明显比之前更加强大。
- **预期**：天罚锁头若升华，之前能阻挡羽箭者将无法阻挡。

## 特殊机制

### 封神榜
- 林天浩持有封神榜，可将击杀之辈送上封神榜并召唤为己用。
- **生命值增幅**：送墨可渊卜上封神榜后，生命值瞬间上涨数千亿（因墨可沙国人口成为助力）。
- 上封神榜者需具备价值（如墨可渊卜为墨可沙国先祖）。
- 被封神榜收录者从虚影转为实体，俯首称臣。

### 人王令
- 反映对势力的掌控度，以百分比显示。
- 收服墨可沙国后从 75% 提升至 80%。
- 百分比提升对生命值增幅明显。

### 机械师体系（墨可沙国特色）
- **全民机械师现象**：墨可渊卜以个人机械图纸倾囊相授，使机械师成为最吃香职业。
- **早期碾压**：在墨可渊卜图纸加持下，机械师可快速获得同期厉害机械武器，刷怪效率碾压同期其他职业者，碾压维持到九转。
- **稳定等价**：走墨可渊卜路子相当于玄级甚至地级隐藏职业。
- **弊端**：
  - 后期难以进步，缺乏自主创新能力。
  - 形成"衣来伸手饭来张口"的巨婴，机械飞升困难。
  - 机械基础扎实但顶端东西差劲。
- **职业失衡**：严重时六转弓箭手不如四转机械师吃香；非机械师难以找到工作。

### 跨世界干预
- 其他世界大能会出手扼杀异族天骄（无冤无仇亦然）。
- 血红色眼眸仅为技能投影，非真身降临，随手为之。
- 方世界大能（如三清圣人）可破开虚空以一指逼退干预者。
- 林天浩感悟：遇到其他种族天骄也应扼杀。

### 奎微长天十转战术
- **障眼法**：升空大量假导弹欺骗血红色眼眸，未穿插真弹（鸡贼但有耐心）。
- 利用假导弹分散血红色眼眸力量，为自身争取喘息。
- 渡劫期间林天浩收回焚心梦魇、沙海毒帝入封神榜，避免被秒杀损失。
