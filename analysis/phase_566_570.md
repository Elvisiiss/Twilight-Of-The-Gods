# 第五百六十六章至第五百七十章 设定分析

## 一、基础设定

### 1.1 月轮克玄承认阴谋设定
- **承认**：月轮克玄承认与图图鲁圣山做局，目的是吞掉浩渺大陆
- **失败原因**：林天浩太聪明太谨慎，没有上当
- **后果**：杀戮之神即将复苏，林天浩面临无尽杀戮威胁

### 1.2 修德里·浩鸿与修德里·白芸设定
- **修德里·浩鸿**：浩渺无极宫宫主，主战，想要牺牲千万将士复苏杀戮之神
- **修德里·白芸**：浩渺无极宫成员，比月轮克玄强上几分，能够牵制神灵，最终选择撤兵
- **决策**：修德里·白芸决定撤兵，认为留下雪帝比复苏杀戮之神更好

### 1.3 常水泱策反设定
- **手段1**：揭露真相，指出将士是复苏杀戮之神的祭品
- **手段2**：以地缺商帮百分之三十以上的财富威胁将士家人
- **手段3**：拿出三十件伪神器悬赏，动摇军心
- **手段4**：分析局势，指出就算杀了雪帝，浩渺帝国也会被图图鲁帝国吞并

### 1.4 希图半神撤离设定
- **行为**：见浩渺帝国撤兵，也选择离开
- **原因**：孤军奋战没有意义

### 1.5 镇北十城选择设定
- **决策**：出海，不愿意留在月轮帝国成为杀戮之神的祭品
- **原因**：月轮帝国是定时炸弹，随时可能被当作祭品

### 1.6 月轮克玄击杀设定
- **过程**：林天浩祭出七宝玲珑塔，牧云黎·萨塬出手镇压，亡灵之神和杀戮天使围攻，天罚锁头击杀
- **结果**：月轮克玄死亡，亡灵被林天浩奴役
- **全服通告**：恭喜玩家雪帝成功击杀月轮克玄

### 1.7 图图鲁·洪穹撤离设定
- **行为**：带人赶到，见月轮克玄已死，选择撤退
- **原因**：月轮帝国已是空架子，没有打的必要
- **收获**：偷袭浩渺帝国几座主城，小赚一笔

### 1.8 山海帝国攻占月轮帝国设定
- **时间**：半个月
- **结果**：月轮帝国全境被山海帝国攻占，山海帝国进一步复苏
- **奖励**：山海藏图+1，山海帝国气运+10，个人幸运+20，自由属性点+100000

### 1.9 天罚弓箭手二转设定
- **条件**：需要寻找到天罚套装，每一件天罚套装装备可以进行一次转职
- **线索**：浩渺无极宫可能有一件天罚套装装备

### 1.10 海外开荒设定
- **目的**：为月轮帝国两百三十亿百姓寻找新栖息地，同时寻找天罚装备和破解无尽杀戮的方法
- **队伍**：三支队伍，两支由神灵带领，一支由林天浩亲自带队
- **目标**：北海七子（七座超级岛屿，面积相当于三分之二个月轮帝国）

### 1.11 圣地争霸赛设定
- **时间**：一年后开启
- **参与对象**：圣地之主亲自登台角逐
- **奖励**：丰厚奖励，可能超越圣地天骄新人赛的品阶+1

### 1.12 北海海域设定
- **内海**：一百海里内，以前隶属于月轮帝国
- **北荒海域**：内海出去，纵深超过百万海里，有七座超级岛屿（北海七子）
- **危险**：有些地方就算神灵进去都出不来

### 1.13 米莱伏龙设定
- **身份**：常年生活在海域的向导
- **知识**：了解未开发海域的情况，知道北海七子的位置和大小

## 二、属性系统

- **天罚伤害**：基础伤害破亿，暴击两亿+

- **效果**：远程攻击，天罚状态下必定命中
- **伤害**：基础伤害破亿，暴击两亿+
- **用途**：屠杀士兵，锁头领域强者

### 3.2 生死簿（神器）
- **效果**：写下名字使其持续掉血
- **用途**：锁定敌人

### 3.3 七宝玲珑塔（神器）
- **效果**：收入敌人，随身携带，屏蔽窥探
- **用途**：收入月轮克玄，配合神灵围攻击杀

### 3.4 昆仑镜（神器）
- **效果**：瞬间移动，穿越空间
- **用途**：快速移动，不怕偷家

### 3.5 山海藏图（神器）
- **效果1**：幸运+10
- **效果2**：闪避+10%
- **效果3**：主动催动，对所有神灵级以下的兽类生灵产生压制
- **效果4**：山海图中自成一小世界，可容纳千亿生灵
- **耐磨度**：不可摧毁
- **特点**：首次获得加闪避属性的装备，闪避可闪避普通攻击和技能

### 3.6 天罚套装（超神级）
- **效果**：天罚弓箭手转职必备装备
- **数量**：多件，每一件可以进行一次转职
- **线索**：浩渺无极宫可能有一件

### 3.7 三柄飞刀（月轮克玄）
- **效果**：远程攻击
- **用途**：攻击林天浩

### 3.8 超级航船（北诺青姬）
- **容量**：百万人
- **数量**：十五艘
- **用途**：出海迁徙

### 3.9 大型船只（月轮帝国）
- **容量**：十万人以上
- **数量**：超过一千艘
- **用途**：出海迁徙

### 3.10 伪神器（常水泱）
- **数量**：三十件
- **用途**：悬赏威胁将士家人
