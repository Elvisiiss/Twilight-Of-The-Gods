# 第1441-1445章 设定分析

## 基础设定

### 世界背景
- **凡殿**：林天浩担任殿主之位；历史上曾"尘封"过一次，本篇章中多方势力预言将再度尘封。
- **山海帝国**：林天浩（雪帝）创建并与之绑定的国家，本章遭遇全面投毒、兽潮、城镇劫掠等多重灾难。
- **浩渺大陆**：当前主舞台；浩渺无极宫、月轮魔宫、西极神殿、希图神殿等圣地均被他覆灭。
- **神域**：更高层级地图，可在神域封神、成为神王乃至神皇；焚心梦魇建议林天浩"去神域其实也挺好的"。
- **平行世界**：焚心梦魇来自平行世界；该世界存在"疯天帝"，本应提前去神域，却选择守护世界耽误了发展。

### 主角状态（林天浩 / 雪帝）
- 身份：凡殿殿主、山海帝国之主、被尊称为"雪帝"。
- 当前等阶：完成第七次转职（七转），等级上限开放至五千级。
- 转职地点：古朝秘境。
- 主要属下：墨可南天（已入灵网世界）、墨可南风、奇楠角檩、杜洛魅卜、沙海毒帝、黑天傲真、冥王白小风、焚心梦魇、奎微长天。
- 隐藏关系：从前有座山拥有超神级隐藏职业，与林天浩互通消息。
- 装备：兽神宝瓶（用于帮助手下提升品阶）、昆仑镜（瞬移工具）、天机阁（推演工具）、人王令（属性增幅）。

### 势力格局
- **墨可沙国三大家族**：墨可家族、杜洛家族、高同家族（高同家族被杜洛家族覆灭，仅余5名余孽）。
- **阿来特星系**：与米国、地心世界、石尊主支持的国家合作，是本章投毒事件的幕后主使之一。
- **圣地背后势力**：来自其他大陆的大势力，浩渺无极宫背后势力派出"长剑青年"和"白衣女子"等代表。
- **图图鲁圣山**：与兽人有关联的大势力。
- **未来商会**：林天浩势力的总部，由墨可南天原先经营。

## 属性系统

### 生命值
- 林天浩在毒雾中生命值骤降 **一千亿**，且数字还在疯狂攀升。

### 人王令机制
- **属性增幅**：人王令以百分比形式增幅全属性。
- **绑定关系**：林天浩与山海帝国一荣俱荣、一损俱损。
- **下降触发条件**：当林天浩生命值下降时，人王令增幅百分比随之下降。
- **本篇数值变化**：从 **75%** 降至 **73%**（毒雾解决后停留在此值）。
- **隐藏风险**：对方大规模投毒可能已经发现了人王令的增幅效果。

### 自由属性点（任务奖励）
- 任务【铲除高同家族余孽】：自由属性点 **+10000**。
- 任务【提升品阶】：自由属性点 **+30000**。

### 灵魂力
- 第二真身操控依赖灵魂力分散。
- 林天浩当前灵魂力能够控制第二真身行动，但难以同时操控本体+第二真身进行高强度战斗。
- 灵魂力不足时，悟道与第二真身操控难以兼顾。
- 推演天机阁会大幅抽走精神力。

### 等阶体系（品阶）
- **职业品阶提升路径**：宗师 → 王级 → 皇级（兽神宝瓶可帮助跨越）。
- **转职等阶**：一转至九转，可冲击十转；七转后等级上限为五千级。
- **高手等级**：宗师级、星耀级、半步神品、神品。
- **神域等级**：封神 → 神王 → 神皇。

## 装备系统

### 天罚装备系列
- **天罚护肩**（本篇核心新装备）：
  - 品阶：未知。
  - 佩戴要求：天罚弓箭手。
  - 效果1：天罚攻速 **+1**，不受攻速阶段性削减影响。
  - 效果2：百分比减伤 **5%**，对神灵级攻击依旧有效。
  - 效果3：能够阻挡一次致命攻击，冷却 **1小时**。
  - 效果4：幸运 **+10**。
  - 效果5：心境通明，悟道速度 **+10倍**。
  - 效果6：最大生命值增加 **50%**。
  - 效果7：最大护甲增加 **50%**。
  - 效果8：最大魔抗增加 **50%**。
  - 效果9：双重真身——可释放出一道跟本体一模一样的真身，该真身拥有本体全部属性、技能、神通，本体被击杀后可选择在真身直接复活；当灵魂力到达一定地步后，可同时操控第二真身战斗；冷却时间 **24小时**。
  - 耐磨度：不可摧毁，佩戴后不可盗取，不可掉落。
  - 获取途径：完成墨可南天任务【提升品阶】奖励获得。

### 第二真身特性（由天罚护肩衍生）
- 与本体完全一致：属性、技能、神通均相同。
- 操控方式：通过分散灵魂力进入第二真身进行掌控。
- 与"一气化三清"区别：
  - 一气化三清只能用于副职业，不能进行战斗，分身像绝对忠诚的傀儡。
  - 第二真身可用于战斗，是真正用意识操控的真身。
- 意识完全进入第二真身时，第二真身即为本体。
- 双重视角：本体感官+第二真身感官同时传入脑海。
- 限制推测：本体与第二真身距离过远可能导致掌控力下降，平时需待在本体身边。
- 应用：可让第二真身代为改写生死簿名字、辅助天罚锁头、远程锁头攻击；悟道因需全神贯注暂无法由第二真身分担。

### 关键道具
- **兽神宝瓶**：可帮助属下提升品阶（宗师升王级，王级升皇级）。
- **昆仑镜**：瞬移工具，林天浩带沙海毒帝回帝都龙城时使用。
- **人王令**：与山海帝国绑定，按百分比增幅全属性。
- **天机阁**：推演势力与事件，消耗精神力较大。
- **太古黑塔**：用于关押犯人（黑天傲真将抓捕的偷袭者关入其中）。
- **冰封图（墨可古城图）**：核心主脑小风的主人藏身其中；二维化进入是林天浩绝对无法接受的。

### 任务奖励道具
- **诸神的赐福 +1**（任务【铲除高同家族余孽】奖励）。
- **装备进化卷轴 +5**（任务【铲除高同家族余孽】奖励）。

## 技能系统

### 七转技能：无敌领域
- 等级：1星。
- 效果：释放一个方圆 **十米** 的领域，在该领域范围内绝对无敌，但不能离开领域范围。
- 持续时间：**1个小时**。
- 消耗：无。
- 冷却：**24小时**。
- 熟练度：0/100。
- 战术价值：
  - 可出其不意斩杀顶尖强者（强者靠近时施展，对方连逃跑机会都没有）。
  - 大幅降低被控制的概率。
  - 补全林天浩此前缺乏的"近距离正面击杀强者"短板。

### 林天浩已有技能（本篇提及）
- **一气化三清**：副职业分身技能，只能用于副职业，不能进行战斗；分身为绝对忠诚的傀儡。
- **天罚锁头**：天罚羽箭锁定追踪能力，可借助第二真身更易施展。
- **生死簿**：改写名字的技能，可由第二真身代为操作。
- **洞察之眼**：可全力展开，用于夜间城楼侦测搞事者。
- **绝对穿梭**：用于前往古朝秘境转职。

### 属下技能特性
- **沙海毒帝**：可吸收/吞噬毒雾，但瘟疫型毒素会通过人传人扩散，难以独自覆盖整个山海帝国。
- **焚心梦魇**：可帮助林天浩快速恢复精神（推演天机阁后修复精神损伤）。
- **黑天傲真、冥王白小风、焚心梦魇**：林天浩派出的三主力，负责镇压城镇劫掠者。

### 圣地背后势力代表（未出手）
- **长剑青年**：背后背三柄长剑，天赋高但傲慢；自称"如果不是天道眷顾让林天浩无限复活，我随便杀他"。
- **白衣女子**：长剑青年的师姐，性格谨慎；斥责师弟傲慢，认为雪帝"不好对付"，"要是雪帝那么好对付，我们就不会等到现在才动手，更不会想着借阿来特星系的力量"。

## 怪物系统

### 兽潮
- **触发方式**：由兽人势力在夜间引动，覆盖山海帝国各大城镇。
- **攻击目标**：主城防守尚可，小镇因毒雾侵蚀严重无力抵挡。
- **规模**：极大，能够引动如此大规模兽潮的势力被推测为比浩渺无极宫更强大的超级势力。
- **应对**：焚心梦魇、沙海毒帝出手后兽潮"成不了气候"，沙海毒帝还抓住了几个引动兽潮的兽人。

### 兽人
- **来源**：非浩渺大陆本土势力，自述"我们不是浩渺大陆的，来这里只是想要分一杯羹"。
- **外形**：虎头兽人（被抓住的几位）。
- **关联势力**：推测与图图鲁圣山有关（兽人否认，但林天浩心存疑虑）。
- **目的**：等待凡殿再度尘封，分一杯羹。
- **态度**：轻蔑林天浩，认为"大势不可逆"，他们背后的"大人物"甚至不需要亲自露面就能让林天浩毫无还手之力。
- **历史参照**：上一任凡殿之主以凡人之躯屠杀神灵（不借助外力），其统治下凡殿仍被尘封；认为林天浩与上一任凡殿之主最多伯仲之间。

### 投毒者
- **构成**：NPC、冒险者；大部分是其他国家冒险者，少部分是龙国冒险者。
- **投毒规模**：覆盖山海帝国所有城镇，毒素总量堪比之前墨可拉丁大沙漠的毒素。
- **毒素特性（瘟疫）**：
  - 传染性极高，人传人。
  - 即使一丁点毒素也可能导致人传人，快速波及整个山海帝国。
  - 杀伤力不可小觑，致死率极高，图图鲁行省人口开始大范围下降。
  - 暂无解药。
  - 沙海毒帝可吸收毒雾，但被感染者会传染未感染者。

### 偷袭主城的高手
- **第一波**：两位星耀级 + 一位宗师级高手，闯入山海帝国一座主城，抢夺大量财物，击杀不少护卫。
- **后续**：陆陆续续有两波偷袭主城的高手，被黑天傲真抓起关入太古黑塔。
- **处置**：被林天浩命令扒光衣服倒吊城墙公开示众。

## 副本系统

### 古朝秘境
- 林天浩转职专用地点，第七次转职（七转）在此完成。
- 转职过程"驾轻就熟"，顺利完成。

### 未来商会总部
- 林天浩势力核心据点，墨可南天等人会在此出现。
- 与墨可南天交涉任务、与核心主脑小风沟通均在此进行。

### 冰封图（墨可古城图）
- 核心主脑小风的主人藏身所在。
- 林天浩可凭当前输出能力击破二维化的冰封图，但暂未出手。
- **二维化进入**：林天浩绝对无法接受的方式。

### 太古黑塔
- 关押犯人的场所，黑天傲真将抓捕的偷袭者关入其中。

### 图图鲁行省
- 山海帝国的行省之一，本篇遭遇大规模偷渡者和毒雾问题。
- 是娇小萝莉、高大兽人等敌对角色的潜伏据点。

## 战斗系统

### 转职机制
- 每次转职放开等级上限并获得本职业技能。
- 七转后等级上限：**五千级**。
- 转职地点：古朝秘境。
- 七转获得技能：无敌领域（1星）。

### 任务系统
- **任务发布方**：NPC可向林天浩发布任务。
- **任务结构**：任务名称、任务要求、任务奖励、任务惩罚。
- **接取方式**：脑海提示音响起，选择是否接取。
- **本篇任务一**（杜洛魅卜发布）【铲除高同家族余孽】：
  - 要求：击杀墨可沙国高同家族余孽 0/5。
  - 奖励：自由属性点+10000、诸神的赐福+1、装备进化卷轴+5。
  - 惩罚：无。
- **本篇任务二**（墨可南天发布）【提升品阶】：
  - 要求：帮助墨可南风、奇楠角檩、杜洛魅卜三人完成一次品阶提升（0/3）。
  - 奖励：天罚护肩+1、自由属性点+30000。
  - 惩罚：无。
  - 完成耗时：3天。

### 卡BUG机制（本篇核心发现）
- **原理**：林天浩帮助属下NPC提升品阶，理论上可触发NPC发布的任务，完成任务后再获得奖励。
- **效果**：既提升属下实力，又获得不菲的任务奖励。
- **历史损失**：此前帮助沙海毒帝、黑天傲真提升品阶时未索取任务奖励，"损失惨重"。
- **可行性**：依托兽神宝瓶，后续遇到类似情况都可借此套利。
- **性质**：行为本身有点"卡BUG"，但可行性非常高。

### 摸尸与掉落
- 击杀NPC后可摸尸获取物品与属性点（本篇未直接描写，沿用前文机制）。

### 全服喇叭
- **功能**：可向全服发布悬赏/通告。
- **本篇使用**：
  - 抓捕和击杀所有在山海帝国的投毒者，给予丰厚奖励。
  - 化解山海帝国毒雾、解决可传播性毒素，给予丰厚奖励。
- **使用方式**：连续开启多次。

### 治疗奖励机制
- 牧师参与治疗伤患可获得奖励，因此"不少牧师加入到了治疗队伍之中"。

### 处置机制
- 抓捕的偷袭者可被公开折辱（扒光衣服倒吊城墙示众）。
- 林天浩可利用抓捕者钓鱼，看背后势力是否出来营救。

## 特殊机制

### 天机阁推演
- **功能**：推演目标背后的势力。
- **本篇应用**：推演几位偷袭者背后的势力，看到"长剑青年"吩咐事情，听到"浩渺无极宫"几个字。
- **代价**：精神被抽走一大截；连续动用损伤不低。
- **辅助**：焚心梦魇可帮助快速恢复精神。
- **限制**：连续推演损伤较高，灵魂力提升不容忽视。
- **表现形式**：被迷雾笼罩的空间，看到模糊画面与关键字。

### 凡殿尘封机制
- **历史**：凡殿曾尘封过一次（上一任凡殿之主统治下）。
- **预言**：本篇多位敌对角色预言凡殿将再度尘封。
- **上一任凡殿之主**：以凡人之躯屠杀神灵，不借助外力（与林天浩借助诸般外力不同）。
- **实力对比**：林天浩与上一任凡殿之主"最多在伯仲之间"。
- **影响**：凡殿尘封后，山海帝国随之尘封，外部势力可"分一杯羹"。

### 灵网世界与二维化
- **墨可南天**：已进入灵网世界，现实由弟弟墨可南风管理。
- **核心主脑小风**：忠诚对象在冰封图中，对林天浩不忠心。
- **二维化**：进入冰封图的受限方式，林天浩绝对不接受。
- **沟通机制**：小风可作为林天浩与冰封图中存在的沟通中介。

### 复活机制
- **第二真身复活**：本体被击杀后，可选择在第二真身直接复活（天罚护肩效果9）。
- **无限复活**：林天浩拥有"天道眷顾"无限复活能力（敌对势力长剑青年提及）。

### 人王令绑定
- 林天浩因人王令一步登天，但也因人王令与山海帝国绑定。
- 山海帝国子民大规模死亡 → 林天浩生命值下降 → 人王令百分比下降 → 全属性持续下降。
- 形成"浩劫"循环：对方不直接出手，通过屠戮百姓削弱林天浩。

### 势力观察者机制
- **暗处观察者**：图图鲁行省高山上的"高大兽人"与"娇小萝莉"（手脚戴银色铃铛、嘴叼棒棒糖）。
- **白衣女子与长剑青年**：来自浩渺无极宫背后势力，祭拜被林天浩覆灭的浩渺无极宫。
- **共同策略**：暂不出手，借阿来特星系之力消耗林天浩，"跟着喝口汤"。
- **共识**：雪帝已惹众怒，多势力联手势必不会放过他。

### 偷渡者机制
- **图图鲁行省**：出现大量偷渡者，与投毒事件同步发生。
- **性质**：有规模、有预谋的行为。

### 投毒事件全貌
- **覆盖范围**：山海帝国所有城镇。
- **参与者**：多国冒险者（包括龙国少部分）+ NPC。
- **毒源推测**：可能来自阿来特星系。
- **总量**：堪比墨可拉丁大沙漠的毒素储备。
- **后果**：
  - 一个时辰内山海帝国尸横遍野。
  - 林天浩生命值下降一千亿。
  - 人王令从75%降至73%。
  - 需紧急处理尸体防止更大麻烦。
- **应对**：沙海毒帝吸收毒雾+全服喇叭悬赏+龙国冒险者下场+黑天傲真等三人镇压。
