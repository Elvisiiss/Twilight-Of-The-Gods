# 第五百二十一章至第五百二十五章 设定分析

## 一、基础设定

### 1.1 林天浩与希图半神赌约设定
- **赌约内容**：赌圣地天骄新人赛总决赛谁获得第一
- **希图获胜条件**：林天浩只提一起宣战这一个要求
- **凡殿获胜条件**：希图半神答应之前的三个要求（天赋进化之花十朵、装备进化卷轴五十份、三位被封印神灵的信息）
- **规则**：契约由诸神黄昏规则加持，违约无效

### 1.2 胖子生命值提升计划设定
- **胖子基础生命值**：突破一亿五千万（林天浩、猴子、苟到万古加持）
- **西伯利亚之狐生命值**：一亿一千万（召唤火焰翼龙）
- **绑定契约效果**：西伯利亚之狐绑定胖子，胖子生命值突破两亿六千万
- **苏璃生命值**：四千万（蟠桃+召唤兽生命共享）
- **苏璃获得召唤火焰翼龙后**：生命值突破一亿两千万
- **苏璃绑定胖子后**：胖子生命值达到三亿八千万
- **装备效果**：范围灼烧装备根据生命值百分比灼烧，三亿八千万生命值带来恐怖灼烧伤害
- **短板**：之前胖子追求双抗和生命值，其他属性不行，遇到高吸血对手反伤无意义
- **解决办法**：搞一套重伤属性高的装备

### 1.3 硬闯浩渺无极宫设定
- **目的**：阻止浩渺无极宫与乐神会合作，调查内部情况
- **守卫**：两位九转高手
- **结果**：林天浩祭出打神鞭，一秒六十攻速打碎守卫长剑
- **转折**：修德里·茉莉出现，阻止守卫

### 1.4 修德里·茉莉设定
- **身份**：浩渺无极宫二宫主之女
- **立场**：反对浩渺无极宫与乐神会合作
- **原因**：非我族类，其心必异
- **行动**：帮助林天浩进入浩渺无极宫内部

### 1.5 修德里·浩途设定
- **身份**：浩渺无极宫二宫主，修德里·茉莉父亲
- **立场**：支持与乐神会合作（势在必行）
- **结果**：被林天浩用七宝玲珑塔收入，带到弑神学院

### 1.6 牧云黎设定
- **身份**：乐神会成员，阿来特星系牧云黎家族
- **特点**：全身布满纹身，光头
- **能力**：纹身探查，可以搜索整个浩渺大陆及周边区域
- **家族特长**：擅长寻觅，即便隐藏很深的东西也能找到
- **地位**：修德里·浩鸿尊称其为大人

### 1.7 龙窟设定
- **内容**：神龙留下的宝藏之地
- **危险**：危险重重，有残留的龙威（神灵级神龙留下的龙威比不少神灵的神威还要强大）
- **浩渺无极宫优势**：有办法破除龙威
- **乐神会优势**：牧云黎家族擅长寻觅，一个月就找到了一处龙窟
- **合作内容**：乐神会找龙窟，浩渺无极宫破除龙威，双方分赃

### 1.8 阿来特星系设定
- **目的**：摧毁银河世界，浩渺大陆是第一站
- **手段**：派遣类似于谷梨木家族的势力（最少十个起步），乐神会至少有十尊神灵
- **计划**：借浩渺无极宫的名头做事情，畅通无阻

### 1.9 第四次造神时代设定
- **目的**：对抗阿来特星系
- **乐神会作用**：阻碍第四次造神时代进度

### 1.10 黑心龙设定
- **身份**：阿来特星系神灵，被林天浩奴役
- **作用**：作证阿来特星系的真实目的
- **知识**：了解牧云黎家族的特长

- **特点**：纹身探查范围广，但无法穿透弑神学院区域

- **过程**：林天浩揭示乐神会的真实目的，召唤黑心龙作证，指出乐神会借浩渺无极宫名头做事情的风险

- **进阶**：纹身悬浮编织成阵盘，探查更远区域，消耗巨大
