# 第851-855章 阶段分析

## 基础设定

### 裂空领域机制
- 林天浩第一个领域，通过观虚空裂缝领悟
- 核心能力: 无尽裂空，可撕裂大量空间裂缝
- 空间裂缝可相互抗衡牵制
- 消耗: 无，冷却: 无

### 人面花机制
- 相人生，夺人命，噬人魂
- 可吞噬生命力和灵魂力
- 一旦相人而生，会一直锁定目标直至命中
- 难以躲闪，类似天罚锁头

### 心魔古城炼器师
- 奥鲁·弗兰奇: 心魔古城排名前三的炼器师
- 实力强悍，性格暴躁
- 喜以活人生魂炼器
- 曾负责开采灵魂玉晶矿脉

### 太玄魔子
- 灰衣书生，儒道修炼者
- 实力深不可测，野心道长完全看不透
- 发布连环任务，奖励丰厚
