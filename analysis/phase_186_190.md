# 《诸神黄昏》设定提取 - 第186-190章

## 一、基础设定

### 1.1 亡灵之神现身
- **形态**: 八面魔方，可折叠化作八道人影，融合成浑身手臂、长腿、眼珠子的怪物
- **状态**: 被封印，正在复苏，实力不及巅峰的百万分之一
- **力量来源**: 十万生灵献祭
- **武器**: 十六条手臂，各持不同武器，不可摧毁特性

### 1.2 普陀天龙技能
- **佛怒自在莲**: 巨大金红色莲花，收拢目标
- **佛怒自在印**: 佛门法印，镇压目标
- **佛光普照**: 净化亡灵，降低亡灵威势
- **金色尖锥**: 特殊装备，可旋转攻击
- **金色权杖**: 特殊装备，可远程攻击

### 1.3 不可摧毁特性打破
- **机制**: 不可摧毁装备有极限，达到极限后可被摧毁
- **方法**: 打神鞭百分百破甲，配合三头六臂叠加属性
- **结果**: 亡灵之神六件武器出现裂纹

### 1.4 三头六臂战斗
- **效果**: 佩戴三种主武器，属性叠加，幽冥长弓获得打神鞭百分百破甲效果
- **消耗**: 每秒100MP，可通过嗑药回蓝延长持续时间
- **冷却**: 一个小时

### 1.5 天火流星触发
- **频率**: 平均一分钟触发一次，一万两千箭触发一次
- **伤害**: 每次数百万生命值，暴击可上千万
- **叠加生命值**: 击杀亡灵每秒增加1900+生命值

### 1.6 亡灵之神逃跑
- **方式**: 化作灰白色光芒，进入墓室下方阵盘
- **状态**: 重新进入彻底封印状态
- **回血**: 战斗状态每分钟两百万，封印状态可能提升

### 1.7 生死簿锁头
- **伤害**: 每秒9万多，每分钟500多万
- **效果**: 持续掉血，无需脱离战斗即可生效

### 1.8 亨利集团悬赏
- **金额**: 十亿
- **目标**: 雪帝真实身份
- **性质**: 诈骗集团，悬赏可能是骗局

### 1.9 野心道长
- **身份**: 救了林天浩妹妹的人
- **热度**: 狂战公会开出八千万年薪，各大公会拉拢
- **态度**: 尚未表态

### 1.10 国际论坛
- **米国**: 有人完成二转，嘲讽龙国区
- **火药味**: 各国玩家互相嘲讽

- **不可摧毁打破**: 打神鞭百分百破甲配合三头六臂，打破不可摧毁特性

### 5.4 战术运用
