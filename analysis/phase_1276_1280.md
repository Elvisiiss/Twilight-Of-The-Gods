# 第1276-1280章 设定分析

## 基础设定

- **墨渊**：多层地下结构副本，已明确分为第六层与下三层等区域，各层存在不同怪物与机制。
- **蓝星**：现实世界背景，二十年前至今不可能有人大批量屠龙。
- **诸神黄昏**：游戏内副本/世界，林天浩在其中发育一年多，积累了属性与技能。
- **坳龙村**：疯王原为该村老村长。
- **势力格局**：墨渊下三层传闻中由疯王、孤王、龙王三方合作，意图不明。
- **道门与大宗**：道门有鬼术（隐秘，被冠以"阴天子"名号）；大宗有不传秘术（如炼魃术），因理念与世人不合被妖魔化。俗语"乱世道门盛世佛"——诸佛金身、道祖泥像，乱世不出、盛世渡人，"佛渡有元人"。
- **实验体制度**：墨渊内存在编号实验体（一号至若干号），每个实验体死亡/被封印后掉落对应编号吊坠，构成隐藏任务收集链。

## 属性系统

- **龙族血脉**：纯正程度分级；人族获得途径有两种推测——先辈与龙族交合，或强者屠龙采纳精血为子孙缔造。林天浩血脉过于纯正，被怀疑为屠龙而来。
- **境界划分**：大宗强者之上，拥有舍利子的大宗强者是完全不同的等级；天象境分上境与下境，二者实力差距非常大。
- **修炼方向**：体修（肉身淬炼路线）、尸道（活死人路线）；龙虎尊者选择破而后立，废掉原有修为改修炼体。
- **阴阳属性**：
  - 至阴之力：尸祖天月的尸气。
  - 至阳至刚之力：野心道长的金光咒、五雷正法。
  - 阴阳同根之龙血：活龙血（活体真龙之血）+ 死龙血（被炼为魔骨尸龙后的龙血），二者同根同源但属性相反。
- **阴阳佛血**：龙虎尊者炼化后预期产物，黑小萌若融合可对大部分佛法免疫或大幅减免伤害，道术伤害亦会下降。

## 装备系统

- **九号实验体的吊坠**：特殊品质，从空灵女妖被封印后的粘稠液体中获得。
- **舍利子**：大宗强者修炼而成的金色珠子，形成极难；可作封印核心（"以我舍利，封镇九方"），可引动天地之力，对感悟佛法有极大用处，价值不菲；取出后持有者虚弱至极。
- **符箓**：可包裹舍利子，屏蔽被封印者的听觉与外界感知。
- **储物戒指 / 储物法宝**：空间储物道具；空灵女妖提到林天浩"没有那么庞大的储物法宝"，无法承载整具龙骨。
- **袈裟**：龙虎尊者衣物，修炼时脱下。
- **权杖**：龙虎尊者原持法器，已失去。

## 技能系统

- **龙炎**：林天浩技能，可焚烧粘稠液体成黑色污垢碎块，持续全力输出消耗极大。
- **佛光普照**：龙虎尊者佛门术法，受体内黑色液体影响后佛光不如之前强盛。
- **掌心雷**：野心道长雷法，"雷法可破万邪"，可顺粘稠液体蔓延。
- **金光咒**：野心道长至刚至阳术法，可笼罩护体。
- **五雷正法**：野心道长至刚至阳雷法。
- **阴阳五雷**：
  - 含阴五雷（至阴，黑色粘稠液体状）与阳五雷（至阳，紫色雷霆）。
  - 设定上道门中人一人只能修炼一种雷法，不可能同时炼成，野心道长为特例。
  - 双雷同时拍出可用于淬炼体魄。
- **炼魃术**：大宗秘术，将自身炼成"活死人"，配合阴阳同根之龙血与阴阳双极之力可"一步登天"。
- **经文念诵**：龙虎尊者念诵繁杂经文，可使舍利子流转金色符文，压制并拷问被封印妖物。
- **无踪无迹**：无踪鬼童能力，难以被察觉；在其石室内被增强——速度更快，且攻击或被攻击均不会打破隐匿状态（优于刺客隐身）。

## 怪物系统

- **神灵级真龙**：可献祭自身复活机会与龙骨，汇聚岁月长河中的力量针对单一目标；被斩杀后可爆发出极强力量。
- **空灵女妖（九号实验体）**：由墨渊粘稠液体凝聚而成的人形怪物，可吸食精气；掌控粘稠液体作战；被封印于舍利子中。
- **无踪鬼童**：墨渊第六层存在，无踪无迹特性，攻击力一般，但在自身石室中能力被增强。
- **水蛭**：墨渊第六层另一种可吸食精气的存在，会留下粘稠液体。
- **魔骨尸龙**：黑小萌被炼制后的状态，本体为黑龙，实力恐怖，对雷法克制敏感。
- **疯王**：坳龙村老村长，实力"强可怕"，行踪不明，喜欢做奇奇怪怪的实验，是林天浩后续击杀目标。
- **孤王、龙王**：传闻与疯王合作于墨渊下三层。

## 副本系统

- **墨渊**：
  - **第六层**：空灵女妖、无踪鬼童所在层；遍布粘稠液体与缝隙，存在石室结构；石室会增强其中怪物能力。
  - **下三层**：疯王、孤王、龙王活动区域，具体内容不明。
- **诸神黄昏**：林天浩发育一年多的副本世界，可放弃全部属性技能重修（类比龙虎尊者废修为重修）。
- **隐藏任务**：收集齐全部实验体装备（吊坠）；林天浩目前已收集多件，仅差两件，预计当日可集齐，完成后触发击杀疯王的后续任务。
- **战利品机制**：击杀/封印实验体掉落对应编号吊坠，归属由队伍协商（林天浩与龙虎尊者就吊坠归属进行价格谈判）。

## 战斗系统

- **舍利子封印**：以舍利子为核心释放佛光封镇，被封印者以银白色流光形态被吸入舍利子；持有者会极度虚弱。
- **龙血淬体**：一次性大量吸收熔炼龙血对肉体负担极大，可造成肌肤、血肉、筋脉、五脏六腑寸寸龟裂，需配合阴阳之力调和；过程持续约两个半小时。
- **阴阳五雷淬体**：在龙血与阴阳之力淬炼基础上进一步强化体魄。
- **复活机制**：死亡后消耗复活币复活，林天浩被一分为二消耗四枚复活币才复活。
- **精气吸食**：粘稠液体可吸食目标精气，少量不明显，量大后非常麻烦。
- **石室增益**：怪物在自身石室中获得能力增强（如无踪鬼童速度提升、隐身不可破）。
- **境界突破预期**：龙虎尊者预期能"鲤鱼跃龙门"一步到达天象境下境。

## 特殊机制

- **龙血价值体系**：
  - 外界龙血按滴交易，拍卖场单滴可达一二十亿。
  - 林天浩与龙虎尊者议价：1斤龙血 = 10枚复活币（林天浩友情价）；林天浩白送10滴，剩余等价交换。
  - 黑小萌以"3斤阴阳佛血"作为日后偿还条件。
- **复活币交易**：队伍内部以复活币作为通用等价物进行装备/物资结算；龙虎尊者持有7枚复活币，议价后欠林天浩13枚（10滴白送 + 1斤换10枚，已付7枚，欠3枚；后以吊坠抵10枚，最终欠13枚）。
- **舍利子取用代价**：自行破开丹田取出舍利子，属"杀敌八百自损一千"的极端手段，持有者战力大幅削弱。
- **黑色液体侵蚀**：龙虎尊者体内一滴黑色液体可加速内劲溃散，可通过打坐恢复，但后续修为再进一步难如登天——是其决定破而后立的根因。
- **真假判断**：黑小萌可判断他人话语真假，用于牵制空灵女妖等不可信存在。
- **阴阳佛血克制关系**：黑小萌融合后对佛法免疫/减免、道术伤害下降，使其成为潜在不可控威胁；野心道长与龙虎尊者对此有所警惕。
- **实验体编号与实力悖论**：空灵女妖为"九号实验体"，按序号推断应不强，但实际战力强劲。
- **传音交流**：角色间可"私下传音"进行不为他人所知的对话（龙虎尊者与野心道长就禁地之事传音）。
- **体修重修路线**：废掉原有修为后改修炼体，需借助外力（龙血、阴阳之力、阴阳五雷）淬炼，全程可能三月五月或十年八年完成吸收炼化。
