# 第三百七十六章至第三百八十章 设定分析

## 一、基础设定

### 1.1 红枫古墟特殊规则
- **心境影响**：进入后会让人变得抑郁，觉得世间一切无用，甚至产生活着无用的念头
- **规则紊乱**：五转区域，规则运行不正常，超出正常范围的规则影响
- **压抑感**：潜移默化中影响欲望，削弱追求和动力

### 1.2 古火副本设定
- **名字与环境反差**：名为古火，实则极致寒冷
- **难度选择**：地狱级难度（奖励最大化）
- **关卡设计**：每关保底一个宝箱，通关评分高可能触发隐藏副本
- **特殊机制**：尸体复活规则，非控尸术，而是规则作祟

### 1.3 垂钓老人身份
- **身份推测**：人类始祖之一的黄帝
- **与凡殿关系**：凡殿老殿主的半个师父
- **任务发布**：三年内核山海帝国彻底复苏，奖励人王称号、人王令、人王剑

### 1.4 圣地出世计划
- **普陀天龙所属圣地**：隶属于东方的隐世圣地
- **出世策略**：踏着月轮魔宫出世
- **合作条件**：以凡殿为尊，全大陆公开

## 四、技能系统

### 4.1 冰灵火猴技能
- **狂暴**：提升攻击和防御
- **冰灵附身**：释放冰灵古炎
- **移形换影**：快速移动技能
- **冰炎锁**：冰冻控制技能
- **分心爪**：分散注意力的攻击技能

### 4.2 普陀天龙技能
- **佛法金光**：范围攻击，可击退尸体
- **禅杖射击**：枪械形态下的远程攻击
- **超度**：佛门技能，试图净化尸体

### 4.3 冰灵古炎特性
- **冰火双重**：既灼烧又冰冻
- **蔓延效果**：火焰命中后会蔓延到全身
- **持续伤害**：每秒1001点伤害
- **减速效果**：移速、攻速下降3.75%

### 4.4 尸体复活规则
- **复活机制**：非控尸术，而是规则作祟
- **媒介测试**：心脏、小脑、四肢、头颅均非操控媒介
- **传送跟随**：尸体会跟着玩家传送到下一关卡
- **摧毁方式**：需要彻底摧毁肢体才能阻止复活
