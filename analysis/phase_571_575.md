# 第五百七十一章至第五百七十五章 设定分析

## 一、基础设定

### 1.1 北荒海域海兽设定
- **内海**：一百海里内，海兽数量较少，品质较低（黑铁、青铜级）
- **北荒海域**：纵深超过百万海里，海兽数量增加，品质提升（白银、黄金级）
- **【魔】特征**：大部分海兽都跟【魔】沾点边，三天内击杀超过两千头跟【魔】有关的boss级海兽
- **反常现象**：前世这方海域似乎没有跟【魔】挂钩，大范围出现【魔】特征海兽，可能存在危险和机缘

### 1.2 魔眼幽灵鲲设定
- **类型**：七转海兽，黄金品阶
- **等级**：2198级
- **生命值**：15.2亿
- **攻击力**：189万
- **特征**：具备【魔】的特征
- **击杀**：林天浩开启天罚和三头六臂，一秒不到解决，首杀北海通报

### 1.3 凝水分身设定
- **来源**：击杀元水神灵后，弑神者印记获得的能力
- **属性**：拥有林天浩百分之五十的全属性
- **功能**：可以进行战斗，也可以进行摸尸
- **区别**：有别于一气化三清，是可以进行战斗的分身

### 1.4 血湖洞府设定
- **位置**：北荒海域
- **三洞主**：三角血虎鱼（身形似人，身上满是血色鳞片，头上有三枚奇怪犄角）
- **二洞主**：七彩海蟒（身着长裙的女子，太阳穴微微鼓起，有七彩鳞片包裹，眸子彩色流转）
- **反应**：发现林天浩屠杀海兽，派遣巡逻队探查，后下令黄金品阶以上海兽退走

### 1.5 极影蟹设定
- **能力**：速度极快，用于侦查
- **任务**：前往浩渺大陆探查情况，明天晚上回来
- **目的**：了解林天浩的底细和浩渺大陆的局势

### 1.6 王者海兽地盘设定
- **迹象**：高品阶海兽不增反减，几乎碰不到高品阶海兽
- **原因**：进入了某尊强大海兽王者的地盘，海兽有领地意识
- **应对**：林天浩准备继续前进，王者级海兽若来找麻烦就灭了它

### 1.7 魔腾鬼船设定
- **外观**：通体黑灰色，黑的像是干涸的血液，灰色是原本颜色，缠绕无数黑红色藤蔓
- **传说**：上面有一尊强大恐怖的虚空魔神附在上面，任何接触到魔腾鬼船的都会被吞噬
- **真相**：魔鬼藤占据了航船，飘荡在大海之上，成为让人畏之如虎的魔腾鬼船
- **诅咒**：攻击魔腾鬼船的人会被诅咒

### 1.8 魔鬼藤设定
- **类型**：诡异生灵
- **等级**：未知（？？？）
- **攻击力**：未知（？？？）
- **特征**：黑红色藤蔓，细小如钢丝，粗大如水桶
- **能力**：攻击速度极快，普通箭矢被轻易抽碎，天罚箭矢可命中，造成1.47亿伤害（无暴击）
- **诅咒**：血色藤蔓攻击，穿透领域，将人传送至魔腾鬼船内部

### 1.9 魔腾鬼船内部设定
- **环境**：船舱休息室，两张略显老旧的双人床，两张单人书桌，书桌上摆放古书
- **诡异现象**：房门锁死，耐磨度极高，需要大量攻击才能打碎；与亡灵之神失去联系
- **笔记本线索**：记录海员死亡事件，连续三天死亡人数翻倍，死者眼睛里长出洁白无瑕的花朵，最后一页写着“她来了”

### 1.10 诡异神灵设定
- **类型**：魔鬼藤是诡异生灵，还是诡异神灵
- **能力**：压制亡灵之神，改变林天浩容貌，制造幻象
- **规则**：诡异存在附属于自己的规则，无法被常规武力消灭，需要找到本体破解规则

### 1.11 龙凤仙岛设定
- **位置**：落星海域，距离大陆数十万海里
- **传说**：拥有两大神级传承，登岛之人都有机会获得
- **前世信息**：米国一批人去过，好几个得到神级传承，拥有超越同阶段冒险者的实力
- **神级传承**：不同于神级隐藏职业，可多人获得

### 1.12 海员设定
- **规模**：几十万人，都是五百级以上的五转者，不少超过一千级的六转职业者
- **性别**：全是男人，没有女人
- **目的**：寻找龙凤仙岛，获得神级传承
- **称呼**：黑子、小伍、撸铁、菲德华、麦林哥（麦林仔）

### 1.13 菲德华和麦林哥设定
- **关系**：情侣（受叫菲德华，攻叫麦林哥）
- **等级**：六百多级
- **行为**：在房间里堂而皇之的做运动，被撸铁驱赶

### 1.14 撸铁设定
- **等级**：一千一百五十一级
- **职业**：狂战士
- **态度**：血气方刚，受不了菲德华和麦林哥的行为
