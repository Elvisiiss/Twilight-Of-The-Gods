# 《诸神黄昏》设定提取 - 第136-140章

## 一、基础设定

### 1.1 王后菲欧丁雨击杀事件
- **身份**: 星辰王国王后，清芙芸的母亲
- **罪名**: 犯上作乱，意欲弑君
- **结局**: 自愿让林天浩击杀，获得悬赏奖励
- **任务**: 半个月内击杀国王亚伯拉，奖励自由属性点+1000，幽冥长弓+1，诸神的赐福+1
- **惩罚**: 升级所需经验值翻十倍

### 1.2 幸运手镯
- **等级**: 特殊
- **佩戴要求**: 无
- **效果**: 幸运+10
- **耐磨度**: 100
- **获取方式**: 击杀王后菲欧丁雨奖励
- **影响**: 死亡轮回和天火流星触发概率提升，从几百下触发一次提升到一百下左右触发一次

### 1.3 绿影套装
- **等级**: 黄金级
- **佩戴要求**: 10级弓箭手
- **属性**: 攻击力+9999，暴击+50%，生命值+150000，蓝量+15000，物穿+15%，移速+5
- **特点**: 不加攻速，被国王亚伯拉针对

### 1.4 丞相克森罗的邀请
- **身份**: 星辰王国丞相
- **提议**: 让林天浩成为星辰王国新王，迎娶三位公主
- **诚意**: 两个女儿成为侍女
- **条件**: 诸神赐福前置任务卷轴，任务要求成为星辰王国国王

### 1.5 大元帅洛林牧原的支持
- **身份**: 星辰王国大元帅
- **支持**: 与克森罗联手支持林天浩成为国王
- **条件**: 诸神赐福前置任务卷轴，任务要求一个月内成为星辰王国国王

### 1.6 神级隐藏职业·佛门神僧
- **等级**: 神级
- **传承者**: 普陀天龙
- **特点**: 现实是佛门高僧，精通佛门七十二绝技，可施展佛门神通

### 1.7 第二职业转职卡
- **等级**: 特殊
- **使用要求**: 目前只拥有一个主职业的玩家
- **效果**: 使用后可获得第二主职业
- **特点**: 一次性消耗品，使用后消散
- **价值**: 可转职两个隐藏职业，获得两个职业特性，近战远程切换，升级获得10个自由属性点

### 1.8 超度亡灵任务
- **发布者**: 普陀天龙
- **要求**: 一个月内超度十万亡灵（所有人形生命体死后的亡灵）
- **当前进度**: 108/100000
- **惩罚**: 无
- **奖励**: 第二职业转职卡

### 1.9 蒂雪涧之死
- **身份**: 星辰王国大公主
- **死因**: 勾结魔窟，意图谋反被国王亚伯拉发现，被通缉后死亡

### 1.10 后土赐福·城隍庙
- **等级**: 特殊建筑
- **使用要求**: 仅限雪帝，不可赠送，不可掉落，不可窃取，不可剥夺
- **效果**: 未知
- **耐磨度**: 不可摧毁
- **获取方式**: 洛林牧野任务完成奖励

### 1.11 知识神树的叶子
- **等级**: 传说级
- **来源**: 浩渺帝国圣地
- **价值**: 整个星辰王国都没有
- **获取方式**: 黑袍首领提供，作为击杀国王亚伯拉的额外奖励

### 1.12 浩渺无极宫
- **身份**: 浩渺帝国的势力
- **关系**: 黑袍首领可能来自浩渺无极宫
