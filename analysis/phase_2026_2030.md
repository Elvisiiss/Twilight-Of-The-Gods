# 第2026-2030章 设定分析

## 基础设定
### 世界背景
- **平行世界（时间长河支流）机制**（核心新设定）
  - 强行穿梭时间长河 → 在时间长河上开出一条分叉 → 形成平行世界（与主世界相同但时间线被破坏）
  - **支流不长久的本质**：支流在主流中流淌，会被未知力量污染
  - **不祥之力**：侵蚀进入时间长河支流的世界
    - 侵蚀一切：人、规则、所有一切
    - 最终世界完全被侵蚀，变成诡异秘境，回归主世界，成为人探索获宝的历练场所
  - **主世界无不祥法则**：理论上无法领悟不祥法则
  - **被不祥侵蚀的世界是无道状态**：无法领悟任何法则
  - **理论例外**：正在被不祥侵蚀的平行世界，有可能领悟不祥法则（但只是理论）
- **秘境起源机制**：所有秘境都是被不祥侵蚀的平行世界回归主世界形成
- **不祥侵蚀速度加快机制**：若继续穿梭时间长河，不祥侵蚀速度会加快
- **时间长河主流寻找**：理论上是顺着支流可找到主流回到主世界，但无人做到过
- **保留记忆的少数特例**：神界金字塔最顶尖的几位强者可以让人短时间清醒；正常进入时间长河者记忆全无
- **神界通道**：神界与仙界的通道已被斩断，信息也彻底断绝
- **雷罚殿规模**：明面上60位仙祖，暗地里可能还有
- **进入秘境者总数**：312人

### 主要势力与组织
- **雷罚殿**：仙界巨无霸，明面60位仙祖
  - 牵头阻止散修进入秘境
  - 寻找规则本源之心（最大目的）
  - 龙雷仙祖（神兽雷龙，仙祖初期）
- **孤王城**：3位仙祖坐镇
  - 浮生库龙（半步仙祖）
  - 张灵腐（半步仙祖）
  - 许闻声（半步仙祖）
  - 派出9人进秘境（每位仙祖可让3人进入）
- **神炼仙宗**：风影乘（大供奉，仙帝后期）参与秘境探索
- **天剑门**：匀剑仙帝（半步仙祖）、露蓉鳞（仙帝巅峰，仙祖之女）
- **无影宗**：与天剑门合作，6人组
- **万兽仙宗**：在魔瞳沙海出现的势力

### 关键NPC/人物
- **林天浩**（化名林小雨）
  - 半步仙帝境界，战力远超境界（露剑仙祖推测其战力"至少仙祖初期水准"）
  - 三炼之法900层
  - 时间、空间、火焰三种本源之道都达天道境九百九十九层
  - 即便仙祖出手，他亦有抗衡之力
- **葛卜拳**：青剑门仙帝，元凶之一，被林天浩一拳打爆身躯
- **瘦小男子**：葛卜拳同伙，掌握"虚空隐身大法"，自爆身亡
- **露蓉鳞**：天剑门长老，仙帝巅峰，仙祖之女
  - 持6柄帝兵飞剑
  - 持吞天葫芦
  - 被林天浩空间莲花困住，本源之火灼烧身躯和灵魂
- **露剑仙祖**：天剑门老祖，露蓉鳞之父，仙祖级
  - 隔空投影出手救人
  - 评价林天浩："此子甚是妖孽"，"真实战力我都看不透，但至少是仙祖初期水准"
  - 警告女儿："不可与之为敌"
- **林墨澄**：神界来人，仙王境界
  - 高马尾女孩，衣着与仙界略有差异
  - 了解规则类秘境
  - 父亲是位大人物（暗示打崩仙界之人）
  - 揭示不祥之力、平行世界、规则本源之心等核心信息
- **风影乘**：神炼仙宗大供奉，仙帝后期
- **张灵腐**：孤王城，半步仙祖
- **许闻声**：孤王城，半步仙祖
- **浮生库龙**：孤王城，半步仙祖（自称"小龙"）

## 属性系统
### 基础属性
- **三炼之法**：林天浩达到900层
  - 体魄、灵魂、能量三修
  - 即便葛卜拳反应快，长出的手臂仍被一掌崩碎
  - 一掌可让仙帝吐血、崩飞帝兵
- **不祥侵蚀**：会被不祥之力侵蚀的人或世界
  - 朋友、亲人、规则都逃不过
  - 最终变成诡异秘境中的怪物
- **境界与战力差距**：
  - 林天浩：半步仙帝境界，战力仙祖初期
  - 露蓉鳞：仙帝巅峰 + 6柄帝兵飞剑 + 吞天葫芦，被林天浩轻易压制

### 称号系统
- **道友**：仙祖互相称呼
- **小友**：仙祖对晚辈炼器师的称呼
- **林大师**：神炼仙宗、孤王城对林天浩的尊称
- **散修**：无势力修士
- **道主大人**（前世称呼）：仙界天道之主

### 品阶系统
- **境界细分**：
  - 仙帝初期 / 中期 / 后期 / 巅峰
  - 半步仙祖
  - 仙祖初期 / 中期 / 后期
- **战力跨越**：
  - 半步仙帝战力可达仙祖初期（林天浩）
  - 仙祖之女仙帝巅峰可被半步仙帝压制（露蓉鳞 vs 林天浩）
- **炼器师等级**：帝级炼器师 = 仙祖级地位

## 装备系统
- **不祥之剑**：诸神黄昏规则类宝物，被不祥侵蚀后层级提升
  - 效果：降低目标范围百分之五移动速度
  - 不祥侵蚀后效果对神界大能一样有效
- **帝兵飞剑（6柄）**：露蓉鳞的帝兵配置
- **吞天葫芦**：露蓉鳞葫芦类法宝，可吸收火焰
- **青色大印**：葛卜拳的帝兵（见风就涨）
- **金色长剑**：葛卜拳的帝兵
- **九张符箓（金光护身）**：葛卜拳保命符
- **数十符箓**：葛卜拳防御用
- **空间戒指 / 储物袋**：常规储物法宝
- **时空修炼宝塔**：林天浩专属（在无道秘境中仍可使用）
- **极品帝兵**：林天浩炼制可换世界之心
- **世界之心**（雷属性 / 火属性）：可赠予交换
- **不祥侵蚀宝物**：带出秘境后不祥之力会逐渐溃散

## 技能系统
### 林天浩技能
- **空间本源天道境之力**：可硬撕开世界之力
- **空间莲花**：可笼罩敌人，让帝兵飞剑都撕不开豁口；可燃烧本源之火
- **阴阳焚天炉**：火之异象
  - 由天道境九百九十九层火之本源之力催动
  - 融合林天浩对炼器一道的理解
  - 召唤火焰长龙
- **空间穿梭**：瞬移到敌人身侧
- **时空冻结**：四周时间和空间同时冻结，仙帝巅峰动用世界之力也无法短时间破开
- **时间错位**：让目标全身各处时间流速不同
- **三炼之法（900层）**：一拳打爆仙帝身躯
- **能量大手**：隔空一压，巨大能量手掌从天而降
- **灵魂力操控**：用强大灵魂力操控不祥之剑
- **吞天噬地**：在魔瞳沙海吞噬魔气，可同时增强灵魂和体魄（首次遇到）

### 露蓉鳞技能
- **界域**：仙帝级防御领域
- **吞天葫芦**：吸收火焰
- **六柄帝兵飞剑**：剑修配置

### 葛卜拳技能
- **后背长四臂**：可硬抗林天浩一掌
- **符箓防御**：九道金光护身
- **虚空隐身大法**：瘦小男子的隐身术

### 露剑仙祖技能
- **隔空投影**：从女儿体内飞出伟岸虚影
- **观察力**：看不透林天浩真实战力，但能推测"至少仙祖初期"

## 怪物系统
- **不祥侵蚀的怪物**（在秘境中）
  - 来自时间长河支流被污染的世界
  - 旧时间线的生灵，相对现在不存在，无法被杀死
  - 固定运行规则，遵循本能行动
  - 例如：王铁匠（诸神黄昏新手村NPC）
- **不祥生灵特性**：
  - 不能被带出秘境
  - 看到熟悉的"故人"会短暂恢复清明
- **【魔瞳】**：魔祖眼眸演化的巨大存在，散发魔气
  - 林天浩吞天噬地可吞噬魔气
  - 魔气可同时增强灵魂和体魄

## 副本系统
### 诸神黄昏新手村秘境（被不祥侵蚀的平行世界）
- **进入人数**：312人
- **入场规则**：每位仙祖可让3人进入；散修仙祖同样有权限
- **进入后状态**：
  - 道消失，能量消失
  - 储物袋打不开
  - 无法吸收仙石恢复仙力
  - 只能依靠肉身战斗或体内储存力量
- **特例**：林天浩的时空修炼宝塔仍能正常打开
- **环境**：暗红色天空，破败的村庄
- **结构**：与诸神黄昏新手村布局一模一样
- **NPC状态**：被不祥侵蚀，眼神空洞，对人产生奇怪反应
  - 王铁匠：林天浩出现时说"你回来了"，敲击铁块攻击心脏
- **进入最低时间**：5年（不到时间无法出去）
- **传送机制**：进入后被随机传送分散
- **宝物**：
  - 规则本源之心（最珍贵，比宇宙之晶还强大）
  - 不祥侵蚀的装备（被提升到不属于原层次的高度）
  - 复活币
  - 各种低阶装备被不祥侵蚀后变高级
- **特殊规则**：林墨澄提示，秘境看谋略、体魄和灵魂（不是常规境界）

### 魔瞳沙海
- **林天浩吞魔气修炼**：在【魔瞳】之上吞噬魔气
  - 同时增强灵魂和体魄（首次遇到）
  - 进入时空修炼宝塔第二层加速吞噬（3天=3年）
- **探索者聚集**：上千仙帝
  - 半步仙祖十几位
  - 各大势力 + 散修
  - 联盟机制：万兽仙宗、古尸圣殿等

## 战斗系统
- **半步仙帝 vs 仙帝中期**：林天浩轻松压制葛卜拳（一掌打爆身躯）
- **仙帝自爆**：仙帝中期自爆，仙帝巅峰硬扛也"有些不好受"
- **时空冻结**：林天浩可冻结时空，让仙帝巅峰无法逃遁
- **空间莲花禁锢**：仙帝巅峰 + 帝兵飞剑都无法撕开豁口
- **本源之火灼烧**：身躯和灵魂双重灼烧，痛得惨叫不断
- **仙祖投影**：可隔空显化，但只是投影（如露剑仙祖）
- **仙祖评价战力**：看不透林天浩真实战力，至少仙祖初期水准

### 战斗技巧
- **剑修同境界强出三分**：剑修优势
- **无道状态战斗**：纯粹肉身和招式，剑修剑法招式更有效发挥
- **背后偷袭**：葛卜拳吸引注意力，瘦小男子虚空隐身偷袭
- **符箓瞬移**：捏碎符箓瞬移消失

## 特殊机制
### 不祥之力机制
- **侵蚀范围**：人、规则、所有一切
- **侵蚀过程**：从支流开始，最终世界完全被侵蚀变成诡异秘境
- **不祥法则不在万法之中**：林天浩无法用万法之躯领悟不祥法则
- **不祥生灵特性**：
  - 杀不死（因为相对现在不存在）
  - 固定运行规则
  - 看到熟悉的故人会短暂恢复清明
- **不祥生灵不能带出秘境**
- **始作俑者**：使用时间长河制造出诡异世界的人，可以被带出秘境
  - 一旦被带走，秘境失去支撑，彻底崩溃，泯灭在时间长河之中

### 神界信息
- **神界金字塔最顶尖强者**：可让不祥侵蚀者短时间清醒
- **进入时间长河者记忆全无**：直至回到对应时间节点，记忆才复苏（那时不祥侵蚀也到顶峰）
- **神界疯子实验**：试图获取不祥之力，做实验，最终失败被打击销声匿迹

### 平行世界理论
- **平行世界是影子**：不是真实存在
- **穿梭时间长河者会被冲刷掉记忆和身上所携带的一切**
- **只有创造平行世界的人是真实存在的生命**（其他都是影子）
- **理论转机**：正在被不祥侵蚀的平行世界，有可能领悟不祥法则

### 储物装备限制
- **常规空间法宝**：在无道秘境中无法使用
- **时空修炼宝塔**：特殊法宝，在无道秘境中仍可使用

### 仙祖级权限
- **秘境进入权限**：每位仙祖可让3人进入
- **散修仙祖**：同样有权限带人
- **雷罚殿机制**：60位仙祖明面，资源丰富

### 林天浩的探索计划
- **目的1**：寻找炼制时空修炼宝塔第三层的宝物
- **目的2**：建立属于自己的势力，需要底蕴
- **目的3**：寻找能够破解不祥之力的方法
- **目的4**：寻找规则本源之心（创造规则本源世界突破仙帝）
- **目的5**：把不祥之力转移到自己所在的世界，争取破局时间

### 林墨澄揭示的关键信息
- 平行世界、不祥之力的本质
- 时间长河无法真正抵达过去或未来
- 平行世界在支流中会被不祥之力侵蚀
- 完全侵蚀后变成诡异秘境回归主世界
- 神界大能也无法阻挡不祥侵蚀
- 主世界没有不祥法则，无法领悟
- 例外：正在被不祥侵蚀的平行世界可能领悟不祥法则（仅理论）
