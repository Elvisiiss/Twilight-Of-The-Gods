# 第2016-2020章 设定分析

## 基础设定
### 世界背景
- **宇宙之晶**：凡界、仙界等世界的基础，通过空间长河汇聚各种力量凝结而成，诞生条件极为苛刻，万年至十万年才可能诞生一颗；演变世界后无法被掠夺，强行掠夺会承受因果反噬（即便是至强者都可能身死道消）
- **空间长河**：与时间长河并列的宇宙级概念，空间之道层次越高，能遁入的虚空层次越深；修炼者穿梭虚空、隐遁虚空都是进入空间长河；通过感应空间长河流向有可能找到宇宙之晶
- **凡界起源**：并非被人创造，而是在宇宙之晶的基础上自然诞生；没有人（包括源主）能真正创造充满万物生灵的世界
- **宇宙之晶用途**：顶尖强者寻找宇宙之晶以培养后辈突破仙帝境；用宇宙之晶创造的世界能产生功德、气运、香火等特殊力量；尤其气运之力可改天换地
- **诅咒机制**：仙界被打崩后，仙界众生受到诅咒，无法真正意义上领悟本源法则
- **因果反噬机制**：被人利用承受因果，可降低大能掠夺宇宙之晶的难度；当年打崩古仙界之人可能就是被利用来承受因果
- **时间长河穿梭机制**：
  - 穿越者不属于过去时代，记忆会被冲刷干净，所有一切都会消失
  - 直到重新来到现在的时间，记忆才会恢复
  - 身体会消失，只剩下一道光团
  - **特例**：拥有万法之躯本源抗性者，时间长河只能冲散身躯，无法冲散记忆
  - 寒气可注入光团护佑周全

### 主要势力与组织
- **雷罚殿**：仙界第一势力，拥有两位仙祖（祭雷老祖、噬雷老祖）
  - 祭雷老祖：温和派，不愿起无端争斗，能与外来者沟通
  - 噬雷老祖：粗犷中年人形象，雷罚殿第二位仙祖，后被仙界天道（道主）显化附身
- **百世仙宗**：百世老祖为九世仙祖级强者转世，本可突破仙祖境，但对境界无深执念
- **仙界天道/道主**：仙界天道之主，等级凌驾于仙祖之上（源主级），借噬雷老祖身躯显化
- **源主层级**：仙祖对应源神，源主高于源神，是仙界天道之主的层次

### 关键NPC/人物
- **林天浩**（化名"韩飞羽"）：半步仙帝境界，战力可斩仙祖；拥有空间、时间、火、灵魂、生命等多本源天道境999层；万法之躯、不灭兽魂、不死不灭（转生次数8）
- **祭雷老祖**：雷罚殿第一仙祖，主张与林天浩合作让其灌输本源之力恢复仙界
- **噬雷老祖**：雷罚殿第二仙祖，被仙界天道借身显化
- **百世老祖**：百世仙宗始祖，九世仙祖级转世；可九步演化源神虚影融入体内，九步后气息达源主境
- **巫灵儿**：黑天麒麟血脉女子，源主境强者；来历不凡，连仙界天道都要顾忌；持暗红色长枪
- **寒无心**：寒气女子，源主级强者，能冻结时间和空间的寒气；曾立誓"命运绑定，万世不改"保护林天浩的世界；与林天浩一同穿越时间长河
- **道主大人**：即仙界天道之主，借噬雷老祖身躯显化，渴望借林天浩时间本源之力穿梭时间长河改变过去
- **林伯浔**（伏笔）：林天浩之父，半步仙皇级，五兽血脉
- **罗夜镁**（伏笔）：林天浩之母，仙王级
- **林小雨**：林天浩重生后的名字（与打崩古仙界之人的女儿同名，疑为巧合）

## 属性系统
### 基础属性
- **能量层次**：决定性因素，半步仙帝即使领悟本源法则，仍受限于"自身能量层次太低"的根本缺陷
- **万法之躯本源抗性**：极高，包括时间本源抗性；可抵挡时间长河的冲刷，保留记忆
- **不灭兽魂 / 不死不灭**：转生次数8（说明非转生而来）
- **兽神之躯**：林天浩本有血脉之力

### 称号系统
- **道主**：仙界天道之主，源主级
- **韩飞羽**：林天浩在仙界使用的化名
- **道友**：仙祖级别强者互相的称呼

### 品阶系统
- **仙王（行星级）→ 仙皇（恒星级）→ 仙帝（星系级）→ 仙祖（星域级）→ 源神 → 源主**
- 仙祖对应源神，源主高于源神
- 半步仙帝：林天浩重生前境界
- 半步仙祖：介于仙帝和仙祖之间

## 装备系统
- **帝兵虹芒**：喋血魔帝手中的帝兵（伏笔，下一阶段触发事件）
- **三足小鼎（噬雷镇天鼎）**：噬雷老祖的帝兵，可变大如山岳从天而降
- **短刀**：噬雷老祖战斗使用的近战帝兵
- **暗红色长枪**：巫灵儿的武器
- **世界光轮**：噬雷老祖演化的小世界，充满雷霆与雷霆生灵

## 技能系统
### 本源之力战斗技巧
- **本源领域**：本源之力形成领域（如雷之本源星河领域），威力远超单纯法则乱轰
- **空间本源领域**：林天浩对抗星河雷域所用
- **空间莲花**：林天浩绝学，可让雷霆之力围绕旋转无法伤身；境界提升后威力天差地别
- **吞天噬地**：林天浩吞噬能力，面对仙祖级强者时已无用
- **空间穿梭**：林天浩瞬移手段
- **时间本源异象：时间错位**：让目标范围全身各处时间流速不同（如手臂10倍、丹田50倍、脑袋100倍、腿200倍），导致身体不协调，影响"气"的运转
- **时间本源之力**：强行改变四周时间流速，让目标攻击变迟缓
- **黑洞吞噬**：可吞噬雷霆光束等能量攻击

### 噬雷老祖技能
- **星河雷域**：以雷之本源之力构建的星河，具有真实星河之力
- **眉心紫色符文**：释放雷霆光束的仙祖级神通
- **世界光轮**：本源世界之力显化，可撕开时间本源
- **九条手臂**（伏笔）：噬雷被附身前的伏笔

### 百世老祖技能
- **九步源神虚影融合**：每走一步身后浮现一尊源神虚影融入体内，九步后达源主境
- "本想积累百世"：暗示百世轮回积累能力

## 怪物系统
- **雷霆生灵**：噬雷老祖世界光轮中由雷霆诞生的生灵
- **死星**：星空中无生命星球，强者战斗波及可摧毁数颗
- **生命星球**：脆弱，仙祖级战斗波及即可摧毁

（本阶段未明确，仅铺垫世界观）

## 战斗系统
- **战斗场地选择**：仙祖级战斗需飞至天外，远离生命星球，否则随便一点战斗波动就可摧毁生命星球
- **仙祖级战斗波动**：能蔓延数万里，形成黑色藤蔓之花般的裂缝
- **战斗观察机制**：仙帝级强者可在星球上感知天外战斗
- **境界与战力差距**：
  - 半步仙帝 vs 仙祖：林天浩可正面对抗噬雷老祖的星河雷域
  - 一拳对轰数百次：林天浩与噬雷老祖近身战斗，"舒爽"体验
  - 力量层次差距：噬雷老祖力量比林天浩只强不弱
- **恒星作为武器**：仙祖可操控恒星撞击目标（噬雷老祖用两颗恒星做"肉夹馍"攻击）
- **火焰焚烧恒星**：林天浩两团火焰点燃并焚烧两颗恒星
- **天威锁定**：噬雷老祖使用仙界天道之力锁定林天浩

## 特殊机制
### 时间长河机制
- **时间长河**：可以划开虚空显现，朝着过去行走
- **时间本源之力冲刷**：疯狂冲刷身躯
- **身躯消散**：只剩光团
- **寒气护佑**：源主可从胸口拉出一缕寒气打入光团保护
- **时间长河裂缝**：可被撕开口子，光团钻出后到达过去时间节点

### 重生机制
- **重生为婴儿**：被生下来的"大胖小子"
- **记忆保留**：万法之躯的本源抗性使记忆不被冲散
- **万法之躯积累悟性保留**：积累的本源抗性依然在
- **血脉来源**：暗示林天浩原本就属于这个时代/星空（五兽血脉伏笔）

### 命运绑定
- **命运誓言**：源主级强者可立下"命运绑定，万世不改"的誓言
- **玄妙契机**：誓言落下会落在两人身上形成命运契约
- **命运已定**："因果已成，命运已定"——命运机制不可违背

### 因果机制
- **因果反噬**：强行掠夺宇宙之晶会承受因果反噬
- **降低因果**：让他人承受因果，可降低掠夺宇宙之晶的难度
- **大世界对抗承担因果**：让两个拥有宇宙之晶的世界相互对抗，承担彼此因果

### 仙界恢复机制
- **本源之力灌输**：将空间本源之力灌入仙界本源，可使仙界得到恢复
- **时间问题**：凭一人灌输万年也难让仙界完全恢复
- **飞升者贡献**：刚飞升者灌输仙力，本源强者灌输本源之力
