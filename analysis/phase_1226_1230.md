# 第1226-1230章 设定分析

> 本文档基于第1226章至第1230章原文内容整理，覆盖主线主角林天浩（玩家ID：雪帝）在古神秘境中获取神灵传承、遭遇各类木系怪物及植物异种的剧情，提取所有可见的游戏设定数据。

## 基础设定

### 世界观与地理
- **古神秘境**：本阶段主要场景，特殊秘境，对外开放，内含神王境、神皇境强者众多；普通神灵拥有较小地盘（庭院+洞府结构）
- **无尽星海**：进入古神秘境的必经通道，需具备资格方可进入
- **银河世界**：主角阵营所属世界
- **无尽星空**：异种生物来源地，可引入其他世界物种
- **沼泽地宫**：血食者一派（正柳无烟、师爷）的据点

### 神灵社会规则
- 神灵居所结构：外层庭院供子孙后代及仆人居住，洞府为神灵个人居所；双修神灵外，夫妻神灵极少共用洞府
- 神灵之间纯粹爱情稀少，多数结合是为延续更强大血脉后代
- 神灵与凡人结合困难：层次差距过大，后代难以超越神灵自身；男性神灵与女性凡人结合时，凡人母体难以承受胎儿生长
- 拥有强大血脉的凡人会成为神灵青睐对象
- 神灵批量与凡人结合产生的后裔大多存在缺陷

### 玩家系统
- **玩家ID**：雪帝（林天浩）
- **全服通告机制**：击杀重要怪物后触发全服通告，可选择隐藏姓名
- **原地复活**：玩家拥有原地复活能力，但存在无法复活的极端情况
- **天人合一状态**：进入后悟道速度加快；无意识状态下可提前预判危机攻击
- **天地共主**：林天浩被设定为天地共主，可视为天地宠儿

### 阵营与势力
- **血食者**：相互之间为争夺血食可以内斗，但排斥勾结人类屠杀同族者
- **虫魔三皇**：血食者阵营下属
- **正柳无烟、师爷**：血食者阵营核心，散布雪帝持有神灵尸体的消息以借刀杀人
- **青牙鬼煞**：半帝级NPC，与雪帝合作猎杀同族血食者，对古神秘境了解有限（后期进入吃残羹剩饭）
- **尼德栗芙、黑天傲真**：林天浩麾下顾问型NPC，提供识见支持
- **罗天之主**：可击杀三帝大人的强者，见识广博，主角寄望其提供异种信息

## 属性系统

### 数值体系
- 伤害/生命值采用"亿"作为主要单位（如 -29亿、-2611亿、31257亿）
- 毒伤采用"万"为单位（如 -19万/次）
- 自由属性点为通用资源（地心球藤掉落+200，对当前阶段主角属"毛毛雨"）

### 关键属性维度
- **生命值（HP）**：以亿为单位衡量
- **攻击力**：以亿为单位衡量
- **减伤**：降低受到的伤害
- **毒抗**：降低持续中毒伤害
- **减速免疫**：天罚之靴可免疫任何减速效果
- **生命蜕变**：已完成蜕变的生命体对毒抗和减伤有显著加成

### 等级与境界体系
- **职业者等级**：王级 < 皇级
  - 王级职业者无法完全抗衡普通神灵
  - 皇级职业者可压制普通低级神灵
- **神灵境界**：普通神灵 < 神王境 < 神皇境
- **帝级相关境界**：帝级（大帝）/ 半神 / 伪神，等级在10000级左右或更低
- **转生/转职层级**：十转 < 十一转 < 十二转（推测地底植物异种为十一转或十二转）

### 悟道系统
- 悟道速度受多重加成：天人合一状态、造化玉碟、其他加成
- 法则修炼阶段示例：火系法则可至"真意圆满"

## 装备系统

### 已知装备
- **嗜血龙甲**：受攻击时回血（与地心球藤回血机制类似），技能层次较低，面对强者效果大打折扣
- **修罗神剑**：林天浩主武器，可引动天雷地火；配合"邪剑仙形态"使用
- **天罚之靴**：免疫任何减速效果
- **楼中楼**：青牙鬼煞持有，可变大作为武器砸下，内部含规则可周旋敌人；但可能被腐蚀性黑色液体破坏
- **造化玉碟**：悟道加成道具
- **封神榜**：可将强大生物融入其中以增强领地防御（主角意图收入地底异种）

### 掉落系统（地心球藤示例）
- 装备+5
- 技能书+3
- 自由属性点+200
- 金币+5000
- 其他杂物
- 该阶段掉落对主角基本无用（凑数性质）

### 装备评分
- 装备词条以"+N"形式表示数量
- 高阶装备由强者使用方有意义

## 技能系统

### 主角技能
- **箭由心发**：以意念控制羽箭发射
- **天罚锁头**：附着于羽箭，使羽箭无视阻挡必中目标；但被黑色液体吞噬无效
- **天罚之手（进化版）**：林天浩最强回血手段之一
- **枯木逢春**：逆天级百分比回血技能，回血效果极高
- **空间闪烁**：瞬间位移技能
- **邪剑仙形态**：剑仙变身形态
- **天雷地火**：通过修罗神剑引动，天雷从天降劈斩藤蔓，地火从地面焚烧
- **无意识的天人合一**：被动预判危险，可避开无法感知的攻击

### 感知/识见类技能
- **神识**：地底行动的主要感知手段
- **火眼金睛**：可用眼睛观察地底深处
- **洞察之眼**：范围大但需目光所及，无法窥探地底深处

### 领域类技能
- **领域展开**：皇级以上强者可施展，可被更强攻击打出裂纹
- 青牙鬼煞的领域可被赤色藤蔓打出细小裂纹，被黑色液体腐蚀

### 怪物技能（玄木古人）
- 再生、复生、恢复、蜕变、进化
- 无尽藤蔓、无尽分身
- 血肉繁殖、狂暴、霸体

### 怪物技能（地心球藤）
- 受攻击时回血（类似嗜血龙甲）
- 藤蔓数量持续增加，可达上百条

### 怪物技能（地底植物异种）
- 藤蔓穿透虚空
- 藤蔓钻入伤口蔓延至心脏
- 黑色液体腐蚀领域
- 黑色液体具备生命特征，可自主躲避剑气
- 黑色液体可吞噬天罚锁头羽箭
- 神识完全无法感知其藤蔓与液体

## 怪物系统

### 地心球藤（1226章）
- 出现位置：木系神灵庭院中央（伪装为小树苗）
- 机制：受到攻击时恢复生命值
- 攻击：藤蔓从地下破土抽打
- 伤害：每条藤蔓约29-33亿
- 主角击杀伤害：每箭2611亿，对方回血1305亿+100亿/次
- 仍被主角击杀

### 玄木古人（王级，1227章）
- 等级：10000级
- 生命值：31257亿/31311亿
- 攻击力：59亿
- 木系生命值偏高（木系天生生命力强）
- 特性：
  - 不断裂变分身，分身生命值与技能低于本体，但攻击力完美继承
  - 藤蔓不惧火焰
  - 可遁入地底，留下藤蔓继续攻击
  - 数之不尽的藤蔓四面八方席卷
- 弱点：属性相克（火克木）

### 地底神秘植物异种（1228-1230章）
- 推测等级：帝级，等级≤10000级，可能为半神或伪神；可能为十一转乃至十二转
- 来源：可能来自无尽星空或其他世界的异种（非银河世界原生物种）
- 隐藏地底，本体始终未现身
- 太古异种类别，守地盘时天然立于不败之地
- 攻击力递增的藤蔓梯队：
  1. **赤色藤蔓**：王级亡灵难以应对，会被击杀
  2. **金色/暗金色藤蔓**：可对抗半帝级青牙鬼煞，单击伤害315亿、201亿、202亿
  3. **黑色藤蔓**：可追击主角与青牙鬼煞，使主角感到威胁
- 黑色液体：从黑色藤蔓中流出，漆黑如墨，有生命特征
  - 可腐蚀青牙鬼煞的领域
  - 可吞噬天罚锁头羽箭
  - 可避开剑气
  - 接触被命中后果严重
- 战术特点：逐步展露实力，疑似"老叟戏顽童"
- 击杀难度极高：植物系生命力强+始终藏地底+本体不可见

### 木系神灵果园陷阱（1230章）
- 枯萎果树仍能发射尖刺（如羽箭般高速飞行）
- 普通亡灵难以反抗
- 神灵留下的物品即便衰弱也不至于太弱

### 亡灵（主角召唤物）
- 亡灵状态战力为巅峰的70%
- 包括：风之俊男、火之俊男等
- 高阶亡灵数量有限，损失后伤不起
- 风之俊男、火之俊男被地底异种湮灭

## 副本系统

### 古神秘境（主副本）
- 开放性：会对外开放，可重复探索
- 内含神灵传承、神灵尸体、神王尸体等高价值资源
- 进入条件：需通过无尽星海（需资格）
- 多方势力混战：人类玩家、血食者、外部强者（来吃残羹剩饭）

### 神灵居所子区域
- **庭院结构**：可容纳数百至上千人居住
- **洞府**：神灵私人居所
- **果园**：神灵被击杀后果树枯萎，但残留陷阱仍具威胁
- 单个神灵地盘面积有限

### 传承获取
- 火系神灵传承：普通火系神灵传承，马马虎虎
- 木系神灵传承：林天浩正在收集
- 传承由青牙鬼煞带路寻找

## 战斗系统

### 伤害数值示例
| 攻击方 | 目标 | 单次伤害 |
|--------|------|----------|
| 地心球藤藤蔓 | 风之俊男 | 29亿-33亿 |
| 林天浩羽箭 | 地心球藤 | 2611亿（含回血1305亿+100亿） |
| 暗金藤蔓 | 青牙鬼煞 | 315亿 |
| 黑色藤蔓 | 青牙鬼煞 | 201亿、202亿 |
| 奇幻花毒 | 林天浩 | 19万/次（持续） |
| 毒素持续伤害 | 青牙鬼煞 | 5亿+/秒 |

### 战斗机制
- **属性相克**：火克木（火之俊男 vs 玄木古人应有胜算）
- **百分比回血**：枯木逢春、地心球藤均采用百分比回血
- **领域对抗**：领域可被物理攻击打出裂纹，可被腐蚀液体侵蚀
- **天雷地火**：范围AOE，可摧毁大量藤蔓（瞬息超千条）
- **走位闪避**：高机动单位可纯靠走位避开藤蔓
- **必中机制**：天罚锁头使羽箭无视藤蔓阻挡
- **吞噬机制**：黑色液体可吞噬羽箭
- **法印拖拽**：青牙鬼煞法印可定位并拖拽地底目标，方圆十里地动山摇

### 减伤/抗性体系
- 林天浩：高减伤+生命蜕变+毒抗 → 毒素几乎无感（19万/次相较生命值连挠痒痒都不算）
- 青牙鬼煞：自身有毒抗+生命蜕变，仍每秒掉血5亿+
- 减速免疫：天罚之靴完全免疫任何减速

## 特殊机制

### 全服通告
- 击杀重要怪物触发
- 可选择隐藏姓名
- 可被用作情报战工具（血食者散布雪帝持有神灵尸体消息）

### 中毒机制（多状态叠加）
| 毒素名称 | 效果 | 持续时间 |
|----------|------|----------|
| 奇幻花毒 | 持续掉血（19万/次） | 持续 |
| 裂变古花之毒 | 承受伤害+100% | 5分钟 |
| 诡豆花毒 | 所有治疗效果-50% | 5分钟 |
| 白莲古毒 | 持续掉血 | 持续 |

### 楼中楼规则空间
- 可变大作为武器
- 内部含独立规则
- 可将敌人拉入其中周旋
- 但无法承受腐蚀性液体（会被破坏）

### 封神榜机制
- 可将强大生物融入封神榜
- 用于增强领地安全（特别是地底防御）
- 主角意图将地底异种收入其中

### 地底作战限制
- 主角可在地底自由行动，但主要依赖神识
- 火眼金睛可用眼睛观察地底
- 洞察之眼范围大但需目光所及
- 地底异种的藤蔓/液体神识完全无法捕捉

### 太古异种领地机制
- 守地盘时天然立于不败之地
- 攻击梯次递增（赤→金→黑）
- 本体不可见，仅斩藤蔓百千条也难伤根本

### 石碑攻击机制（1230章）
- 从天而降，数量递增，速度递增
- 散发乌光笼罩目标
- 限制身躯，迟滞灵魂
- 每块石碑落下增加压力
- 天罚之靴免疫其减速效果
- 无意识天人合一可预判落点

### 阴沟翻船原则
- 强者常因轻视小风险而死亡，而非被强敌追杀
- 林天浩用亡灵探路策略基于此原则
- 验证：风之俊男、火之俊男因探路触发陷阱而湮灭
