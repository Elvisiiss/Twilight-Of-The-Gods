# 第961-965章分析

## 基础设定

### 岗亭规则世界
- **核心**：岗亭内存在强大的规则之力，岗亭主人实力恐怖
- **规则**：不进入岗亭、不违背岗亭规则就不会有事
- **危险**：踏足岗亭的人会发生不可测变化，可能被某种存在占据身体和记忆

### 六道闸门
- **第一道**：切断林天浩与已释放攻击的联系
- **第二道**：切断林天浩与身上装备的联系
- **第三道**：切断林天浩身体和大脑之间的联系
- **推测**：第四道可能涉及灵魂层面，第五、六道可能涉及因果轮回

### 摩罗塔楼规则世界
- **现状**：各楼层出现岗亭主人的分身
- **威胁**：密密麻麻数十位岗亭主人同时出现，视觉冲击强烈
- **危险**：岗亭主人可脱离岗亭行动，但受限于某些规则

### 妄莱城危机
- **严重性**：超越萨德·林丐月能够掌控的极限
- **困境**：离开妄莱城的人都有各种原因死亡，99%的人无法离开
- **根源**：妄莱城与真世界接壤，被各种不可逆规则侵蚀

## 属性系统

### 体魄蜕变（第三次）
- **效果**：每五点伤害实际掉血1点（之前是每四点掉1点）
- **提升**：伤害减免从75%提升到80%

### 灵魂升华（第二次）
- **效果**：灵魂厚实程度提升一倍，承受灵魂系伤害降低55%，施展灵魂系攻击效果提升55%

### 邪剑仙形态确认
- **攻击品阶**：超过圣人级，能够伤害规则世界中的诡异存在
- **防守能力**：开启后可抵御精气神被抽离的效果

## 技能系统

### 绝对穿梭（超神级技能）
- **效果**：瞬间穿梭空间，脱离危险区域
- **用途**：逃离岗亭主人的六道闸门攻击

### 天罚锁头（绝对类技能）
- **特性**：必定命中，无法被彻底破解
- **限制**：岗亭的规则之力可切断其与林天浩的联系

### 邪剑仙形态（超神级传承）
- **效果**：天地变色，剑出天雷地火，攻击品阶超过圣人级
- **防守**：可抵御精气神被抽离，守护灵魂

## 战斗系统

### 林天浩vs采茶女（续）
- **战斗方式**：邪剑仙形态释放天雷地火+箭由心发天罚锁头
- **采茶女技能**：戏袍加身，转移攻击到戏台子，戏台子吸收伤害
- **结果**：戏台子不堪重负碎裂，采茶女被岗亭主人收编

### 林天浩vs岗亭主人
- **战斗方式**：邪剑仙形态攻击岗亭
- **岗亭主人技能**：六道闸门，逐层切断林天浩与攻击、装备、身体的联系
- **结果**：林天浩使用绝对穿梭逃离，岗亭主人展现恐怖实力

### 林天浩vs音响老太婆
- **战斗方式**：邪剑仙形态攻击
- **老太婆技能**：镜像分身，音乐影响理智，抽离精气神，突然消失
- **结果**：老太婆突然消失，林天浩无法追踪

## 特殊机制

### 规则世界交织机制
- **现象**：岗亭规则世界与中心广场规则世界交织在一起
- **后果**：天罚羽箭悬停在岗亭外，攻击速度骤降
- **范围**：可能整个妄莱城的规则世界都交织在一起

### 记忆篡改机制
- **可能性**：亡灵之神怀疑自己记忆被篡改
- **危险**：若记忆可被篡改，林天浩的重生秘密可能暴露
- **解释**：窥探记忆极为困难，需从无数记忆碎片中寻找有用信息

### 精气神抽离机制
- **效果**：音响老太婆可抽离目标体内的精气神
- **抵抗**：邪剑仙形态可抵御这种效果

## 重要事件

### 采茶女被收编
1. 采茶女逃入岗亭，天罚羽箭悬停在岗亭外
2. 岗亭主人出现，扔出戏袍给林天浩
3. 林天浩摧毁戏袍，获得体魄蜕变和灵魂升华
4. 林天浩贪婪攻击岗亭，岗亭主人暴怒

### 六道闸门事件
1. 第一道闸门切断林天浩与已释放攻击的联系
2. 第二道闸门切断林天浩与装备的联系
3. 第三道闸门切断林天浩身体和大脑的联系
4. 林天浩使用绝对穿梭逃离

### 音响老太婆现身
1. 中心广场出现真正的规则诡异（提音响的老太婆）
2. 老太婆变年轻，抽离林天浩精气神
3. 林天浩开启邪剑仙形态抵抗
4. 老太婆使用镜像分身，突然消失

### 摩罗塔楼危机
1. 各楼层突然亮灯，出现岗亭主人的分身
2. 数十位岗亭主人同时质问林天浩
3. 萨德·林丐月出面保护林天浩
4. 岗亭主人忌惮摩罗塔楼内的存在，撤退

### 妄莱城危机揭露
1. 萨德·林丐月透露妄莱城危机远超想象
2. 离开妄莱城的人都有各种原因死亡
3. 99%的人无法离开妄莱城
4. 岗亭主人不是妄莱城最大的麻烦
