# 第1466-1470章 设定分析

## 基础设定

### 地理与势力
- **神州大地**：统称，包含中州大陆、浩渺大陆等。
- **中州大陆**：当前正遭迷雾怪物肆虐，已失去远程传信能力，发生翻天覆地的变化。
- **浩渺大陆**：林天浩所属领地，曾被无极登天宫屠戮数以百亿百姓。
- **神域**：神品之境强者可前往追求更高境界之地。
- **凡殿**：林天浩所在的势力，设有副殿主等职位。
- **无极登天宫**：中州大陆超级势力之一，与林天浩为不死不休的敌对关系。
- **怒龙城**：中州大陆城池，城主为烈红雨（红雨大帝），城主府秘境入口位于黄金盒子内。
- **众神黄昏**：当前时代背景，疑似已无神品之境强者存世。
- **帝落时代**：神州大地当前所处的时代，神灵遗弃之地。

### 秘境机制
- **黄金盒子**：内含秘境入口，黄金能隔绝迷雾对秘境的侵蚀。
- **秘境规模**：怒龙城主府秘境很大，内有城池、湖泊、小楼，可容纳大量人口生存。
- **黄金屋**：城池外可利用其生存的器具。

## 属性系统

### 转数与品阶
- **转数体系**：七转、九转等（林天浩当前为七转冒险者）。
- **品阶**：可通过特殊任务提升，品阶+1为特殊任务奖励，极其稀少（大帝之境强者也未必拥有）。
- **品阶提升效果**：
  - 林天浩品阶再提升一次，可打出五千万亿以上的秒伤。
  - 品阶再提升两次，伤害甚至可能达到数万兆。

### 自由属性点
- **获取途径**：通过收容迷雾怪物提交任务获得。
- **兑换比例**：1只迷雾怪物 = 1万自由属性点。
- **实例**：半月收容298只迷雾怪物；提交320只迷雾怪物 = 320万自由属性点。

### 生命值与回血
- **迷雾怪物回血**：每秒回血数值不低于六千万亿。
- **林天浩生命值**：当前不缺，可利用迷雾怪物叠加生命值。

## 装备系统

### 黄金系列器具
- **黄金盒子**：内含秘境入口，可关押收容迷雾怪物，可隔绝迷雾侵蚀。
- **黄金战车**：焚心梦魇操控的交通工具，具备漂移能力，原本迷雾怪物对其敬而远之。
- **黄金锁链**：焚心梦魇操控的攻击/束缚武器，可化作流光席卷八方，能够缠绕迷雾怪物。
- **黄金屋**：城外生存器具。
- **黄金特性**：
  - 对迷雾怪物有克制作用。
  - 坚韧程度有限，迷雾怪物若反抗可轻松打穿黄金。
  - 之前能够收容怪物是因为怪物被黄金压制后基本不会反抗（被定义为无法反抗）。
  - 怪物相互吞噬后可能对黄金产生免疫力，出现挣脱黄金锁链的现象。

### 其他装备
- **天罚之手**：林天浩的武器/手段，连体魄蜕变都无法幸免于难。

## 技能系统

### 技能品阶机制
- **技能品阶固定**：大部分攻击、技能、神通品阶固定，无法提升。
- **后期衰减**：技能阶位不够时，面对品阶过高的对手效果大幅下降。
- **道的提升**：道是少数能够不断提升品阶的手段，理论永无止境。

### 林天浩技能
- **雷电跳跃**：触发概率已很高，但对高阶生灵基本无效。
- **冰冻之心**：神灵级技能，对品阶过高对手基本没用。
- **本源灼烧**：神灵级技能，对品阶过高对手基本没用。
- **天地同心**：冷却型技能，使用后可大幅推进悟道境界（如将空间大道推至问道境第十四层）。

### 体魄蜕变
- **减伤效果**：非常离谱，连天罚之手都无法幸免。
- **弱点**：可被道的力量从根源上摧毁。

## 怪物系统

### 迷雾怪物
- **等级**：最差都有九转铂金级的力量。
- **回血能力**：每秒回血不低于六千万亿。
- **行为特征**：
  - 遇到危险会跑路，提前发现危险时收容困难。
  - 原本对黄金战车敬而远之，近期开始主动攻击。
  - 会相互吞噬增强。
- **相互吞噬机制**：
  - 转化率约30%（远超正常吞噬类手段的5%）。
  - 永久性增强，气息攀升后不回落（观察3天无回落）。
  - 可连续吞噬，无冷却限制。
  - 争斗形式简单，纯力量比拼，败者被张口吸入。
  - 前十二天未发生相互吞噬，近三天发生五次（异常频率上升）。
- **生命共同体假说**：吞噬转化率离谱，疑似同根同源、曾为一个整体（与创世神传说相关）。

### 石头巨人
- **特征**：拖拽巨斧的石头人，体型巨大但动作不慢。
- **攻击方式**：挥动巨斧，可斩断黄金铁链。
- **反抗能力**：被黄金铁链缠绕后仍能挣扎，使黄金铁链出现裂纹。
- **气息**：比一般收容的怪物强大，但未强大太多。

### 墨麟水
- **本体**：墨麒麟。
- **境界**：与沙海毒帝分开时已达皇级巅峰，如今可能已达大帝之境。
- **状态**：在中州大陆很久未出手，踪迹成谜。

## 副本系统

### 秘境
- **位置**：通过黄金盒子进入。
- **怒龙城城主府秘境**：烈红雨居所，湖泊旁有小楼。
- **关押风险**：秘境中关押的迷雾怪物可能相互吞噬，最终只剩一只极恐怖的怪物，可能从内部打破秘境。

## 战斗系统

### 境界体系
- **冒险者转数**：七转、九转等。
- **品阶级别**：铂金级等。
- **境界进阶**：皇级巅峰 → 大帝之境 → 神品之境 → 神王之境 → 神帝 → 圣人境 → 天道圣人 → 更高境界。
- **半步境界**：如半步神品之境（黑天傲真）。

### 战力对比
- **中州大陆底蕴**：还有好几位大帝之境的强者。
- **神品之境**：整个诸神黄昏疑似已无存世，极为罕见。
- **黑天傲真**：半步神品之境，可吊锤变异后的迷雾怪物。
- **焚心梦魇、沙海毒帝**：联手收容迷雾怪物。

### 伤害数值
- **林天浩当前**：七转品阶。
- **提升一次品阶**：可打出五千万亿以上秒伤。
- **提升两次品阶**：伤害可能达到数万兆。

## 特殊机制

### 道的系统
- **道境层次**：问心境 < 问道境 < 法则境 < 道境。
- **问道境层数**：
  - 第十二层：天赋逆天可达，可成就道境。
  - 第十三层：天赋、资质、道统再强也无法达到，需圣人境之上超级大能转世，凭借前世圣人因果加持才可能领悟。
  - 第十四层：前所未见，闻所未闻（林天浩达到）。
  - 第十五层：疑似可达（林天浩空间大道在问道境未走到底）。
- **道的特点**：力量可从根源上摧毁其他力量（如体魄蜕变），是少数能持续提升品阶的手段。
- **已知大道**：力之大道、空间大道。

### 转世重修机制
- **前世觉醒**：前世境界越高，觉醒前世记忆越迟。
  - 普通神灵转世：出生有异象，脑海有功法加持。
  - 神王之境转世：出生平平无奇，成长后测试天赋时觉醒部分修炼记忆。
  - 圣人境转世：觉醒更迟，避免引动天地异象招来仇家。

### 封神榜
- **功能**：击杀目标送入封神榜，可获得相应信息（如击杀烈红雨可获知整个中州大陆信息）。

### 创世神传说
- **传说内容**：天地初开只有一人，头顶天脚踏地，境界实力不详，撑开混沌天地；其死后身体化作天地万物与生灵，被尊为创世神。
- **关联设定**：迷雾与迷雾怪物疑似为创世神死亡后分散的整体，故吞噬转化率离谱。
- **推测境界**：迷雾怪物最差为九转铂金级，整体活着时的境界至少天道圣人级或更高。

### 远程传信
- **失效原因**：因迷雾笼罩，中州大陆已失去远程传信能力，需派人外出通知。

### 任务系统
- **特殊奖励任务**：如品阶+1任务，极其稀少，大帝之境强者也未必拥有。
- **任务交流**：大帝强者之间非敌对关系时会交流部分任务奖励信息。
- **收容任务**：怒龙城可提交收容的迷雾怪物，转化为自由属性点奖励。

### 体魄蜕变减伤
- **效果**：非常离谱，连天罚之手都无法幸免。
- **克制**：道的力量可从根源上摧毁。
