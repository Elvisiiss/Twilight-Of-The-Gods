# 第四百六十一章至第四百六十五章 设定分析

## 一、基础设定

### 1.1 弗德兰城地下城设定
- **位置**：弗德兰城城主府深处地下
- **结构**：螺旋台阶向下，约半小时路程
- **内容**：一座小城，上万七转起步的高手
- **特点**：幽冥之气浓郁且纯粹，压迫感极强

### 1.2 奥鲁圣地设定
- **身份**：弗德兰城背后的势力，隐世圣地
- **实力**：上万七转起步的高手，七转起步，品阶不低
- **统治者**：奥鲁弗德兰（高品阶神灵）
- **特点**：表面打着月轮帝国旗号进攻希图帝国，实则嫁祸山海帝国

### 1.3 奥鲁弗德兰设定
- **身份**：奥鲁圣地之主，高品阶神灵
- **等级**：宗师级半神
- **特点**：面容妖异，看穿林天浩的七十二变伪装，信仰之地规则由他掌控
- **目的**：阻止山海帝国完全复苏，需要大量女人

### 1.4 域外邪魔设定
- **类型**：意识体，不死不灭
- **能力**：大范围勾动人的七情六欲，让人变得癫狂
- **封印**：奥鲁弗德兰制造梦幻空间封存其意识，需要源源不断的女人满足其七情六欲

### 1.5 营养仓设定
- **类型**：科技感十足的营养仓
- **数量**：保守估算不低于十万个
- **内容**：每个营养仓中躺着一个女人，身体在营养仓中，意识在梦幻空间被折磨
- **位置**：城堡中央深井一圈，从深井最深处堆砌上来

### 1.6 空间裂缝设定
- **位置**：深井下方
- **连接**：连接黄泉世界（充斥幽冥之气的世界）
- **作用**：幽冥之气的来源，奥鲁圣地留在这里就是为了镇压空间裂缝

### 1.7 亡灵之神感知设定
- **能力**：亡灵大道对灵魂的感知力极强
- **发现**：奥鲁圣地真正的生命体不超过十人，大部分人没有灵魂，是行尸走肉或假象
- **结论**：奥鲁弗德兰在狐假虎威，一切都是假象

### 1.8 奥鲁圣地第二尊神灵设定
- **身份**：身材瘦小的男人
- **特点**：散发出强横的力量，与海神波塞冬抗衡
- **真相**：可能是假象，并非真实存在的神灵

### 1.9 黄泉世界设定
- **类型**：充斥幽冥之气的世界
- **连接**：通过空间裂缝与浩渺大陆连接
- **作用**：幽冥之气的来源

### 1.10 弗德兰城阴谋设定
- **计划**：以月轮帝国旗号进攻希图帝国，嫁祸山海帝国
- **细节**：所有细节都朝着山海帝国引，让希图帝国误以为是山海帝国进攻
- **目的**：让月轮帝国和希图帝国联手对付山海帝国
