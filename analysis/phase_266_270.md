## 一、基础设定

### 1.1 东方古国名称
- **山海帝国**：东方古国正式名称
- **复苏范围**：取代瀚海王国、混乱之地、无尽海、幽冥之地四大区域，向浩渺大陆和通幽古墟蔓延

### 1.2 圣地体系
- **凡殿**：山海帝国背后的圣地
- **圣地职责**：在国家危难时出手相助
- **圣地特点**：事情少、资源多，类似核武器，不到万不得已不出手

### 1.3 职业等级体系
| 等级 | 名称 | 说明 |
|------|------|------|
| 1-9转 | 凡人转职 | 九次转职，九次蜕变 |
| 半神 | 超越凡人 | 逐渐超脱凡人程度，但仍是凡人 |
| 伪神 | 无限接近神灵 | 但还不是神灵 |
| 神灵 | 真正的神灵 | 神灵之间亦有强弱之分 |

### 1.4 悟道境界
| 境界 | 说明 |
|------|------|
| 真意 | 领悟道的初级阶段 |
| 问心 | 真意圆满后的下一境界 |
| 法则 | 领悟法则力量 |
| 问道 | 追寻道的真谛 |
| 道境 | 具备成为神灵的资格 |

### 1.5 天赋与隐藏职业等级
- **神级天赋/隐藏职业**：具备成神潜力，开发全部潜力基本都能成神
- **超神级天赋/隐藏职业**：超越神级，能触碰世界顶端，突破神灵极限（成圣）
- **神级之下**：需香火成神、悟道成神等，难度系数大

## 七、特殊机制

### 7.1 造化玉碟机制
- **悟道加速**：领悟道的速度提升100倍
- **道的记录**：承受道的攻击后自动记录，可观摩悟道
- **效果**：林天浩在15天内海之真意到达化实高级（真意圆满）

### 7.2 封神榜机制
- **名额限制**：名额一旦使用永久占用
- **恢复效果**：上封神榜后击杀可恢复巅峰状态
- **权衡**：把名额给九转高手有些吃亏

### 7.3 生死簿机制
- **功能**：写下目标名字使其持续掉血
- **应用**：对海神波塞冬使用，准备击杀后救治上官虹旬

### 7.4 凡殿领地机制
- **等级**：九转星耀级
- **领地贡献值**：1亿/1000亿
- **属性加成**：十三种属性加成，含全系减伤和弹速提升
