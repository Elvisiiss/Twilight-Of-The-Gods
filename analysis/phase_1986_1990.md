# 第1986-1990章 设定分析

## 基础设定
### 世界背景
- 故事发展到暴乱星海、修仙界、仙界等多地
- 四方边界设定揭示：
  - **东方**：永恒火海（星球间火焰连接成火海网络，不知何因燃烧）
  - **西方**：无尽黑暗（彻底黑暗，吞噬一切，让人迷失）
  - **北方**：极寒之地（无冰雪，但能冻结灵魂，只有寒天族能进入）
  - **南方**：暴乱星海（动乱星域，空间极其不稳定）
- 神域可能在四方边界之外
- 暴乱星海：空间极其不稳定，易被拉入空间乱流，有星空异种和星空灾害
- 修仙界：一块独立大陆，面积约十几个星系大小，有妖兽和修仙者
- 仙界：通过登仙台飞升或大乘期渡劫飞升到达
  - 浩瀚无垠，星域上千个
  - 灵力、神力、圣力都有
  - 雷罚殿（类似神域雷罚神殿）

### 主要势力与组织
- **天域三巨头**：九宫殿、兽神山、寒天楼
- **五行仙宗**：被曹自泫震慑，结束与龙须洞天纷争
- **雷罚殿**：仙界势力，与神域雷罚神殿一字之差
  - 镇守使：卢月仙王
  - 铸仙楼：飞升者灌输仙力之地
- **东雪雷燕一族**：仙界妖族势力
- **修仙家族石家**：修仙界家族，挖骨移植

### 关键NPC/人物
- **林天浩（韩飞羽）**：半步恒星级，星系级炼器师
- **寒赋源**：寒赋瑶三哥，星系级，战斗狂人
- **羽金焰**：妖族金翅狱焰鸟，星系级后期
- **洛芸凤**：人族，真凤血脉，星系级后期（原男性，血脉觉醒后中性）
- **小恶魔**：邪恶气息少年，无名字，救下女婴，林天浩传记忆种子
- **女婴**：身怀至尊法骨，后背脊椎骨散发数十种道韵
- **陈无敌**：飞升者，苦修八千年成仙
- **东雪珂薰**：东雪雷燕一族，飞升者
- **封七**：铸仙楼仙官，地仙（武神后期），雷罚殿
- **卢月仙王**：南土星域唯一仙王，雷罚殿镇守使

## 属性系统
### 基础属性
- **天罚之脑（10星）**：任意攻击永久降低目标10亿最大生命值
- **百花起，落花贴**：11种本源法则化作花朵，命中目标每秒永久降低110亿最大生命值
- **真凤血脉**：对生命力感知极其敏锐（洛芸凤）
- 仙界能量体系：灵力、神力、圣力都有

### 称号系统
- **星系级炼器师**：林天浩在寒天楼的身份
- **无敌武神**：林天浩的称号
- **飞升者**：仙界对新来者的称呼
- **散仙**：大乘期渡劫失败后侥幸活存的修仙者
  - 八级散仙、九级散仙等

### 品阶系统
- 武道境界：半步恒星级 → 恒星级 → 半步星系级 → 星系级 → 半步星域级 → 星域级
- 仙界境界划分：人仙 → 玄仙 → 地仙 → 天仙 → 仙王 → 仙皇 → 仙帝 → 仙祖
  - 人仙 = 武神初期
  - 玄仙 = 武神中期
  - 地仙 = 武神后期
  - 仙王/仙皇/仙帝/仙祖 = 行星级前/中/后/巅峰（推测）
- 散仙级别：八级散仙、九级散仙
- 星空异种品阶：行星级、星系级、星域级
- 修仙境界：大乘期（渡劫飞升）

## 装备系统
- **时空修炼宝塔**：林天浩炼制
  - 第一层：30倍时间差
  - 第二层：365倍时间差
- **复活币**：林天浩在空间风暴中发现
  - 外观与银河世界复活币相似
  - 与诸神黄昏有关联的物品
- **宝灵图**：寒赋源的空间法宝，可藏人
- **长鞭**：仙官武器，可打飞飞剑
- **飞剑**：陈无敌的绝世飞剑（雷火淬炼九九八十一次）
- **仙石**：
  - 下品仙石
  - 飞升者需100万下品仙石或灌输仙力300年
  - 东雪雷燕一族只需1万下品仙石
- **盔甲**：仙官装束

## 技能系统
- **空间本源道境**：第十二层
  - 空间穿梭赶路
  - 扭曲空间阻挡攻击
  - 空间风暴中勉力支撑
- **时间本源之力**：扭曲时间护佑自身
- **百花起，落花贴**：
  - 11种本源法则（金木水火土、风雷冰、空间、时间、剑）化作花朵
  - 配合天罚之脑永久降低目标生命值
  - 每秒降低110亿最大生命值
  - 未来"百花齐放"可达每秒降低千亿生命值
- **天罚之脑（10星）**：任意攻击永久降低目标10亿最大生命值
- **不灭兽魂**：灵魂力强大
- **兽神之躯**：十大基础属性无时无刻不在增加
- **万法之躯**：持续提升悟性和抗性
- **曹自泫三篇功法**：炼体、炼魂、炼气（各300层）
- **记忆种子**：林天浩打入小恶魔识海
  - 包含炼器炼丹心得
  - 空间本源法则感悟
- **凤鸣**：洛芸凤的攻击，火焰光环扩散逼退敌人
- **冻结行星**：寒赋源隔空一抓，冻结十数颗行星撞击敌人

## 怪物系统
- **星空异种**：
  - 暴乱星海中生存，只有攻击本能，无法沟通
  - 星系级需星域级才能说话
  - 行星级、星系级、星域级等
  - 举手抬足可打爆恒星
  - 古籍记载：可能由强大无匹的生灵创造
- **银眼八爪鱼**：从黑洞中出现，与银河世界克系神灵有关
- **妖兽**：修仙界的怪兽，最强约武王级星兽水平
- **八只星系级星空异种**：暴乱星海遭遇

## 副本系统
- **暴乱星海**：南方边界，空间极其不稳定
  - 空间乱流
  - 空间风暴（可轻易摧毁恒星）
  - 星空异种密集
  - 危险与机遇并存
- **修仙界**：独立大陆，十几个星系大小
  - 妖兽生存
  - 修仙者追杀邪恶气息之人
- **登仙台/仙路**：散仙登仙界途径
  - 雷霆、火焰、幻象、刀光剑气
  - 3000梯后雷霆真正恐怖
  - 6667台阶：心魔劫（最难一关）
  - 仙门：登临仙界
- **铸仙楼**：飞升者灌输仙力之地
  - 灌输仙力300年或100万下品仙石
  - 顶部最强仙官：武神后期（地仙）
  - 门口十几个武神初期仙官
- **雷罚殿**：仙界势力，管辖铸仙楼
- **南土星域**：仙界星域，有地图

## 战斗系统
- **林天浩 vs 星系级星空异种**：
  - 百花起落花贴降低生命值
  - 天罚之脑10星永久降低10亿生命值
  - 11种本源法则命中每秒降低110亿生命值
- **寒赋源三人战斗**：
  - 冻结行星撞击敌人
  - 凤鸣火焰光环逼退
  - 星系级星空异种举手抬足打爆恒星
- **曹自泫 vs 五行仙宗**：
  - 巨大手掌笼罩宗门
  - 击碎道境99层藤蔓、土龙
  - 五色大阵被压制
- **仙路考验**：
  - 雷霆：林天浩万法之躯无视
  - 心魔劫：6667台阶，林天浩灵魂力驱散
  - 林天浩一瞬破心魔
- **仙官 vs 陈无敌**：仙官长鞭打飞飞剑
- **林天浩 vs 封七**：林天浩瞬间禁锢地仙

## 特殊机制
- **天域规定**：行星级不可在生命星系战斗
- **四方边界**：
  - 东：永恒火海
  - 西：无尽黑暗
  - 北：极寒之地（仅寒天族可入）
  - 南：暴乱星海
- **神域位置**：可能在四方边界之外
- **天罚之脑（10星）**：
  - 任意攻击永久降低目标10亿最大生命值
  - 对星系级星空异种生效
  - 对银河世界永恒之境强者基本不生效
- **百花起，落花贴**：
  - 11种本源法则化作花朵
  - 命中每秒降低110亿生命值
  - 未来"百花齐放"可达千亿
- **复活币**：与银河世界复活币相似，在空间风暴中发现
- **空间风暴**：
  - 可轻易摧毁恒星
  - 可将人卷入空间乱流
  - 林天浩空间本源道境第十二层勉力支撑
- **登仙台/仙路**：
  - 散仙登仙界途径
  - 大乘期渡劫失败后选择
  - 6667台阶心魔劫最难
  - 林天浩一瞬破心魔
- **仙界飞升**：
  - 大乘期渡劫飞升
  - 登仙台攀仙路飞升
- **铸仙楼规则**：
  - 飞升者需灌输仙力300年
  - 或100万下品仙石
  - 有背景者可减免（东雪雷燕一族只需1万）
- **仙界境界**：人仙、玄仙、地仙、天仙、仙王、仙皇、仙帝、仙祖
- **仙界星域**：上千个，南土星域有地图
- **雷罚殿**：与神域雷罚神殿一字之差，暗示仙界与神域有关
- **仙祖**：雷罚殿最强者境界
- **小恶魔考验**：
  - 林天浩考验小恶魔是否挖女婴道骨
  - 小恶魔拒绝，林天浩传记忆种子
- **至尊法骨**：女婴后背脊椎骨，散发数十种道韵
- **真凤血脉**：洛芸凤拥有，对生命力感知敏锐
- **真凤血脉觉醒**：影响性别（原男性变中性）
- **东雪雷燕一族**：仙界妖族，可减免铸仙楼费用
- **记忆种子**：林天浩打入小恶魔识海，传授炼器炼丹心得和空间本源法则感悟
- **银河世界关联线索**：
  - 银眼八爪鱼（与克系神灵相似）
  - 复活币
  - 曹自泫（像眼镜）
  - 蔚蓝星球
  - 雷罚殿（与雷罚神殿一字之差）
