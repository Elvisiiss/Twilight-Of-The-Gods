# 第四百九十一章至第四百九十五章 设定分析

## 一、基础设定

### 1.1 归叶无青 vs 天忍血佛战斗设定
- **战斗过程**：归叶无青用火雨逼出天忍血佛，天忍血佛用魔法护盾抵挡，归叶无青故意装作没发现，火球拐弯砸向天忍血佛；天忍血佛秒进潜行，归叶无青卖破绽，天忍血佛用替身假死，真身在归叶无青身后背刺击杀
- **战斗结果**：天忍血佛获胜，归叶无青落败
- **特点**：归叶无青技能华丽，天忍血佛危机意识强，替身假死反杀

### 1.2 双子星天赋设定
- **类型**：罕见天赋，一般同时出现，两个人共用一个天赋
- **效果**：相互之间可以共享彼此的属性
- **等级**：黄级到神级，不同层次共享属性比例不同（黄级10%，玄级20%，地级50%，天级100%）
- **例子**：图图鲁圣山双子星兄弟（圣级，孪生兄弟，共享全属性）

### 1.3 人器合一设定
- **类型**：特殊能力
- **效果**：人器合一，越战越勇，每次攻击比前一次更强
- **例子**：铁锤战士人锤合一，巨斧战士人斧合一

### 1.4 血魔鬼修设定
- **类型**：魔道修行方式
- **效果**：通过杀戮变强，需要击杀人形生命体才能变强
- **例子**：西极神殿高大壮汉（领悟真意，问心无我层次）

### 1.5 天忍血佛设定
- **身份**：西极神殿参赛选手（原白洛克圣地）
- **职业**：刺客
- **特点**：第一个加入圣地的玩家，秒进潜行状态，现实是顶尖忍者，危机意识强，替身假死反杀，藏于影子之中的隐匿之法
- **装备**：忘忧匕首（白洛克神殿任务奖励）

### 1.6 高大壮汉设定
- **身份**：西极神殿参赛选手
- **职业**：狂战士
- **特点**：领悟真意，问心无我层次，血魔鬼修，血色掌印和鬼影重重攻击

### 1.7 忘忧匕首设定
- **类型**：特殊装备
- **来源**：白洛克神殿任务奖励
- **效果**：打破人器合一状态，造成高额伤害

### 1.8 封赤大元帅设定
- **身份**：浩渺帝国顶梁柱之一，手握重兵的权臣
- **特点**：为人刚正不阿，军中威望高，喜欢狐族女子
- **结局**：前世为狐族女子公然造反，失败被镇压，狐族被追杀

### 1.9 狐族女子设定
- **身份**：封赤大元帅的妻子
- **特点**：妖艳动人，嫁给封赤大元帅的目的是利用他的权势帮助狐族崛起
- **结局**：前世封赤大元帅造反失败，狐族被追杀

### 1.10 圣地天骄新人赛下午场设定
- **对阵**：图图鲁圣山 vs 西极神殿
- **结果**：西极神殿获胜，晋级四强
- **赛制**：淘汰赛制，每轮五局三胜

## 二、属性系统

### 2.1 归叶无青属性
- **等级**：1级（法师）
- **技能**：满天冰锥、满天火球、满天风刃、满地土刺、法术盾牌、替身术
- **特点**：技能华丽，杀伤力强，战斗技巧和心性不如天忍血佛

### 2.2 天忍血佛属性
- **职业**：刺客
- **技能**：秒进潜行、替身假死、藏于影子之中的隐匿之法、背刺
- **装备**：忘忧匕首
- **特点**：危机意识强，把握时机精准，现实是顶尖忍者

### 2.3 双子星兄弟属性

- **职业**：狂战士
- **技能**：人器合一（人锤合一、人斧合一）
- **特点**：默契高，越战越勇，每次攻击比前一次更强

### 2.4 高大壮汉属性
- **职业**：狂战士
- **领悟**：真意，问心无我层次
- **技能**：血色掌印、鬼影重重
- **特点**：血魔鬼修，攻击力强，压制双子星兄弟

### 2.5 天忍血佛背刺伤害

### 2.6 双子星兄弟攻击伤害

- **战斗过程**：归叶无青用火雨逼出天忍血佛，天忍血佛用魔法护盾抵挡；归叶无青故意装作没发现，火球拐弯砸向天忍血佛；归叶无青卖破绽，天忍血佛用替身假死，真身在归叶无青身后背刺击杀
- **战斗结果**：天忍血佛获胜，归叶无青落败
- **特点**：归叶无青技能华丽，天忍血佛危机意识强，替身假死反杀

### 9.2 双子星兄弟 vs 高大壮汉和天忍血佛（2V2）
- **战斗过程**：双子星兄弟人器合一，越战越勇；高大壮汉血色掌印和鬼影重重压制；天忍血佛藏于影子之中，三柄飞刀和匕首背刺打破巨斧战士人器合一，击杀巨斧战士；高大壮汉和天忍血佛联手击杀铁锤战士
- **战斗结果**：西极神殿获胜，拿下赛点
- **特点**：双子星兄弟越战越勇，天忍血佛一招打破人器合一，血魔鬼修攻击力强

### 9.3 归叶无青和盾战士 vs 高大壮汉和天忍血佛（2V2）
- **战斗过程**：归叶无青法术瞬发，盾战士守护在归叶无青身边；天忍血佛用忘忧匕首打破盾战士盾牌，击杀盾战士；归叶无青无力回天，被击杀
- **战斗结果**：西极神殿获胜，晋级四强
- **特点**：忘忧匕首打破盾牌，天忍血佛针对盾战士出手

### 9.4 战斗策略
- **归叶无青策略**：大范围法术攻击，卖破绽引诱敌人
- **天忍血佛策略**：秒进潜行，替身假死，藏于影子之中，针对盾战士
- **双子星兄弟策略**：人器合一，越战越勇，默契配合
- **高大壮汉策略**：血色掌印和鬼影重重压制

### 9.5 关键技能应用
- **替身假死**：天忍血佛的核心技能，反杀归叶无青
- **人器合一**：双子星兄弟的核心技能，越战越勇
- **血色掌印**：高大壮汉的核心技能，压制双子星兄弟
- **藏于影子之中**：天忍血佛的隐匿之法，欺骗性强
- **忘忧匕首**：天忍血佛的核心装备，打破人器合一和盾牌
- **魔法护盾**：天忍血佛抵挡火雨伤害，不触发潜行状态打破

## 十、特殊机制

### 10.1 替身假死机制
- **效果**：替身承受攻击，真身隐藏，然后反杀
- **特点**：欺骗性强，出其不意

### 10.2 人器合一机制
- **效果**：人与武器合二为一，越战越勇，每次攻击比前一次更强
- **破解**：攻击特定地方，亦或者足够强横的攻击伤害

### 10.3 双子星天赋机制
- **效果**：相互之间可以共享彼此的属性，不同等级共享比例不同
- **特点**：完美互补，默契高，易打出梦幻联动

### 10.4 血魔鬼修机制
- **效果**：通过杀戮变强，需要击杀人形生命体才能变强
- **特点**：攻击力强，压制力强

### 10.5 忘忧匕首机制
- **效果**：打破人器合一状态，造成高额伤害，打破盾牌
- **来源**：白洛克神殿任务奖励

### 10.6 秒进潜行机制
- **效果**：瞬间进入潜行状态，移速不受影响
- **特点**：特殊潜行技能，普通潜行有三秒前摇，移速下降

### 10.7 藏于影子之中机制
- **效果**：隐匿之法，藏于影子中
- **特点**：欺骗性强，按正常思路会判断为潜行状态

### 10.8 修德里·浩鸿干预机制
- **目的**：阻止希图帝国和月轮帝国战争扩大
- **手段**：与两国协商，只让石坦城和石垭城打，不追究后续

### 10.9 圣地天骄新人赛机制
- **规则**：每个圣地参赛人员最少六个，最多八个，淘汰赛制，每轮五局三胜
- **奖励**：丰厚，第一名获得神器和天赋高级进化

### 10.10 浩渺帝国叛乱机制
- **人物**：封赤大元帅（刚正不阿，手握重兵），狐族女子（妖艳动人，利用封赤大元帅）
- **过程**：封赤大元帅为狐族女子公然造反，失败被镇压，狐族被追杀
- **林天浩计划**：帮助提高造反成功率
