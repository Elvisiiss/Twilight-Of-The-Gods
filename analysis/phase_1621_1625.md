# 第1621-1625章 设定分析

## 基础设定

### 世界背景
- **诸神黄昏**：游戏世界，以打怪升级为核心机制，可能前往神域以后才会涉及到修炼天赋。
- **大灾变倒计时**：最后十个月，时间紧迫，是推动剧情的重要时间节点。
- **银河世界**：主角所在的世界，面临被摧毁的威胁。
- **阿来特星系**：外部敌对势力，企图入侵银河世界，建立道统招收天才冒险者。

### 主要地理区域
- **浩渺大陆**：主要活动区域，猿山城位于其中。
- **九幽之地**：林天浩在此经历了四千多年苦修（外界仅一年多），可获取幽冥钻心竹等材料。
- **不周圣地 / 不周古地**：深处有由巨大石柱组建的奇怪建筑，为超神级隐藏职业转职祭坛所在地；曾有盘古一族存在。
- **地心世界**：林天浩往返的据点之一。
- **古朝秘境**：另一处超神级隐藏职业转职祭坛所在地。
- **猿山城**：阿来特星系在浩渺大陆建立道统的所在地。

### 异世界体系
- **异世界职业者涌入诸神黄昏**：包括修仙者、武者、天使世界、玄龙世界等。
- **散仙机制**：修仙者大乘期后应飞升成仙，飞升失败且未死于雷劫者可修成散仙。
  - 散仙不算神灵，但拥有堪比神灵的战斗力。
  - **十二阶散仙**：据说已堪比三品神灵，因存在岁月悠久，甚至超过三品神灵。
- **异世界强者目的**：搜寻各种宝物，重金收购特殊装备道具，把控重要九转副本，压缩蓝星冒险者发育空间。

### 核心规则
- **神灵不能出手**：神灵无法直接干预诸神黄昏，但异世界散仙等"卡BUG"存在可绕过此规则。
- **时空蝴蝶效应**：林天浩作为"时空蝴蝶"，其行为改变了历史走向（前世未出现异世界强者扎堆现象）。

## 属性系统

### 角色属性
- **蓝量**：技能消耗资源（如星空步每次位移消耗10000蓝量）。
- **生命值**：受到攻击会降低，可被护盾类技能降低伤害，可自然恢复。
- **熟练度**：技能拥有熟练度属性（如0/100），可用于技能升级。

### 力量层级体系
- **凡人级** → **神灵级**（一品、二品、三品等） → **神帝级**
- **圣人级**：高于一般神灵层级（如空天古兽的天赋手段层级已至圣人级）。
- **界域级**：高于神域层次的力量体现。

## 装备系统

### 转职相关装备
- **天罚装备**：用于超神级隐藏职业转职消耗。
- **天罚戒指**：林天浩持有的转职道具，可在转职祭坛触发转职。
- **超神级天赋觉醒石**：用于天赋觉醒的稀有道具。

### 武器装备
- **金色宝塔（金塔）**：六臂巨人空天萨林的武器，可飞出撞击敌人，具不小威能。
- **圣器残片**：金德兰的武器，暗红色金属碎片，可悬浮于空、撕裂虚空、洞穿手掌，可被界域阻挡。
- **道之源神的刻刀**：林天浩的武器，可划开圣人级囚笼。
- **重盾**：胖子使用的武器，可砸地触发技能。
- **长枪**：血蝉王使用的武器。
- **飞剑 / 长剑**：剑无双、白衣剑圣使用的武器。

### 特殊道具
- **山海图**：至宝，可用于携带银河世界之人跨越星域逃亡。
- **昆仑镜**：林天浩拥有的位移类至宝。
- **时空修炼宝塔**：用于专门提升技能熟练度的修炼场所。
- **幽冥钻心竹**：九幽之地获得的材料，质地特殊，非直接食用。
- **丹药**：可治疗伤势（六臂巨人服用来恢复）。

## 技能系统

### 超神级隐藏职业：天罚弓箭手
- **转职机制**：通过天罚戒指在转职祭坛进行，每次转职称为"X转"（如第八转、第九转）。
- **转职现象**：不周古地上空雷云翻滚，光柱劈开雷云从天而降落在转职者身上。
- **转职收益**：每转获得新技能。

### 星空步（未知品质）
- **当前星级**：1星
- **效果1**：在一颗星球上时，可无限位移，不限距离，无冷却（在神域一次位移最多一百万亿公里）。
- **效果2**：在无尽星空时，每一步可抵达下一颗星球，最多连续走九步，每步冷却一小时。
- **效果3**：技能到达十星时，升华为"星域步"，每一步可跨越一个星域。
- **消耗**：10000蓝量/次位移
- **冷却**：跨越星球一步一小时，可累积九步
- **熟练度**：0/100

### 林天浩其他能力
- **绝对穿梭**：位移类技能。
- **无敌虚化**：位移/保命类技能。
- **天罚之手**：伤害类手段。
- **十六大圣人异象**：林天浩掌控十六种圣人异象，实力突飞猛进，凡人中几乎无人能抗衡。
- **空间之道**：林天浩对空间之道有掌控。
- **灵魂法则**：林天浩在灵魂法则上造诣极高，掌握本源灵魂真意。

### 六臂巨人技能
- **六臂擎天 / 天地囚笼**：空天古兽的天赋手段，层级已至圣人级。
  - 六条巨大手臂从大地拔地而起，在云霄抓取冰蓝色铁链。
  - 拉出冰蓝色囚笼笼罩目标区域。
  - 共有九十九层，纵使神帝强者也难从中出来。
  - 囚笼被划开后会瞬间恢复，不留痕迹。
  - 可连同整个猿山城一同笼罩。
- **神域 / 界域展开**：六臂巨人可展开神域，为首者可展开界域层次的力量。
- **空间挪移**：可瞬间空间移动躲避攻击。
- **空间壁垒**：无形防御壁垒，可阻挡法则攻击。

### 金德兰技能
- **圣器残片操控**：操控多枚暗红色金属碎片进行攻击，可洞穿身体、撕裂虚空。
- **本源灵魂之力凝炼武器**：从眉心抽出一缕本源灵魂之力凝炼成钢针状武器，蕴含本源灵魂法则力量。
  - 可刺入对方眉心，无视界域防御。
  - 持续搅动精神识海，造成剧烈痛楚。
  - 需消耗心神持续操控。

### 白衣剑圣技能
- **势（剑势）**：一种玄妙的力量，无坚不摧、无物不破的绝对自信之势。
- **一剑斩**：可撕开六臂巨人的神域，是唯一正面撕开神域的冒险者。

### 胖子技能
- **群体嘲讽**：高品技能，强制范围内敌人朝自己移动，连六臂巨人也无法免疫。
- **钢铁洪流**：用重盾砸地，召唤上千尊体型高大的钢铁巨人冲向敌人。
- **守护之盾**：给目标释放能量盾牌，降低目标承受的大部分伤害。
- **霸王引**：冲锋类技能，可瞬间冲杀到敌人前方。

### 血蝉王技能
- **心脏共振**：范围性攻击手段，以自身为中心方圆百里，瞬间让生灵心脏跳动速度大幅度增加，几乎不能防御，造成心脏痛楚与生命值损失。
- **流光化身**：身体化作流光进行高速移动攻击。
- **血色翅膀**：三对血色翅膀，震动时触发心脏共振。

### 苏璃 / 召唤兽技能
- **黑猫爪击**：从虚空探出黑色猫爪攻击，速度极快，难以捕捉，可撕开六臂巨人后背。
- **三生轮回子**：召唤兽，孩童形态，体型可缩小为光点，力量惊人（可掀飞六臂巨人），可抵挡空间之力。

### 剑无双技能
- **飞剑术**：双手掐诀，飞剑如流星雨般轰出，蕴含剑之法则，霸道无双，有帝王临尘之感。

## 怪物系统

### 六臂巨人（空天古兽 / 空天萨林）
- **外形**：六条巨大手臂，赤金色眼眸，眼眸深处有浓烈杀意。
- **特点**：手持金色宝塔，拥有神域/界域，可施展天地囚笼。
- **战斗方式**：近战肉搏、空间之力压迫、空间挪移、宝塔撞击。
- **弱点**：本源灵魂法则攻击可无视界域防御；白衣剑圣的"势"可斩开神域。
- **数量**：九十九尊六臂巨人同时出现。

### 血蝉王
- **外形**：身后有三对血色翅膀的中年男子形态。
- **特点**：阿来特星系顶尖强者，拥有范围性心脏共振手段。
- **战斗方式**：心脏共振、长枪近战、流光化身高速移动。
- **实力评价**：可让方圆百里冒险者同时痛苦，但顶尖冒险者可扛住。

### 盘古一族
- 出现于不周古地，转职祭坛建成后已离开。

## 副本系统

### 转职祭坛
- **不周古地转职祭坛**：由巨大石柱组建而成的奇怪建筑，用于超神级隐藏职业转职。
- **古朝秘境转职祭坛**：另一处超神级隐藏职业转职地点。
- **转职流程**：取出天罚戒指 → 确认转职 → 雷云光柱降临 → 转职完成 → 获得新技能。

### 九转副本
- 重要的进阶副本，被异世界强者把控，压缩蓝星冒险者发育空间。

## 战斗系统

### 力量层级对抗
- **力量层级差距**：力量层级的差距不是技巧所能弥补的，界域可阻挡低于其层级的攻击。
- **领域 / 神域**：六臂巨人展开的领域等同神域，为首者达界域层次。
- **界域**：高于神域的力量层次，凭界域可近乎无敌（除本源法则等更高层级攻击）。

### 攻防机制
- **本源法则**：高于普通法则的力量层级，可无视界域正面防御（如本源灵魂法则刺入眉心）。
- **势**：玄妙力量，无坚不摧的绝对自信之势，可斩开神域。
- **空间壁垒**：可阻挡法则攻击，但被无法则加持的高速飞剑撞击出现裂纹。
- **空间之力压迫**：可使目标动作迟滞如慢动作，同时持续降低生命值。
- **护盾机制**：能量盾牌可降低目标承受的大部分伤害。

### 团队配合
- **召唤师**：本体较弱易被针对，依赖召唤兽作战（如苏璃）。
- **坦克**：嘲讽类技能可控制敌人目标，护盾类技能保护队友。
- **输出**：剑客以"势"和法则攻击破防，远程以圣器残片输出。

## 特殊机制

### 时空与修炼机制
- **时空差异**：九幽之地四千多年苦修 = 外界一年多时间。
- **时空蝴蝶**：林天浩作为时空蝴蝶，改变历史走向，导致异世界强者提前涌入诸神黄昏。
- **悟道速度加持**：加入阿来特星系道统可获得悟道速度加持。

### 异象与天赋
- **圣人异象**：林天浩掌控十六大圣人异象，实力可抗衡神灵。
- **修炼天赋**：吸纳天地灵气速度、修炼武技速度等。

### 转生与飞升机制（修仙者世界）
- 大乘期 → 飞升成仙 → 飞升失败未死于雷劫 → 修成散仙。
- 散仙不算神灵，可绕过"神灵不能出手"规则进入诸神黄昏。

### 道统机制
- **阿来特星系道统**：建立在猿山城，对外招收天才冒险者，讲道说法，提供悟道速度加持。
- **目的**：削弱蓝星顶尖战斗力（刺杀巅峰冒险者）、压缩发育空间、分一杯羹。

### 刺杀机制
- 蓝星巅峰冒险者遭遇不止一次刺杀，出手者非常强，基本一击必杀，目的是削弱顶尖战斗力。

### 囚笼机制
- 圣人级天地囚笼共九十九层，可连同整个城池一同笼罩。
- 被划开后瞬间恢复，不留痕迹。
- 纵使神帝强者也难从中出来。

### 逃脱与转移机制
- **山海图 + 星空步**：林天浩的备选逃亡方案，可携带银河世界之人跨越九大星域逃出生天（需将星空步提升至十星）。
- **创世主**：阿来特星系的最高存在，若出手则逃亡方案不可行。
