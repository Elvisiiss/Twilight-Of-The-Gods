# 《诸神黄昏》设定提取 - 第131-135章

## 一、基础设定

### 1.1 旱魃的故居副本
- **难度**: 地狱级难度，每秒掉血10万
- **格局**: 跟雪尸的足迹相似，但到处都是滚烫的岩浆
- **持续掉血**: 地狱级难度每秒掉血10万，普通难度每秒掉血100
- **通关条件**: 见到旱魃就算通关
- **首通奖励**: 装备×99，技能书×62，自由属性点+100

### 1.2 烈焰僵尸（青铜级）
- **等级**: 50级
- **生命值**: 1000万/1000万
- **攻击**: 59850
- **技能**: 烈焰射线，尸山火海，焚心，尸气滚滚，火天尸源，无心尸毒，九尸焰影，霸体，狂暴
- **叠加生命值**: 一只烈焰僵尸叠加75点生命值

### 1.3 落日镇
- **身份**: 东方古国的边陲小镇
- **状态**: 凡殿之主力量复苏后得以复苏，依托于旱魃的故居隐藏
- **实力**: 年轻书生自称在落日镇还算厉害，但在东方古国如同蝼蚁
- **东方古国**: 掌控法则、移山填海的强者比比皆是

### 1.4 秋水茹（魔琴鬼女）
- **身份**: 落日镇居民，魔琴鬼女
- **能力**: 琴声化作刀剑攻击，月下琴境（幻境）
- **幻境内容**: 财、权、色诱惑，人之贪念
- **弱点**: 林天浩拥有无垢之眼，可看破幻境

### 1.5 年轻书生
- **身份**: 落日镇居民，实力强大
- **能力**: 御剑术，九剑防御，上千飞剑
- **评价**: 林天浩叠加600多万生命值都无法打破其防御
- **奖励**: 护身飞剑（黄金级）

### 1.6 红毛火尸（白银级）
- **等级**: 50级
- **生命值**: 6000万/6000万
- **攻击**: 69692
- **技能**: 熔岩爆裂，火焰鬼爪，烈焰焚身，浴火重生，烈焰灼烧，烈火本源，霸体，狂暴
- **特点**: 法术系怪物，速度快

### 1.7 旱神之殿
- **身份**: 旱魃的神庙
- **状态**: 被打砸破败，神牌只剩下"神"字
- **神牌名字**: 旱神之殿
- **历史**: 旱魃是黄帝之女，上古十大魔神之一

### 1.8 旱魃
- **身份**: 黄帝之女，上古十大魔神之一，旱神
- **状态**: 分身状态，本尊超出二转界限
- **态度**: 不希望东方古国复苏，认为会面临神罚
- **信息**: 杀戮之神被封印在月轮帝国尸山血海

### 1.9 杀戮之神
- **身份**: 以杀证道的神明
- **事迹**: 曾连斩九位神明，最终被几位神王联手重创封印
- **封印地点**: 月轮帝国，尸山血海

### 1.10 帝国地图
- **月轮帝国**: 玩家完成二转后可进入的大地图之一
- **浩渺帝国**: 玩家完成二转后可进入的大地图之一
- **希图帝国**: 玩家完成二转后可进入的大地图之一
- **全球玩家**: 所有玩家都会进入这三个帝国，国战频繁爆发
