# 第1436-1440章 设定分析

## 基础设定

- **游戏世界名称**:诸神黄昏
- **成神路线**:
  - 神格成神:需大机缘,门槛相对较低但上限受限
  - 悟道成神:难度极高
  - 香火成神:需较高影响力与充足香火(如林天浩拥有山海帝国影响力及城隍庙香火,香火可源源不断增强魔抗)
- **机械师设定**:机械师成神天然比其他职业困难,故其追求的不是成神而是永生,灵网世界即为机械师研究的初衷
- **灵网世界**:由核心主脑掌控,意识体在其中一生注定无法成神
- **意识体**:存在于灵网世界中,无法成神,死亡后复活非常困难(非冒险者)
- **机械飞升**:难度比悟道成神还要困难
- **重生者机制**:林天浩为重生者(两世为人),其改变历史会带来蝴蝶效应,导致他人命运改变(如前世未觉醒天赋者今生觉醒)
- **墨可沙国**:由核心主脑实际掌控,三大家族(杜洛家、奇楠家、墨可家)共同守护先祖遗留之物
- **山海帝国**:林天浩拥有较高影响力,可利用其进行香火成神
- **凡殿**:林天浩创建的势力,设有长老令牌、贡献值制度

## 属性系统

- **自由属性点**:可通过任务奖励获得(如【老乞丐的复仇】任务奖励自由属性点+10000)
- **生命值**:可通过人王令反馈(统治区域内的生命值反馈机制)
- **魔抗**:可通过香火源源不断增强(林天浩城隍庙香火增强魔抗)
- **剑道感悟**:可通过神级天赋"问剑"在接触新剑时获得
- **剑道伤害**:可通过神级天赋"问剑"在接触新剑时永久提升
- **属性增幅来源**:基础属性、悟道速度、输出能力是诸神黄昏中最顶尖的三个东西

## 装备系统

- **超神级机械材料**:三大家族各自守护的晶片,为先祖遗留之物,有大用
  - 神秘的晶片属性:
    - 使用要求:未知
    - 效果:未知
    - 耐磨度:不可摧毁
  - 数量分布:三大家族每家3枚,核心主脑小风手里也有(存放位置未知)
  - 用途:奎微长天转职(十转)需要至少10枚这样的初级超神级机械材料
- **天罚装备**:如天罚头盔(附带万倍悟道速度技能,一个月冷却时间)
- **神器**:珍贵装备类别
- **装备升级卷轴**:任务奖励可获得
- **诸神的赐福**:任务奖励物品
- **长老令牌**:凡殿长老身份象征
- **超神级机械材料外部插件**:可使核心主脑对主人保持绝对忠诚

## 技能系统

- **万倍剑道领悟速度**:从前有座山传承一转附带技能,无地点限制、无冷却限制
  - 一天相当于27年的悟道
  - 一个月相当于810年悟道
- **万倍悟道速度**:天罚头盔附带技能,有一个月冷却时间
- **普通职业者悟道增幅**:通常为2~10倍,20倍已属天方夜谭
- **洞察之眼**:林天浩的技能,可展开观察目标
- **机械领域**:杜洛魅卜的技能,可被剑气穿透
- **剑气**:剑修技能,霸道且穿透力极强,可环绕周身防御热武器,可穿透机械领域
- **超神级隐藏职业转职**:
  - 普通方式:需超神级隐藏职业转职祭坛(如古朝秘境即为一个巨大的超神级隐藏职业转职祭坛)
  - 特殊传承:从前有座山的传承可不限地点快速完成九转
- **神级天赋"问剑"(4星)**:
  - 效果1:每接触一柄新的剑,获得剑道感悟和4个自由属性点
  - 效果2:每接触一柄不同的剑,剑道领悟速度提升0.04倍
  - 效果3:每接触一柄新的剑,剑道伤害提升0.04倍
  - 熟练度:952/10000(注:该熟练度为接触的新的剑的数量)
  - 特点:与击杀野怪无关,较为少见

## 怪物系统

- **域外魔族**:心魔古城中存在的怪物,从前有座山曾在心魔古城快速击杀域外魔族
- **心魔**:心魔古城冒险者的心魔,根源在百里千柔(心魔古城主人)

## 副本系统

- **心魔古城**:冒险者活动副本,城主为百里千柔,冒险者心魔根源所在地
- **古朝秘境**:巨大的超神级隐藏职业转职祭坛(知晓者不多)
- **太古黑塔**:黑天傲真可祭出的塔类空间,可进入其中
- **个人小秘境(微型秘境)**:杜洛家族先辈制造,不到二十亩大小
  - 开启条件:需拥有杜洛家族嫡系血脉之人咬破手指、双手掐诀
  - 内部可藏匿超神级机械材料,需专门强者守护
- **康洛城空间跳跃点**:空间传送节点,出此节点后可能遭遇伏击

## 战斗系统

- **转职等级体系**:九转之上为十转
  - 九转王级:如奇楠角檩、杜洛清云
  - 九转宗师级:如杜洛魅卜
- **十转条件**:需超神级机械材料(奎微长天十转至少需10枚初级超神级机械材料)
- **战斗力分级**:
  - 绝顶强者:林天浩都不知道具体身份的强者级别
  - 超神级隐藏职业者:现阶段即可击杀九转王级高手(如从前有座山击杀杜洛清云)
- **职业对比**:
  - 剑修输出:同等情况下比弓箭手输出强出不知多少
  - 战士超神级隐藏职业:输出一等一
- **战斗机制**:
  - 热武器:无法穿透剑修环绕周身的剑气
  - 剑气:可穿透机械领域
  - 超神级隐藏职业者可能拥有变态技能,能通过被击杀对象了解有用信息
- **贡献值奖励(招揽高手进入凡殿)**:
  - 招揽九转王级高手(如奇楠角檩、寒楼楼主):凡殿贡献值+1000亿
  - 招揽九转宗师级高手(如杜洛魅卜):凡殿贡献值+80亿

## 特殊机制

- **神级天赋觉醒**:
  - 需神级天赋觉醒石
  - 散人获得神级天赋觉醒石极为困难
  - 圣级天赋觉醒石无法觉醒神级天赋(从前有座山曾用圣级天赋觉醒石无法觉醒,后用神级天赋觉醒石成功)
- **神级天赋觉醒石获取途径**:可由公会重金购买(如浮屠公会重金收购),再转赠他人
- **封神榜**:林天浩持有
  - 击杀目标可送其上封神榜
  - 上榜者可在短时间内恢复到满状态
  - 上榜者会失去自由
  - 上榜者可能再进一步,甚至成就神品
- **生死簿**:林天浩可祭出,用于强行逼人现身
- **昆仑镜**:林天浩可祭出的传送工具,可前往心魔古城等地
- **冰封图**:可藏人的特殊物品(从前有座山的主人躲在其中)
- **凡殿招揽机制**:
  - 招揽高手可获凡殿贡献值
  - 加入凡殿的成员对林天浩绝对忠诚(胖子、猴子、眼镜、小小剑、苏璃等均如此)
  - 核心主脑因超神级机械材料外部插件导致对原主人绝对忠诚,林天浩的绝对忠诚规则对其无效
- **人王令**:林天浩统治区域反馈机制
  - 要求统治该区域,但不限定必须是山海帝国
  - 未反馈生命值的原因可能为核心主脑或其主人(灵网世界由核心主脑掌控)
- **超神级隐藏职业对比**:
  - 天罚弓箭手(林天浩):转职极为困难
  - 灭世机械师(林天浩):转职极为困难,需超神级机械材料
  - 战士超神级隐藏职业(从前有座山):传承可不限地点快速完成九转,一转即附带万倍剑道领悟速度(无限制)
- **苍穹之上存在**:疑似神灵之上的存在,非冥王(冥王之子才是真正的冥王),可对下方发出警告(雷云翻滚),获得其传承者拥有超神级隐藏职业
- **摄像头/视频记录**:杜洛魅卜身上的摄像头可记录战斗画面,可投放供他人查看
- **好友系统**:可添加好友、发送截图、进行物品交易
