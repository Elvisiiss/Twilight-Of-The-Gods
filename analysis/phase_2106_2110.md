# 第2106-2110章 设定分析

## 基础设定

### 世界背景

- **第三关·大禹王朝·北罔城（继续）**：林天浩通过劫官盐逼迫城主言长海行动。
- **大禹王朝动荡深化**：战乱即将开始，言长海师父血魔老祖警告"大禹王朝可一点都不太平，战乱很快就要开始了"。
- **蜕凡机制感悟（深化）**：林天浩因实力不足不得不对北罔城城主妥协低头，这是伪装蜕凡无法出现的真实感受。

### 主要势力与组织

- **北罔城城主府**：城主言长海（隐藏武夫），师父血魔老祖（女，老怪物）；有密室藏银票、秘籍、炼灵珠；可调度5000城卫军（派出1000后剩4000）。
- **陶家**：北罔城低调世家，被言长海怀疑是幕后指使（实际是林天浩）；产业悄悄扩张。
- **毕家**：林天浩合伙人毕成才家族；表面商贾，行省有关系。
- **神武司（提及）**：大禹王朝的武道机构，林天浩未直接接触。
- **边关诸侯领地**：陌雪领等，领主无力支撑可找人接替。

### 关键NPC/人物

- **林天浩**：劫官盐、潜入城主府、偷银票秘籍、中五毒掌、躲藏恢复、决定前往陌雪领。
- **言长海**：北罔城城主，表面只会武功皮毛，实际是隐藏武夫；密室藏500多万两银票、天星诀、霸王拳、炼灵珠；师父为血魔老祖。
- **血魔老祖**：言长海师父，女性，看上去年轻但气息像活了几百年的老怪物；修炼五毒掌；受伤疗养中，需吸食流民生命力疗伤；欲让言长海用童男童女加速疗伤。
- **赵虎**：虎头帮帮主，三流巅峰武夫；请师兄（二流武夫？）帮忙剿匪；押运官盐被林天浩射杀3人后逃跑。
- **毕成才**：林天浩合伙人，传递情报，掩护林天浩身份。
- **莫七鋆**：山雨庄园护卫队长，跟随林天浩。
- **小林子**：林天浩义子，传递情报（城主府招募流民异常）。
- **叶统领**：城主府统领，负责镇压流民闹事、搜查五毒掌伤者。

## 属性系统

### 基础属性

- **林天浩武道境界**：从无到有，修炼天星诀一日千里，一天内真气逼近赵虎（三流巅峰）。
- **林天浩体魄**：兽神之躯加持下体魄强横，恢复力惊人（不死不灭）；可正面碰撞三流巅峰武夫赵虎"非死即残"。
- **言长海境界**：表面只会武功皮毛，实际隐藏修为不低（密室有武道秘籍和炼灵珠）。
- **血魔老祖境界**：受伤状态下与林天浩对掌被击退七八步喷血；未受伤时实力恐怖，疑为武林神话级别。
- **赵虎境界**：三流巅峰武夫，可化作流光逃跑。

### 称号系统

- **"师父"**：言长海对血魔老祖的称呼。
- **"城主大人"**：言长海的官职称呼。
- **"血魔老祖"**：言长海师父的名号（带"魔"字，邪派色彩）。
- **"领主大人"**：林天浩即将成为陌雪领领主的称呼。

### 品阶系统

- **武夫境界体系（深化）**：三流 → 二流 → 一流 → 武神 → 武林神话（可活几百岁，如张三丰、逍遥子、达摩祖师级别）。
- **城卫军规模品阶**：北罔城5000城卫军（派出1000剿匪后剩4000）。
- **城主府财富品阶**：言长海密室藏500多万两银票（上供后剩余）。
- **诸侯领地品阶**：
  - 边关军队数量动辄上万
  - 厉害城主可招募两三万士兵
  - 陌雪领3座城仅剩8000军人（很少）
- **大禹诸侯数量**：800+诸侯，常年阳奉阴违不纳税。

## 装备系统

- **炼灵珠**：言长海密室珍藏，黑色漆黑如墨的珠子；可强行灌输内力进入人体；每天只能给人提供一缕真气；最多同时让三人使用；效果来的太慢；林天浩偷走后测试有效。
- **天星诀**：言长海密室的内功心法秘籍，可修炼到一流武夫境界；林天浩偷走后修炼一日千里。
- **霸王拳**：言长海密室的外功拳法秘籍；林天浩偷走。
- **银票（500多万两）**：言长海密室藏银，林天浩偷走。
- **木匣子**：言长海密室装炼灵珠和秘籍的容器，常被打开。

## 技能系统

### 五毒掌（血魔老祖）

- **效果**：中掌后手掌心出现黑色，毒素蔓延四肢百骸，整条手臂变黑；持续折磨；找大夫不通（会暴露身份）；一流高手也要丧命。
- **限制**：林天浩兽神之躯可硬抗，约半个时辰痕迹完全消失。
- **治疗**：兽神之躯极大治疗伤势，甚至不死不灭。

### 天星诀（林天浩修炼）

- **品阶**：内功心法，可修炼到一流武夫境界。
- **林天浩修炼速度**：一日千里，一天内真气逼近三流巅峰赵虎；得益于兽神之躯加成。
- **限制**：只能够修炼到一流武夫境界，更高境界需要新功法。

### 霸王拳（林天浩获得）

- **品阶**：外功拳法。

### 林天浩战略技能（深化）

- **劫官盐战术**：连续抢三次官盐，逼北罔城城主行动；山贼无销路，官府选择再拉一批；林天浩就是要挑衅。
- **自导自演山贼抢货**：掩护自身商队被劫的假象。
- **流民闹事掩护**：发银子让流民闹事，分散城主府注意力。
- **盐仓百姓施压**：世家豪门推动百姓冲击盐仓，进一步施压。
- **射杀少城主嫁祸陶家**：林天浩安排射杀言长海儿子，嫁祸陶家，引城主出府。
- **潜入城主府**：城主出府后林天浩翻墙进入，避开巡逻。

### 言长海技能

- **隐藏武夫身份**：表面只会武功皮毛，实际修为不低。
- **密室机关**：卧室床下密道，前两个台阶无痕迹是陷阱（踩上触动机关），第三个台阶开始才能走。

### 血魔老祖技能

- **五毒掌**：见上。
- **吸食流民生命力疗伤**：通过招募流民进入城主府，吸食生命力加速恢复；童男童女效果更好但风险大。

## 副本系统

- **第三关·乞丐到皇帝副本（继续）**：
  - 林天浩与北罔城城主博弈阶段
  - 劫官盐 → 逼城主请外援 → 制造混乱 → 潜入城主府偷宝
  - 中五毒掌 → 躲藏恢复 → 决定离开北罔城
  - 转移大本营至陌雪领

## 战斗系统

### 林天浩 vs 血魔老祖（潜入城主府遭遇战）

- **过程**：
  - 林天浩偷完东西出来遭遇血魔老祖
  - 血魔老祖化作残影冲来
  - 林天浩无内力纯体魄力量对掌
  - 林天浩后退半步，血魔老祖噔噔噔后退七八步喷血
  - 林天浩中五毒掌，手掌心变黑
  - 林天浩转身逃跑，血魔老祖欲追但气血翻涌再喷血，放弃追击
- **结果**：林天浩中毒逃跑；血魔老祖伤势加重（"养了这么久的伤，又被这小子打回去了"）。
- **关键点**：林天浩无内力纯体魄力量伤到血魔老祖，惊到对方。

### 林天浩 vs 赵虎押运队（第二次劫官盐）

- **过程**：林天浩弓箭远程射杀6个官兵，赵虎化作流光逃跑。
- **结果**：赵虎逃脱，林天浩放弃追击避免暴露身份。

### 城卫军搜查林天浩

- **过程**：城卫军挨家搜查手掌黑色痕迹，林天浩躲藏半个时辰等痕迹消失。
- **结果**：林天浩在北罔城露面，城卫军检查手掌无发现，过关。

## 特殊机制

### 炼灵珠机制

- **效果**：每天只能够给人提供一缕真气；最多同时让三人使用。
- **限制**：效果来的太慢，非快速变强之法。
- **言长海评价**：炼灵珠虽然不错，但效果太慢。
- **林天浩测试**：有效，安排手下修炼。

### 五毒掌机制

- **中毒症状**：手掌心变黑 → 整条手臂变黑 → 毒素蔓延四肢百骸 → 持续刺痛折磨。
- **致命性**：一流高手也要丧命。
- **治疗限制**：找大夫会暴露身份；只能硬扛。
- **兽神之躯对抗**：约半个时辰痕迹完全消失；兽神之躯可极大治疗伤势，甚至不死不灭。

### 血魔老祖疗伤机制

- **疗伤方式**：吸食流民生命力。
- **加速方式**：童男童女效果更好，但前期风险大。
- **流民来源**：城主府以招募流民为名暗中抓捕。
- **疗伤状态**：受伤时实力削弱，恢复后实力恐怖（疑武林神话级别）。

### 密室机关机制

- **位置**：城主府卧室床下密道。
- **陷阱**：前两个台阶无痕迹、有灰尘，踩上会触动机关。
- **识别方法**：眼力惊人者可注意到台阶痕迹差异。
- **地下密室**：藏白银、黄金、珠宝、银票、秘籍、炼灵珠。

### 城主买官与上贡机制（深化）

- **买官价格**：100万两白银（北罔城城主）。
- **上贡机制**：每年还要上贡给上层。
- **城主财富来源**：搜刮百姓、收保护费（虎头帮）、克扣官盐等。
- **言长海财富**：密室藏500多万两银票（上供后剩余）。

### 诸侯领地接替机制

- **接替原因**：领主扛不住野蛮子进攻，找替罪羊。
- **放弃领地重罪**：诛九族。
- **战死沙场**：算牺牲。
- **逃跑**：算逃兵，诛九族。
- **接替难题**：有底蕴的大家族大势力都不愿意接手烫手山芋。
- **陌雪领情况**：领主独孤陌雪多次求助卸任，无人愿意接。

### 林天浩战略转移机制

- **离开北罔城原因**：
  - 血魔老祖伤好后会找他麻烦（武林神话级别）
  - 自己实力不足以正面抗衡
  - 需要正规军（山贼非正规）
  - 需要自己的地盘
- **选择陌雪领原因**：
  - 挨着北莽山脉（天然屏障+熟悉地形）
  - 领地大居民少
  - 无人愿意接手（容易接管）
  - 有三座城池
  - 林天浩有钱（500万两）可养军

### 武林神话机制

- **寿命**：可活几百岁。
- **代表人物**：张三丰、逍遥子、达摩祖师（蓝星武侠故事）。
- **血魔老祖推测**：气息像活了几百年的怪物，疑为武林神话级别，但与超级武林神话有差距。

### 兽神之躯机制（深化）

- **治疗恢复**：极大治疗伤势，甚至不死不灭。
- **武道修炼加成**：修炼天星诀一日千里（一天真气逼近三流巅峰）。
- **体魄强度**：无内力纯体魄力量可击退血魔老祖。
- **毒素清除**：半个时辰清除五毒掌毒素。
