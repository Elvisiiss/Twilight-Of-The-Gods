## Phase 0: 技术选型与项目初始化

### 任务 0.1 — 确定技术栈 [前置]

**描述**: 选择游戏引擎、编程语言、数据库、网络方案。

**需要决策**:

| 决策项 | 推荐方案 A (小团队) | 推荐方案 B (大团队) | 说明 |
|--------|-------------------|-------------------|------|
| 游戏引擎 | Unity 2022 LTS+ | Unreal Engine 5.4+ | UE5 画面更好但门槛更高 |
| 编程语言 | C# | C++ | 跟随引擎选择 |
| 数据库 | PostgreSQL + Redis | PostgreSQL + Redis + MongoDB | SQL 做主数据，Redis 做缓存 |
| 网络框架 | Mirror / Netcode for GameObjects | 自研 C++ 服务器 | A 适合 100 人以下同时在线 |
| 服务端逻辑 | C# (Unity 服务端) | 独立 C++/Go 服务器 | A 可先用 P2P 模式 |
| 版本管理 | Git + Git LFS | Perforce | 美术资源多用 LFS |

**输出**: `docs/tech_stack.md` — 技术选型文档，列出所有依赖库和工具

**参考**: 本任务的执行取决于团队规模和目标。如果目标是**可玩原型**，选择方案 A。

## Phase 1: 核心框架

### 任务 1.1 — 实现游戏循环 [MVP]

**描述**: GameManager 单例控制游戏状态机。

**执行细节**:
```
状态机: Boot → Login → CharacterSelect → Loading → Playing → Paused → Dead → Respawn
```
- Boot: 加载配置、初始化服务
- Playing: 正常游戏循环(Update/FixedUpdate)
- Paused: 暂停菜单，冻结游戏逻辑

**输出**: `Scripts/Core/GameManager.cs`

## Phase 2: 角色系统

**参考文档**: [05_等级与属性系统](05_等级与属性系统.md) | [06_职业与天赋系统](06_职业与天赋系统.md)

### 任务 2.1 — 实现基础属性系统 [MVP]

**描述**: 创建角色属性数据结构，实现属性计算管线。

**执行细节**:
- 一级属性(直接显示在面板): HP, MP, 攻击, 法强, 护甲, 魔抗, 攻速, 移速
- 二级属性(计算得出): 物穿%, 法穿%, 暴击率, 暴击伤害, 吸血%, 韧性
- 三级属性(后期): 幸运, 神威抗性, 法则感悟层数
- 属性来源分层计算:
  ```
  最终属性 = ((基础属性 + 升级加点) × 职业倍率 + 装备属性) × 天赋倍率 × 势力加成 × 神赐倍率
  ```
- 攻速衰减公式（核心）:
  ```
  0-10:   1 装备点 = 1.0 实际攻速
  10-20:  1 装备点 = 0.5 实际攻速
  20-30:  1 装备点 = 0.25 实际攻速
  30+:    1 装备点 = 0.125 实际攻速
  ```
- 移速衰减: 10 点后 1 点 = 0.05

**参考**: [05_等级与属性系统](05_等级与属性系统.md) 第 2 节

**输出**: `Scripts/Character/CharacterStats.cs`, `Scripts/Character/StatModifier.cs`

## Phase 3: 战斗系统

**参考文档**: [09_战斗机制详解](09_战斗机制详解.md)

### 任务 3.1 — 实现伤害计算管线 [MVP]

**描述**: 完整的伤害计算公式 + 伤害类型系统。

**执行细节**:

**伤害类型（按优先级排序）**:
1. 真实伤害 — 无视一切防御和减伤
2. 百分比真实伤害 — 按目标最大 HP 计算，无视一切
3. 魔法伤害 — 受魔抗减免
4. 物理伤害 — 受护甲减免

**伤害计算公式**:
```
普攻伤害 = ATK × (1 + 伤害加成%) × (1 - 目标护甲减免%)
技能伤害 = ATK × 技能倍率 × (1 + 法强加成%) × (1 - 目标魔抗减免%)
真实伤害 = 技能/被动原始数值（无减免）
暴击伤害 = 基础伤害 × (1.5 + 暴击伤害加成%)
最终伤害 = max(1, 计算伤害 - 目标护盾)
```

**伤害处理流程（顺序）**:
1. 闪避判定 → 2. 格挡判定 → 3. 护盾吸收 → 4. 减伤%减免 → 5. 护甲/魔抗减免 → 6. 免疫判定 → 7. 实际扣血

**参考**: [09_战斗机制详解](09_战斗机制详解.md) 第 2 节

**输出**: `Scripts/Combat/DamageSystem.cs`, `Scripts/Combat/DamageData.cs`

### 任务 3.3 — 实现控制系统(CC) [MVP]

**描述**: 硬控/软控 + 韧性 + 霸体。

**执行细节**:

**硬控**(使目标完全无法行动):
- 眩晕: 无法移动/攻击/施法
- 冰冻: 无法行动 + 解冻后第一次攻击 1.5x 伤害
- 石化: 无法行动 + 护甲翻倍
- 击飞: 浮空 + 落地硬直
- 睡眠: 受到伤害唤醒
- 放逐: 无法攻击也无法被攻击

**软控**(限制但不完全阻止):
- 减速: 移速减少
- 定身: 不能移动但可攻击
- 致盲: 普攻必定 miss
- 沉默: 不能施法
- 缴械: 不能普攻

**反控机制**:
- 韧性: 每点韧性减少 1% 控制时长
- 霸体: 5 秒免疫一切控制(包括击飞)，30 分钟冷却
- 净化玉坠: 最高 93% 概率免疫控制

**控制时长公式**: `实际时长 = 基础时长 × (1 - 韧性%) - 免控减免`

**参考**: [09_战斗机制详解](09_战斗机制详解.md) 第 4 节

**输出**: `Scripts/Combat/CCSystem.cs`, `Scripts/Combat/CCEffect.cs`

## Phase 18: 打磨与平衡

### 任务 18.1 — 数值平衡

**描述**: 全系统数值调优。

**执行细节**:
- 建立 Excel 数值模型: 输入各系统参数 → 输出不同等级/职业的期望战斗力
- 平衡目标:
  - 同等级同品质装备下,各职业 PvE 效率差距 < 20%
  - BOSS 战时长: 普通 2-3 分钟 / 地狱 8-12 分钟
  - 升级速度: 1-10 级(1 小时) / 10-50 级(每级 2-3 小时) / 50-100 级(每级 5-10 小时)
- 经济平衡: 控制通胀(金币产出 vs 消耗比例)
- 天平测试: 遍历所有职业 × 装备组合

**输出**: `docs/balance_model.xlsx` — 数值模型电子表格

---

### 任务 18.2 — 性能优化

**描述**: 帧率/内存/加载时间优化。

**执行细节**:
- 目标: 稳定 60 FPS(中配)/30 FPS(低配)
- 对象池使用率: 所有高频创建销毁对象 > 90%
- 地图分块加载: 只加载玩家周围 3×3 Chunk
- Draw Call: < 500(中配) / < 1000(高配)
- 网络包大小: 单包 < 1KB(移动) / < 5KB(战斗事件)
- 内存: < 4GB(低配) / < 8GB(中配)

---

### 任务 18.3 — 测试与QA

**描述**: 系统化测试流程。

**执行细节**:
- 单元测试: 伤害计算/属性叠加/经验公式 必须有自动化测试
- 集成测试: 各系统交互(如装备属性影响技能伤害)
- 平衡测试: 自动化模拟战斗(不同职业/等级/装备组合)
- 压力测试: 100 玩家同屏 / 1000 并发连接
- 回归测试: 每次更新后运行完整测试套件

**输出**: `Tests/` 测试脚本文件夹
