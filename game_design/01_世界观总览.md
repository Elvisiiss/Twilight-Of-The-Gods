## 一、前提设定（分层揭示）

《诸神黄昏》的世界真相采用**洋葱式分层揭露**结构。玩家在不同游戏阶段接触到的"真相"截然不同，设计团队需确保每个阶段的叙事逻辑自洽，同时在深层设定中埋设伏笔。

### 第一层 | 表层：全息VR网游（Ch.1-400）

**时间定位**：2032年5月20日

这是玩家在游戏最初期接触到的世界观——一个看似普通的"全息虚拟现实网游"。

| 要素 | 说明 |
|------|------|
| 游戏名称 | 《诸神黄昏》（Twilight of the Gods） |
| 开服时间 | 2032年5月20日 [Ch.001] |
| 游戏性质 | 跨时代虚拟网络游戏，由**银河主神**利用古地球诸神力量打造 [Ch.001] |
| 账号绑定 | 虹膜 + DNA 双重绑定，更换登录器不改变账号 [Ch.001] |
| 职业体系 | 弓箭手、战士、刺客、法师、牧师五大基础职业 [Ch.001] |
| 核心口号（公开） | "五年后，游戏将与现实融合" [Ch.001] |

**该阶段核心系统**（详见后续各系统设计文档）：
- 基础属性系统（HP/MP/攻击/法强/护甲/魔抗/攻速/移速/物穿/法穿/幸运/韧性）
- 装备稀有度体系（普通→精英→黑铁→青铜→白银→黄金→铂金→钻石→传说→史诗→神器→超神器，共12级）
- 天赋觉醒系统（黄级→玄级→地级→天级→圣级→神级→超神级）
- 副本系统（简单/困难/噩梦/地狱四级难度）
- 红名/PK/公会/诸神赐福/世界BOSS系统

**该阶段的"已知真相"**：
- 植物人可通过游戏实现现实康复 [Ch.001]
- NPC存在复杂派系斗争和自我意识 [Ch.001-045]
- 新手村下方封印着黄帝之子——**旱魃** [Ch.026]
- 存在"弑神者印记"——以凡人之躯斩杀神灵的传承 [Ch.076-095]
- 成神之道有四：**香火成神、功德成神、悟道成神、封天成神** [Ch.076]

### 第二层 | 技能具现与大灾变前兆（Ch.401-875）

游戏技能开始突破"虚拟"边界，在现实世界产生物理效果。

| 揭示内容 | 说明 |
|----------|------|
| 技能具现 | 游戏内获得的技能和属性开始在现实中生效 [Ch.401+] |
| 植物人机制 | 游戏中修炼可恢复植物人的现实意识，本质是灵魂修复 [Ch.401+] |
| 银河主神身份初现 | 游戏背后的创造者开始展现更高层次的意图 |
| 古东方神灵之力 | 游戏力量的本源来自远古东方神灵的遗留 |

**该阶段关键认知转变**：游戏不再只是"游戏"，而是一个**力量训练和觉醒的场域**。

### 第三层 | 宇宙级训练棋盘（Ch.876-1940）

这是世界观最大的转折点——游戏的真实用途被揭露。

| 揭示内容 | 说明 |
|----------|------|
| 真实目的 | 《诸神黄昏》是一座**百年训练棋盘**，为银河世界培养战士 [Ch.876+] |
| 真正威胁 | **阿来特星系**（Alait Galaxy）将持续入侵银河世界 [Ch.876+] |
| 战争规模 | 阿来特星系出动5000亿大军围攻银河世界 [Ch.1928-1935] |
| 游戏与现实的融合进程 | 五年期限到达后，游戏世界与蓝星现实**部分融合** |
| 幕后推手 | 星空管理局、雷罚神殿等超级势力在银河世界**下注**，将战争视为收割财富的机会 [Ch.1936-1940] |

**关键数据**：
- 主角林天浩生命值突破6000亿 [Ch.876-895]
- 蓝星地心封印着超过**十万亿**永恒之境怪物 [Ch.1916-1920]
- 银河世界保卫战开盘赔率：坚持十年 1赔50 [Ch.1906-1910]
- 主角转生到距银河世界至少**十万个星系**外的北山星域 [Ch.1965]

**银河世界境界体系**（该阶段确立）：
```
凡人 → 神灵 → 圣人 → 天道圣人 → 永恒之境 → 源神 → 源主
```

### 第四层 | 最终真相：墟主的模拟人生（Ch.1991-2231）

所有设定被彻底颠覆——蓝星（银河世界）、阿来特星系和诸神黄昏游戏本身，都是更高层次存在的创造物。

| 揭示内容 | 说明 |
|----------|------|
| 主角真实身份 | **林天浩 = 无上墟主**，经历了**90,000次模拟人生** [Ch.2191-2215] |
| 核心目标 | 寻找**复活被冰封的蓝星**的方法 [Ch.2191-2215] |
| 胖子（动乱墟主） | 林天浩的兄弟，执**黑子造魔神**阵营 [Ch.2191-2215] |
| 猴子（上一任墟主） | 已死，以**影子形式**长存；是真正的长生者与银河世界**重启者** [Ch.2216-2231] |
| 诸神黄昏起源 | 猴子死前**逆转蓝星时间线**，开启诸神黄昏，将传承给予林天浩、胖子、眼镜、林青青等人 [Ch.2216-2231] |
| 一体三世界理论 | 蓝星（银河世界）、阿来特星系、诸神黄昏三个小世界，可能是同一创造者（猴子）的布局产物 [Ch.2216-2231] |
| 最终结局 | 林天浩与胖子成功**复苏银河世界**，推动其从**小世界→中等世界→高等世界**的升级 [Ch.2216-2231] |

**该阶段完整境界体系**：
```
凡人 → 仙人 → 仙王（行星级）→ 仙皇（恒星级）→ 仙帝（星系级）
→ 仙祖（星域级）→ 源神 → 源王 → 源皇 → 源帝 → 墟主 → 无上墟主
```

**世界观终极真相一览表**：

| 层次 | 玩家认知 | 真相 |
|------|----------|------|
| 表层 | VR游戏 | 力量训练场 |
| 中层 | 训练场 | 宇宙战争预备 |
| 深层 | 战争准备 | 超级势力赌局棋盘 |
| 核心 | 棋盘 | 无上墟主的第90,000次模拟人生 |
| 终极 | 模拟人生 | 为复活一颗被冰封的星球 |

## 二、时代时间线

### 2.1 三大造神时代

《诸神黄昏》宇宙经历了三个"造神时代"，每个时代创造的神灵体系对应现实世界不同神话体系。

| 时代 | 对应体系 | 特征 | 关键信息 |
|------|----------|------|----------|
| **第一时代** | 东方神系 / 三千神魔 | 洪荒世界，古东方神灵鼎盛，发生"巫妖量劫"式内战 [Ch.076] | 现在所在大陆不及当时洪荒世界的**亿分之一** [Ch.076] |
| **第二时代** | 西方神系 / 希腊诸神 | 西方众神崛起，封印东方古国于皑皑白雪之下 [Ch.076-095] | 冰雪女神为代表 [Ch.076] |
| **第三时代** | 克苏鲁神系 | 克苏鲁神话体系介入宇宙格局 [Ch.876+] | 与不祥之力体系相关 |

### 2.2 第四时代关键时间节点

| 时间 | 事件 | 章节 |
|------|------|------|
| 2032年5月20日 | 《诸神黄昏》正式上线 | Ch.001 |

### 3.2 小世界（凡界 / Mortal Realms）

小世界是宇宙结构的最底层，依附于高等世界存在。

| 小世界 | 说明 | 章节 |
|--------|------|------|
| **蓝星（银河世界）** | 主角的母星，后升级为高等世界 | Ch.2216-2231 |
| **阿来特星系** | 敌对星系，与诸神黄昏可能同源 | Ch.876+ |
| **诸神黄昏世界** | 游戏虚拟世界，实为一个独立小世界 | Ch.001, Ch.2216+ |
| **北山星域** | 距离银河世界十万+星系的外域 | Ch.1965 |

**小世界特征**：
- 法则层次上限：悟道最高23层（普通人9层，天骄12层） [Ch.1991+]
- 时间长河依附于高等世界
- 可通过世界之心创造和培育

**小世界升级为中等世界的条件** [Ch.2216+]:
1. 自主创造小世界（非依赖世界之心）
2. 自主诞生圣人（百花齐放）
3. 多种族百花齐放
4. 小世界中需有土著生灵自然诞生

### 3.3 中等世界（Mid Worlds）

共有**9个**中等世界，分布在神界之下 [Ch.1991-2115]：

| 中等世界 | 描述 | 关键势力/特征 |
|----------|------|------------|
| **仙界** | 东方修仙体系世界 | 雷罚殿（仙界第一势力）、百世仙宗、彼岸升仙府 |
| **天域** | 与仙界平行的高武世界 | 突破仙祖无限制 |
| **星界** | 星际文明体系世界 | 星盟（统治者）、学院制教育、完整经济体系 |
| **真武界** | 武道/剑道世界 | 真武剑宗，已被打崩 |
| **玄天界** | 未知（小说中提及较少） | - |
| **冥界** | 幽冥/亡灵体系世界 | 幽冥一族 [Ch.046-70] |
| **魔域** | 魔道三大派系 | 天魔、血魔、心魔三足鼎立，魔渊为底牌 |
| **灵域** | 灵族/元素生命世界 | 五大灵族（土、火、水、金、木） |
| **妖域** | 妖族世界 | 东雪雷燕一族等 |

**中等世界特征**：
- 仙祖（=源神）有数量上限，受天道限制
- 古仙界巅峰时期拥有上百位仙祖 [Ch.1991-2015]
- 中等世界可升级为高等世界（需世界之主达源帝境界 + 多个小世界晋升） [Ch.2216]

### 3.4 高等世界（神界 / 源界 / Divine Realm）

- **层次**：位于中等世界之上，拥有**独立时间长河**
- **居民**：源神境及以上存在
- **代表势力**：圣教（神界大势力）、骨剑仙宗、棺材铺杀手组织
- **神域**：神界核心区域，拥有超越源主级的力量体系（源王→源皇→源帝→墟主）

**高等世界诞生过程** [Ch.2216-2231]：
1. 不祥之地被撕开一条口子
2. 神域时间长河奔涌而出，流向新河道
3. 小世界时间长河汇入
4. 中等世界时间长河汇入（9条），加速河道拓宽
5. 新世界自身时间长河独立形成——高等世界诞生

### 3.5 墟外（Beyond the Void）

位于三界结构之外的未知领域：

| 区域 | 描述 |
|------|------|
| **不可知之地** | 主世界之外的屏障，无时间，无空间 [Ch.2216+] |
| **不祥之地** | 时间长河之外，孕育"不祥生灵"的领域，不祥之力可侵蚀一切 [Ch.2016-2040] |
| **神秘之地** | 不可知之地之外，连墟主进入都**必死**的终极未知区域 [Ch.2231] |

### 3.6 时光长河系统

时光长河是小说的核心宇宙机制，也是理解世界观的关键。

| 概念 | 定义 | 关键规则 |
|------|------|----------|
| **时间长河** | 每个世界拥有独立的时间长河，代表该世界的命运流向 [Ch.2191+] | 每条河代表一个世界 |
| **主流** | 主世界的时间线，所有平行世界的基准 | 主流稳定即可维持世界不灭 |
| **支流** | 从主流分出的时间分支，形成平行世界 | 支流上的生灵为"影子"，非真我，注定消散 [Ch.2016-2040] |
| **支流还原** | 踏上支流，过去的人与物会再次出现 [Ch.2191+] | 是探寻过去的途径 |
| **河流交融** | 两条主流可交汇形成全新主流 | 世界融合的理论基础 |
| **时间冻结** | 源神级战斗波及时间长河时，长河为保护正常时间线会冻结附近时间 [Ch.1901-1905] | 局部时间静止 |
| **能量守恒** | 生灵死亡后能量还给时间长河，再分配给其他生灵 [Ch.2041-2065] | 宇宙能量循环法则 |
| **不祥侵蚀** | 支流被不祥之力污染，最终完全侵蚀，世界化为**秘境**回归主世界 [Ch.2016-2040] | 所有秘境皆由此形成 |

**多重时间长河理论**：
- 银河世界可能不在当前主流时间长河中
- 神域可能在**另外一条**时间长河
- 银河世界时间长河曾被藏于**林塔墟主**（世界兽）体内 [Ch.2216+]

## 四、五阶段叙事架构

这是面向游戏开发的内容分段方案，对应玩家在MMORPG中经历的五个主要版本/资料片。

### 阶段一：新手世界（对应Ch.1-400）

| 维度 | 说明 |
|------|------|
| **范围** | 新手村系统（每个新村容纳1万人）→ 主城体系（星辰王国、黑风城） |
| **核心冲突** | NPC派系斗争（老村长 vs 王铁匠）、东方古国 vs 西方神灵（开端） |
| **玩家规模** | 单一服务器万人级，公会成长期 |
| **关键势力** | 孤雪公会、逐梦公会、独霸公会 |
| **标志事件** | 新手村毁灭事件、弑神者印记获得、凡殿复苏、东方古国线索开启 |
| **玩家等级** | 1-50级（二转前） |
| **开发重点** | 新手引导、基础战斗、副本体系、公会系统、阵营选择 |

### 阶段二：王国纷争（对应Ch.401-875）

| 维度 | 说明 |
|------|------|
