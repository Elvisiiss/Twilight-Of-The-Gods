## 5. 约定说明

本文档及所有游戏设计文档遵循以下约定：

| 约定符号 | 含义 | 示例 |
|---------|------|------|
| `[Ch.X]` | 原著小说章节引用 | `[Ch.001]` = 小说第1章 |
| `[Ch.X-Y]` | 原著小说章节范围引用 | `[Ch.001-025]` = 第1至25章 |
| `[推断]` | 原文未明确给出，由分析推演的数值/机制 | `伤害公式 [推断]` |
| `(See: XX_文件名)` | 交叉引用，指向另一个设计文档 | `(See: 06_职业与天赋)` |
| `[CHAR:]` | 角色相关标签 | `[CHAR: 林天浩]` |
| `[LOC:]` | 地点相关标签 | `[LOC: 10086号新手村]` |
| `[SYS:]` | 系统/机制相关标签 | `[SYS: 红名系统]` |
| `[ITEM:]` | 物品/装备相关标签 | `[ITEM: 生死簿]` |
| `[EVENT:]` | 事件/任务相关标签 | `[EVENT: 东方古国复苏]` |

**文件结构约定**：
- 所有设计文档编号为 `XX_文档名.md`（XX = 01~14），位于 `game_design/` 目录
- Tier 2-3 文件统一包含 "源材料列表" 章节
- 所有推论性数值必须标注 `[推断]`，原著数据标注章节出处
- 交叉引用禁止使用原始文件路径，统一使用文件名（不含 `.md` 后缀）
