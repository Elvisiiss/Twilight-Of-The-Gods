# 07 技能与能力大全

> **核心定位**：本文档是《诸神黄昏》MMORPG技能系统的完整设计参考，涵盖从新手村基础技能到无上墟主终极能力的全部技能体系。
> **设计目标**：为策划、数值、程序团队提供一套完整、可落地的技能框架——从1星基础技能到超神级天赋，每个技能均有明确的数值效果、消耗、冷却与进化路径。

## 1. 技能分类体系

### 1.1 按类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **主动技能** | 需玩家主动释放，消耗MP/HP | 天罚、霸体、空间闪烁、五箭齐发 |
| **被动技能** | 自动生效，无需手动触发 | 天罚之手、双重真伤、冰冻之眼 |
| **神通/巡天神技** | 需领悟，无法通过技能书学习 | 虚空的归途、无尽裂空、诛仙剑阵 |
| **天赋技能** | 天赋觉醒获得，随星级成长 | 天罚之手、天罚之心、天罚之脑 |
| **领域技能** | 展开领域影响范围内所有单位 | 海神领域、夜天领域、玄空领域 |
| **法则技能** | 法则感悟衍生的攻击/防御手段 | 空间冻结、时间错位、百花起·落花贴 |

### 1.2 按星级

| 星级范围 | 品质等级 | 典型技能 | 上限 |
|----------|---------|----------|------|
| **1星-3星** | 基础/普通 | 霸体、空间闪烁、玄冰之翼、星月净化 | 可升至10星 |
| **4星-6星** | 进阶/稀有 | 嗜血龙甲、枯木逢春、死亡轮回 | 可升至10星 |
| **7星-9星** | 高级/史诗 | 天罚之手（后期）、天罚之心 | 部分可升至10星+ |
| **10星** | 满星/传说 | 天罚之脑（10星=降10亿最大HP） | 技能上限 |
| **不可升星** | 神赐/特殊 | 双重真伤、原地复活、火眼金睛、七十二变 | 固定星级 |

### 2.1 核心主动技能

#### 天罚 (Heavenly Punishment) —— 招牌技能

| 属性 | 数值 |
|------|------|
| **类型** | 主动技能（天罚弓箭手一转） |
| **星级** | 无星级（随职业转职进化） |
| **消耗** | 无额外消耗（替换普攻模式） |
| **冷却** | 无（模式切换） |
| **效果** | 普攻必定命中，无视攻击距离，圣人之下不可闪躲格挡 [Ch.401-420] |
| **限制** | 天罚状态下无法使用五箭齐发 [Ch.431-440] |

**伤害进化**：
- 一转期（Lv.50-100）：天罚攻速3.11（一秒九箭），单箭伤害452万~494万 [Ch.401-420]
- 二转期（圣地赛）：天罚攻速10.31，单箭伤害1.08亿~2.2亿 [Ch.521-545]
- 四转期（希图攻略）：天罚攻速52.05，单箭伤害百亿级 [Ch.876-895]

**攻速转换机制**：普攻攻速可通过加点转换为天罚攻速，转换比例由消耗的自由属性点决定 [Ch.431-440]。24万自由属性点可使天罚攻速从3.11突破至10.31 [Ch.581-605]。
