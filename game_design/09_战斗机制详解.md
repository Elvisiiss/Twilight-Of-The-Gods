# 《诸神黄昏》战斗机制详解

> **文档说明**：本文基于《诸神黄昏》小说(第1-1990章)中提取的战斗系统设定，推断公式标注[推断]，所有数据标注引用章节范围。

## 一、基础战斗框架

### 1.1 战斗类型

《诸神黄昏》采用**实时动作战斗**系统，非回合制。战斗结果取决于玩家的操作技巧、属性数值、技能搭配和战术决策。

| 战斗类型 | 说明 | 引用 |
|----------|------|------|
| PVE | 玩家vs野怪/Boss，含副本战斗、世界Boss战 | Ch.001-095 |
| PVP | 玩家vs玩家，含切磋、竞技场、野外PK | Ch.026-095 |
| 公会战 | 公会间大规模对抗，含攻城战 | Ch.046-160 |
| 国战 | 帝国级战争，万人以上规模 | Ch.136-185 |
| 圣地战 | 圣地间对决，高端战力为主 | Ch.476-545 |
| 星际战 | 跨世界/星际舰队级，数十亿战场 | Ch.1891-1990 |
| 概念战 | 法则vs法则、大道vs大道、源神级战斗 | Ch.1891-1965 |

### 1.2 普攻机制

#### 走A(风筝)
玩家需同时完成**走位、拉弓、瞄准、射击**四个步骤才能实现边移动边攻击 [Ch.001-025]。这是弓箭手和远程职业的核心操作技巧。

#### 攻速系统
攻速决定每秒普攻次数，受属性加成递减机制约束 [Ch.251-275]：

| 攻速区间 | 实际转化比例 | 引用 |
|----------|--------------|------|
| 0-10 | 装备/属性+1 = 实际+1.0 | Ch.251-275 |
| 10-20 | 装备/属性+1 = 实际+0.5 | Ch.251-275 |
| 20-30 | 装备/属性+1 = 实际+0.25 | Ch.251-275 |
| 30-40 | 装备/属性+1 = 实际+0.125 | Ch.251-275 |
| 40+ | 以此类推，每超一个10节点减半 | Ch.251-275 |

**攻速递减公式** [推断]：实际攻速 = 基础攻速 + sum(每点攻速加成 × 0.5^floor(当前攻速/10))

**攻速典型数值**：

| 阶段 | 攻速 | 每秒普攻数 | 引用 |
|------|------|-----------|------|
| 1级弓箭手初始 | 0.63 | 约0.63箭/秒 | Ch.001-025 |
| 20级(清风套装) | 8.12-10+ | 约8-10箭/秒 | Ch.046-070 |
| 20级(花费785自由点) | 20 | 约20箭/秒 | Ch.096-120 |
| 五箭齐发状态 | 20 | 100箭/秒(5×20) | Ch.096-120 |
| 远程裂变状态 | 39.2 | 约196箭/秒(裂变后) | Ch.161-185 |
| 三头六臂双弓 | 93.12 | 约466箭/秒(5×93) | Ch.251-275 |
| 狂暴状态 | 更高 | 约1100+箭/秒 | Ch.251-275 |

#### 手动瞄准
玩家需要手动瞄准目标 [Ch.001-025]。精准攻击要害位置可触发高额暴击 [Ch.001-025]。

#### 攻速属性获取差异
- 弓箭手：每点自由属性点+0.02攻速 [Ch.001-025]
- 其他职业：每点自由属性点+0.01攻速 [Ch.001-025]

#### 冷却管理
技能有独立冷却时间，从数秒(如空间闪烁)到24小时(如时间暂停、无敌金身)不等 [Ch.001-095]。

| 霸体 | 30分钟 | Ch.071-075 |
| 玄冰之翼 | 60分钟 | Ch.046-070 |
| 枯木逢春(3星) | 12小时 | Ch.026-045 |
| 无敌金身 | 24小时 | Ch.001-025 |
| 时间暂停 | 24小时 | Ch.401-420 |
| 伤害转移 | 半个月 | Ch.476-545 |

#### 动画取消
高技巧玩家可通过操作取消技能后摇，实现技能间的无缝衔接 [推断 from Ch.071-075中的浮空连击技术]。

### 1.4 战斗移动

#### 移动速度
- 弓箭手初始移速：3.1 [Ch.001-025]
- 移速突破10后，每自由属性点+0.05 [Ch.046-070]
- 移速受装备、技能、Buff叠加影响

#### 地形与障碍物
- 灌木林场景：阻挡视线和攻击，适合偷袭 [Ch.161-185]
- 冰雪环境：冰雪系怪物在雪地上每秒回复10万HP [Ch.076-095]
- 岩浆环境(旱魃副本)：地狱级每秒掉血10万 [Ch.121-135]
- 水域：海神领域范围内，海神波塞冬不被秒杀则1秒回满血 [Ch.251-275]

#### 空间移动
- **空间闪烁**：无施法前摇，瞬间5米位移，可穿墙 [Ch.046-070]
- **逐影瞬杀**：瞬移30米到目标影子，造成120%攻击力伤害 [Ch.151-160]
- **神行百里**：神行镜技能，瞬间移动 [Ch.121-135]
- **绝对穿梭**：穿梭任何壁垒包括世界壁垒，持续5分钟，冷却1小时 [Ch.876-895]
- **星空步**：连走九步跨越九颗星球 [Ch.1916-1940]

## 二、伤害系统

### 2.1 伤害类型

| 伤害类型 | 说明 | 减免方式 | 引用 |
|----------|------|----------|------|
| **物理伤害** | 受护甲减免 | 护甲、物穿 | Ch.001-025 |
| **魔法伤害** | 受魔抗减免 | 魔抗、法穿 | Ch.001-025 |
| **真实伤害** | 无视所有防御和减伤 | 无法减免(最高级伤害类型) | Ch.001-025 |
| **百分比伤害** | 按目标最大HP计算 | 无法通过护甲魔抗减免 | Ch.046-070 |
| **灵魂伤害** | 作用于灵魂层面 | 需灵魂防御 | Ch.161-185 |
| **亡灵属性伤害** | 作用于灵魂，痛感强烈 | 常规防御无效 | Ch.176-180 |

### 2.2 伤害计算公式 [推断]

#### 普攻伤害
```
普攻伤害 = 攻击力 × (1 + 伤害加成%) - 目标护甲 × (1 - 物穿%)
最小伤害 = 1 (保底伤害)
```
[推断基于Ch.001-025中的攻击力和护甲互动描述]

#### 技能伤害
```
技能伤害 = 攻击力 × 技能倍率 × (1 + 加成%) - 对应防御 × (1 - 对应穿透%)
```
[推断基于Ch.046-070中的逐影瞬杀120%攻击力描述]

#### 真实伤害
```
真实伤害 = 无视防御和减伤，直接扣减HP
```
[Ch.001-025：真实伤害无视防御]

#### 暴击伤害
```
暴击伤害 = 基础伤害 × 暴击倍率(默认2.0，可被装备/技能提升)
```
[推断]

### 2.3 百分比HP伤害机制

这是主角林天浩的核心输出来源，基于超神级天赋"天罚之手" [Ch.001-025]：

#### 天罚之手进化路线

| 星级 | 普攻真伤 | 每次普攻永久提升生命值 | 实战参考伤害 | 引用 |
|------|----------|------------------------|--------------|------|
| 1星 | 1%最大HP | +1 HP | 初期/未明确展示 | Ch.001-025 |
| 2星 | 2%最大HP | +2 HP | 初期/未明确展示 | 推断 |
| 3星 | 3%最大HP | +3 HP | HP 44万时13,200/箭 | Ch.026-045 |
| 4星+ | 更高% | 更高叠加 | HP 350万时105,000+/箭 | Ch.076-095 |
| 后续 | 随星级持续提升 | 随星级提升 | HP 27亿时2.2亿/箭 | Ch.476-545 |

**天罚伤害公式** [推断]：
```
天罚真伤 = 自身最大HP × (天罚之星级)% 
即：星级每升1星，百分比+1%
```

#### 生死簿机制
神赐装备，写下目标名字后远程持续造成真伤 [Ch.046-070]：
```
生死簿伤害 = 10,000 + (自身最大HP × 1%) / 秒
```
[Ch.046-070: 每秒10000+1%最大生命值真实伤害]

| 持有者HP | 每秒生死簿伤害 | 引用 |
|----------|---------------|------|
| 64万 | 16,400/秒 | Ch.046-070 |
| 665万 | 76,500/秒 | Ch.121-135 |
| 830万 | 93,000/秒 | Ch.171-175 |
| 27亿 | 1,800万+/秒 | Ch.476-545 |

### 2.4 特殊伤害机制

- 实战案例：每秒转移243亿伤害 [Ch.581-605]；百里千柔攻击80亿→自身承受738亿 [Ch.876-895]
