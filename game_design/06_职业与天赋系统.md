## Part A: 职业系统

### 1. 基础职业总览

《诸神黄昏》在角色创建时提供六大基础职业选择。每个职业具有独特的属性加成倍率和战斗定位 [Ch.1]。

#### 1.1 弓箭手（Archer）

| 项目 | 内容 |
|------|------|
| **定位** | 远程物理DPS，持续输出核心 |
| **主属性** | 攻击力、攻击速度、暴击 |
| **玩法风格** | 站桩远程输出，需要保持安全距离；攻速上限极高，适合"机关枪"流派 |
| **职业特色** | 攻速成长远高于其他职业（+0.02/点 vs +0.01/点），是攻速衰减机制下唯一能"突破天际"的职业 |
| **代表技能** | 连射、普攻增幅（距离+5%）、雷电跳跃（50%概率溅射10%伤害）、五箭齐发 [Ch.1] |
| **一转分支** | 木系弓箭手——所有伤害攻击可附带1%吸血 [Ch.121-135] |

#### 1.2 战士（Warrior）

| 项目 | 内容 |
|------|------|
| **定位** | 坦克/近战DPS，团队前排 |
| **主属性** | HP、护甲、魔抗 |
| **玩法风格** | 正面冲锋吸收伤害，嘲讽控场；可副修近战输出 |
| **职业特色** | HP成长每点+20（其他职业+10），护甲和魔抗双倍加持，是最硬的职业 |
| **代表技能** | 双重甲（反弹伤害）、双重盾（控制时获得护盾）、双重斩（多重攻击效果）[Ch.1] |
| **适合玩家** | 新手友好，生存能力强，团队副本必备 |

#### 1.3 刺客（Assassin）

| 项目 | 内容 |
|------|------|
| **定位** | 近战爆发/高机动性 |
| **主属性** | 攻击力、移速、暴击 |
| **玩法风格** | 潜行刺杀，一击脱离；高移速使其难以被放风筝 |
| **职业特色** | 攻击、移速、暴击三项双倍加持，是面板利用率最高的职业 |
| **代表技能** | 潜行类技能、背刺、高暴击倍率技能 [Ch.1] |
| **注意事项** | 身板脆，被群控后极易暴毙，对操作要求高 |

#### 1.4 法师（Mage）

| 项目 | 内容 |
|------|------|
| **定位** | 远程魔法AoE，法术炮台 |
| **主属性** | 法强、蓝量、移速 |
| **玩法风格** | 大范围AOE清场，高爆发秒脆皮；需要站桩读条 |
| **职业特色** | 法强、蓝量、移速三项双倍加持，技能伤害上限极高 |
| **代表技能** | 各类元素法术（火球、冰锥、雷暴等）[Ch.1] |
| **属性面板** | 与牧师相同的基础加成，但技能路线完全不同 |

#### 1.5 牧师（Priest）

| 项目 | 内容 |
|------|------|
| **定位** | 治疗/辅助/增益 |
| **主属性** | 法强、蓝量、移速 |
| **玩法风格** | 团队治疗和buff核心；兼具辅助输出能力 |
| **职业特色** | 属性加成与法师完全相同（法强/蓝量/移速双倍），治疗量受法强加成 |
| **代表技能** | 各类治疗术、净化术、复活术、团队增益buff [Ch.1] |
| **团队地位** | 团队副本不可或缺，高端队伍争抢对象 |

#### 1.6 格斗家（Fighter / Martial Artist）

| 项目 | 内容 |
|------|------|
| **定位** | 近战控场/元素双修 |
| **主属性** | 均衡属性 |
| **玩法风格** | 近身连控，冰火双系切换；技能连招循环 |
| **职业特色** | 属性加成为标准倍率（无额外双倍），但技能天赋独特——冰系减速/冻结，火系灼烧/爆发 [推断] |
| **代表技能** | 近战连控序列、冰火双系切换技能 [Ch.26-45, Ch.96-120] |
| **原著出处** | 黑风城格斗家作为城卫军出现，技能以连控为主 [Ch.96-120] |

### 2. 职业属性加成差异表

每升一级获得5点自由属性点。每1点属性点投入到不同属性时，各职业的实际增幅如下 [Ch.1]：

| 职业 | HP | MP | 攻击 | 法强 | 护甲 | 魔抗 | 攻速 | 移速 | 暴击 |
|------|-----|-----|------|------|------|------|------|------|------|
| **战士** | **+20** | +5 | +1 | +1 | **双倍** | **双倍** | +0.01 | +0.1 | +0.5% |
| **弓箭手** | +10 | +5 | **双倍** | +1 | +1 | +1 | **+0.02** | +0.1 | **双倍** |
| **刺客** | +10 | +5 | **双倍** | +1 | +1 | +1 | +0.01 | **双倍** | **双倍** |
| **法师** | +10 | **双倍** | +1 | **双倍** | +1 | +1 | +0.01 | **双倍** | +0.5% |
| **牧师** | +10 | **双倍** | +1 | **双倍** | +1 | +1 | +0.01 | **双倍** | +0.5% |
| **格斗家** | +10 | +5 | +1 | +1 | +1 | +1 | +0.01 | +0.1 | +0.5% |

> 来源：[Ch.1] 明确列出五种职业的属性差异。格斗家的数据为推断补全 [推断]，原著中格斗家出现在 [Ch.26-45] 和 [Ch.96-120] 但未说明其属性加成差异。

**设计洞察**：

- **弓箭手**是唯一攻速成长翻倍的职业（+0.02/点），这使得攻速衰减机制下弓箭手能比其他职业更早突破攻速瓶颈。
- **战士**的生命值成长（+20/点，其他职业+10）和双抗双倍使其天然成为坦克。
- **刺客**的三属性双倍（攻击/移速/暴击）使其操作上限极高。
- **法师/牧师**共享相同的属性双倍（法强/蓝量/移速），但通过技能体系实现完全不同的战斗定位——这是MMORPG职业设计中的经典"同属性不同职能"设计。

| **黑铁** | Iron | ~2.0x | — | [推断] |
| **青铜** | Bronze | ~3.0x | 第3个主动技能槽 | [推断] |

| **钻石** | Diamond | ~20x | 高级领域 | [Ch.376-400] |
| **传说** | Legendary | ~35x | 巡天神技槽位 | [推断] |

> 属性倍率部分为推断值（原著未给出精确数值），基于不同品阶NPC之间的战力差距推测 [推断]。

同一转职等级内，品阶差异可能导致战力差距达数十倍甚至数百倍 [Ch.431-465]：

| 品阶 | 战力层级 | 典型案例 | 来源 |
|------|---------|----------|------|
| **星耀** | 基准线 | 洛夫白智（九转星耀级）、落霞峰峰主 | [Ch.276-295] |
| **宗师** | 远超星耀 | 莫家/沐家/姚家坐镇、烟雨楼楼主 | [Ch.276-295] |
| **王** | 碾压宗师 | 修德里·白芸（融合前）、心猿魔女 | [Ch.521-545] |
| **皇** | 碾压王级 | 修德里·白芸（融合妖魔祖奎后） | [Ch.581-605] |

> 实战案例：修德里·白芸从王级提升到皇级后，力量"超越诸神黄昏允许的极限" [Ch.581-605]。

#### 4.2 超神级转职——天罚弓箭手

超神级隐藏职业的转职不遵循普通等级制，需要进入专门的超神级转职祭坛 [Ch.401-420]：

- **祭坛位置**：古朝本身即为祭坛（阴阳双鱼图案），由道之源神建造 [Ch.326-400]
- **转职材料**（三道同时催动）：
  1. **黑山印**——黑山之主（夜天子/诸葛狗蛋）持有 [Ch.351-400]
  2. **刻刀**——古朝皇帝苏北褚持有，道之源神的刻刀 [Ch.401-420]
  3. **打神石**——蛮徒皇朝皇帝诸葛龙庭持有 [Ch.401-420]
- **一转技能**：天罚——普攻必定命中，无视攻击距离，圣人之下不可闪躲格挡 [Ch.431-440]
- **攻速转换**：天罚状态下攻速独立计算，初始0.2（转换后约3.11，一秒九箭），五箭齐发等技能无法叠加 [Ch.431-440]
- **四转技能**：洞察之眼——方圆一百万公里的上帝视角观察 [Ch.876-895]

### 7. 天赋七级体系

#### 7.1 标准天赋等级

天赋按照品质从低到高分为七级 [Ch.1]：

```
黄级 → 玄级 → 地级 → 天级 → 圣级 → 神级 → 超神级
```

| 等级 | 英文参考 | 稀有度 | 典型效果 | 拥有者案例 |
|------|---------|--------|----------|-----------|
| **黄级** | Yellow | 常见 | 单一属性小幅加成 | 普通玩家 |
| **玄级** | Mystic | 较常见 | 单一属性中等加成 | 普通玩家 |
| **地级** | Earth | 不常见 | 复合属性加成 | 中端玩家 |
| **天级** | Heaven | 稀有 | 显著战力提升 | 高端玩家 |
| **圣级** | Saint | 极为稀有 | 机制级效果（50倍等效倍率等） | 猴子、周小胖、苏璃 |
| **神级** | Divine | 极其稀有 | 系统级机制改变 | 小小剑（无穷剑距） |
| **超神级** | Super Divine | 唯一级 | 颠覆游戏规则 | 林天浩（天罚之手/天罚之脑）、水如烟 |

> 原著记载：前世十年，超神级天赋的存在无人知晓 [Ch.1]。

## 设计总结

《诸神黄昏》的职业与天赋系统呈现三大设计特色：

1. **职业属性双倍机制**：每个基础职业在2-3项核心属性上有"双倍"加成，使得同等自由属性点的分配产生截然不同的角色成长曲线。弓箭手的攻速双倍（+0.02/点）是最极端的案例——配合攻速衰减机制，使弓箭手成为游戏中唯一可能突破攻速天花板的职业。

2. **天赋品质的"稀有度-强度"正相关**：从黄级到超神级，每个等级的天赋都是质变而非量变。圣级天赋的50倍等效倍率（德智体美）、超神级天赋的规则级颠覆（天罚之手忽略距离和闪避），使得顶级天赋的持有者与其他玩家拉开维度级的差距。

3. **隐藏职业的任务驱动设计**：每个隐藏职业都有独特的解锁任务链——天罚弓箭手需要三道材料、东方古国复苏需要十份诸神赐福——将职业获取与世界观探索深度绑定，使隐藏职业不仅是战力的提升，更是游戏世界的探索成就。
