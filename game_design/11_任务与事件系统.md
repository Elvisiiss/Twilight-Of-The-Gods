# 11 任务与事件系统

> 基于《诸神黄昏》小说全2231章分析，提取可供MMORPG参考的任务框架与事件机制。

---

## 1. 任务分类

### 1.1 主线任务（Main Quest）

主线任务是玩家等级推进的核心驱动，具有线性门槛结构。

**门槛体系：**

| 门槛类型 | 触发条件 | 示例 | 章节引用 |
|----------|---------|------|----------|
| 等级门槛 | 达到指定等级 | Lv10开放新手村扭曲丛林副本 | Ch.001-025 |
| 转职门槛 | 完成转职 | 一转Lv10→二转Lv50→三转Lv100→四转Lv200 | Ch.146-150 |
| 装备门槛 | 佩戴特定装备 | 生死簿需神赐资格，打神鞭仅限雪帝 | Ch.121-135 / Ch.156-160 |
| 声望门槛 | 声望达到指定值 | 冒险者公会徽章等级对应不同任务权限 | Ch.121-135 |
| 前置任务 | 完成指定任务链 | 东方古国复苏需集齐十神赐 | Ch.096-120 / Ch.251-275 |

**主角任务线结构（可作为主线任务参考）：**

```
新手村阶段 (Lv1-10)
  └─ 基础引导任务 → 扭曲丛林副本(首通) → 收集BOSS头颅 → 众神任务·摧毁新手村
主城阶段 (Lv10-50)
  └─ 遗失的公主副本 → 黑水湖副本 → 击杀王后 → 击杀国王亚伯拉 → 雪尸的足迹 → 东方古国复苏
二转阶段 (Lv50-100)
  └─ 旱魃的故居 → 攻破黑风城 → 三城一都 → 东方古国复苏完成 → 圣地之主就任
圣地阶段 (Lv100+)
  └─ 圣地天骄新人赛 → 弑神学院 → 超神级转职 → 击杀外系神灵 → 人王称号
```

### 1.4 对立任务（Opposing Quest）

两个玩家/队伍获得互相矛盾的目标。

**经典对立任务示例：**

| 对立组 | 任务A | 任务B | 设计意图 | 章节引用 |
|--------|------|------|---------|----------|
| NPC权力斗争 | 老村长·保护老酒鬼 | 老村长·击杀老酒鬼 | 迫使玩家站队 | Ch.001-025 |
| 神魔对立 | 摧毁新手村（神之任务） | 保护新手村（默认） | 代价与回报博弈 | Ch.026-045 |
| 神灵对立 | 冰雪女神·摧毁凡殿（奖励星辰王国） | 凡殿之主·保护凡殿（东方古国复苏） | 神灵阵营选择 | Ch.076-095 |
| PK触发 | 悬赏击杀雪帝（黑风城） | 雪帝反击（生死簿锁头） | 全服猎杀vs反猎杀 | Ch.096-120 |
| 势力冲突 | 帮助夜行者建立政权 | 维护星辰王国正统 | 政治立场站队 | Ch.096-120 / Ch.121-135 |
| 王位争夺 | 扶持蒂雪涧/清芙芸 | 扶持蕾欧娜 | 三方博弈 | Ch.046-070 |
| 圣地对抗 | 凡殿vs浩渺无极宫 | 双方都有任务奖励 | 圣地级PVP驱动 | Ch.476-545 |

**对立任务设计要点：**
- 双方奖励不可兼得，选择后锁定阵营[Ch.026-045]
- PK触发型对立：红名值>1万触发全服猎杀任务[Ch.046-070]
- 对立双方均可获得丰厚奖励以激励参与

### 6.3 NPC阴谋机制

NPC可以被系统设计为主动操控玩家的角色[Ch.026-045]：
- 设计对立任务迫使玩家互相争斗
- 利用任务奖励引导玩家为NPC的私人目标服务
- NPC存在自身利益诉求，不完全为玩家服务

### 6.4 NPC力量进化

- 王村长（野外BOSS）从青铜级突破到铂金级——可升级的BOSS[Ch.151-155]
- NPC可获得"与冒险者一样升级成长"的诸神赐福[Ch.046-070]
- 妖魔化NPC（吸收妖魔血脉提升品阶）[Ch.581-605]

### 7.6 特殊事件：百神争锋 [Ch.251-275]

```
触发条件：多神灵同时争夺同一位玩家赐福权
表现形式：神灵降下光柱争夺（如鸿钧老祖白色光束力压宙斯金色光束）
参与神灵：东西方神灵+克苏鲁神灵均可参与
玩家选择：可在参与争锋的神灵中选择一位获得赐福
设计要点：神灵之间存在实力等级差异，高阶神灵可压制低阶神灵
```

```
玩家利用：可通过诱导神灵出手触发雷罚削弱神灵
```
