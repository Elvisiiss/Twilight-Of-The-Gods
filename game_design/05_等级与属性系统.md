## 1. 系统进化总览

《诸神黄昏》的数值系统经历了五个阶段的演化，每个阶段的数值尺度都发生了质的飞跃：

### 1.1 阶段1：游戏初期（Ch.1~95，新手村到主城）

- 阶段特征：纯粹的MMORPG数值系统
- 核心属性：HP/MP/攻击/法强/护甲/魔抗/攻速/移速
- 等级范围：Lv.1 ~ Lv.50
- 数值尺度：HP从100到数万级 [Ch.1, Ch.46-70]
- 核心机制：基础属性成长、装备驱动、技能星级、天赋觉醒

### 1.2 阶段2：王国争霸（Ch.96~275，一转至二转临界）

- 阶段特征：转职系统引入，品质等级分化
- 核心属性增加：真实伤害、吸血率、免控率、暴击率/暴击伤害
- 等级范围：Lv.20 ~ Lv.50（二转临界）
- 数值尺度：HP从数十万到数千万 [Ch.96-275]
- 核心机制：一转元素分支、装备进化、诸神赐福、公会/领地

### 1.3 阶段3：圣地争锋（Ch.276~465，二转至四转）

- 阶段特征：半神、神灵体系引入，悟道境界出现
- 核心属性增加：神威抗性、悟道境界、法则之力
- 等级范围：Lv.50 ~ Lv.500+（NPC等级达2000~5000级）
- 数值尺度：HP从数千万到数十亿 [Ch.276-465]
- 核心机制：弑神者印记、领域系统、超神级转职、黑域等级

### 1.4 阶段4：神战纪元（Ch.476~1990，四转至更高）

- 阶段特征：神灵/圣人/天道圣人/永恒境界叠加
- 核心属性增加：法则层次、本源之力、血脉觉醒度
- 数值尺度：HP从百亿到万亿（银河级） [Ch.476-1990]
- 核心机制：神格凝聚、圣位争夺、时间长河、源神体系

### 1.5 阶段5：超脱纪元（Ch.1991~2231，最终）

- 阶段特征：源神→墟主的终极境界
- 核心属性增加：本源法则深度、规则之力、时间长河掌控
- 数值尺度：脱离数值化，进入"创造世界"层级 [Ch.1991-2231]
- 核心机制：三炼之法、世界之心、时间长河穿梭、高等世界诞生

### 2.2 每级成长机制

#### 2.2.1 自由属性点

- **每升一级**：获得5点自由属性点 [Ch.1]
- **可分配属性**：HP、MP、攻击、法强、护甲、魔抗、攻速、移速（8个常规属性）
- **特殊加成**：部分天赋可倍增属性点效果（如圣级天赋"德智体美"：自由属性点x5且加点提升全属性，实际收益50倍）[Ch.96-120]

#### 2.2.3 属性衰减机制

**攻速衰减**（最关键的限制机制）：
- 1~10点攻速：1自由属性点 = 1.0攻速
- 10~20点攻速：1自由属性点 = 0.5攻速
- 20~30点攻速：1自由属性点 = 0.25攻速
- 每档减半，依此类推 [Ch.1, Ch.46-70]
- 实战案例：林天浩花费785自由属性点将攻速提升到20箭/秒 [Ch.96-120]

**移速衰减**：
- 突破10点后：1自由属性点 = 0.05移速 [Ch.46-70]

**攻速与天罚攻速的转换**（天罚弓箭手专属）：
- 天罚状态下攻速独立计算，初始仅0.2（转换后约3.11，即一秒九箭）[Ch.431-440]
- 攻速突破10是天罚弓箭手的重要里程碑 [Ch.581-605]
- 天罚护心镜：天罚攻速+1 [Ch.521-545]

### 4.4 悟道境界体系

在神灵/圣人之前，修行者需要通过悟道提升实力 [Ch.301-325]：

```
真意境界 → 问心三境 → 法则境界
              ├── 无物（心无旁骛，道意自然）
              ├── 无我（心中无我，道由心发）
              └── 无尘（心无尘缘，道由天生，可调动天地间真意）
```

- 悟道速度加成：造化玉碟100倍 + 弑神者印记空间亲和力1000倍 = 1100倍 [Ch.301-325]
- 仙女图额外提供50%悟道速度加成 [Ch.326-345]
- 问心到达无尘后，提升异常缓慢 [Ch.326-345]

### 4.5 法则层次体系

- 普通法则：基础9层为极限 [Ch.1916-1940]
- 本源法则（空间/时间等）：12层为极限 [Ch.1916-1940]
- 林天浩空间本源法则：突破12层极限达到第13层 [Ch.1916-1940]
- 灵魂本源法则：最高19层 [Ch.1941-1965]
- 时间本源法则：最高17层 [Ch.1941-1965]

### 4.6 武道境界体系（试炼之地第三关）

```
三流 → 二流 → 一流 → 武道宗师 → 武道大宗师 → 陆地神仙 → 仙人
```

### 7.3 属性对战斗的实际影响公式（核心战斗公式推断）

#### 7.3.1 物理伤害公式 [推断]

```
普攻伤害 = ATK × (1 - 目标伤害减免%)
目标伤害减免% = 护甲 / (护甲 + 常数K)
```

- 当物穿% > 0：实际护甲 = 目标护甲 × (1 - 物穿%)
- 当暴击触发：伤害 = 普攻伤害 × 暴击伤害倍率
- 当触发真实伤害：无视护甲和魔抗直接扣减HP

#### 7.3.2 真实伤害公式（天罚之手）

```
天罚伤害 = 自身当前HP × 天罚之手百分比
```

- 天罚之手2星：3%HP [Ch.26-45]
- 天罚之手星级越高，百分比越高（具体数值需进一步确认）[推断]

#### 7.3.3 吸血公式

```
吸血量 = 实际造成伤害 × 吸血率%
```

- 木系弓箭手一转特性：所有伤害类攻击吸血1% [Ch.121-135]
- 装备可提供额外吸血率（如领主战甲吸血+20%）[Ch.96-120]

#### 7.3.4 免控公式

```
实际控制持续时间 = 原始控制时间 × (1 - 免控率)
```

- 净化玉佩初始免控80%，进化后最高93% [Ch.46-70, Ch.276-400]
- 韧性额外减少控制强度 [Ch.1]

#### 7.3.5 反伤公式

```
反伤伤害 = 承受伤害 × 全能反伤%
```

- 黑铁树人套装：反伤20% [Ch.1]
- 领主战甲套装：全能反伤20% [Ch.96-120]
- 王铁匠反伤约70% [Ch.26-45]

#### 7.3.6 暴击率与暴击伤害

- 默认暴击倍率：200% [推断]
- 暴击率可通过装备/天赋叠至100% [Ch.276-295]
- "无限暴击"技巧：攻击致命位置大幅提升暴击概率 [Ch.1]
