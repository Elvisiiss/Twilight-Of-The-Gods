## Part A: 悟道/修炼体系

### A1. 悟道之路总纲

悟道是《诸神黄昏》后游戏期最核心的成长维度，独立于等级和转职系统。悟道境界决定了玩家对"道"的掌控程度，直接影响技能威力、领域强度和越级战斗能力。

#### A1.1 完整悟道进阶链

```
真意 → 问心·无物 → 问心·无我 → 问心·无尘 → 法则境 → 天道境 → 大道境
```

#### A1.2 各阶段详解

##### 第一阶段：真意（入门）

| 属性 | 说明 |
|------|------|
| **定位** | 道的浅薄运用，掌握某种"真意"即入门该道 |
| **效果** | 技能获得对应真意加持，威力提升约30%-50% |
| **已知真意类型** | 力之真意、空间真意、箭之真意、剑之真意、刀之真意等 [Ch.301-325] |
| **突破条件** | 对该道的基础理解达到阈值，首次领悟通常需要机缘或导师引导 |
| **时间参考** | 普通玩家1-3个月（无加速）；林天浩在力之领域中数小时内入门力之真意 [Ch.301-325] |

##### 第二阶段：问心三境

**问心·无物（初级）**

| 属性 | 说明 |
|------|------|
| **定位** | 心无旁骛，道意自然，顺畅释放真意 |
| **效果** | 真意技能释放速度+30%，消耗-20% |
| **突破条件** | 真意圆满 + 心境达到"忘物"状态 |
| **时间参考** | 普通玩家6-12个月；林天浩数天（1100倍加速）[Ch.301-325] |

**问心·无我（中级）**

| 属性 | 说明 |
|------|------|
| **定位** | 心中无我，道由心发，意由心动 |
| **效果** | 真意技能可"随心而发"（取消部分前摇），威力+50% |
| **突破条件** | 无物圆满 + 经历一次"忘我"战斗体验 |
| **时间参考** | 普通玩家1-2年；林天浩约一周（1100倍加速）[Ch.301-325] |

**问心·无尘（高级）**

| 属性 | 说明 |
|------|------|
| **定位** | 心无尘缘，道由天生，可调动天地间真意 |
| **效果** | 可调动周围环境的道之力，领域技能范围+100%，威力+100% |
| **突破条件** | 无我圆满 + 精神与天地产生共鸣 |
| **时间参考** | 林天浩花费21天达到无尘高级 [Ch.326-345] |
| **注意事项** | 问心到达无尘后提升异常缓慢，是第一个真正的瓶颈 [Ch.326-345] |

##### 第三阶段：法则境

法则境分为普通法则和本源法则两个层级。

**普通法则（基础9层）**

| 层数 | 名称 | 效果递进 |
|------|------|----------|
| 第1层 | 法则初悟 | 可调动单一法则之力，技能附带法则属性伤害 |
| 第2-3层 | 法则贯通 | 法则覆盖范围扩大，伤害倍率提升 |
| 第4-6层 | 法则精通 | 可创造简易法则领域，压制同级及以下敌人 |
| 第7-8层 | 法则升华 | 法则领域内自身属性大幅提升 |
| 第9层 | 法则圆满 | 普通法则极限，可触摸更高层次的天道之力 |

**本源法则（扩展至12层，可打破极限）**

> 空间、时间、生命、灵魂、死亡、力等为本源法则，基础极限为12层 [Ch.1916-1940]

| 层数 | 突破难度 | 关键效果 |
|------|----------|----------|
| 1-9层 | 对应普通法则 | 本源法则威力远超同级普通法则 |
| 10-12层 | 极高，需特殊机缘 | 打破世界规则限制，可使用本源领域 |
| 13层+ | 打破极限，史诗级成就 | 林天浩空间本源法则达第13层，可撕开空间封锁 [Ch.1916-1940] |

**已知本源法则列表**

| 本源法则 | 类型 | 代表能力 |
|----------|------|----------|
| 空间本源法则 | 至高 | 瞬移、空间封锁、空间切割、撕开空间壁垒 |
| 时间本源法则 | 至高 | 时间暂停、时间加速/减速、时间错位 |
| 生命本源法则 | 上等 | 复活生灵、生命汲取、生命创造 |
| 灵魂本源法则 | 上等 | 灵魂攻击、灵魂奴役、灵魂重塑 |
| 死亡本源法则 | 上等 | 即死判定、亡灵操控、生命剥夺 |
| 力之大道 | 至高 | 盘古大神的根本大道，可压制一切生灵 [Ch.301-325] |
| 火之本源法则 | 中等 | 焚天灭地、法则之火 |
| 雷之本源法则 | 中等 | 雷劫攻击、天罚之力 |
| 命运本源法则（左手） | 至高 | 操控命运轨迹 |
| 因果本源法则（右手） | 至高 | 因果倒置、因果斩断 |

##### 第四阶段：天道境

| 属性 | 说明 |
|------|------|
| **最高层数** | 999层（天道境极限）[Ch.1991-2115] |
| **特征** | 每一层都代表对天道某一条规则的完全掌控 |
| **突破方式** | 每突破一层需渡一次小天劫，每百层渡大天劫 |
| **参考进度** | 林天浩空间本源法则问道境999层 [Ch.1966-1990] |

##### 第五阶段：大道境

| 属性 | 说明 |
|------|------|
| **最高层数** | 仅1层（大道唯一）[Ch.1991-2115] |
| **特征** | 掌握大道本身，超越所有法则和天道 |
| **限制** | 受平行世界限制，在某个平行世界内只能存在一位大道境掌控者 |
| **状态** | 小说中为本阶段的终极追求，是后期扩展包的核心目标 |

### A3. 三炼之法（核心后期成长系统）

#### A3.1 系统概述

三炼之法是曹自泫传授给林天浩的核心修炼法门，要求**炼体、炼魂、炼气**三者同时修炼 [Ch.1966-1990]。这是后期扩展包中最重要的平行成长线，与等级系统、悟道系统形成三维成长矩阵。

**传授背景：**
- 传授者：曹自泫（寒天楼强者，600+层，星域级巅峰战力）
- 获得条件：加入寒天楼并通过考验
- 功法特性：无上限，可一直提升，越到后期越强 [Ch.1976-1985]

#### A3.2 三篇功法详解

| 功法 | 核心效果 | 属性关联 | 修炼难度 |
|------|----------|----------|----------|
| **炼体** | 增加防御、力量、敏捷、生命值上限 | 体魄属性全面强化 | 中等（需承受巨大物理压力） |
| **炼魂** | 强化灵魂力、灵魂抗性、神识范围 | 灵魂属性+精神抗性 | 较高（灵魂层面的痛苦考验） |
| **炼气** | 凝实纯粹"气"，无属性无等级 | 能量储备+技能消耗减免 | 最高（需在体内构建能量循环） |

> **核心设计理念**：三法同修，互相促进。单一修炼速度缓慢，三者齐头并进则产生共鸣加速效果。

#### A3.3 层数与战力对照表

| 三炼之法院层数 | 对应战力等级 | 关键能力解锁 | 章节参考 |
|---------------|-------------|-------------|----------|
| 100层 | 神灵级巅峰 | 体魄可承受神灵攻击 | - |
| 300层 | 星域级入门（武神级） | 三法共鸣，可越级战斗 | [Ch.1966-1990] |
| 600层 | 星域级巅峰（仙祖级） | 曹自泫的境界；一人可战多位同级 | [Ch.1976-1985] |
| 900层 | 半步源神 | 体魄初步超越星域极限 | [Ch.2016-2040] |
| 2200层 | 源神级 | 肉身硬抗源神攻击 | [Ch.2036-2040] |
| 3000层 | 源神巅峰 | - | - |
| 6150层 | 源主级 | 万法难伤，道之层次飞跃 | [Ch.2046-2050] |
| 9999层 | 源主巅峰 | 只差一步突破万层大关 | [Ch.2051-2055] |
| **破万层** | 源王级+ | 跨入全新层次，神域顶尖 | [Ch.2086-2090] |

#### A3.4 三炼之法加速手段

| 加速方式 | 效果 | 条件 |
|----------|------|------|
| 吞噬世界之心 | 先天之气可改造身体和灵魂，加速三炼 | 需吞天噬地技能 [Ch.1991-2015] |
| 时空宝塔修炼 | 365倍时间差 | 自行炼制或购买 [Ch.1981-1990] |
| 雷霆淬体 | 黑色雷霆淬炼身躯和灵魂 | 渡劫或特殊区域 [Ch.1991-2015] |
| 本源法则加持 | 掌握的本源法则越多，三炼速度越快 | 万法之躯天赋配合 [Ch.1901-1905] |

#### A3.5 游戏化设计要点

```
1. 三炼之法院数 = 三项独立进度条，必须保持平衡
2. 若某一项远超其他两项，将产生"失衡惩罚"（修炼速度递减）
3. 每100层触发"三炼共鸣"，全属性爆发性增长
4. 破万层为资料片级成就，解锁专属外观和称号
```

### A4. 突破机制与天劫体系

#### A4.1 天劫类型

| 天劫类型 | 触发条件 | 内容描述 | 难度等级 |
|----------|----------|----------|----------|
| **雷劫** | 大境界突破 | 天降各色雷电，淬体同时毁灭肉身 | 中-极高 |
| **心魔劫** | 灵魂/精神突破 | 幻境中面对心魔，信念崩塌则突破失败 | 高 |
| **道问** | 天道境突破 | 天地发问，回答道的本质，答错则倒退 | 极高 |
| **炼心劫** | 天道级天赋觉醒 | 炼狱万载+百世轮回，考验意志 [Ch.1901-1905] | 顶级 |

#### A4.2 炼心劫详解（后期核心考验）

触发道具：天道级天赋觉醒石 [Ch.1901-1905]

**三阶段考验：**
1. **炼狱五百年**：油锅一百年 + 刀山一百年 + 烈火焚身三百年
2. **百世轮回**：投胎畜生道一百世，体验各种生灵之苦
3. **最终考验**：最后一世为龙族少主（有意识复苏的机会），若无法觉醒即失败

**破解关键**：信念不崩塌，意识复苏 [Ch.1901-1905]

**奖励**：觉醒万法之躯（永恒级天赋）

#### A4.3 雷劫等级体系

| 雷劫等级 | 对应突破 | 雷电特征 |
|----------|----------|----------|
| 三九雷劫 | 金丹-元婴 | 27道天雷 |
| 六九雷劫 | 大乘-仙劫 | 54道天雷 |
| 九九雷劫 | 仙帝-仙祖 | 81道天雷 |
| 升仙劫 | 凡人-仙人 | 特殊雷劫，含心魔成分 |
| 天道雷劫 | 仙帝巅峰 | 被误认为第四位仙祖时引发 [Ch.1991-2015] |

#### A4.4 道种-道树-道果体系

```
道种（元婴期凝结）
  ├── 萌芽阶段：需持续灌入真意和法则感悟
  ├── 道树（仙王级成形）：根植于体内小世界
  │     ├── 枝干 = 不同道的方向
  │     └── 叶片 = 道的具体感悟
  └── 道果（源神级凝结）
        ├── 一颗道果 = 一条本源法则圆满
        ├── 多颗道果 = 掌握多条本源
        └── 九颗道果 = 触及大道门槛
```

> **推论**：蓝星和诸神黄昏可能是同一人创造的两个小世界（一体双小世界理论），规则互通，打怪升级本质是掠夺另一个世界的"道" [Ch.2041-2065]

## Part B: 宇宙架构

### B1. 世界层级体系

《诸神黄昏》的宇宙由多个层级的世界构成，形成金字塔式的世界等级结构。

#### B1.1 完整层级图

```
┌─────────────────────────────────────────────────┐
│                  墟 外（不可知之地）              │
│  ┌───────────────────────────────────────────┐  │
│  │           高 等 世 界（神界 / 源界）       │  │
│  │  ┌─────────────────────────────────────┐  │  │
│  │  │       中 等 世 界（9个）             │  │  │
│  │  │  ┌─────────────────────────────┐    │  │  │
│  │  │  │   小 世 界（凡界/凡间）     │    │  │  │
│  │  │  │  无数，不断新生和消亡      │    │  │  │
│  │  │  └─────────────────────────────┘    │  │  │
│  │  └─────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────┘  │
│           不祥之地（时间长河之外）               │
└─────────────────────────────────────────────────┘
```

#### B1.2 小世界（凡界/凡间）

| 世界名称 | 特征 | 状态 |
|----------|------|------|
| **蓝星（地球）** | 银河世界核心，龙国所在 | 后期冰封→复苏→开启修仙时代 [Ch.2191-2231] |
| **银河世界** | 含蓝星、诸神黄昏等，超级势力布局棋盘 | 升格为高等世界 [Ch.2216-2231] |
| **诸神黄昏（游戏世界）** | 与蓝星一体双生，猴子逆转时间线产物 | 最终与蓝星融合 [Ch.2216-2231] |
| **阿来特星系** | 外部入侵势力大本营，可能为一体三世界之一 | 持续入侵状态 [Ch.376-400] |
| **北山星域** | 林天浩转生之地，距银河世界10万+星系 | 洞玄盟管辖 [Ch.1961-1965] |

### B3. 时光长河系统

时光长河是宇宙运行的底层机制，是所有世界存在的本源脉络。

#### B3.1 核心定义

| 属性 | 说明 |
|------|------|
| **本质** | 主世界运行的核心结构，每条时间长河代表一个世界 [Ch.2116-2231] |
| **结构** | 主流 + 分支（支流/平行世界）|
| **与世界的对应** | 高等世界拥有独立时间长河，小世界时间长河跟随高等世界 |
| **持久性** | 不会因世界泯灭而泯灭，墟主只能改变流向无法让其消失 [Ch.2116-2231] |

#### B3.2 核心机制

**能量守恒法则：**
```
生灵死亡 → 能量还给时间长河 → 再分配给其他生灵
```
> 这是宇宙的终极循环法则，所有修为、生命力本质上都是时间长河的能量借贷 [Ch.2016-2040]

**主流与分支：**

| 类型 | 说明 | 稳定性 |
|------|------|--------|
| **主流** | 世界的"真实"时间线 | 稳定，不祥难以侵蚀 |
| **分支（平行世界）** | 强行穿梭时间长河产生的分叉 | 不稳定，最终被不祥侵蚀 |
| **交融** | 主流与支流可交融形成全新主流 [Ch.2116-2231] | 需要外部干预 |

**时间冻结机制：**
- 源神级战斗可能波及时间长河
- 时间长河为保护正常时间线，自动冻结附近世界时间
- 战斗结束后恢复 [Ch.1901-1905]

**多重时间长河：**
- 银河世界可能不在当前时间长河 [Ch.2016-2040]
- 神域可能在另外一条时间长河
- 不同时间长河之间可由墟主级存在操控联通

#### B3.3 穿梭时间长河规则

| 保留内容 | 被冲刷掉的内容 |
|----------|----------------|
| 本源悟性（万法之躯） | 境界修为 |
| 本源抗性 | 道的力量 |
| 全部记忆 | 本源规则之心创建的世界 |
| 天赋技能 | 装备和法宝（部分） |

> **关键**：记忆是穿梭时间长河的核心；保留记忆可快速恢复实力，失去记忆则恢复极为缓慢 [Ch.2016-2040]

**多重穿梭限制：**
- 第二次进入需闭关提升时间本源抗性（林天浩闭关两万多年）[Ch.2016-2040]
- 冲刷之力累积，越多次穿梭冲刷越强
- 穿越者不属于过去时代，会被时间长河排斥

#### B3.4 "时间之外"技能（顶级能力）

| 属性 | 说明 |
|------|------|
| **获得方式** | 隐藏副本"亡国魂下的生存挑战"通关奖励三选一 [Ch.2141-2165] |
| **效果** | 自由出入时间长河内外，不被时间长河之外的不详侵蚀 |
| **战略价值** | 可无视不祥之力自由穿梭，后期副本和高危区域的必需能力 |
| **同档可选** | 一念源帝（境界瞬达源帝中期）、天下无我 |

#### B3.5 不祥侵蚀机制

| 属性 | 说明 |
|------|------|
| **来源** | 时间长河之外的不祥之地 [Ch.2016-2040] |
| **侵蚀对象** | 人、规则、所有一切 |
| **侵蚀过程** | 支流（平行世界）被不祥之力污染 → 世界完全侵蚀 → 变成诡异秘境回归主世界 [Ch.2016-2040] |
| **同化效果** | 被不祥同化后，道的力量溃散但不消失，增强体魄和灵魂 |
| **不相容性** | 不祥之力与道的力量相互侵蚀，理论上不能同时存在 [Ch.2016-2040] |
| **惧怕** | 时间长河中的力量，进入会快速消融；需不祥完全侵蚀世界后才能降临主世界 [Ch.1991-2115] |
