## 一、新手村级（新手区）

> **设计定位**: 玩家1-20级的新手阶段体验区域。每个新手村容纳1万人，是游戏教学、基础战斗、NPC派系系统的核心场景。

---

### 10086号新手村 (Novice Village #10086)
- **尺度**: 村
- **所属区域**: 星辰王国 / 浩渺大陆边陲
- **首次出场**: [Ch.001]
- **描述**: 游戏中最典型的初始新手村，容纳一万人。村内NPC存在三派权力斗争（老村长派系、王铁匠派系、老酒鬼派系）。村庄下方封印着黄帝之女——旱魃（世界BOSS级存在）。冰焰魔矿是释放封印的关键道具。新手村在剧情推进中最终被冰雪女神摧毁 [Ch.042-043]，玩家转移至主城区域。
- **重要性**: 初始出生点 / 新手教程 / 剧情引爆点
- **连通地点**: 扭曲丛林 → 黑水湖 → 雪尸的足迹 → 凡殿圣地 → 天星城
- **关键事件**: 收集红眼兔眼珠 [Ch.003-005]；猎杀十大新手村BOSS [Ch.006-010]；NPC派系斗争暴露 [Ch.011-015]；旱魃封印发现 [Ch.026-030]；诸神任务：摧毁新手村 [Ch.031-033]；新手村被冰雪女神毁灭 [Ch.042-043]
- **主要NPC/怪物**: 老村长（守护者/后BOSS化）、王铁匠（武器锻造/后BOSS化）、老酒鬼（隐藏BOSS）、十大野外BOSS（艾尔伏斯等）
- **游戏机制标注**: 安全区（前期）→ 毁灭事件触发后变为废墟 / 新手出生点 / 基础副本入口 / 红名系统触发区

### 扭曲丛林副本 (Twisted Jungle Instance)
- **尺度**: 副本 / 小型秘境
- **所属区域**: 10086号新手村外围
- **首次出场**: [Ch.006]
- **描述**: 新手村外的隐藏副本区域，充满树人怪物和扭曲植物。副本分为简单/困难/噩梦/地狱四级难度。地狱级终极BOSS为九头蛇柏，通关可获得枯木逢春技能。首次通关可获得黑铁级树人套装（13件套）、大量自由属性点和技能书奖励。是玩家第一个接触的副本系统。
- **重要性**: 首个副本 / 新手装备来源 / 技能获取地
- **连通地点**: 新手村 → 黑水湖
- **关键事件**: 首次进入隐藏副本 [Ch.016]；地狱级首通 [Ch.018-020]；首通获全服通告 [Ch.020]
- **主要NPC/怪物**: 扭曲树人、树人王、九头蛇柏（地狱级终极BOSS）
- **游戏机制标注**: 副本入口（4级难度）/ 首通奖励 / 装备掉落 / 技能书产出

### 黑水湖 (Blackwater Lake)
- **尺度**: 副本 / 小型秘境
- **所属区域**: 新手村外围
- **首次出场**: [Ch.072]
- **描述**: 新手村附近的水域副本区域。首通后可解锁技能限制放开机制——允许玩家突破技能等级上限，是古武术修炼的重要前置条件。湖中分布水系怪物和隐藏BOSS。
- **重要性**: 技能突破解锁 / 古武前置
- **连通地点**: 新手村 → 扭曲丛林 → 雪尸的足迹
- **关键事件**: 副本首通，解锁技能限制放开 [Ch.072-075]
- **主要NPC/怪物**: 水系精英怪、隐藏水兽BOSS
- **游戏机制标注**: 副本入口 / 技能系统解锁触发器 / 古武解锁条件

### 雪尸的足迹 (Footprints of the Snow Zombie)
- **尺度**: 副本 / 中型秘境
- **所属区域**: 新手村冰原方向
- **首次出场**: [Ch.039]
- **描述**: 冰原主题的中型副本群，表面是雪尸怪物巢穴，实则是封印冰雪女神的监狱。副本深度探索后触发冰雪女神本体释放事件。地狱级难度通关后，冰雪女神被彻底释放，成为全服世界级威胁。副本内含有冰系宝物、冰焰魔矿矿脉等隐藏资源。
- **重要性**: 神灵级BOSS巢穴 / 弑神事件发生地 / 剧情转折点
- **连通地点**: 新手村 → 冰雪城 → 凡殿圣地
- **关键事件**: 地狱级首通，释放冰雪女神本体 [Ch.039-041]；冰雪女神毁灭新手村 [Ch.042-043]；深度探索发现封印真相 [Ch.079-081]；林天浩击杀冰雪女神，获得弑神者印记 [Ch.082-085]
- **主要NPC/怪物**: 冰雪女神（神灵级BOSS）、雪尸群、冰霜守卫、冰晶巨龙（精英BOSS）
- **游戏机制标注**: 副本入口（4级难度）/ 弑神者印记解锁 / 冰系免疫掉落 / 世界BOSS触发 / 神殿级BOSS

### 新手村封印之地 (Sealed Lands Beneath the Village)
- **尺度**: 特殊区域（地底）
- **所属区域**: 10086号新手村正下方
- **首次出场**: [Ch.026]
- **描述**: 新手村正下方深层的封印空间，封印着黄帝之女——旱魃（世界BOSS）。封印由老村长世代看守，冰焰魔矿（共三枚）是破坏封印的关键材料。封印一旦被打破，旱魃将觉醒成为全服级威胁。该区域与其说是"地点"，不如说是一个"事件触发器"，代表了每个新手村都封印着远古存在的基本设定。
- **重要性**: 世界BOSS封印 / 新手村毁灭触发器 / 东方古国剧情起源
- **连通地点**: 新手村（地上）→ 凡殿圣地 → 黄帝之墓
- **关键事件**: 发现封印存在 [Ch.026-028]；冰焰魔矿收集 [Ch.029-030]；封印解除触发旱魃觉醒 [Ch.031-033]
- **主要NPC/怪物**: 旱魃（世界BOSS，黄帝之女）、老村长（守护者）
- **游戏机制标注**: 世界BOSS触发区 / 特殊材料产出 / 剧情锁

### 凡殿圣地 (Sanctuary of the Mortal Hall / Fan Dian)
- **尺度**: 圣地（可建设领地）
- **所属区域**: 真正新手村区域 / 浩渺大陆东部
- **首次出场**: [Ch.086]
- **描述**: 上古弑神者留下的圣地，位于"真正新手村"的中心。林天浩击杀冰雪女神后成为凡殿之主。圣地位于一个与外界隔绝的灵气浓郁区域，可被玩家建设和发展。凡殿是东方古国复苏任务的核心据点，也是未来对抗西方神灵势力的前哨基地。拥有独立的领地特性、建筑系统和NPC招募机制。
- **重要性**: 玩家领地 / 阵营核心 / 东方古国枢纽 / 后期战争指挥中心
- **连通地点**: 新手村废墟 → 天星城 → 黑风城 → 东方古国遗迹 → 各主城（传送阵）
- **关键事件**: 林天浩成为凡殿之主 [Ch.086]；凡殿圣地复苏 [Ch.087-088]；东方古国复苏任务启动 [Ch.089-090]；获得月老赐福、后土娘娘赐福 [Ch.091-092]
- **主要NPC/怪物**: 前代弑神者（灵魂残留）、东方神灵（月老、后土娘娘等的赐福虚影）
- **游戏机制标注**: 安全区 / 领地建设系统 / 传送枢纽 / 阵营总部 / 东方神灵赐福获取点 / 复活点

### 黑风寨 (Heifeng Stronghold)
- **尺度**: 小型据点（野外区域的强盗巢穴）
- **所属区域**: 黑风山脉外围
- **首次出场**: [Ch.057]
- **描述**: 活跃于黑风城周边的山贼据点，寨主布特牙儿司统治着一批山贼喽啰。是玩家从新手区过渡到城镇区域后遇到的第一个野外据点类挑战。林天浩单人攻破黑风寨，击杀了寨主。
- **重要性**: 首次野外据点攻略 / 铂金装备来源
- **连通地点**: 黑风城 → 黑风山脉
- **关键事件**: 林天浩单刷黑风寨 [Ch.057-060]；寨主布特牙儿司被击杀 [Ch.058]
- **主要NPC/怪物**: 布特牙儿司（寨主BOSS）、山贼喽啰、黑风山贼精英
- **游戏机制标注**: 野外据点 / BOSS刷新点 / 可重复挑战 / 装备掉落

### 黑风山脉 (Heifeng Mountain Range)
- **尺度**: 野外区域 / 山脉
- **所属区域**: 黑风城东北
- **首次出场**: [Ch.061]
- **描述**: 连接黑风城与外域的广袤山脉，地势险要、魔兽横行。山体深处封印着魔王之子格雷洛林森，是夜行者组织的主要活动区域。山脉内包含龙窟入口、黑曜石矿脉、稀有药草产地等资源。是20-40级玩家的主要野外练级和资源采集区域。
- **重要性**: 野外练级区 / 封印地点 / 公会领地建设
- **连通地点**: 黑风城 → 黑风寨 → 夜行者魔窟 → 龙窟 → 凡殿领地
- **关键事件**: 魔王之子封印发现 [Ch.061-063]；建立首个玩家领地 [Ch.119-120]；夜行者接触 [Ch.106-108]
- **主要NPC/怪物**: 魔王之子格雷洛林森（封印中）、各类魔兽、夜行者成员
- **游戏机制标注**: 野外PVP区 / 公会领地建设区 / 资源采集 / 魔兽猎场 / 隐藏副本入口（龙窟）

### 夜行者魔窟 (Nightwalker Demon Cave)
- **尺度**: 副本 / 地下区域
- **所属区域**: 黑风山脉深处
- **首次出场**: [Ch.106]
- **描述**: 夜行者组织的地下据点和训练场。夜行者是致力于拯救魔王之子格雷洛林森的秘密组织，成员以刺客和暗系职业为主。魔窟是夜行者的三大据点之一，内设训练室、情报交换站和通往更深层封印之地的密道。玩家可在此接取夜行者系列任务、获取暗系装备和技能。
- **重要性**: 隐藏组织据点 / 暗系职业任务线 / 装备进化
- **连通地点**: 黑风山脉 → 魔王之子封印地
- **关键事件**: 林天浩获得装备进化卷轴 [Ch.106-108]；接触黑袍首领 [Ch.121-125]
- **主要NPC/怪物**: 黑袍首领（夜行者三大首领之一）、夜行者刺客、暗影魔兽
- **游戏机制标注**: 副本入口 / 暗系职业任务线 / 装备进化NPC / 隐藏声望系统

---

### 落日镇 (Sunset Town)
- **尺度**: 镇（小型据点）
- **所属区域**: 星辰王国边境
- **首次出场**: [Ch.115]
- **描述**: 位于星辰王国边陲的小型镇落，是前往山海帝国方向的必经之路。镇上有基础的铁匠铺、药剂店和旅店，是玩家在长途跋涉中的补给点。落日镇以日落时分的壮丽景色闻名，也是多个支线任务的触发地。
- **重要性**: 边境补给点 / 支线任务中心
- **连通地点**: 星辰王国区域 → 山海帝国方向
- **关键事件**: 边境贸易路线任务线 [Ch.115-120]
- **主要NPC/怪物**: 镇长老、商队护卫、边境巡逻兵
- **游戏机制标注**: 安全区 / 任务发布点 / 补给商店 / 坐骑驿站

## 二、城镇/区域级

> **设计定位**: 玩家20-80级的主要活动区域。每座城池拥有独立的护城大阵、城卫军、政治派系和经济体系。

---

### 天星城（Tianxing City / 星辰王国首都）
- **尺度**: 城（王国首都）
- **所属区域**: 星辰王国核心区域
- **首次出场**: [Ch.046]
- **描述**: 星辰王国的王都，以宏伟的星辉宫殿和复杂的政治生态著称。城市分为王宫区、商业区、冒险者公会区、贫民区和贵族区。天星城是星辰王国三大公主争夺王位的核心舞台。桃花楼位于商业区，是天星城的社交和信息交换中心。城市拥有强大的护城大阵和九位白银将军拱卫。
- **重要性**: 王国首都 / 政治中心 / 核心主城
- **连通地点**: 新手村 → 凡殿圣地 → 冰雪城 → 黑风城 → 山海帝国（传送阵）
- **关键事件**: 触发"遗失的公主"任务 [Ch.046-048]；王后菲欧丁雨与国王亚伯拉的政治斗争 [Ch.049-051]；林天浩结识水如烟 [Ch.101-102]；国王颁布雪帝禁足令 [Ch.056]；冒险者公会会长就任 [Ch.121-125]
- **主要NPC/怪物**: 国王亚伯拉、王后菲欧丁雨、蕾欧娜公主、蒂雪涧大公主、清芙芸二公主、水如烟（花魁/天罚传承者）、兰迪柯震大将军、丞相克森罗
- **游戏机制标注**: 安全区（主城）/ 阵营任务中心 / 拍卖行 / 公会注册 / 王国声望系统 / 红名惩罚触发区 / 王室任务线

---

### 黑风城（Heifeng City）
- **尺度**: 城
- **所属区域**: 星辰王国东部
- **首次出场**: [Ch.096]
- **描述**: 星辰王国东部的重要城市，因毗邻黑风山脉而得名。黑风城拥有完整的护城大阵（后被林天浩攻破），是东部区域的商业和军事中心。林天浩成为第一个攻破主城的玩家，获得封神榜奖励。攻破后黑风城纳入林天浩势力范围，成为凡殿领地的外围城市。
- **重要性**: 首个可攻略主城 / 领地扩张跳板 / 封神榜获取地
- **连通地点**: 天星城 → 黑风山脉 → 黑风寨 → 凡殿领地 → 冰雪城
- **关键事件**: 林天浩进攻黑风城 [Ch.109-110]；护城大阵被摧毁 [Ch.111-113]；城卫军集体失踪（国王授意）[Ch.111]；获得封神榜 [Ch.121-125]
- **主要NPC/怪物**: 布特牙儿司（城主，逃亡）、洛林牧野（大元帅之弟）、义军首领（兽皮壮汉）
- **游戏机制标注**: 可攻略主城 / 领地系统 / PVP攻城战 / 护城大阵 / 城主变更

---

### 冰雪城（Ice and Snow City）
- **尺度**: 城
- **所属区域**: 星辰王国北部冰原
- **首次出场**: [Ch.120]
- **描述**: 位于星辰王国极北冰原的城市，终年积雪覆盖。冰雪城是西方神灵体系——特别是冰雪女神信仰——在凡间的重要据点。城中有冰雪女神神殿，供奉着冰雪女神的神像。冰雪城居民多为冰系修行者和雪原猎手，对东方古国阵营的玩家有天然敌意。
- **重要性**: 西方神灵阵营据点 / 冰雪系资源 / 阵营对抗前线
- **连通地点**: 天星城 → 雪尸的足迹 → 赤峰城
- **关键事件**: 冰雪女神信徒集会 [Ch.120-125]；冰系修炼资源争夺 [Ch.130+]
- **主要NPC/怪物**: 冰雪女神祭司、雪原猎手、冰霜骑士
- **游戏机制标注**: 西方阵营主城 / PVP争夺区 / 冰雪系商店 / 阵营声望

---

### 赤峰城（Chifeng City / Red Peak City）
- **尺度**: 城

## 三、王国/大陆级

> **设计定位**: 构成游戏世界地理基础的宏观区域，定义了阵营、文化和核心冲突的地理框架。

### 星辰王国 (Kingdom of Stars)
- **尺度**: 王国
- **所属区域**: 浩渺大陆西部
- **首次出场**: [Ch.046]
- **描述**: 浩渺大陆西部的主要人类王国，以西方中世纪奇幻风格为基调。王国由国王亚伯拉统治，三位公主竞争王位继承权。政治生态复杂：王后菲欧丁雨派系、大公主蒂雪涧派系、二公主清芙芸派系、小公主蕾欧娜派系相互博弈。王国信仰体系更接近西方神灵（冰雪女神等），与东方的山海帝国形成文化对抗。国土包括天星城（首都）、黑风城、冰雪城、赤峰城、孤风城、浮灵城等主要城市。
- **重要性**: 西方阵营大本营 / 初期核心舞台
- **连通地点**: 山海帝国（东方）→ 幽冥之地（地下）→ 凡殿圣地（独立领地）
- **关键事件**: 王位之争 [Ch.046-070]；国王禁足令 [Ch.056]；凡殿崛起 [Ch.086-095]；黑风城沦陷 [Ch.111-113]
- **主要NPC/怪物**: 国王亚伯拉、王后菲欧丁雨、三位公主、大元帅洛林牧原
- **游戏机制标注**: 王国声望系统 / 西方阵营 / 王室任务线 / PVP阵营

- **游戏机制标注**: 东方阵营 / 修仙系统 / 炼丹/灵符/阵法 / 阵营切换

## 四、秘境/副本级（30+）

> **设计定位**: 核心PVE内容载体。秘境是游戏中最丰富的战斗和探索场景，分为传统副本、开放式秘境和特殊事件秘境三类。各秘境分布在浩渺大陆的不同区域。

- **所属区域**: 新手村冰原

### 黄帝之墓 (Tomb of the Yellow Emperor)
- **尺度**: 大型秘境
- **所属区域**: 山海帝国 / 东方古国遗迹区
- **首次出场**: [Ch.150]
- **描述**: 远古东方黄帝的陵墓秘境，是一座巨大的地下宫殿群。秘境内充满机关、守护兽、古代兵俑和黄帝残魂。秘境的终极奖励与东方古国复苏任务线直接关联——可获得远古东方神灵的传承赐福。秘境分为多层：外围墓道（机械机关+亡灵）、中层墓室（五行守护阵）、核心棺椁室（黄帝残魂试炼）。
- **重要性**: 东方古国任务关键 / 核心剧情秘境
- **连通地点**: 山海帝都 → 天古城 → 东方古国遗迹区
- **关键事件**: 黄帝残魂试炼 [Ch.155+]；东方神灵赐福获取 [Ch.160+]
- **主要NPC/怪物**: 黄帝残魂（终极BOSS）、五行守护兽、古代兵俑、机关傀儡
- **游戏机制标注**: 主线副本 / 东方古国任务链 / 神灵赐福掉落 / 多阶段BOSS战

### 道之古朝秘境 (Ancient Dao Dynasty Realm)
- **尺度**: 大型秘境
- **所属区域**: 天古城外围
- **首次出场**: [Ch.200]
- **描述**: 远古道之王朝的遗留秘境，代表失落的修仙文明巅峰。秘境内保存着完整的古代修仙宗门结构——藏经阁、炼丹房、悟道崖、渡劫台等。秘境的最大特色是"道韵感悟"系统——玩家在秘境内可通过观摩古代仙人留下的道韵痕迹，直接提升对"道"的理解。道之古朝也是获取远古炼丹术和灵符术的唯一途径。
- **重要性**: 修仙体系核心秘境 / 道韵感悟 / 古代技艺获取
- **连通地点**: 天古城 → 红枫古墟 → 浩渺无极宫
- **关键事件**: 道韵感悟系统解锁 [Ch.205+]；远古炼丹术获取 [Ch.210+]
- **主要NPC/怪物**: 古仙人残影、道韵守护灵、化凡试炼傀儡
- **游戏机制标注**: 道韵系统 / 修仙传承 / 远古丹药配方 / 灵符配方 / 时间限制

### 红枫古墟 (Red Maple Ancient Ruins)
- **尺度**: 开放式秘境
- **所属区域**: 红枫城外围红枫林
- **首次出场**: [Ch.225]
- **描述**: 位于红枫林深处的古代废墟秘境，以满地的红色枫叶和荒废的古建筑群为景观特色。废墟内遍布木系灵气，是木系职业转职和进阶的理想场地。古墟深处存在一棵沟通天地的"世界古树"，树下封印着远古木系神灵。秘境的核心机制是"灵根觉醒"——允许玩家获得或强化木系灵根。
- **重要性**: 木系职业核心秘境 / 灵根系统
- **连通地点**: 红枫城 → 道之古朝秘境

## 六、中世界（九个）

- **连通地点**: 浩渺大陆（飞升）→ 天域 → 星界 → 神域（源界）
- **关键事件**: 身合天道 [Ch.2041-2065]；雷罚殿统治 [Ch.1991-2015]；百世仙宗传承 [Ch.1991+]

## 七、高维/宇宙级

> **设计定位**: 超越凡界和中世界的最高层次区域，代表宇宙规则的本源。是游戏终极阶段的内容载体。

### 神域 (Divine Realm / Shenyu)
- **尺度**: 高等世界 / 神域核心
- **所属区域**: 高等世界层 / 超越九大中世界
- **首次出场**: [Ch.276]
- **描述**: 位于三界结构最顶层的高等世界，拥有独立的时间长河。只有达到源神境（仙祖级）以上才能进入神域。神域是神灵的真正居所——在浩渺大陆"降临"的神灵都只是分身或投影。神域内部包含多个超级势力：雷罚神殿（神域中最强势力之一）、圣教、骨剑仙宗、棺材铺杀手组织等。神域的法则等级远超凡界和中世界——超神级天赋觉醒石等物品只在神域存在。神域的终极存在等级体系为：源神→源王→源皇→源帝→墟主。
- **重要性**: 最高世界 / 终极舞台 / 墟主级内容
- **连通地点**: 九大中世界 → 不祥之地 → 墟 → 不可知之地
- **关键事件**: 超神级天赋觉醒石获取 [Ch.276-278]；雷罚神殿/圣教势力介入 [Ch.1936-1940]；墟主级大战 [Ch.2191-2215]
- **主要NPC/怪物**: 雷罚神殿殿主、圣教教主、骨剑仙宗宗主、棺材铺杀手、各路源神/源帝
- **游戏机制标注**: 终极世界 / 源神级内容 / 高等世界法则 / 终极势力战 / 独立时间长河

- **重要性**: 本源法则源头 / 终极力量来源
- **连通地点**: 神域 → 墟 → 不可知之地
- **关键事件**: 本源法则直接感悟 [Ch.1991+]

- **游戏机制标注**: 本源法则系统 / 最终力量体系 / 创造者玩法

### 不可知之地 (The Unknowable Land)

- **连通地点**: 墟 → 不祥之地 → 神秘之地（传闻）
- **关键事件**: 墟主探查不可知之地 [Ch.2216+]
- **主要NPC/怪物**: 未知（设定中不存在明确的"居民"）
- **游戏机制标注**: 终极边界 / 未来扩展 / 无法穿越 / 宇宙级谜题

### 不祥之地 (Land of the Ominous / Buxiang Zhidi)
- **尺度**: 特殊区域（位于时间长河之外）

- **连通地点**: 凡殿（初始安置地）→ 随身携带（后期）
- **关键事件**: 宝塔炼制 [Ch.1976-1980]；365倍修炼 [Ch.1980+]
- **主要NPC/怪物**: 无（个人修炼场所）
